## 研究问题与贡献

EmbodiedWorld-200K 提出并研究“具身世界智能体”（EWA）：能在开放世界三维环境中感知、推理并执行通用动作的智能体。现有工作大多局限于单一场景的特定任务，向新环境迁移差。论文贡献三层：发布超过 20 万样本的大规模开放世界具身规划数据集 EmbodiedWorld-200K，样本带有多级标注（从底层相机运动轨迹到高层语义指令）并附统一评测划分与任务指标；提出两阶段训练方案——离线监督预训练加在视频世界模型内的交互式强化学习后训练；实证两阶段均带来明确收益，尤其在分布外场景。数据集、基线检查点与训练评测代码已公开。工作在腾讯混元实习期间完成，arXiv 编号 2610.25959。

## 方法与系统

数据管线：以公开游戏视频库 OGameData（覆盖 150 多个 3D 开放世界游戏、逾百万 gameplay 片段）为基础，先用相机运动轨迹做导航连贯分割，再做离散动作量化（W/A/S/D 加转向的动作词汇），最后用前沿视觉语言模型 Qwen3.5-27B（vLLM 张量并行部署）生成详细移动指令与高层目标导航描述两级指令，构成“初始观测-指令-动作序列”三元组。基线模型刻意保持极简：以 Qwen-VL 为骨干，任务指令与预测动作序列全部保留在 VLLM 原生文本 token 空间，不引入专门动作头，模型以单个 JSON 对象输出完整动作序列。阶段一在数据集训练划分上做交叉熵监督微调；阶段二把阶段一模型在视频世界模型（低成本环境代理）内滚动，VLM 依据当前场景自适应生成任务指令并锚定一个视觉问答奖励判断滚动是否完成指令，产生的偏好轨迹对交给 DPO 做后训练，全程无需额外人工标注。

## 实验设置与数据

评测在 EmbodiedWorld-200K 评测划分上进行，指标为任务完成度 TM、方向准确率 DirAcc、归一化动态时间规整 nDTW 与导航误差 NE。外部基线覆盖三族：映射到 W/A/S/D 动作空间的 VLN 模型（Uni-NaVid、StreamVLN）、游戏基础模型（NitroGen，无语言条件，作视觉反应下界）与零样本前沿 VLM（InternVL3-8B、Gemini-3.5）。自家骨干 Qwen3-VL-4B 做阶段一前后对比，LoRA 微调 2 个 epoch。分布外评测用图像生成模型合成初始观测的未见场景，考察阶段二收益。

## 结果、限制与结论

论文报告：阶段一微调使 Qwen3-VL-4B 全指标提升（TM 从 54.9 到 62.0、DirAcc 从 70.1 到 72.0、nDTW 从 67.1 到 83.6、NE 从 51.7 降到 35.6，即加 7.1、1.9、16.5 与减 16.1），并在 TM、nDTW、NE 上领先全部外部基线（相对最强对手加 9.2、20.2 与减 19.1），DirAcc 与 Gemini-3.5 基本持平（72.0 对 72.4），说明这些收益不能靠更强的通用模型直接获得；Uni-NaVid 为 TM 47.9、StreamVLN 为 47.2、NitroGen 为 45.6、InternVL3-8B 为 54.9。阶段二世界模型内 DPO 后训练在分布外场景带来清晰改善。局限：数据来自虚拟游戏环境，向物理机器人的迁移为当前材料未确认；动作空间为离散 W/A/S/D，不覆盖连续控制；评测依赖 VQA 奖励的质量。对组内的启示：20 万级开放世界导航规划语料加世界模型代理后训练，是训练通用导航规划智能体的一条低成本可复现路线。
