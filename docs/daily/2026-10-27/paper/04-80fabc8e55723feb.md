## 研究问题与贡献

人类在物理世界中推理时会灵活切换推理形式：装家具时读说明书、换视角、在心里旋转板材判断是否放得下。斯坦福大学（Stanford University，NeuroAI Lab）的 Ψ-0.6（Psi-0.6）追问：AI 系统能否学会"哪种表征对解决当前物理世界问题有用"？当前物理 AI 的能力碎片化在各自的专用模型里——视觉编码器负责感知、VLM 负责描述与回答、世界模型负责预测与想象，各自独立的架构与接口让它们难以在同一个推理过程中组合，也无法通过下游任务反馈联合优化。

Ψ-0.6 是一个统一的视觉-语言世界模型（8B 参数自回归 transformer），提出"思维流"（streams of thought）：把图像、文本、相机位姿、深度、光流与点轨迹全部序列化为共享 token 接口中可生成、可解释的表征；推理过程按需交错这些表征。论文围绕三重统一展开：能力统一（一个词表、一个 transformer 做感知/几何/语言/想象）、组合统一（一次预测的输出成为下一步的上下文，如由图像对估计相机位姿、再由位姿生成新视角）、优化统一（因为几何中间量与想象视角都是同一策略的动作，任务奖励可以联合优化"生成什么表征、何时生成、如何使用"）。模型构建在先前 PSI（Probabilistic Structure Integration，Ψ）框架之上并扩展到语言与灵活推理。

## 方法与系统

### 统一模型与任意到任意提示

图像、相机位姿、深度、光流、点轨迹与文本都作为 token 序列输入 8B 自回归 transformer（文本为下一 token 预测，图像为 rectified flow 生成），感知、描述、模拟因此成为同一模型的不同条件预测。提示只声明"给定什么、要求什么"：RGB0,C0→1→RGB1 是新视角合成，RGB0,RGB1→C0→1 是位姿估计，换成光流 F 即得运动条件生成与光流估计——任务是 token 的排列组合。继承自 PSI 的细粒度控制（逐 patch 的指针 token 声明模态与时空位置，支持目标化条件与场景编辑）与概率式预测（未指定内容保持多种合理续段的分布）使这一接口异常灵活。

### 训练配方：预训练-中训练-后训练

预训练在大规模视频（自然场景、人类活动、机器人交互）上做视觉世界建模与几何整合：纯 RGB 序列训练外观与运动，交错序列训练图像与深度/光流/相机结构之间的关系。中训练先用 FineWeb-Edu 与 DCLM 纯文本学语言，再以全局与时间索引的图文/视频描述对做视觉-语言对齐。后训练做指令调优：图文/视频问答、文本到视频的相机与物体运动控制、空间推理与反事实想象；预训练与中训练序列保留在混合中以保护广泛预测能力。

### 强化学习：自适应思维流

作为概念验证，RL 应用于视频问答：策略（与 VLM 同一模型）为每个问题发出一个"记号"（notation），声明使用哪条思维流，例如 d0,c2→3,f2→3 表示在第 0 帧请求深度、在 2→3 帧请求相机运动与光流。训练先用过滤式行为克隆（拒绝采样微调）学会发出记号，再用 on-policy GRPO（LoRA 参数）以组相对优势更新；奖励是"该记号相对纯 RGB 输入把正确答案损失降低了多少"。数据由 EgoDex、Something-Something v2、PE、OpenVid-1M 的描述转成问答对构成。

## 实验设置与数据

空间智能评测用 MindCube（多视角空间推理，问题涉及反事实相机运动、视角差达 90 度），对比 DeepSeek-VL2-Small、LLaVA-OneVision-7B、Qwen3-VL-8B 等开源通用 VLM 与 RoboBrain、Space-Qwen、Spatial-MLLM 等空间专家，另有零样本、组合提示（逆动力学选真实视角 / 新视角合成想象视角）、SFT（Tiny 测试集）三种设定。反事实想象用 FlowBench：FlowBench-Sim（仿真室内场景）与 FlowBench-Real（DROID、Bridge V2、Language-Table、RT-1、Berkeley UR5 五个机器人数据集加注反事实运动问题），指标含 8 类问答准确率与运动预测质量（rEPE、方向误差、ΔPSNR 等），基线含 FOFPred、InstructPix2Pix（含特权 mask 变体）、Qwen-Image-Edit 与 Grounding DINO+SAM2+Depth Pro 模块化专家（后者有特权输入）。世界建模解码用两项自研技术：pMotion（先一次前向算每 patch 运动概率、按概率从高到低逐 patch 生成光流）与文本增强 CFG（2× 图文 - 1× 纯图 logits）。RL 评测在训练分布留出集（相对提升均值 5.6%）与四个完全未见基准（EgoDex/HanDyVQA/TGIF-QA/STAR/EgoPlanBench2 中四个，均值相对提升 9.0%）上报告。

## 结果、限制与结论

论文报告：MindCube 零样本 49.7–51.3%（RGB-only/RGB-D/RGB-camera 三种配置），超过所列开源通用 VLM 与空间专家；逆动力学组合提示升到 57.7%；SFT 后 RGB-only 68.7%、RGB+camera 76.3%（Tiny 测试集），超过 SFT-only 的 Qwen2.5-VL 与 3DThinker，接近 3DThinker SFT+RL 的 76.0%，落后 GeoThinker 的 83.0%。FlowBench-Sim 世界建模上，Ψ-0.6（pMotion+CFG2.0）运动像素相对端点误差 0.454、方向误差 8.1°，在无特权输入的方法中最强（模块化专家 0.552/1.4° 但有 GT mask 与相机内参特权）；问答微调后八类均值 73.6（Qwen3-VL-8B 微调 77.9 为最高，Ψ-0.6 在 Closer/Count/Feasibility 等类别领先）。FlowBench-Real 仅用仿真训练即从 37.0 升到 48.9，超多数通用 VLM。RL 后策略在训练分布留出集均值相对提升 5.6%（EgoDex 最大），四个未见基准均值相对提升 9.0%，best-of-k 明显高于单次 rollout。

限制（作者自述）：训练数据、算力与研究工程规模都显著小于当代前沿多模态系统，结果建立的是概念与功能性结论而非性能上限；统一带来的能力间正负迁移未被分离量化，稀疏 MoE 是自然的下一步。开放问题：光流/点轨迹目前只是"代理动作"，通向机器人控制需要 IK 或动作 token 化。对组内而言，Ψ-0.6 展示了"几何表征作为可学习中间推理步骤"的完整配方，其 token 级世界模型接口对无人机导航中"何时依赖深度/光流/想象视角"的可学习调度有直接参考价值。
