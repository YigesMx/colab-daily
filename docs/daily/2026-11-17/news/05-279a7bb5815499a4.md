## 事件概述

2026 年 11 月 16 日，据量子位刊发的阿里巴巴授权发布稿报道，阿里巴巴正式发布全新一代基座大模型 Qwen4-Max，称其为"面向真实全场景的 AI 队友"。Qwen 官方博客同步上线《Qwen4-Max: Your New Teammate Has Arrived》（本次已抓取留存），确认该模型基于全新 Qwen4 架构，总参数 2.4 万亿、具备原生视觉能力、支持百万 token 上下文窗口。据授权发布稿，Qwen4-Max 现已上线千问 AI 平台提供 API 服务，Qwen4 系列中小尺寸模型据称将陆续开源发布。

## 已确认事实与证据

来自 Qwen 官方博客（qwen.ai，本次抓取留存原文）的事实：

- Qwen4-Max 基于新 Qwen4 架构：2.4 万亿参数骨干、原生视觉能力、一百万 token 上下文窗口；官方定位为覆盖工作、创作与发现的"全天候 AI 队友"，强调专业工具使用、长周期任务执行与交付质量，宣称可覆盖 3D 建模、游戏开发、精密制造、金融、法律、医疗和前沿科学发现等场景。
- 官方博客附有综合性能对比图（编程、工作与长周期任务），称 Qwen4-Max 相对上一代 Qwen3.8-Max 在评测的几乎所有能力项上有明显提升。

以下为阿里巴巴提供给量子位的授权发布稿口径（发布方宣称的评测与商用数据，本次未做独立复测）：

- 架构与效率：采用基于 Qwen 稀疏注意力（QSA）的全新 MoE 架构，2.4T 总参数仅激活 71B，每 token 激活参数较上代少 25%；在 Terminal-Bench 4.0 编程评测的 Xhigh 档位下，每次尝试平均 token 用量从 Qwen3.8-Max 的 289K 降至 151K（减少近 50%），评测得分从 38.9 提升至 48.5（提升近 25%），完成单任务平均费用降低 58%。
- 榜单成绩：CodeArena 全球前端编程盲测 Webdev 榜位列全球第 6，居 GPT6-Astra 与 Claude Fable5.1 之间，为发布稿所称"中国模型最好成绩"；Agents' Last Exam（ALE）取得 46.7 的最高分，较上代提升 18.8 分；Chartography 图表理解评测 54.2 分（提升 12.2 分）；JobBench 专业工作评测 68.5 分；法律专业评测 HLAB-Vals-1.1 得 21.3 分。
- 机制与应用：模型内实现"持续交付"（Live Delivery）机制，可先交付可用首版再逐版扩展；发布稿举例称其在汽车制造中将单个工件加工编程的人工用时从 475 分钟降至 24 分钟、在金融投研中调用 90 个 MCP 专业工具产出底稿与报告、在材料发现中连续 48 小时自主运行并经 4 轮闭环真实合成一种新型冷却液材料、在药物发现中完成 3239 项计算评估并优选候选分子。其构建的 Work360 全场景建模体系覆盖 721 个细分领域，系统评测得分 52.69，较上代提升超 10%。
- 商用信息：Qwen4-Max 已上线千问 AI 平台提供 API，缓存命中价格每百万 token 低至 0.5 元；用户可通过阿里 Token Plan 调用，或在千问办公、Qoder、千问 APP 等应用中体验；据称 Qwen4 系列中小尺寸模型将陆续开源发布。

## 影响与后续观察

- 竞争层面，Qwen4-Max 直接对位国际头部旗舰模型，发布方口径显示其在智能体、编程、图表理解与专业任务多项评测进入第一梯队；若中小尺寸模型按计划开源，将影响开源生态的格局与下游应用成本。
- 商用层面，缓存命中价格低至每百万 token 0.5 元、单任务平均费用较上代降约 58%，显示头部模型的价格战仍在继续，利好长上下文与智能体类应用的成本结构。
- 待验证事项：各项榜单成绩与行业应用案例均为发布方宣称，需以第三方榜单快照和独立复测为准；"中小尺寸模型将陆续开源"的时间表与许可条款当前材料未确认；原生视觉与百万上下文在真实长任务中的稳定性有待实际使用检验。官方博客页面元数据与授权发布稿所述发布日期口径存在差异，具体发布时刻以阿里官方后续披露为准。
