# OpenAI 宣布 GPT-5.6 Sol API 降价

## 事件概述

OpenAI 在 X 上宣布，未来三个月下调 GPT-5.6 Sol 的 API 与超额 credit 价格，降幅超过 20%。新智元报道，标准输入价格从每百万 token 5 美元降至 4 美元，输出价格从 30 美元降至 20 美元；订阅套餐内置额度不发生变化。

## 已确认事实与证据

OpenAI 官方 X 账号发布了两条降价公告，并称价格下调与 Sol 推理效率提升有关。新智元整理的定价信息显示，缓存输入从 0.5 美元降至 0.4 美元，缓存写入从 6.25 美元降至 5 美元；长上下文输入从 10 美元降至 8 美元，输出从 45 美元降至 30 美元。这些数值应以 OpenAI 定价页和公告口径为准，且限时政策存在到期调整可能。

报道还称，符合条件的 ChatGPT Work 和 Codex credits 正在陆续推送，而 Pro、Plus、Business 订阅价格与内置用量不变。关于“针对 Anthropic IPO 路演”或竞争策略的解读来自科技博主和记者评论，不是 OpenAI 官方说明。同日，Codex 负责人 Tibo 称 Codex 周活跃用户突破 2000 万，并表示已启动额度消耗过快的正式调查。

## 影响与后续观察

对高吞吐 API 和编码类工作负载而言，输出与缓存价格下降会直接降低边际成本，可能改变模型选型和代理式应用的成本结构。但它不能直接推出模型能力变化，也不能证明服务利润率或长期价格趋势。

后续应关注 OpenAI 定价页的有效期、credit 发放规则、服务质量和速率限制是否同步调整，以及 Anthropic、Google 和开源模型是否跟进调价。额度调查结果也需等待官方披露。
