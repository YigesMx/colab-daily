## 事件概述

Meta 官方宣布启动"Meta Enterprise Platform"——扎克伯格称之为公司业务的下一个主要支柱，旨在帮助企业用 AI 实现增长与转型；前 MongoDB CEO 兼总裁 Chirantan "CJ" Desai 加入 Meta 出任首席企业平台官，直接向扎克伯格汇报。

## 已确认事实与证据

- 官方新闻稿（about.fb.com，2026-09-28）：平台初期将把 Meta 的全栈技术——Muse 智能体、Meta Business Agent、Muse API、Muse Code 等——带给企业与开发者。
- CJ Desai 履历由官方确认：MongoDB CEO 兼总裁，此前任 Cloudflare 产品与工程负责人、ServiceNow 总裁兼 COO 近八年。
- 新闻稿全文与发布时间已存档核对；产品定价、首批客户、营收目标未披露。

## 影响与后续观察

- 这是 Meta 在广告与硬件之外首次把"企业 AI 平台"提升为独立业务支柱，直接对标微软/谷歌/亚马逊的企业智能体与 Copilot 生态；Muse 系 API 与 Code 的开放程度将决定开发者迁移意愿。
- 任命企业软件老将掌舵，显示 Meta 有意把消费级智能体（Muse 应用 9 月上线以来下载持续攀升）的能力转化为企业收入。
- 后续观察：Muse API 定价与 SLA、企业版与消费版 Muse 的数据边界、首批标杆客户与 CJ Desai 的组织动作。
