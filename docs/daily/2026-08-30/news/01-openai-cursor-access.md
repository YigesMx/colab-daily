# OpenAI 宣布断供 Cursor

## 事件概述

OpenAI 发布公告称，将终止与 Cursor 的合作关系。根据机器之心对官方声明的转载，Cursor 对 OpenAI 模型的直接访问将于 2026 年 11 月 12 日结束。公告将原因与 Cursor 被 SpaceX 收购后的控制权变化及 OpenAI 对相关方遵守服务条款的信心联系起来。

## 已确认事实与证据

OpenAI 称，难以确信 SpaceX 会在服务条款范围内使用其技术，并引用此前 X/xAI 相关合同与条款争议。公告还提及即将推出的模型 Astra 需要更高层级的合规问责。Cursor 联合创始人 Michael Truell 公开回应称遗憾，并表示 GPT 系列模型在 Cursor 用户中的占比约 5%。OpenAI 官方页面自动化访问返回 403，本文事实依据来自其 URL、机器之心全文 API 和媒体报道链，不补造官方未说明的条款细节。

## 影响与后续观察

该事件显示模型访问权正成为 AI 产业链竞争中的控制点，编程工具需要评估模型供应商集中度、迁移成本和条款变化。后续应观察 Cursor 的替代模型方案、用户流失情况、Anthropic 或 Google 是否维持访问，以及 Astra 发布前 OpenAI 对高风险分发渠道的治理规则。
