# GPT-5.6 Terra 登陆 Kiro 后重算编程账单

## 事件概述

OpenAI 与 AWS 公布了一项针对 Terminal-Bench 2.1 的联合测试：在 Kiro 开发智能体平台中，GPT-5.6 Terra 完成一个成功任务的成本较此前下降约 82%。这不是一次单纯的模型降价，而是模型、智能体框架和编排系统共同作用的结果。

## 已确认事实与证据

新智元报道称，GPT-5.6 Sol、Terra、Luna 已在 Kiro 的 IDE、CLI 和 Web 形态中运行。Terra 在 7 月 30 日降价 20%，但联合测试中的单任务成本下降约 82%。OpenAI 官方解释效率来自三层：发起和组织上下文的智能体框架、调度请求的编排系统，以及 GPU 上的模型。Kiro 的 spec-driven 流程还加入人工确认与自动测试。OpenAI 官方页面自动化访问返回 403，本文仅按已确认报告口径陈述。

## 影响与后续观察

该结果把模型评估从“每百万 token 单价”推进到“完成一个任务的总成本”。开发团队应同时测量准确率、失败重试、工具调用次数和上下文组织成本。后续需关注 Terminal-Bench 外的真实仓库任务、Kiro 与 Claude 模型的对比成本，以及隐藏推理链对可调试性和安全审计的影响。
