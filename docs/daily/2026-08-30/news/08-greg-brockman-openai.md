# OpenAI 还是 Altman 的公司吗？

## 事件概述

The Verge 与新智元报道称，Sam Altman 仍是 OpenAI CEO，但联合创始人 Greg Brockman 正在覆盖公司除研究之外的多条核心业务线，包括 ChatGPT 产品策略、Codex 统一智能体平台、企业销售、市场进入和算力业务。

## 已确认事实与证据

报道援引 API 与应用产品负责人 Thibault Sottiaux 的说法：“到最后所有人都向 Greg 汇报。”此前 OpenAI 多名高管离开，包括 CRO Denise Dresser、前 COO Brad Lightcap 和数据中心扩张负责人 Chris Malone。Brockman 在 CNBC 采访中称不同时期有不同领导班子，他和 Altman 是常量。此前庭审披露其 OpenAI 股份价值接近 300 亿美元，并与 Altman 存在历史财务纽带；这些内容来自公开报道和法庭记录。

## 影响与后续观察

若产品、企业销售和算力集中到 Brockman，OpenAI 的 IPO 叙事、成本控制和智能体产品节奏会更依赖双创始人结构。后续应关注正式组织架构、IPO 前高管留存、消费级产品发布，以及董事会如何约束创始人之间的财务与治理关联。
