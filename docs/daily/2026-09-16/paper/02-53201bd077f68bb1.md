## 研究问题与贡献

GeomVLA 针对当前视觉-语言-动作（VLA）模型的一个结构性错位：绝大多数 VLA 在 2D 图像上运行，而机器人操作本质上需要在度量 3D 空间中推理几何、接触与运动。已有 3D 操作策略与几何化 VLA 多聚焦静态 3D 场景表示，缺少"中间层未来推理应如何表示并与控制耦合"的答案。GeomVLA 的贡献是把感知、潜在场景运动预测与动作生成统一到共享的机器人中心 3D 坐标系：VLM 预训练特征经深度与相机标定提升为空间接地的 3D 场景 token，同时保留 VLM 学到的语义表示；再引入 3D 场景轨迹去噪器学习"场景点在 3D 中预期如何运动"的潜在表示，并通过几何感知注意力把运动 token 注入 3D 流匹配动作去噪器。这是团队关注的 VLA 架构与 3D 表征方向的核心工作。

## 方法与系统

系统分两级：第一级把预训练 VLM 的 2D 特征按深度与标定反投影为机器人中心 3D 场景 token，使语义与度量几何共存；第二级是任务条件化的 3D 场景轨迹去噪器，预测场景点的 3D 运动轨迹。关键设计在于去噪器不把预测轨迹当作开环计划执行，而是抽取中间运动 token，通过几何感知注意力条件化 3D 流式动作去噪器，让"场景将如何动"与"机械臂应如何动"在统一几何坐标系中耦合。消融显示单纯加入未来运动推理并不足够，主要收益来自场景表示、运动预测与动作生成之间的几何一致性。

## 实验设置与数据

评测覆盖 CALVIN（长时序语言条件操作基准）、LIBERO 与 RoboTwin2.0 仿真套件以及真实机器人操作实验，且不使用机器人动作预训练。与强基线（含主流 2D VLA 与 3D 化 VLA）对比，并做了表征、空间支持与架构的消融。

## 结果、限制与结论

论文报告在 CALVIN 上取得 SOTA，在 LIBERO 与 RoboTwin2.0 上保持竞争力，并在真实机器人操作上超过强基线；消融表明几何一致性（而非未来运动推理本身）是收益主要来源。局限：论文摘要与正文未报告逐任务失败分析与跨实验室部署条件；3D 提升依赖深度与标定质量，深度退化场景的行为需在全文复核；CALVIN SOTA 与真实场景收益之间的差距未在本摘要层量化。对团队的启示：与其在 2D VLA 上外挂几何，不如把几何一致性作为感知-预测-动作全链路的统一约束，这一设计对操作类具身系统具有直接参考价值。
