# DeepSeek Harness 插件生态在 GitHub 快速扩张

## 事件概述

量子位报道称，DeepSeek Harness 上线后，GitHub 上带 dsh-plugin 标签的公开仓库已超过 700 个，社区正在把这套开源 Agent Harness 扩展成浏览器、长期记忆、多智能体、开发面板甚至娱乐系统。

## 已确认事实与证据

报道列出的项目包括：可组建多 Agent 团队并显示任务状态的 dsh-agent-teams；把文件、终端、Git、后台任务和子 Agent 汇入侧边栏的 DSH Better Sidebar；支持工作区文件引用的 dsh-at-file；维护跨会话项目记忆的 dsh-memory-evolve；迁移 Claude Code 配置/会话的 bridge 工具；接入视觉模型的 ModLens；以及 Web UI、终端 UI、回滚、录制回放和 Obsidian 导出等扩展。DeepSeek Harness 的核心架构口号是 Everything is a Plugin。

## 影响与后续观察

生态扩张显示 Agent Harness 的接口化程度正在提高，长期记忆、本地工具和团队协作成为高频扩展点。但也需要审查插件权限、供应链安全、配置迁移风险和上下文膨胀；游戏、广告等非生产插件不应被解读为可靠性证明。
