# OpenAI 更换 CRO 并推出 Ultrafast 处理模式

## 事件概述

OpenAI 一方面调整销售组织负责人，另一方面为 GPT-5.6 Sol 推出名为 Ultrafast 的有限预览处理模式。

## 已确认事实与证据

报道称，Dali Rajic 接替任职九个月的 Denise Dresser 出任首席营收官；此前 Brad Lightcap 与 Fidji Simo 等高管职位也发生变化。OpenAI 公开称每周活跃用户超过 10 亿、企业客户超过 200 万，并已秘密向 SEC 提交潜在 IPO 前文件。Ultrafast 由 OpenAI 与 Cerebras 合作支撑，官方称最高可达标准处理 14 倍、750 output tokens/s，当前仅有限预览，将随容量扩展。

## 影响与后续观察

组织调整与高速推理同时出现，指向企业部署和响应延迟的优先级。后续需独立验证吞吐、长上下文稳定性、价格与配额，以及高速度是否影响拒答、工具调用和复杂任务质量。
