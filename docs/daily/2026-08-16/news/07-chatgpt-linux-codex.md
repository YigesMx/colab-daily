# ChatGPT 桌面应用进入 Linux，Codex 获得本地开发入口

## 事件概述

OpenAI 宣布 ChatGPT 桌面应用 Linux 版进入预览，ChatGPT、Work 与 Codex 被整合到同一桌面客户端中。

## 已确认事实与证据

报道援引 OpenAI 与 TechCrunch 称，Linux 预览面向全球开放，首批支持 Ubuntu 24.04/26.04 LTS、Debian 13、Fedora 43/44，提供 x64 与 ARM64 的 .deb/.rpm 安装包。应用内 ChatGPT 负责对话，Work 面向复杂多步任务，Codex 保留独立视图，工作流不变且历史记录与 ChatGPT 分开。Codex 负责人 Tibo 称功能基本与其他平台持平。

## 影响与后续观察

Linux 是开发者密集平台，本地文件、代码库与终端访问使 Codex 从浏览器助手更接近工程代理。后续需观察权限模型、沙箱隔离、秘密处理、发行版兼容性和代理实际执行闭环，而不是只看入口整合。
