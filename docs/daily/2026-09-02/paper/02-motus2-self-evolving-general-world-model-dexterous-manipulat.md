# Motus2: A Self-Evolving General World Model for Dexterous Manipulation

**一句话结论**：Motus2 把"提动作的策略、预测后果的仿真器、判断好坏的评估器"三种能力装进同一个共享权重的视频-动作世界模型，用 13 万小时自我中心人类数据打底、机器人域中训练对齐，再通过值引导的模型强化学习形成自我进化闭环——在不拆分网络的前提下，让灵巧操作策略能从自己的失败和次优交互中学习。

## 研究问题与贡献

论文的核心论点是：当前机器人基础模型几乎完全依赖精选的动作监督数据集做监督模仿，而动作对齐的机器人演示采集昂贵，且纯模仿既不知道一个动作好不好、也没有从自身结果改进策略的机制。作者由此提出"自进化"（self-evolving）的表述：模型应能预测并评估候选动作的后果，再把评估反馈用于策略改进。

在数据侧，论文认为自我中心人类视频是可规模化的灵巧交互先验来源：单目数据覆盖面广，同步双目数据额外提供隐式深度线索和更准的 3D 手部姿态。但迁移到机器人仍有两大困难——指尖滑移、抓取形成、松开等接触关键事件从纯视觉常常无法分辨；第一视角操作本身是部分可观测的（手遮挡物体、后果延迟出现）。

贡献有三：一是面向灵巧操作的通用世界模型，在共享参数的视频-动作模型中联合建模可执行动作块、动作条件未来观测和任务进度值，暴露策略/仿真器/评估器三个控制接口，并附带轻量触觉专家；二是自我中心数据规模化与机器人域迁移研究，建立了双目人类数据的 scaling 趋势；三是值引导的闭环自进化方法，Best-of-N 测试时规划与 DiffusionNFT 模型强化学习把值估计转化为策略更新。

## 方法与系统

**整体形式化**。任务被表述为语言条件灵巧操作的 POMDP，观测含视觉、本体感觉和可选触觉。因为手频繁遮挡物体和接触，当前观测不是充分的马尔可夫状态，策略以观测历史为条件。模型在共享骨干上按"动作优先"次序分解联合密度：策略（世界-动作模型 WAM）提出动作块 → 仿真器（动作条件世界模型 AC-WM）预测未来视频 → 评估器（价值模型 VM）估计任务进度。三个因子是同一模型的不同接口，而非分别训练的网络。

**阶段化信息流掩码**。预训练阶段用块内互相可见、无值查询的联合视频-动作训练；进入机器人域中训练后，引入只读值查询，每个窗口组织为干净的教师强制观测历史加上若干动作优先块（本体感觉、动作块、未来视频、值查询）。动作 token 不能读同块的未来视频或值 token；未来视频 token 可读当前动作；值查询可读两者但对其他 token 隐藏。跨块因果且有窗。作者称之为"块自回归"：块间自回归，块内低层动作由 flow matching 联合生成。骨干从一个视频扩散基础模型初始化，双目视频 latent 共享时间与垂直坐标但占据不同水平 RoPE 区段。

**轨迹依赖监督路由**。精心挑选的成功轨迹才激活动作监督；失败、次优和任务无关交互被路由到仿真模式（动作作为干净条件变量、只监督未来预测）或评估模式（动作视频全干净、只监督值读出），从而从坏轨迹学动力学和结果评价，而不教策略模仿坏行为。

**数据课程**。预训练阶段 1 用低分辨率单目自我中心数据 500K 步、高分辨率单目 340K 步；阶段 2 引入多分辨率同步双目数据 450K 步。中训练用机器人轨迹加人-机器人对齐数据（Wuji 人类手套采集数十小时，中训练总计超 100 小时）落地到机器人域。语料总量约 13 万小时：单目部分含 Egocentric-100K（100,500 小时）、Egocentric-10K（10,000）、EgoVerse（1,200）、EgoDex（800）；双目部分含 Ropedia（7,000）、EgoScale（6,000）、LightWheel（1,200）、JD-Group（2,000）、CyberOrigin（1,200）。标注统一为 134 维手部姿态表示。

**值引导闭环**。值学习沿用 VLAC 相对进度公式：成功轨迹段目标 $r\_t=\Delta t/(T-t)$，失败与任务无关段取负值，离散化为分类目标。规划时 Best-of-N：提出 N 个块、逐支仿真打分、执行最高值块、附加真实观测后重规划。策略优化用 DiffusionNFT：把分支值经标准化映射为最优性权重 $\hat r\_i\in[0,1]$，在 EMA 参考策略预测两侧构造隐式速度场 $v^{\pm}=(1\mp\beta)v\_{\mathrm{ref}}\pm\beta v\_\theta$，高值候选拉近、低值候选推远。整个更新异步执行（Ray 宏异步流水线，参考 AcceRL），只更新动作相关参数，视频骨干和评估器冻结。

**工作记忆与触觉专家**。上下文机制有三个变体：固定滑窗（KV 缓存有界、时间 RoPE 窗口相对重定基）、全局自回归（保留全部历史干净 latent，代价随 episode 增长）和混合工作记忆（锚帧+近窗全分辨率+持久记忆 token 表示中间历史）。触觉专家遵循 T-Rex：骨干把动作块从 $\sigma=1$ 去噪到固定 $\sigma\_c$ 一次，执行前每个子块用最新触觉窗完成 $\sigma\_c\to 0$ 的精修，同时用 flow matching 预测执行后的真实力窗作为监督。

## 实验设置与数据

主套件五个目标机器人任务：Place Ball、Put Phone（空间定位与放置）、Attach Eraser、Screw Bulb（精密对齐与持续接触）、Multi-Finger（多指协调抓取）。MBRL 研究用 Put Phone 和 Multi-Finger；记忆研究用独立的 Find Square 和 Press Button 探针（关键证据可能被遮挡或超出短窗）；触觉研究用 Pull Out the Paper Cup（Sharpa Wave 传感）和 Tear Paper（Wuji Hand 2）。真机每任务 20 个配置、仿真长程研究 25 个，每配置一次闭环 rollout，全部谓词满足才算成功，报告宏平均成功率。对照包括匹配 SFT 协议的 $\pi\_{0.5}$，以及仅初始化不同的 WAN-SFT（视频基础模型直接 SFT）、Pretrain-SFT（自我中心预训练后 SFT）与 Motus2（中训练后 SFT）。

## 结果、限制与结论

**主结果**（论文报告值）：WAN-SFT 平均 0%，Pretrain-SFT 51%，Motus2（Midtrain-SFT）84%——自我中心预训练贡献 51 点，机器人域中训练再加 33 点。Motus2 在 Place Ball 和 Attach Eraser 达 100%，Screw Bulb 90%，Multi-Finger 70%，Put Phone 60%。

**Scaling 律**（论文报告值）：在 2k/4k/10k/20k 小时嵌套双目子集上，held-out 人类动作预测最优误差拟合出 $\mathcal{L}^\*\_{\mathrm{val}}(D)\approx 0.101-0.005\ln D$ 的对数线性关系，说明单目自我中心数据的 scaling 趋势在双目观测下同样成立（测量范围内）。

**MBRL 与规划**（论文报告值）：基线 65.0%，+Planning 67.5%（+2.5），+MBRL 72.5%（+7.5），+MBRL+Planning 75.0%；规划在 MBRL 后仍有 2.5 点增益，两者近似可叠加。附录可视化显示成功 Screw Bulb 轨迹的预测进度从 0.34 升至约 0.81，失败轨迹在丢进度后下降。

**长程记忆**（论文报告值）：全局自回归在仿真 Find Square/Press Button 上为 84%/72%（宏平均 78%），混合记忆 64%/40%（52%）；真机 65%/50%（57.5%）对 30%/20%（25%），全局自回归全面占优。

**触觉**（论文报告值）：拉纸杯 65%→75%，撕纸 55%→70%，宏平均 60.0%→72.5%（+12.5 点）。

**限制**：论文自认首要限制是穿戴式触觉监督的跨本体可扩展性——触觉手套随手形变形产生材料应变和内部织物接触噪声，且现有灵巧手与人手不构型同构（小指常偏长、整体偏厚大），单一手套版型无法同时适配人手和机器人手，跨本体触觉学习的规模与可靠性受限。未来方向是穿戴式触觉材料与拟人灵巧手设计的进展，以及在更强视频基础模型上统一视觉、语言、动作、触觉与值信号。从 track 视角补充：主套件 84% 平均建立在"中训练+SFT"的强匹配协议下，跨本体泛化和真机长程任务覆盖有限；13 万小时为原始录制时长，论文明确指出过滤和切分后的有效训练数据更小；单目与双目数据混合配比对最终增益的分解（原文未报告）。
