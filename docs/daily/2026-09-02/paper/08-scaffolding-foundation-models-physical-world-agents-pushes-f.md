# Scaffolding Foundation Models into Physical-World Agents Pushes the Frontier of Long-Horizon Navigation

**一句话结论**：论文提出 NavMCP——一个把"会推理的 VLM"与"会走路的导航基础模型（NFM）"通过意图、观测、记忆三通道耦合成完整智能体的脚手架框架，两个模型都不重训练；在三个具身问答基准上刷新纪录（HM-EQA 76.7%），真机 Unitree Go2 上总体成功率 78.3%，并且任务时程越长优势越大（相对最强基线从 +10 点扩大到 +45 点）。

## 研究问题与贡献

长时程物理世界智能体需要两种当今基础模型各自只有一半的能力：VLM 能推断缺失信息、分解目标、修正高层计划，但把推理反复"落地"成导航动作时脆弱且低效；导航基础模型（NFM，如 Qwen-RobotNav、Uni-NaVid、NavFoM、SAME、ABot 系列等）能稳健地把语义目标变成闭环导航动作，却以有界 episode 为单位执行，不保留任务级推理状态。作者（上海交大、Qwen 团队、中关村学院、阿德莱德大学 AIML、北大、清华的合作团队）的核心论点是：问题不在于造更强的推理器或导航器，而在于把两类模型的互补能力组织成"持续的物理世界 agency"——NFM 延长 VLM 的动作时程，VLM 延长 NFM 的推理时程。EQA（具身问答）被选为检验场景：远处或初始不可见的证据迫使智能体形成搜索假设、访问多个区域、积累正负面观测并自行判断证据何时足够作答，这正是长时程 agency 的完整闭环。

论文识别出传统"把导航器包一层工具调用"的 episodic tool interface 存在三个结构性缺口：其一，**指令与意图错配**——路线级指令表达不了智能体的证据需求、搜索模式、预算和约束；其二，**中间观测丢失**——有用证据可能出现在 rollout 路径上任何位置（走廊里经过的物体、门缝里瞥见的房间），只返回终点状态和最终观测会把它们全部丢弃；其三，**跨调用无积累**——独立调用不保留已搜索区域、已排除假设、不确定发现和负面结果。论文的三项贡献：提出 NavMCP 智能体脚手架框架；设计以证据为中心的三通道接口（intent/observation/memory）；在三个仿真 EQA 基准和 Unitree Go2 真机上验证全面最优且优势随时程增长。

## 方法与系统

NavMCP 的形式化是一个 agent–executor 接口：给定问题 q，VLM 智能体在每个回合 t 读取上下文 C_t，要么给出答案，要么发出一次证据需求；执行器（实例化为 Qwen-RobotNav）把自然语言子目标、自我中心观测和导航状态映射为短时程 waypoint 轨迹，跑完一次 rollout 后返回轨迹级观测。论文强调执行器只看自我中心 RGB、位姿和在线探索地图，不假设对未见几何或物体位置有特权访问；由于智能体只依赖调用-返回 schema，任何支持相同意图模式和返回格式的执行器都可替换。

三通道设计各自堵住一个缺口。**意图通道**把证据需求翻译成一次语义导航调用，包含模式、自然语言子目标、步数预算和可选约束；提供两种与 NFM 训练评测机制对齐的模式：`navigate_to_object`（物体目标搜索，对应 Object Navigation）与 `navigate_by_instruction`（语言引导移动，对应 VLN），例如智能体可以请求"在厨房台面上找咖啡机"而不必微操底层控制。**观测通道**把完整 rollout 转成 agent 可用的证据：沿轨迹采样关键帧（而非仅终点帧，因为答案证据可能出现在执行器停下之前），再用基于 VLM 的轨迹摘要器产出"旅程证据"（journey artifact），覆盖子目标状态、路线上下文、观测到的物体、规划线索与不确定性；每个物体/房间提及都绑定来源关键帧和置信标签，摘要器被要求只报告视觉上确证的证据、显式标注不确定性，不把单视角的"没看到"当作确定性否定。**记忆通道**把轨迹证据变成跨调用持久的 EQA 上下文状态 C_t = (H_t, E_t, U_t)：紧凑交互历史 H_t、带来源的证据账本 E_t（正面观测、已搜索区域、不确定发现、负面证据、候选答案支撑）、未决目标 U_t；压缩策略保守——只有当显著信息已外化到账本并带来源引用后才压缩原始工具返回，使长上下文可以围绕"持久证据"而非原始 trace 缩减。

EQA 实例化中，智能体只有在答案被当前观测、旅程证据、审查过的关键帧或笔记本条目支撑时才可作答；正面答案要引用观测内容和位置，负面答案要有覆盖目标可能位置的已搜索区域记录。智能体可用的完整工具集包括视觉类（四向环视、证据仲裁、全景检测计数、细粒度物体检查、回看存档关键帧，以及检测/分割/深度估计）、导航类（两种意图模式、清执行器历史、最终视角对齐的局部动作）和上下文类（episode 内持久证据笔记本）；可选的跨 episode 检索库在全部报告实验中保持关闭，确保结果度量的是 episode 内证据管理而非跨环境记忆。

## 实验设置与数据

仿真评测在三个互补的具身问答基准上进行：HM-EQA（500 道多选题、267 个 HM3D 场景，单问题具身搜索）、MT-HM3D（多目标问题，需跨房间比较与多区域观测推理）、EXPRESS-Bench（2044 道自由形式问题，用 LLM Score 评答案质量、E_path 以参考充分路径长度与实际行程之比加权，同时奖励准确与高效探索）。基线覆盖 Explore-EQA、Memory-EQA、Graph-EQA、ToolEQA、FAST-EQA、Fine-EQA 等；因果分析用 Random Walk、Frontier Exploration 替换 NFM，并设无智能体/单轮/反应式变体。

主结果用 Qwen3.6-Plus 做智能体、Qwen-RobotNav-8B 做执行器；受控消融统一用开源 Qwen3.5-397B-A17B 智能体并对齐 episode、初始状态、预算和感知设置，所有因果结论只依赖这些受控对比。论文报告值为三次独立运行的均值±标准差，波动来源是托管 LLM API 的随机性而非显式随机种子；跨论文对比仅作背景参照、不进入配对显著性检验。效率指标用"归一化等效智能体步数"：以外层 VLM 调用次数 H 为主成本单位（direct-VLM-control 协议下一次决策至多移动 3 米），调用 NFM 的方法额外对每次 rollout 超出首个 3 米段的距离计费（n_eq = H + Σ max(0, ceil(L_k/3m) − 1)），再按场景预算归一化；非 NFM 基线保留原始步数口径。

真机实验在 Unitree Go2 上进行：低难度两任务需单房间取证（如背包上的 logo、饮水机的颜色），中难度两任务需跨房间搜索（如 B01 会议室的投屏码、最近的咖啡品牌），高难度两任务需超 20 米的开放场景探索（如 C3 电梯厅的电梯数、邮局是否营业）；每任务两个不同起始位姿、各重复五次，即每档 20 个、每方法共 60 个 episode，所有方法使用完全相同的起始位姿、查询和环境配置。成功由人工判定：只有在相应档位时限（低 5 分钟、中 10 分钟、高 15 分钟）内自主完成取证并给出有观测支撑的正确答案才算成功，超时或答错均计失败；Go2 本地避障全程开启，但该安全层不提供任何语义目标、答案证据或规划。

## 结果、限制与结论

**跨基准主结果**（论文报告值）：NavMCP 在 HM-EQA 上 76.7±0.1% 准确率（FAST-EQA 69.2），归一化步数 0.15±0.01 为所有报告方法最低；MT-HM3D 上 54.4±1.5%（FAST-EQA 50.5），步数 0.19±0.01；EXPRESS-Bench 上 LLM Score 79.27±0.44、E_path 33.96±0.75（FAST-EQA 分别 68.7、29.25）。在智能体、episode、初始状态、预算全对齐的匹配对比中（同 Qwen3.5 智能体；ToolEQA 复现版获得与 NavMCP 相同的感知与验证工具集，但保留其原有 episodic 导航工具），Explore-EQA 57.6±0.7%、ToolEQA 60.8±0.9%、FAST-EQA 63.5±1.4%，NavMCP+Qwen-RobotNav-8B 达 74.0±0.3%，领先 16.4/13.2/10.5 个点。

**互补性消融**（论文报告值）：固定 Qwen-RobotNav-8B 逐级增强上层，准确率从无智能体 38.2% → 单轮全景 58.4% → 固定探索循环反应式 62.0% → 完整 Qwen3.5 智能体 74.0% → Qwen3.6-Plus 76.7%；固定智能体逐级增强执行器，Random Walk 60.9±3.1% → Frontier 65.3±0.2% → StreamVLN 69.3±0.4% → Qwen-RobotNav-4B 73.3±0.3% → 8B 74.0±0.3%。两侧各自加强都显著涨分，说明 VLM 智能体与 NFM 执行器互补而非可替代。

**协议消融**（论文报告值，均固定智能体与执行器）：完整系统 74.0%；换成 episodic 接口跌到 59.1%（−14.9 点，即接口差距的直接度量）；限制单导航模式 72.0%（−2.0）；观测只回终点 68.1%（−5.9）；去掉旅程分析 69.6%（−4.4）；稀疏关键帧 71.2%（−2.8）；去掉 EQA 上下文状态 69.4%（−4.6）；去掉上下文压缩 −0.9、去掉细粒度物体检查 −0.6。观测与记忆通道贡献了两个最大的组件级效应。附录的"找小黑沙发"episode 展示了证据驱动探索：智能体搜索五个房间、记录负面证据避免重复、收窄假设后切换到物体目标请求，到目标距离曲线先远离再收敛。

**真机结果**（论文报告值）：Unitree Go2 上 NavMCP+Qwen-RobotNav 总体成功率 78.3%（单房间 90% / 跨房间 85% / 超 20 米 60%），frontier 变体 48.3%（70/60/15），反应式变体 38.3%（80/35/0）；相对最强基线的优势在三个时程档依次为 +10、+25、+45 个点——任务时程越长，持续脚手架的价值越大。附录还给出一个超 50 米轨迹的定性案例：智能体把开放性请求分解为子目标、沿地标导航到 Cotti Coffee、从视觉证据核实绿色遮阳伞后作答。

**限制与结论**（论文自述）：NavMCP 依赖大 VLM、推理偏慢，小模型或蒸馏可能降低成本；跨视角重复观测会损害计数类任务。未来方向是用智能体指挥 NFM 探索物理环境、高效采集训练空间智能的具身数据。从 track 视角补充：真机每方法 60 个 episode 相对有限，且论文明确真机只验证 sim-to-real 迁移、不重复全部消融；跨论文主表对比受 API 与代码可用性限制只能作背景参照（论文自己声明全部因果结论依赖匹配条件消融）；论文未展开辅助感知工具的失败模式分析。
