# Zeva: In-Context Causal Learning for Generalizable Embodied Manipulation

**一句话结论**：论文提出 Zeva——第一个让机器人策略在**权重完全冻结**的前提下，从自己执行动作造成的物理后果（而非人类演示或梯度更新）中做"上下文因果学习"的框架；仿真基准 RoboCasa365-Atomic5 平均成功率 76.8% 超过全部对比前沿模型，真实化学实验室基准上各难度级均最优，且重复尝试越多成功率越高（Atomic5 池化累计成功率从 26% 升到 73%），实现了部署期自进化。

## 研究问题与贡献

具身基础模型（VLA 与 WAM）在预训练后部署到物理世界时仍然脆弱：部署环境必然出现预训练未见过的物体几何、接触动力学、视觉变化和本体特定执行误差，这些因素与高维连续状态动作耦合，使相似动作产生截然不同的结果——单靠预训练难以覆盖物理交互的多样性。作者的立场是：机器人应当在执行过程中即时从自身物理交互经验中学习"动作与状态变化之间的因果关系"，并用它指导后续动作。机构署名为清华大学智能产业研究院（AIR）与 Z-Trans AI（域变换），论文通讯作者为 Xin Ding、Hao Wu 与项目负责人 Ting Cao；量子位报道补充域变换由刘云新、曹婷两位教授发起。

论文定位的空白夹在两类已有方法之间：test-time training（RoboTTT、WAM-TTT）用梯度把部署历史压进快权重或记忆模块，但每次交互的"动作-状态变化"结构保持隐式，且优化周期远长于两次连续尝试之间的时间窗口；最近的 in-context 机器人学习（GEN-1.5、Skild S1）保持权重冻结、从少量演示推断新任务，但主要解决任务泛化而非即时交互学习。Zeva 的三项贡献：把真实部署中的具身动作泛化形式化为 In-Context Causal Learning（ICCL，冻结权重 ∇θπ=0）；提出由因果交互提取、双时标因果记忆、上下文策略注入组成的无梯度自进化框架；在仿真与真机操作上验证尝试越多成功率越高、并强于对比的前沿具身策略模型。

## 方法与系统

**ICCL 形式化**。在每个时刻 τ，把动作 u_τ 视为一次与环境交互，其效果是视觉状态变化 Δs_τ = s_{τ+k} − s_τ；因果交换单元定义为 ξ_τ = φ(s_τ, u_τ, Δs_τ)。因果上下文 M 是这些单元的组织化集合，策略以 π(a_τ | o_τ, g, M) 条件化生成动作——作者解释为对冻结策略做"隐式系统辨识"：从过去交互信号推断物体质量、关节约束等潜环境属性，从而泛化到未见过的物理构型。训练目标 L_ICCL 最小化预测因果效应与真实效应之差。

**第一部分：因果交互提取（CTE）**。CTE 用门控递归把视觉潜变量 s_τ、动作编码 u_τ 和观测效果 d_τ 融合为因果交互状态 B_τ = GRU(B_{τ−1}, [s_τ; u_τ; d_τ])（初始状态由任务指令和初始观测编码），再投影为两个持久分量：代表任务进度的**阶段令牌** p_τ 与刻画交互动力学的**因果交互信号** e_τ，二者构成记忆单元 ξ_τ = (p_τ, e_τ)。CTE 的多目标训练包括：因果效果预测（解码 e_τ 加候选动作预测视觉状态变化，把信号锚定在物理效果上）、任务身份聚类（监督对比损失，同任务 episode 聚类）和阶段推进（保证 p_τ 捕捉任务执行的单调推进）。

**第二部分：双时标因果记忆**。**Brief Interaction Trace（BIT）**是最近 K 个交互信号的滑动窗口，提供当前尝试内的即时局部上下文，每次尝试结束清零；**Persistent Interaction Memory（PIM）**在同一 episode 的跨尝试间积累 (p, e) 单元，episode 开始前清空。PIM 用相似度合并控制规模：新单元与既有最相似条目的得分 S_merge = β_p·sim(p, p) + β_e·sim(e, e) 超过阈值时合并，否则追加——只有同时匹配任务进度和物理动力学的经验才会被合并。

**第三部分：上下文策略注入**。决策时用当前阶段令牌 p_τ 从 PIM 检索相位最匹配的 top-K 交互证据 R_τ，记忆上下文编码器构造因果提示 M_τ = F_mem([g; p_τ; P_proj(H_brief); P_proj(R_τ)])，注入冻结策略骨干。骨干采用 Cosmos3 的 rectified-flow 动作生成头：自回归路径编码多模态上下文，扩散路径生成连续动作，因果提示作用于扩散路径的全注意力块。部署全程所有参数冻结，只有交互记忆在线更新；算法在每次尝试内逐步执行"检索-构提示-生成动作-步进-更新 BIT/PIM"，成功即终止。

## 实验设置与数据

评测区分两个单元：episode（由场景布局、物体位姿、机器人初始构型定义的任务实例）与 attempt（从初始观测到终止/成功的一次连续执行）；randomized episode 每次独立采样初始化，fixed episode 固定初始化跨重复尝试（每次尝试前恢复同一初态），BIT 每次尝试清零、PIM 跨尝试保留、episode 间全部清空，所有对比方法获得相同最大重试预算。

仿真用 RoboCasa365-Atomic5（Atomic5）：五个代表性厨房任务（烧水壶开机、关烤箱门、开微波炉、咖啡杯摆位、打开立式搅拌机头），每任务 50 个随机 episode。真机用自建的 ChemLab-Evo：ARX 机械臂、80×60cm 工作台，七个化学实验任务分三级——一级原子操作（拿试管、放烧杯、倒水）、二级短序列（滴定、配盐水）、三级复杂长程（天平称量、萃取），复杂度递增使成功标准从单一原语完成变为按规定顺序完成全部阶段；主基准与每个消融配置每任务 20 个随机 episode。指标为任务成功率 SR 与宏平均，长程任务另报归一化过程分（按顺序完成的最长阶段前缀占比），自进化用累计成功率 CSR@K。基线（本地复现、同训练数据同接口）：Atomic5 上对比 LingBot-VA、Xiaomi-Robotics-1、τ0-WM、Fast-WAM、Cosmos3-Nano；ChemLab-Evo 额外加入 π0.5。

## 结果、限制与结论

**仿真主结果**（论文报告值）：Atomic5 上 Zeva 平均 SR 76.8%（78/86/84/44/92），超第二名 Fast-WAM（72.4）4.4 个百分点；Fast-WAM 在烧水壶（88）、咖啡杯（54）、搅拌机头（94）三个任务上仍单项领先，Cosmos3-Nano 64.8、LingBot-VA 55.2、Xiaomi-Robotics-1 31.2、τ0-WM 29.0。**真机主结果**（论文报告值）：ChemLab-Evo 三个难度级 Zeva 均最优——原子级平均 83.3%（拿试管 100%、放烧杯 70%、倒水 80%）超最强基线 π0.5（73.3%）6.6 个点；短序列级平均 70.0%（滴定 70%、配盐水 70%）超 LingBot-VA（65.0%）5 个点；复杂级平均 7.5%（天平称量 5%、萃取 10%）——所有基线复杂级几乎全军覆没（除 LingBot-VA 2.5% 外均为 0）。长程过程分上天平称量 47.50、萃取 67.14、平均 57.32，超各任务最强基线 8.75 与 8.57 点，平均超最强基线 12.59 点。

**消融**（论文报告值，五个真机任务 SR）：完整模型 100/70/80/70/70；去掉 BIT（仅 PIM）降至 80/50/50/40/55；去掉 PIM（仅 BIT）降至 85/60/70/60/50；两者都去掉 65/40/45/25/35。去掉 PIM 损失 10–20 个点，去掉 BIT 损失更大（15–30 个点，倒水和滴定上跌幅最大），支持跨尝试记忆与尝试内上下文的互补作用。

**部署后自进化**（论文报告值，与主基准分开选取的固定 episode）：Atomic5 池化 CSR 沿四个演化里程碑从 26%（Evolve 1）→ 45% → 70% → 73%（Evolve 4）；ChemLab-Evo 三个原子任务同样单调上升：拿试管 65%→100%、放烧杯 25%→70%、倒水 30%→80%。**一次性人类演示热身**：人类物理引导 ARX 臂完成一次天平称量，CTE 把该轨迹编码进 PIM（策略仍冻结），Zeva 即可复现抓取-转移-放置流程而基线在接近砝码后偏航；量化上热身使放烧杯最多 +20 个点、倒水 +15 个点，拿试管早期里程碑改善后两条件均收敛到 100%。

**跨任务泛化**（论文报告值）：用最近跨任务信号替换任务本地信号，拿试管 SR 100%→95%、倒水维持 80%；换成随机跨任务信号则跌到 55%/45%——最近检索比随机替换高 40/35 个点。检索分析显示因果信号按"功能等效的物理效果"对齐：倒水动作检索到配盐水和萃取中的容器倾斜、夹爪闭合检索到不同器皿的接触建立、抬升检索到跨物体类别的抓后上升。

**限制与结论**（论文自述）：Zeva 只从为任务执行而生成的尝试中学习因果，不会主动为降低不确定性去收集交互；未来工作是因果驱动的探索式采样。从 track 视角补充：复杂级 SR 绝对值仍很低（7.5%），说明该层级远未解决；"演化里程碑 Evolve 1–4 是选定阶段而非连续尝试序号"的表述略含糊（原文未报告每个里程碑对应的精确尝试次数）；演示热身的量化只覆盖三个原子任务；量子位报道强调的"具身 GPT 时刻"属机构解读，非论文结论。
