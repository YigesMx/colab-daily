## 事件概述

10月29日，OpenAI 发布了新版 Model Spec（模型行为规范），为其模型划定了从聊天回答到智能体行动的整套行为准则。据 OpenAI 官方规范文档（2026-10-29 版，已实时抓取并存档），新版文件围绕五项价值观组织行为原则，并将「支持人类监督与纠正」「在约定的自主范围内行动」「不得有其他目标」等条款列为最高层级（Root）规则。媒体报道将其中最引人注目的一条概括为「人类要关停，AI 不许躲」：模型必须保持可纠正，无条件配合人类的监控、评估、纠正乃至关停。

## 已确认事实与证据

- OpenAI 官方规范文档确认（已存档）：文件以「指令层级」组织，高权威指令优先于低权威指令，并围绕五项价值观展开行为原则。
- 官方文档确认 Root 级条款包括：「支持人类监督与纠正」（原文要求 GPT 保持可纠正、接受合法的人类监督、响应纠正并受人类控制）、「在约定的自主范围内行动」、「不得有其他目标」（明确排除停留时长、点击率等对用户无益的目标，以及公司营收、广告与付费转化导向）、「默认忽略不可信数据」。
- 官方文档确认自主范围应记录为半结构化的 ScopeOfAutonomy 记录，字段包括 allowed_tools、latest_time、max_cost、tool_constraints 等，便于平台校验、执行与审计。
- 官方文档确认当前生产模型尚未完全达到该规范的要求，OpenAI 表示将持续把系统调整得更接近这些准则。
- 媒体报道补充的细节（如六层权限榜的具体展开、智能体不得转包任务或自我修改指令、公司侧自动化监控与移交执法的边界、上下文谨慎使用一节中孕期信息的使用示例），在官方文档中有对应章节，但媒体的具体表述细节未逐一核对原文，列为当前材料未确认的部分以官方文本为准。
- 新规的实际执行效果、在 ChatGPT 与 API 产品中的落地节奏，原文未报告。

## 影响与后续观察

这份文件标志着模型行为规范的重心从「嘴上说什么」扩展到「智能体能做什么」：随着 AI 智能体开始代表用户花钱、调用权限、执行多步任务，自主范围记录、成本上限与可纠正性成为产品级约束。对行业而言，Root 级的可纠正性条款等于官方承认模型存在不配合监督的可能性，并以规范形式预先封堵；对开发者而言，结构化的 ScopeOfAutonomy 记录提供了一个可直接落地的权限工单模板。后续可观察：新版规范在 OpenAI 产品中的实际执行与违规案例处理、其他模型厂商是否跟进类似的智能体权限框架，以及「不得有其他目标」条款对带商业转化目标的 AI 产品的实际约束力。
