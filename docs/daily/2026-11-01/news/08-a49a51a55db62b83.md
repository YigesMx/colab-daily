## 事件概述

10月31日，Anthropic 调整 Claude 个人订阅计划：原 Max 5x 与 Max 20x 分别更名为 Max 与 Ultra，价格维持每月100美元与200美元不变；其中200美元档 Ultra 计划对已完成验证的账户取消5小时会话使用限制，用户可在每周额度内连续使用。量子位报道称，多数现有 Ultra 订阅用户已陆续解除限制，新用户需等待账号自动验证。官方帮助中心文档已同步更新并确认了上述变化。

## 已确认事实与证据

- Claude 官方帮助中心《What is the Ultra plan?》（已实时抓取并存档，显示「今日更新」）确认：Max 20x 计划现更名为 Ultra，现有订阅者自动迁移且价格不变；Ultra 每月200美元（网页订阅价），每周用量为 Pro 计划的10倍；已验证账户没有5小时限制，未验证账户暂适用临时限制。
- 官方文档确认验证机制：系统依据账号与支付历史等信息自动验证，无需用户操作；在 Settings 的 Usage 页面若不再显示当前会话进度条，即代表账户已验证；Ultra 的每周用量限制适用于所有模型，另有针对 Fable 的单独每周额度。
- 官方文档还列明 Ultra 权益：优先体验新模型与新产品、支持 Claude Code 终端编码工作流、支持报告/表格/演示文稿等长程后台任务，以及每月附赠 Claude API 额度。
- 量子位报道（已实时抓取全文并存档）补充：原有订阅用户无需手动切换，系统自动迁移计划名称；Max 5x 用户此次主要为名称简化，价格与使用规则无实质变化。
- 报道引述 Anthropic 负责 Claude 订阅产品的 Mike Overell 解释改名缘由：Max 20x 中的「20倍」原指单个5小时窗口内的额度为 Pro 的20倍，而后引入的每周额度只有 Pro 的10倍，命名易引起误解，他为此前的沟通问题道歉；该帖文内容与《华尔街日报》今年6月报道的相关消费者诉讼均为媒体报道，当前材料未直接核对原始帖文与诉讼文书。
- 报道提到的背景（前一天 OpenAI 给 Pro 用户额度翻倍）为另一公司动态，与本次调整的因果关系属媒体联想，原文未报告。

## 影响与后续观察

取消5小时窗口让高价档用户首次可以按自己的节奏连续工作，对依赖 Claude 处理长程任务的重度用户是实质改善；而「20倍窗口额度对10倍周额度」的旧账澄清，也回应了此前关于高价订阅额度宣传的争议。更名之后，Max/Ultra/Pro 的额度规则更加透明，但每周总量上限与 Fable 单独额度的存在意味着「不限量」并非无限使用。后续可观察：验证机制的覆盖速度与新账户等待时长、Ultra 档位未来是否引入更高额度选项、竞品（如 OpenAI）在订阅额度上的进一步调整，以及额度透明化能否减少相关消费者争议。
