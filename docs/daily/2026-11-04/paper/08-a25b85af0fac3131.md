## 研究问题与贡献

世界-动作模型（WAM）通常用未来视频作为预测的未来，但 RGB 未来把任务相关的状态变化与纹理、光照、背景纠缠，导致策略过拟合外观；逐帧的深度/点图又缺乏时间对应，不编码“接近—操作—释放”过程中的本体-物体运动。华南理工、清华、快手 KlingAI Research 等机构（一作 Lingwei Dang、Yan Zhou 等）提出的 Gnomon4D 是一个把显式 4D 几何运动带入动作生成的世界-动作模型：它在 Mixture-of-Transformers 架构上联合生成未来视频、机器人动作与视频对齐的 GeoDelta（每个前景像素上同一物理点的图像平面位移与深度变化 Δu、Δv、Δd），并用预测的相对运动告诉动作专家“在哪里、在何时”聚焦——Interaction-Salient Attention（InSAttn）依据本体-物体相对运动突出交互区域，Transition-Anchored Aggregation（TransAgg）突出抓取、释放等关系变化帧。与既有把 4D 线索仅作训练正则（4D-WAM、GEM-4D）或经独立轨迹-动作接口（TraceGen、μ0）的方案不同，GeoDelta 描述表面运动而非关节或控制信号，人与机器人共享同一“准动作”空间，因此可以在无动作标签的 EgoManip-5000H 人类第一视角视频上预训练，再用 Robot-30H 机器人数据中训。

## 方法与系统

模型在 Wan2.2-TI2V-5B 视频生成器上扩展：Video 专家保持 30 层、宽度 3072，GeoDelta 与 Action 专家由其宽度插值得到（宽度 1024），三者在每层通过联合注意力交换信息、经交叉注意力读取语言指令（UMT5 编码）与本体状态。每个重规划步在 H=32 个控制步上预测动作块、按步长 4 采样 N=8 帧未来视频与 GeoDelta；GeoDelta 在源像素处记录同一 3D 点移动前后在单相机下的投影差与深度差，对相机运动不变，前景限定为本体与被操作物体；为复用冻结的视频 VAE，三分量经软阈值、固定尺度归一化与 μ=31 的符号 μ-law 压缩映射到 RGB 三通道，把更多量化级留给接触附近的微小运动。三模态按流匹配联合去噪，噪声水平按模态独立；GeoDelta 与 Action 共享去噪时钟并先于视频完成，使动作在视频精化前就绪，未来 token 只关注自身时刻之前的动作且干净 token 不关注噪声 token。动作读出用每模态 K=32 个可学习查询：GeoDelta 特征上的轻量头预测 token 属于本体或物体，把 token 运动与邻近本体平均运动的偏差归一化为相对运动场 c，InSAttn 用任务条件的 φ(c) 加运动先验得到显著性并偏置注意力（决定“在哪读”），TransAgg 按显著 token 上 c 的变化量聚合帧（决定“何时读”），交互 token 残差注入稠密动作读出。训练分三步：Video 与 GeoDelta 专家先在 EgoManip-5000H 上无动作标签预训练；该数据从工业级专有视频库经真实场景过滤（剔除动画/CG/AI 生成与变速剪辑，保留 17.2M 片段、37132 小时）、自我中心操作分类器（Kimi-K2.6 标注 + VGGT-Ω 相机轨迹 + Qwen3-VL 嵌入，筛得 342 万片段、7575 小时）与 WiLoR 检测加 MANO 逆运动学的手部重建（手部可见 51% 以上的 145 万片段、2859 小时同时监督两个专家）构成；再加 Action 专家在 IG-10K 来源的 Robot-30H 上中训并在下游后训。仿真与真机的 GeoDelta 标签分别来自渲染深度/对应关系与实测 RGB-D 深度、SAM 3.1 掩码和 RAFT 光流。

## 实验设置与数据

仿真在三个基准上各训一个多任务策略并报成功率：RoboTwin 2.0（50 个双臂任务、干净与域随机化两设置）、VLABench（10 个任务族、ID/未见类别/常识变化/语义指令/未见纹理五赛道）、RoboDojo（42 个双臂任务，按泛化、精度、长程、记忆、开放指令五维宏平均 SR 与部分得分）。基线按未来表示分组：RGB 未来的 Fast-WAM、LingBot-VA 2.0、OpenWAM-Alpha 等；三维几何/流的 X-WAM、WAM4D、FlowWAM、MECo-WAM；结构化读出的 ARPS、STARRY；VLA 侧有 π0.5、Galaxea G-0.5、Qwen-RobotManip 等。真机用 UR5e 加并行夹爪、固定第三人称 RGB-D 相机与腕部相机，五个任务（抽屉收纳、装箱、积木堆叠、颜色分拣、充电器插入）各采 50 条示教（共 250 条）训练所有方法；每任务 80 次试验（共 400 次），一半为训练条件 ID，一半为四种视觉偏移（未见光照、桌布、物体外观、干扰物）各 10 次的 OOD，与 Fast-WAM、X-WAM、FlowWAM 对比。消融在 10 个交互密集的 RoboTwin 2.0 任务上比较未来表示（RGB/深度/2D 光流/GeoDelta）、读出结构（通用查询/仅 InSAttn/InSAttn+TransAgg）与预训练课程。

## 结果、限制与结论

Gnomon4D 在三个仿真基准上均取得最佳平均：RoboTwin 2.0 上干净/随机化 94.56%/94.10%（平均 94.33%，超过最强几何/流基线 MECo-WAM 1.71 点）；VLABench 上对 OpenWAM-Alpha 的领先从 ID 的 0.6 点扩大到未见纹理的 7.4 点；RoboDojo 上整体 SR 23.86% 对 OpenWAM-Alpha 的 11.92%（翻倍），精度维度 28.24% 对至多 20.42%。真机上五个任务全部第一，ID 82.5%、OOD 78.0%：ID 领先最强基线（FlowWAM 75.5%）7.0 点，OOD 差距扩大到 16.0 点——GeoDelta 同时编码图像平面位移与深度变化使其仅损失 4.5 点，而 FlowWAM 损失 14.5 点；按偏移类型，未见物体外观与干扰物下优势最大（各 18.0 点），按任务，颜色分拣与充电器插入最大（22.5 与 17.5 点）。消融显示：未来表示上 RGB+GeoDelta（全前景）83.8/82.9 优于 RGB 81.0/79.0、RGB+深度、RGB+2D 光流与只用本体的 GeoDelta；读出上通用查询 83.6、仅 InSAttn 85.3、InSAttn+TransAgg 86.2（平均）；预训练课程上仅 Wan2.2-5B 初始化为 86.6/85.7（干净/随机化），加 EgoManip-5000H 升至 88.4，再加 Robot-30H 达 91.3（干净设置）。探测实验还发现现有 WAM 的动作注意力偏向本体整体而非交互区域，这是引入关系引导读出的动机。局限方面，论文承认 GeoDelta 依赖实测相机深度（人类视频用单目深度估计）加掩码与光流，细薄、反光与透明表面的误差主要扰动 Δd；作者提出用智能体递归自我改进（把真实场景重建为仿真世界以获得精确 GeoDelta，或用具身反馈迭代改进估计流水线）作为未来方向。整体结论是：预测未来编码了什么（而非多逼真）决定其对控制的价值，显式 4D 几何运动使动作获得外观不变且深度感知的监督。
