# 闭源RSI的严父：18个Agent自主科研，Kimi K3靠Harness逼近Opus 5

## 事件概述

Prime Intellect 发布研究，比较 18 个前沿模型在离线 sandbox 中自主优化 nanoGPT 训练 recipe 的能力。结果显示，开源权重模型 Kimi K3 搭配 Prime Agent Harness 取得 2930 步结果，超过 GPT-5.6 Sol 的 3042 步，并接近 Opus 5 的 2920 步。

## 已确认事实与证据

- 任务要求模型把 1.24 亿参数 GPT 的验证 loss 降到 3.28 以下，基线为 3290 步，人类公开最好纪录为 2600 步，步数越少越好。
- 共执行 153 次全自主实验，单次最长超过 8 天；每次使用 8 张 H200，过程中断网以防直接检索答案。
- 报道称，没有任何一次实验提出真正全新方法，主要收益来自持续试错、噪声处理、工具构建和 infra 迭代。

## 影响与后续观察

结果支持“科研能力不只取决于最强单一模型”，多智能体 harness 和持续 IPython 工作流可能成为 AI4AI 的关键基础设施。该评测仍限于 nanoGPT 优化器速通，不能直接外推到开放科学发现。
