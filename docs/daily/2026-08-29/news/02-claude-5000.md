# Anthropic 发布 Model Hardware Standard 研究预览

## 事件概述

Anthropic 于 2026 年 8 月 27 日宣布向首批科研机构和先进制造伙伴开放 Model Hardware Standard（MHS）研究预览。MHS 是一套让 AI Agent 安全操作物理设备的共享规范，目标是为显微镜、液体处理器、机械臂、相机和实验仪器提供统一的发现、读取、写入与安全边界描述。

## 已确认事实与证据

官方页面确认，MHS 起源于 Anthropic 与 HHMI Janelia Research Campus 的合作，当前面向科学、机器人、电子和制造伙伴开放，未来计划开源。MHS 可接入任何具有可编程接口的设备，并通过标准化驱动把设备能力转换为 read/write 等原语；Agent 可经 MCP、CLI 或 API 控制设备，读取运行数据、编排多设备流程并在条件下调整参数。官方称传统实验室集成常需数周甚至数月，MHS 可把集成工作压缩到数小时或数分钟。

官方页还列出 Genentech、University of Washington、Carnegie Mellon University 和 HHMI Janelia 的早期案例，覆盖蛋白 assay 自动化、远程仪器监控、机械臂与液体处理器协同、剂量响应实验和显微镜系统编排。量子位报道称 Anthropic 展示了 Claude 通过 MHS 控制 LeRobot 生态 SO-ARM101 机械臂；该具体展示细节以媒体报道为准。

## 影响与后续观察

MHS 把 Anthropic 的 Agent 能力从软件工具扩展到可编程物理设备，可能降低实验室和产线自动化门槛，也把提示注入、误操作、物理碰撞和设备安全边界问题提升为部署核心风险。研究预览阶段的关键观察点是安全评估规范、驱动生态、硬件厂商支持范围，以及开源后跨模型、跨厂商互操作性。当前官方案例多为合作方证明或概念验证，生产环境可靠性仍待独立复现。
