# Claude Cowork 获得内置浏览器，Claude in Chrome 正式开放

## 事件概述

Anthropic 于 2026 年 8 月 26 日宣布，Claude Cowork 桌面端将获得内置浏览器。任务需要访问网站时，Claude 可在侧栏打开自己的浏览器，浏览页面、点击、输入和填写表单；该浏览器与用户日常浏览器分离，默认不读取用户标签页、书签、密码或登录状态。

## 已确认事实与证据

官方博客确认，内置浏览器当周逐步推送至 Pro、Max 和 Team 桌面端，Enterprise 管理员当天即可开启；支持 macOS、Windows，Linux 处于测试版。用户可按站点导入登录状态，macOS 支持 Chrome、Edge、Firefox，Windows 和 Linux 测试版当前仅支持 Firefox；银行、邮箱和 SSO 站点默认不导入，除非用户主动选择。

官方同时说明，内置浏览器与 Claude in Chrome 分工：前者用于可交接的网页任务，例如收集资料、从供应商门户取发票或填写表单；后者面向用户已打开页面和已有登录态。新智元报道称 Claude in Chrome 同日向全部付费套餐正式开放，动作可由安全分类器逐条校验后执行。官方帮助文档提示提示注入风险无法完全消除，建议从可信站点开始并在高风险场景保持人工监督。

## 影响与后续观察

内置浏览器让 Agent 拥有独立工作环境，能触达缺少 API 和连接器的旧系统、内部门户和表单流程，可能提升行政、采购和研究自动化覆盖率。同时也扩大了凭证、敏感页面和提示注入的攻击面；后续应关注站点级登录迁移、会话保留策略、企业审计日志、分类器误拦/漏放率，以及桌面端必须在线的运维限制。官方页面未提供合适的非装饰性事件截图，本文不使用生成备用图。
