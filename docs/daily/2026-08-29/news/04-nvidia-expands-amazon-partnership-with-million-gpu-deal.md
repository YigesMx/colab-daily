# NVIDIA 与 Amazon 扩大 GPU 合作，Hugging Face 收购仍待确认

## 事件概述

AI Insider 于 2026 年 8 月 28 日报道，NVIDIA 与 Amazon 宣布扩大合作，计划在 AWS 数据中心额外部署 200 万块 NVIDIA GPU；同日另有报道称 NVIDIA 接近以 129 亿美元收购 Hugging Face。前者是双方合作扩容的公开报道，后者仍处于“报道但未签约”状态，两家公司均未回应评论请求。

## 已确认事实与证据

AI Insider 称，新增部署覆盖 Blackwell Ultra、Rubin 和 Rubin Ultra，时间分布在 2027 年和 2028 年，此前双方已有超过 100 万块 GPU 的合作。报道引述 NVIDIA CFO Colette Kress 称 Vera CPU 也将进入 AWS，合作范围扩展到网络硬件、开放模型以及 Omniverse、Cosmos、Isaac 和 Jetson 等机器人平台，AWS 计划将相关能力用于仓库机器人车队。

同一报道还称，Amazon 自研 Trainium 和 Graviton 处理器年化收入运行率已超过 250 亿美元；NVIDIA 第二季度收入 962 亿美元，其中数据中心收入 890 亿美元，并为未来制造和供应能力承诺 2791 亿美元。关于 Hugging Face，The Information 称双方已达成 129 亿美元收购协议，Business Insider 则称谈判仍未签署且可能失败。本文未在来源页找到 NVIDIA、Amazon 或 Hugging Face 官方公告链接，因此上述财务数字和收购状态均按媒体报道处理。

## 影响与后续观察

若 200 万 GPU 部署落地，将进一步收紧先进 AI 训练与推理基础设施供给，并强化 NVIDIA-AWS 在机器人、仿真和云基础设施上的绑定。Hugging Face 收购若完成，会显著改变开源模型、数据集和开发者社区的独立性；但在签约、监管审批和公司联合确认前，不应视为既成事实。后续应跟踪双方官方新闻稿、监管文件、Hugging Face 社区政策以及开源权重许可变化。
