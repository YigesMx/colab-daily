## 事件概述

新智元报道，Anthropic 宣布将 Claude Cowork 与 Claude Chat 全面合并为"统一的 Claude"入口，用户不再需要区分问答、复杂任务、设计与演示分别使用哪个产品；合并版将首先向 Claude Pro 与 Max 订阅用户推送（官方说法为未来几周内）。

## 已确认事实与证据

据新智元报道与 Anthropic 官方博客可确认：统一后的 Claude 一个入口即可使用 Cowork、Design、Docs、Slides 全部能力，历史对话、Skill 与连接器等既有资产全部保留；Claude 会自行判断任务复杂度并调用对应能力，支持合上电脑后在后台持续推进任务。产品细节上：Claude Docs 支持起草文档，Claude Slides 可将文档一键转为幻灯片，Claude Design 在同一工作区生成视觉稿与界面原型；交互颗粒度细化到像素级——可以直接修改文档某行文字、在 PPT 某页留批注让 Claude 重写、拖拽调整设计元素，并可按常用格式导出或以链接分享。由于文档与演示出自同一对话上下文，内容保持一致，还可设置为每周自动执行。官方公告地址为 claude.com/blog/cowork-is-now-claude。

## 影响与后续观察

此次合并反映 AI 巨头对"超级入口"的争夺：OpenAI 将 Codex 等能力并入 ChatGPT、谷歌把 Gemini 深度嵌入 Gmail/Docs/Workspace，Anthropic 则让 Claude 从"回答窗口"变成"成果空间"，本质是一次 Harness 重构——把复杂性吸收进 AI，让用户只表达目标。对办公软件与生产力工具市场，Docs/Slides/Design 原生化意味着传统文档、演示与设计工作流可能被进一步压缩；对开发者生态，统一入口加共享上下文降低了多工具编排成本。后续观察：正式推送范围与时间表（Team/Enterprise/Cowork 尚需等待）、多 Agent 并行与后台执行的计费方式（官方也提示成本较高）、以及与同期 Claude Code 项目化多 Agent 能力的联动。
