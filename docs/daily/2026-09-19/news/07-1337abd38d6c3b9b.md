## 事件概述

量子位报道，Anthropic 对 Claude Code 的 Projects 功能进行全面重构，原生支持多 Agent 并行：用户下达高阶目标后，协调器（Coordinator）把任务拆解为子任务，调度多个运行在云端独立环境的 Claude Code 实例，各自拉独立 Git 分支并行开发，完成后自动提交 PR。同日 Anthropic 发布《衡量 AI 研发节奏》报告，披露内部研发平台每天并发运行约 3 万个 AI Agent 的运营数据。

## 已确认事实与证据

据量子位报道与 Anthropic 官方链接可确认：重构后的 Projects 以对话为驱动，架构核心是 Coordinator 协调器，工作线程是云端隔离的 Claude Code 实例，拥有独立代码副本与 Git 分支；新增共享记忆机制，各分支线程沉淀的技术规范、架构决策与团队偏好实时同步，避免上下文传递损失；流程完全异步，可移动端查看进度并微调指令。产品目前为 beta，首批面向部分使用云会话项目的 Claude Pro/Max 用户，随后逐步放量到 Team、Enterprise。Anthropic 报告披露：按 Epoch AI 的 AL0–AL5 自动化分级，内部 AL4 级（AI 凭高阶指令端到端完成）研发任务占比 26%，今年 2 月不足 1%；超 90% 研发流程处于 AL3；截至 8 月内部平台常态化并发约 30000 个 AI Agent，单月触发模型决策超 10 亿次，全天候监控系统在 8 月拦截约 0.002% 的高风险或异常行为；7 月 13–20 日约 6% 的 AI 研发算力用于安全与对齐研究，同期 AI 驱动研发算力中约 12% 投向安全相关任务，并表示欢迎第三方评估团队审计。官方链接：claude.com/blog/projects-redesigned 与 anthropic.com/institute/measuring-pace-of-ai-development。

## 影响与后续观察

多分支并行加共享记忆把"一人带一个 Agent 军团"变成产品能力，人的角色从逐行写码转向架构决策、PR 审核与冲突处理；Anthropic 内部 26% AL4 数据首次给出前沿实验室 AI 自主研发进度的量化参照。后续观察：多 Agent 并行的实际 Token 成本与合并冲突处理体验、共享记忆的一致性与安全边界、3 万 Agent 规模运营数据的独立审计进展，以及与 Cursor 同期 Projects beta（同样主打 Coordinator 派发子 Agent）的竞争演化。
