## 研究问题与贡献

一句话结论：人形全身 loco-manipulation 在动态场景中是非马尔可夫的——线索会随物体变化、遮挡或机器人转头而消失；WholeBodyMem 用 SAM3 追踪任务物体、按"物体事件"因果地选择关键帧填入自适应记忆预算，并由动作专家经交叉注意力读取，把基础策略的成功率从仿真 29.1% 提到 72.6%、真机 36.7% 提到 88.3%，标准 SIMPLE 任务同步从 70.2% 升至 86.9%。

全身 VLA（π0.5、GR00T、Ψ0 等）只看当前观测与短本体历史：客人挥过手、可乐先放在哪个座位，等机器人转身取物回来时线索已不在视野内，只看当前帧的策略只能瞎猜。既有记忆方案多面向桌面机械臂：长帧历史代价高且稀释短线索、压缩 token 丢细节、固定间隔采样错过瞬时线索。MBZUAI（Yoshihiko Nakamura 组）提出的 WholeBodyMem 与配套基准 HuMeGo 贡献：

- "前历史记忆"（pre-history memory）问题定义与 object-guided 记忆选择：冻结 SAM3 追踪任务物体，检测其出现/消失/重现/移动/形变事件（用背景特征相似变换扣除相机自运动），事件帧因果地填充 3–7 帧自适应预算，保存原生 backbone token 与掩码池化的物体 token；
- 记忆只通过动作专家进入策略：动作 token 对记忆/物体 token 交叉注意力，读出经 FiLM 调制动作 token；另有决策头把记忆中的线索映射为答案 pad 的动态权重；
- HuMeGo 基准：6 个仿真 + 6 个真机 Unitree G1 记忆依赖任务，线索在决策时刻必然不可观测（场景终止或运动出视野），决策正确性与操作成功率分开计分。

## 方法与系统

底座为全身 VLA（Ψ0 谱系，Qwen3-VL-2B 骨干冻结 + flow-matching DiT 动作专家，36 维全身动作：上肢关节目标 + 下肢命令 {躯干、基座高度、基座速度}，由下层控制器执行）。

记忆构建：记忆帧保留冻结视觉塔的 K=77 原生 token（7×11 网格），预算 B_max=7 帧（当前+6 过去），token 缓存复用。物体追踪：SAM3 以每任务一两个短语（如 "blue cup"）为 prompt，逐帧返回掩码/框/置信度；事件规则共享：消失保留最后可见帧、重现、去相机运动后位移超图像对角线 3%、形变（掩码重叠 ＜65%）等，按事件类型与置信度排序。因果选择（Algorithm 1）：始终保留首/中/当前帧，其余槽位按分数给事件帧，同物体 5 帧内已有选中帧则跳过，只用 ≤t 的帧，平均占 5.4 帧。

记忆读取：选中帧的 token 加帧序号+网格位置正弦编码，投影到动作专家宽度构成 M_t；6 个 DiT 块中 30 个动作 token 各自对 M_t 做多查询交叉注意力，读出经零初始化的 W_F 生成 FiLM scale/shift 调制动作 token（初始等价于预训练策略）。物体 token：至多两物体/帧的掩码覆盖加权平均 + 几何编码，共 ≤14 个，经第二条零初始化交叉注意力并入。决策头：可学习 query 对记忆与物体 token（含 null）注意力后输出每个答案 pad 的 logit，交叉熵训练，其 softmax（动态权重 w）经零初始化映射进入每块 AdaLN，并通过 pad token 交叉注意力把选中 pad 的信息交给动作 token（置信度阈值 0.6 才激活）。训练：flow-matching 损失 + 决策头交叉熵（λ=0.5），仅训记忆编码器/注意力与 W_F；仿真每任务 100 演示 40k 步，真机每任务 15 条遥操作演示 5k 步即部署。

## 实验设置与数据

- HuMeGo 仿真：MuJoCo 2 ms 物理/50 Hz 控制，脚本化全身专家（Dex3 抓取 + cuRobo 规划 + AMO 平衡）产演示，Isaac Sim 渲染头相机 640×360@50 Hz，背景/材质/光照随机化；6 任务覆盖物体记忆（LitLamp、BlinkPad、TouchPad）、空间记忆（HideMug、ShellGame）、时间记忆（FlashPad），每任务 100 演示 + 90 测试场景（3 个随机化等级 L0/L1/L2 各 30 集，答案均衡）。剧集平均 1,155 步（23 s），线索仅占 0.8–14.7% 时长且需在消失后保持 13.5–22.5 s，40.7% 步骤在决策点之后。
- 真机：Unitree G1（29 DoF + Dex3 手，头戴 RealSense D435），SONIC 下层控制器 50 Hz，RTX 5090 实时执行 24/30 步动作块，SAM3 每块跟踪一帧（约 1.25 Hz）；6 任务含 Trash bag（袋停在哪个框）、Remember-chip（人碰过哪罐）、Café A/B/C（先到先得/哪座位有可乐/可乐先停哪）、Chip-cart（记住进度），10 试验/任务，答案均衡。
- 基线：InternVLA-M1、DP、ACT、EgoVLA、π0.5、GR00T、Ψ0（无记忆底座）与 Uniform memory（RoboMME 式均匀采样帧+记忆调制器，同 539 token 预算）。

## 结果、限制与结论

- 14 个 SIMPLE 标准任务：WholeBodyMem 86.9%（365/420），超 Ψ0 的 70.2% 与 Uniform memory 的 76.9%——加记忆不牺牲反应技能，在机器人走动的 T6/T8 上对 Uniform 的增益最大；14 任务中 8 项达到 10/10/10 满分。
- 6 个记忆任务：平均成功 72.6%（L0/L1/L2 为 23.0/21.5/20.8 每级 30 集），对 Uniform 44.4%、Ψ0 29.1%；记忆决策准确率 97%（Ψ0≈随机 30%、Uniform 82%），正确识别线索占比 93.7%。
- 消融（对 Uniform 的 28.2 点增益分解）：关键帧选择贡献 16.0 点（仅换事件选帧即 44.4→60.4），物体 token +5.3，决策头 +4.7，自适应记忆 +2.2；"把记忆拼进冻结 VLM 上下文"反而低于无记忆 Ψ0（25.9%）——记忆必须由动作专家读取。自适应记忆平均省 22.9% token 而不掉点："留住对的帧，而非更多的帧"。
- 真机：60 试验中成功 53 次（88.3%），对 Ψ0 的 22/60（36.7%）；六个任务全部大幅领先（如 Trash bag 9/10 vs 4/10，Remember-chip 10/10 vs 3/10）。
- 限制（原文自述）：SAM3 检测不到的物体其线索会被漏记；在线跟踪带来推理开销；仿真演示为脚本生成存在 sim-to-real 差距。论文投稿 RA-L（IEEE Robotics and Automation Letters）。项目页 memory-before-goal.github.io 已公开，抓取时未发布代码仓库。

对组内启示：HuMeGo 填补了"行走的人形 + 消失线索"基准空白，可直接用于检验我们人形策略的记忆能力；"事件选帧 + 动作专家交叉注意力 + 零初始化分支"是给预训练 VLA 无损挂载记忆的成熟做法；把决策准确率与操作成功率分开报告的评测设计值得沿用。
