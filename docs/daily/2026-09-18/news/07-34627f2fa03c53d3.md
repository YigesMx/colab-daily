## 事件概述

Anthropic 在冻结窗口内宣布产品线整合：Chat 与 Cowork 合并为单一入口，同时首发 Claude Docs 与 Claude Slides，加上进入对话界面的 Claude Design，形成"AI 原生办公全家桶"。用户描述目标后，Claude 自行判断直接回答还是调用更复杂能力在云端继续执行。

## 已确认事实与证据

- 官方动作：Cowork 与 Chat 合并；新发 Claude Docs、Claude Slides；Claude Design 进入对话界面（均为 Anthropic 官方发布、量子位转述）。
- 产品细节：Docs 支持与 Claude 共同编辑、选中追问与评论；Slides 支持生成、编辑、对话内播放并导出 PowerPoint/PDF；报告与 PPT 可来自同一次对话，支持定时任务与手机查看进度。
- 开放节奏：统一入口分批上线，Pro/Max 先行，Team/Free 随后；Docs/Slides/Design 暂处 Beta 仅开放付费订阅；Enterprise 需管理员开启。
- 背景：Cowork 今年 1 月从 Claude Code 孵化（"给非开发者的 Claude Code"，四名工程师十天完成、大部分代码由 Claude Code 自己写）；合并动机是用户不知任务该放哪个入口、跨产品上下文不连贯。
- 定价与模型规格变化官方未在本条材料中披露，属于未知项。

## 影响与后续观察

Anthropic 把 Agent 式协作能力（源自 Claude Code 的执行框架）搬进普通办公场景，与 OpenAI/Google 的办公产品正面交锋；"单入口 + 云端后台执行 + 定时任务"正在把聊天框变成工作流编排器。后续观察：Docs/Slides 的实际产出质量与格式保真度、免费层开放时间、以及与 Microsoft/Google 既有办公套件生态的集成深度。对研究组，这类产品化动向是"Agent 长时程任务可靠性"需求的风向标。
