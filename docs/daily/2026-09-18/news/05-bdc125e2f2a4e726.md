## 事件概述

清华大学计算机系教授、智谱创始人唐杰公开分享其内部观察到的 RSI 早期案例：GLM-5.3 驱动的 Infra Agent 在超 10 万张国产芯片集群上，从零参与搭建并优化一套生产级推理系统，"模型优化系统，系统承载模型"的闭环首次以工程化形态跑进生产环境。

## 已确认事实与证据

- 发布主体：唐杰（智谱创始人）技术博客分享，量子位全文转述并附博客原文。
- 核心数据（发布方报告值）：不到两周端到端吞吐提升至初始基线 3.2 倍。
- 具体工程事实：Agent 自主读取系统反馈、提出假设、修改代码、跑实验并迭代；定位 KV Transfer 场景 Python GIL 并发阻塞，把 Prefill+KV Transfer 相比单独 Prefill 超 20% 的性能损失压到 1% 以内；在 KDA Decode 算子上重组计算拿到 1.71 倍提升。
- 边界声明：智谱明确"还没有实现 RSI"；目标设定、边界划定、风险判断仍由人类工程师负责；该案例是从算子精度、跨层并发到 Kernel 优化的基础设施工作，而非模型自我训练。
- 同文披露：GLM 在真实代码库中发现数千个漏洞，催生受信访问计划；GLM-4.7 前内部用 GLM 写代码"带着被迫成分"，GLM-5.3 已成为日常 Coding 伙伴。

## 影响与后续观察

这是 RSI 叙事里少见的"生产级、可量化"案例：改进对象是推理基础设施而非模型权重，风险可控且收益可测，为"AI 优化 AI 运行系统"提供了模板。后续观察：该闭环能否从推理系统扩展到训练系统与数据管线（即真正触到下一代模型构建）、吞吐提升的复现口径（基线定义、集群规模）、以及安全治理——若 Agent 深度介入基础设施，权限边界与审计机制将变得关键。对算力密集的具身训练团队，该案例提示推理/训练系统调优可能是 Agent 最先产生规模化回报的场景。
