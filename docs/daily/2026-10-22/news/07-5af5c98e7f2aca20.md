## 事件概述

据新智元 2026 年 10 月 21 日报道，香港科技大学郑光廷教授、马松辰研究助理教授团队开源了自动化科研平台"第四大学"（The Fourth Institute）：一座让人类与 AI 智能体社群共同创新的平台，目标不是让 Agent 模仿人类科研流程，而是让人类与 Agent 一起做出真正有价值的创新。项目已在 GitHub 开源，仓库可访问确认。

## 已确认事实与证据

- GitHub 仓库 github.com/EatonZhou/the-fourth-institute 已公开可访问，开源事实可核验；新智元报道全文已获取。
- 据报道，"第四大学"为 Agent 提供持续的身份与工作记录：Agent 可围绕问题长期钻研、积累专长，交流发现、自主组织合作，并行探索不同研究路线；人类可带着已有 AI 账号与 Agent 加入，参与讨论、判断研究价值、共同调整探索方向。
- 据报道，平台设计判断是"人的科研创造力来自非线性思维"，因此为 Agent 社群构建"持续钻研、有效沟通、彼此启发、开放协作"的社会环境（Agent Society），并支持围绕问题建立可互联的"研究基站"。
- 据报道，主要合作开发者包括香港科技大学及智能晶片与系统研发中心的周衣童、张伟豪博士、马松辰博士、博士研究生杜书丞，以及澳门大学博士研究生曲环宇、清华大学博士研究生李路凯；具身智能框架探索与真机实验在智能晶片与系统研发中心研发支持下完成。
- 报道提到 Andrej Karpathy 近日关于"全球只有约 5,000 人真正见识过顶尖 AI 能力"的观察，作为项目动机的引述；该说法为第三方观点。

## 影响与后续观察

- 该项目把"Agent 社群化科研"从概念推向可运行的开源平台，呼应了 Agent 集群参与科学发现的前沿讨论，为普通研究者接入自动化科研提供了低门槛入口。
- 后续值得观察：平台是否能产出经同行检验的科研成果；Agent 间协作质量与成本；研究基站互联机制能否形成真正的跨团队知识交流；社区采用规模。
- 尚未确认：平台目前的实际用户规模与产出未见公开数据；内置科研示例（如元胞自动机探索）的深度与新颖性未经独立评估；具身智能真机实验部分仅见概括性描述。
