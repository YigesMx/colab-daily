## 事件概述

据新智元 2026 年 10 月 21 日报道，DeepSeek 全面开源自研推理框架 DeepInfer 与生产级 Token 编解码组件 deepseek-recipe。DeepInfer 是支撑 DeepSeek V4.1 Flash 大规模线上推理的核心引擎，官方 GitHub 仓库已可访问，仓库描述确认为"面向 DeepSeek 模型的高性能、大规模推理框架"。

## 已确认事实与证据

- GitHub 官方仓库 github.com/deepseek-ai/DeepInfer 已公开，仓库描述与新智元报道一致，开源事实可核验。
- 据报道，DeepInfer 采用 Apache 2.0 协议，deepseek-recipe 采用 MIT 协议；DeepInfer 目前支持 V4.1 Flash，最初主要基于 vLLM 搭建，并参考了 SGLang 与 TensorRT-LLM。
- 据 DeepSeek 官方公布并经报道转述的线上数据：该引擎支撑一个集群每天服务 155 万亿 Token；平均每个请求输入 77K Token，首字延迟平均约 400 毫秒，生成阶段每秒输出约 230 个 Token；平均 96% 的输入命中缓存。这些数字为官方宣称，未经第三方独立测量。
- 据报道，系统将 Prefill 与 Decode 拆分到不同机器：Decode 阶段把 384 个路由专家分摊到 64 张卡；官方离线测试中 64 卡 Decode 每卡每秒最多输出 2.6 万余 Token。支持名单包括英伟达 SM100 GPU 与华为昇腾 950 NPU。
- 报道明确指出：开源版本目前提供离线推理；KV 缓存管理与负载均衡因与内部基础设施深度绑定，代码暂未完整开源，设计细节以技术长文与部署问答形式公开。

## 影响与后续观察

- 继模型权重、TileLang 与算子库之后，DeepSeek 把开源延伸到日处理百万亿级 Token 的线上推理系统，为业界复现低成本大规模推理提供了罕见的一手工程参照。
- 后续值得观察：DeepSeek 承诺的新模型推理代码与性能优化是否持续进入 DeepInfer；离线推理版本向完整在线服务能力的演进；社区在 SM100 与昇腾 950 上的复现与基准对比。
- 尚未确认：官方延迟、吞吐与成本数据（如谷价下每卡每小时 38 美元收入）未经独立验证；跨机房部署方案仅有问答层面的说明。
