## 研究问题与贡献

论文《ACE-Brain-0.6: Scaling Spatial Grounding for Physical Foundation Models》由 ACE-Brain 团队（ACE Robotics、四川大学、南洋理工大学、商汤研究院、上海交通大学；共同贡献者 Yinhe Wang、Tao Tao、Zexin He 等，顾问包括 Dahua Lin、Dacheng Tao、Xiaogang Wang 等）发布。出发点是一个观察：GPT-6 Astra、Claude Opus 5.5 等通用多模态模型在具身操作上表现出的通用性伴随强大的空间感知——Astra 能在视觉干扰物中定位任务相关的交互目标。论文把"视觉 grounding"（把自然语言描述链接到图像中的视觉指称）视为连接高层推理与物理场景的关键组件，研究在固定模型架构与训练配方下，一个开放的 9B 视觉-语言模型能否通过扩大可验证 grounding 监督的规模与覆盖面追上或超过 Astra。成果是一个统一数据流水线（约 154 万样本）与在 Qwen3.5-9B 上单轮微调得到的 ACE-Brain-0.6：在七个公开 grounding 基准上四个超过 GPT-6 Astra，平均分 75.41 对 73.68，并在自建机器人场景基准 RobotGrounding 上以 93.42 领先所有对比模型。

## 方法与系统

所有 grounding 任务被统一为条件文本生成：给定一张或多张图像与自然语言查询，模型输出五种短答案形式之一——点、点列表、框、整数计数或类别 token（yes/no 或表示目标不存在的 none）；坐标为归一化到 0 至 1000 的整数。模型从 Qwen3.5-9B 初始化，微调全部语言模型参数、冻结视觉编码器并禁用多 token 预测头，以非思考模式训练。数据流水线汇集三类来源：三十余个数据集家族的机器人操作录像（单臂、双臂、移动、人形）、带手-物体掩码与接触区域的自我中心人-物交互数据、以及提供完整实例集合、部件掩码与 3D 空间标注的通用指向/grounding 数据加少量通用 VQA。机器人录像缺少物体标签，作者设计了自动标注：按动作信号选关键帧（偏好夹爪状态切换与大幅动作变化），VLM 为每个 episode 与相机构建开放词汇物体表，Grounding DINO 检测、SAM 3 精化框，再由独立 SAM 3 识别分支做语义重标注（IoU 不小于 0.5 才采纳标签，不改框的数量与几何）。问题生成采用模板并保证每个答案可对照标注验证：计数与全实例问题仅在实例集合完整时发出，否定问题核对图像词汇确保无正确答案，自由空间目标只标注二维未占用区域；同时切断问题措辞与答案形式的捷径（任一模板内单一答案形式不超过 70%、yes/no 平衡）。质量控制上每个检测框经 VLM 校验，评测基准图像按匹配排除。最终约 154 万样本、341 万问答对、139 万独立图像。训练仅对答案 token 计交叉熵损失，对话打包为 16384 token 序列并使用变长注意力，AdamW 优化（峰值学习率 1e-5，余弦退火），每轮只训一个 epoch。

## 实验设置与数据

评测覆盖七个公开基准：RefSpatial 与 PointArena（空间约束指称与推理）、PixMo-Count 与 PointArena 计数子集（多实例感知）、RoboSpatial 与 Where2Place（空间关系与自由空间定位）、RoboAfford 与 ShareRobot 可供性子集（功能与交互 grounding），报告各基准官方指标与七基准均值 Avg-7；另有自建 RobotGrounding（2591 题、14 种题型、人工标注框，涵盖指称、计数、缺失目标与跨相机对应，分数为题型宏平均）。所有模型用同一评测框架与提示（温度 0.2、128 token 输出预算），闭式模型经 API 查询。对比对象包括 Qwen3.5-9B 基座、Qwen3-VL-8B、六个同规模开源具身模型（RynnBrain-8B、RoboBrain 2.5-8B、ACE-Brain-0.5-8B、Embodied-R1.5-8B、SenseNova-SI-1.1-8B、PhysBrain 1.5-8B）与五个闭式模型（Claude Opus 5.5、Gemini 4 Argon、GPT-5.5、GPT-5.6-sol、GPT-6 Astra）。数据缩放实验用 0.26M 到 1.55M 的五个数据版本、同一配方从同一基座各训一次，形成只差数据的受控序列。

## 结果、限制与结论

论文报告：微调使基座在七个基准中六个提升、Avg-7 提高近 10 个百分点（65.7 到 75.41），最大增益出现在需要决策而非一瞥的空间关系与受约束指称任务；在开源同规模具身模型中除 ShareRobot 外全部领先，Avg-7 领先次优超过 7 个百分点。与 GPT-6 Astra 互有胜负：四个基准领先（如 RoboSpatial 76.56 对 69.55、RoboAfford 88.14 对 84.94），PixMo-Count 与 PointArena 略落后，RefSpatial 明显落后（71.84 对 80.14），其中放置类子项差距最大（75.00 对 84.00）；RobotGrounding 上 93.42 对 Astra 的 91.10 全场最高，按题型看模型在答案为数字、none 或跨视图对应的题型领先（缺失目标 +42、属性缺失 +26），Astra 在需枚举全部实例或解析空间关系的题型领先。数据缩放显示 0.26M 到 1.55M 样本范围内 Avg-7 从 69.3 升至 75.4，符合每翻倍约 +2.4 分的对数线性趋势（r=0.99），在约 150 万样本处超过 Astra 平均分且未见饱和；对照实验表明仅加倍既有来源而不加新监督类型只带来不到 1 分提升——真正起作用的是监督覆盖的多样性而非重复样本量。限制（作者自述）：模型仍落后于 Astra 的全实例枚举能力与空间约束下的放置任务，原因是二维自由空间监督不刻画三维可行性；下一步是加入完整多实例目标与可行性感知放置数据。项目未提供公开代码或数据仓库（当前材料未确认）。
