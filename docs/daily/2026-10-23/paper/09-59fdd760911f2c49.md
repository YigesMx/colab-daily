## 研究问题与贡献

论文《AirPlayground: Benchmarking Aerial Navigation across Diverse Reconstructed Environments》由南洋理工大学、武汉大学与南京航空航天大学合作（Rangya Zhang、Yujing Shang、Zhuoyuan Yu、Mingsheng Li、Qingsong Yan、Chao Yan、Yuhang Zhang、Mir Feroskhan）。它指出空中导航学习资源的两大缺口：一是缺少跨多样环境的稠密采样飞行演示以支持不同策略形式（单步动作、动作块、路径点、未来视角预测等）的训练；二是缺少覆盖面广的标准化闭环评测。AirPlayground 提供统一基准：94 个照片级 3D 高斯泼溅（3DGS）重建环境（室内 18、城市室外 48、植被 28）配对齐碰撞几何，一套场景自适应流水线自动生成专家飞行数据，得到 94K 条演示与 50 Hz 同步的 4650 万观测-状态-动作样本，并通过可扩展的跨策略 API 让不同范式策略在同一语料上训练、在同一协议下于对应场景中闭环评测。论文基准化了四个范式七种基线，并分析离线预测误差与闭环结果的关系。

## 方法与系统

场景采集使用 XGRIDS Lixel P1 PortalCam 手持扫描仪（广角 LiDAR 加四同步相机，两个鱼眼两个前向），一次走查同时获得度量几何与多视角图像；紧耦合 LiDAR-视觉-惯性状态估计恢复传感器轨迹与度量点云，鱼眼图像去畸变后以点云初始化 3DGS 并在深度监督下优化，动态区域被分割掩码并排除出优化。可执行几何从点云导出：飞行相关高度带的二维占据栅格（每场景一次标注的可导航多边形、按场景膨胀半径膨胀保证离障裕度）用于任务采样与路径规划；无膨胀的三维间隙场预计算一次，按机器人半径回答碰撞与间隙查询（GPU 批量查询，无物理引擎接触）；3DGS 资产、规划栅格与间隙场共享坐标系。专家数据生成按场景自适应：在可导航区域内采样满足最小间距与间隙裕度的起终点对（规划可达才保留），初始航向围绕目标方向随机化；障碍交互不足的场景在自由空间加入箱形障碍。每个任务先在膨胀栅格上 A* 规划参考路径并用视线贪心捷径缩短，50 Hz 闭环中航点跟踪专家读取无人机当前状态输出平面体速度与偏航率，每步同步记录前向 RGB、UAV 状态、局部占据块与执行动作，仅保留成功 episode，每场景目标 1000 条，跨 GPU 并行。跨策略 API 由训练适配器（把轨迹转成各策略的输入与监督，未来观测仅作训练监督）与有状态控制适配器（把各策略输出映射到统一机体系速度指令并按各自节奏执行）组成，支持 PointGoal、ImageGoal 与 Goal-free 三种设定。

## 实验设置与数据

语料共 94 个可执行世界、94000 条成功专家轨迹，50 Hz 下 4650 万同步样本（平均每条 495 步），约合 259 小时、1800 公里飞行、5.9 TB；规划路径平均 19.2 米（最长 235.1 米），episode 平均 9.9 秒；每样本为 256×256 前向 RGB 加 13 维嵌入相对目标的状态、局部占据块与归一化平面体速度控制。渲染保真在 20 场景各 10 张参考图上评测：平均 PSNR 19.19 dB、SSIM 0.655、LPIPS 0.223。94 环境划分为 70 训练、8 验证、16 未见测试；闭环评测在 16 个训练场景与全部 16 个未见场景各 50 个固定 episode（每策略每设定 1600 次），成功标准为到达目标 0.45 米内且无安全违规（碰撞检查体半径 0.12 米，超时 100 秒）。基线七种：CNN-BC、ACT、Diffusion Policy、ViNT、OmniVLA、NWM、NavMorph，主要在 PointGoal 模式下统一协议对比；离线指标为 ADE/FDE/P95 与偏航误差，闭环指标为成功率、A*-SPL、导航误差、碰撞率与越界率。缩放实验用 ACT 在 5/15/35/70 场景嵌套子集上三种子训练。

## 结果、限制与结论

论文报告：闭环结果呈现互补强弱——NWM 在已见场景成功率与 A*-SPL 最高（50.0%/0.50）且碰撞率最低，NavMorph 越界率最低；未见场景上 OmniVLA 成功率与越界率领先（40.5%）、NWM 的 A*-SPL 最高、NavMorph 碰撞率最低；ImageGoal 对七分之三基线优于 PointGoal，而去掉目标输入使全部七种基线成功率下降。关键发现是"更好的离线预测未必更好的导航"：CNN-BC 离线 ADE/FDE 最低但闭环成功率仅 21.0%，平均 ADE/FDE 与成功率的 Spearman 相关为 0.29（与预期负相关相反）；而偏航方向误差、侧向方向误差与转弯子集 FDE 与碰撞率相关性更强（0.51/0.37/0.31），更适合离线安全诊断。执行节奏实验显示 ACT 成功率从 H=1 的 0% 升至长视野的 45%，NavMorph 在中间视野最好，ViNT 不敏感——更频繁查询并不必然更好。几何分析按预测-专家最小间隙变化分组 180 个局部障碍交互样本：间隙减小组闭环最小间隙仅 5.2 cm、参考-障碍碰撞率 37.2%、局部通过率 58.1%，对比间隙增大组的 15.7 cm、13.1% 与 80.3%，说明位移误差未刻画的偏差落点相对障碍的安全代价。数据缩放：ACT 训练场景从 5 增至 70，已见/未见场景中位成功率从 30.6%/16.8% 升至 41.2%/29.4%。论文声明将公开发布飞行数据集、跨策略 API 与基准工具（发布地址当前材料未确认），未提供单独的项目主页或代码仓库链接（当前材料未确认）。
