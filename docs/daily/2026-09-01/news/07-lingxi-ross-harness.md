# 全国第三，公司第二，“初创黑马”灵犀智涌用ROSS Harness把机器人送进工业具身智能第一梯队

## 事件概述

据量子位 2026 年 8 月 31 日报道（灵犀智涌提供、量子位获授权转载），成立约三个月的上海具身智能初创公司灵犀智涌，在第二届世界人形机器人运动会工业场景“装配上料”赛项中，以一台由 Demo 级本体组装而成的机器人通过预赛晋级决赛，最终以 160 分获得全国第三、公司第二的成绩，成为该工业场景赛中除行业头部企业外唯一获奖的机器人公司。支撑这一成绩的是其自研的 ROSS Harness Agent 工业级执行体系。报道称，该赛项评判标准对标真实产线作业，直指长时程稳定性、毫米级精度与扰动下自主恢复能力。

## 已确认事实与证据

以下事实来自量子位报道全文（原文页 HTTP 200 已取得并与冻结来源记录一致）；该文注明“本文由灵犀智涌提供，量子位获授权转载”，属于公司授权发布的宣传性报道，以下内容均应理解为发布方口径：

- **赛事成绩**：灵犀智涌参赛机器人在工业场景装配上料赛项决赛获 160 分，位列全国第三、公司第二；报道强调参赛机为 Demo 组装而非量产机型，同台对手为头部品牌。
- **ROSS Harness Agent**：由联合创始人、CTO 段逸凡博士领衔自研，以控制论奠基人 W. Ross Ashby 命名。报道称其包含五项核心能力：模型抽象（将 VLA、World Action Model 等模型统一为标准接口）、技能抽象（把模型、工具和工程策略封装为带适用条件与安全约束的 Skill）、Agentic AI（Agent 负责目标理解、任务拆解、Skill 编排与异常恢复）、分层安全监控（毫秒级硬件安全到任务级状态判断）、数据飞轮（任务上下文、失败案例与接管路径结构化沉淀并反哺模型与 Skill）。
- **自研模型**：报道同时披露公司有自研 CONWAY 工业原生模型，围绕工业场景局部动作决策，已形成力觉增强、快速推理、动作对齐与安全控制等技术成果（发布方口径，未见独立技术报告）。
- **团队**：联合创始人、CTO 段逸凡为中科大博士，研究方向为具身智能与空间智能；联合创始人、首席科学家吉建民为中科大计算机学院副教授，曾执掌中科大“可佳”“佳佳”服务机器人认知决策系统并获 RoboCup@Home 世界冠军。报道称团队已在机加工上下料、精密打螺丝、定子压合等工业场景做落地验证。
- **下一步**：发布方称正推进 ROSS Harness 的产品化落地，计划通过标准化硬件平台把 Harness 能力交付给更多工业场景。

证据强度说明：量子位原文页可访问，报道含赛项名称、分数、名次等具体可核验要素；但赛事官方成绩单未独立核验，ROSS Harness 与 CONWAY 的技术描述均为公司自述，无第三方技术评测佐证。

## 影响与后续观察

该事件的关注点在于工业具身智能的系统工程路线之争：报道把“单一模型路线”的成功率天花板与“模型 + Harness 执行体系”的自进化路线对立起来，主张工业落地的关键在于执行闭环而非单纯扩大模型参数。这一路线判断与当前行业内对 VLA 模型工程化、Skill 编排与数据闭环的讨论方向一致，对关注机器人工业部署的团队有参考价值；但需注意其论据主要来自公司自身的赛事成绩与路线阐述。

后续值得观察：灵犀智涌所述标准化硬件平台的产品化进展与客户落地情况；ROSS Harness 在第三方评测或更多公开赛事中的可复现表现；CONWAY 模型是否有正式技术报告或开源计划；以及同类“Harness/执行层”路线公司（如 Perceptron、Dexterity 等）的相对进展。
