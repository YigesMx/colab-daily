# Stay Seated: Learning Omnidirectional Humanoid Locomotion on a Passive Mobile Chair with Casters

**一句话结论**：大阪大学与东京大学团队把人形机器人的移动从站立扩展到"坐姿"，在标准站立速度跟踪环境上做最小扩展，用纯任务奖励学出带脚轮的被动移动椅上的全向坐姿移动策略，并零样本迁移到真实 Unitree G1。

## 研究问题与贡献

配备准直驱（QDD）电机的人形机器人即使静止站立也必须持续输出关节力矩支撑体重，带来保持电流与发热；而人类伏案工作时通常坐在椅子上，把体重支撑交给座椅，还可以借助脚轮直接改变工作位置与视角。论文由此提出"坐姿移动操作"（seated loco-manipulation）这一长期目标，本文解决其第一步：**坐姿移动**——人形机器人保持坐姿，在带五个被动脚轮与旋转座椅的移动椅上跟踪全向平移速度 $(v_x, v_y)$ 与偏航角速度 $\omega_z$ 指令。

该任务的难点在于接触拓扑与既有轮式/滑行移动研究不同：骨盆与椅面之间是**非固定接触**，而机器人-椅子系统的推进完全依靠**间歇性的脚-地面接触**，而不是通过固定连接的设备。作者称，据其所知，此前基于深度强化学习的人形移动研究尚未同时处理"非固定身体-工具接触 + 直接脚部推进 + 全向速度指令跟踪"。

论文报告三项贡献：

1. 将被动移动椅上的坐姿移动建模为全向速度跟踪问题，不使用动作模仿奖励或人类示范即学得策略；actor 只用本体感知与速度指令（不含任何接触传感或椅子状态），并直接迁移到实体机器人。
2. 通过对称正则化（SY）、足部滑移惩罚（FS）与指令课程（CC）在 4 个随机种子上的 $2^3$ 全因子比较，发现 FS 单独使用会使部分种子收敛到"原地不动"的局部最优，而 FS 与 SY 或 CC 组合可避免该失效；站立时双腿接触对称是自然涌现的，坐姿下则需 SY 才能可靠获得。
3. 方向与速度分辨的分析发现高速下运输成本（CoT）排序为 后退 < 侧向 << 前进，并归因于后退/侧向的"支撑腿伸展"与前行的"脚跟着地后屈膝"两种不同步态模式。

## 方法与系统

方法上对标准站立速度跟踪环境做最小扩展，不加专门动作参考或新学习算法：

- **机器人-椅子系统建模**：29 自由度的 Unitree G1 + 带 5 个被动脚轮（每个脚轮建模为球铰连接的球体）与旋转座椅的移动椅。仿真采用 mjlab（MuJoCo 系）。骨盆-椅面接触对任务影响大，作者将骨盆碰撞网格细化到与视觉网格一致，并把接触求解的摩擦锥从棱锥改为椭圆锥（impratio=10 等求解器设置抑制了穿透与非自然侧滑）。仿真步长 0.005 s、控制 50 Hz。
- **问题形式化**：离散时间 MDP，策略条件于躯干系速度指令 $\bm{u}_t=[v_x^{cmd}, v_y^{cmd}, \omega_z^{cmd}]$，平移范围 ±1.0 m/s、偏航 ±0.5 rad/s； episode 20 s（1000 步），躯干或椅子倾斜超过 70° 或骨盆-椅面接触连续丢失 1 s 即提前终止。
- **非对称 actor-critic**：actor 观测 $\mathbb{R}^{96}$ 只含硬件可得的本体感知（躯干角速度、投影重力、关节位置/速度、上一动作、速度指令），critic 观测 $\mathbb{R}^{217}$ 额外包含仿真特权信息（足部/脚轮/骨盆-椅面接触状态与力、椅子相对位姿等）。动作为以初始坐姿为中心的归一化关节位置指令 $\mathbb{R}^{29}$，经 PD 控制器执行。
- **奖励设计**：任务奖励（速度跟踪）+ 姿态奖励（躯干/椅子直立、关节不偏离初始坐姿）+ 坐姿保持奖励（骨盆-椅子水平距离的高斯项 + 接触指示项）+ 足部惩罚（抬脚高度、接触期切向速度、落地冲击）+ 正则化惩罚（躯干角速度、全身角动量、自碰撞、关节限位、动作变化率等）。椅子速度不被直接跟踪，椅子完全通过机器人速度跟踪与机器人-椅子接触被动移动。
- **三个全因子训练组件**：SY（左右对称数据增强 + mirror loss，系数 1.0）、FS（接触期足部切向速度惩罚，$w_{slip}=0.25$）、CC（前 2000 次 PPO 迭代平移指令限 ±0.5 m/s，之后扩展到 ±1.0 m/s）。

## 实验设置与数据

实验在 mjlab 中用 PPO 训练：MLP 512-256-128（ELU）、学习率 1e-3、4096 并行环境、10000 次 PPO 迭代、4 个随机种子（42/1234/2026/3407）。域随机化覆盖足摩擦、关节编码器偏置、躯干/椅子质心、脚轮位置与阻尼等，每 2-5 s 施加速度扰动，观测噪声只加在 actor 输入。

评估分为三组：

1. **随机指令评估**：每种条件 1000 次 20 s rollout（10 s 后重采样指令，保留域随机化与扰动），指标为速度跟踪 RMSE、超时成功率、座位相对位移与躯干倾斜；比较 8 个训练条件与一个站立策略基线（mjlab 的 G1 速度跟踪环境，去除 actor 的躯干线速度观测）。
2. **固定指令网格评估**：每条指令保持 10 s、20 次 rollout，绘制 $v_x$-$v_y$ 与 $v_x$-$\omega_z$ 平面的跟踪误差热图与"指令面积"曲线。
3. **方向/速度分辨步态分析**：前/后/左/右四个方向、0.5 与 1.0 m/s，每指令 200 次 rollout（关闭随机化与扰动），统计单脚接触比例、接触力与 CoT（$W_+/(Mgd)$）。
4. **真机部署**：策略零样本直接部署到实体 Unitree G1，定性验证前/后/侧向与转向运动。附录还报告了站立与坐姿的静止功耗对比（每种姿势一次 60 s 测量）。

## 结果、限制与结论

论文报告的主要结果（均为论文自报值，track 未独立复现）：

- 全部 8 个训练条件在随机指令下完成至少 99.45% 的 rollout；SY+CC 取得最低的平移跟踪 RMSE（$v_x$ 0.1512、$v_y$ 0.1268 m/s）与最高超时成功率 99.80%，SY+CC 与 SY+FS+CC 在三个跟踪 RMSE 上数值均低于站立策略。作者明确说明站立基线训练环境与奖励不同，该比较只用于标定坐姿约束下可达的跟踪精度，不代表两种姿势的优劣。
- **FS 失效模式**：FS 单独使用时部分种子在对角前进指令下收敛到完全静止的局部最优（ FS 同时抑制了推进所需的足部运动）；加入 SY 或 CC 后，四个种子中最差的策略也优于最好的 FS 单跑策略，且无需重新调 FS 权重。
- **步态与能效**：纵向运动中 CC 出现左右脚接触不对称，SY+CC/SY+FS+CC 接近完全对称；侧向运动时运动方向对侧腿承担主要推进。1.0 m/s 下 CoT 排序为 后退 < 侧向 << 前进（前进 CoT 约为侧向两倍），前进的高速飞行相比例超过 60%；后退/侧向采用"支撑腿伸展"，前进采用"脚跟着地后屈膝"。FS 降低 CoT 但增大跟踪误差，呈能效-跟踪权衡。
- **真机**：策略仅用本体感知与速度指令、无接触传感即零样本迁移到实体 G1，定性展示全向坐姿移动；真机上未量化跟踪精度与抗扰性。附录报告坐姿静止功耗 101.25 W vs 站立 111.06 W（单次 60 s 测量，外推约多运行 22 分钟），作者明确说明这只是初步结果，不能据此得出一般性节能结论。

限制：仅一种椅子、一种地面条件与限定指令范围；真机跟踪精度、抗扰性与长时间运行未量化；静止功耗对比样本量过小。论文的后续方向包括桌面间坐姿取放操作、能量感知方向选择与"推进-滑行"策略。对组内的启示：坐姿移动作为降低人形机器人长时间桌面作业能耗与稳定性的新形态，其"非固定接触 + 直接脚部推进"建模方式与 SY/FS/CC 的全因子结论（特别是 FS 单独使用的局部最优失效）对设计人形机器人任务奖励与训练组件有直接参考价值。
