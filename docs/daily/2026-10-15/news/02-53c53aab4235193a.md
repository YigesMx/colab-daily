## 事件概述

据新智元 2026 年 10 月 14 日报道，Meta 于深夜发布新一代旗舰模型 Muse Wonder 与完整版 Muse Wonder Full，官方将此次发布定义为迄今最强模型、迈向"个人超级智能"的关键一步。普通版 Wonder 已在 Meta Model API 与编程工具 Muse Code 上线，完整版 Full 目前仅向 Muse Code 订阅用户开放。Meta 首席执行官扎克伯格与首席 AI 官 Alexandr Wang 在播客中称，为此在吉瓦级 Prometheus 超级数据中心上押注超过 1000 亿美元基础设施。

## 已确认事实与证据

- Meta 官方博客给出多项对比数据（厂商宣称）：在自建"个人超级智能指数"中 Muse Wonder Full 得 59.1 分，称超过 Claude Opus 5.5 的 55.2 分与 GPT-6 Astra 的 54.5 分；长周期软件工程基准 SWE-Marathon 得 57.5%，称领先 Opus 5.5 的 46.3% 与 Astra 的 42.5%；AutomationBench 得 45.4 分、MemoryBench 得 85.5 分。
- 第三方评测机构 Artificial Analysis 数据显示：Muse Wonder Full 智能指数 56 分、进入全球第一梯队，普通版 52 分；报道同时注明普通版综合分仍略低于 GPT-6 Astra 与 Gemini 4 Argon。
- 定价与开放范围：普通版 API 每百万 token 输入 4 美元、输出 20 美元（缓存输入 0.20 美元），100 万 token 上下文不加价；完整版随订阅开放，Power Usage 每月 50 美元、Maximum Usage 每月 200 美元，暂未提供独立 API。
- 官方主打两项新能力：Active Memory（跨长对话主动记忆与调取旧信息）与 Active Focus（遇阻后换路径、出错后自查、按新要求调整计划）。
- 报道记录了争议：部分开发者实测认为普通版与跑分不符（如 3D 游戏任务表现差）；Alexandr Wang 回应称模型未针对 3D 演示游戏专门训练并建议在真实编码工作中试用；官方博客则以测试时计算扩展图表回应"刷榜"质疑。
- 报道提到，Meta 在模型卡中写明"采取安全计划保护模型权重"，对开源未作承诺；个人助手 Muse 将"逐步"接入 Wonder；首批用户曾遇额度异常，官方称正在修复并承诺修复后重置额度。

## 影响与后续观察

若长程编程与代理任务优势获得独立验证，Muse 系列将直接进入 Claude Code、Codex 一类编程代理产品的竞争格局，改变此前 Meta 模型的市场位置；巨额基础设施投入的说法目前主要来自播客访谈，尚无财务文件佐证。后续观察：完整版 Full 是否开放独立 API；普通版在更多第三方实测与复测中的口碑；Muse 助手接入的具体时间表；额度问题修复进展；以及 Meta 对开源立场的进一步说明。
