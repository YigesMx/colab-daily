## 研究问题与贡献

这篇论文来自 Sber Robotics Center Brain Team（Gennady Sidorov、Valerii Kornilov、Denis Grankin、Polina Fedotova、Aleksey Postnikov），提出机器人世界基础模型 GreenWAM。核心问题是：机器人既需要世界模型来预测"我的动作会怎样改变场景"，也需要策略来"产生这些动作"，但现有模型通常只为其中一个角色构建和评测，且每台机器人用各自格式记录动作，跨本体对应关系缺失。GreenWAM 证明一个模型可以同时在两种角色上达到一流水平。配套的"配方"有三步：一是共享解剖学动作空间，把 20 个机器人族（从双臂平台到灵巧手人形）的关节映射到统一的 79 个解剖槽位（腿 12、躯干 23、臂 18、手 26），让同一槽位在所有机器人上表示同一关节运动，全族共享一个动作投影器，没有机器人拥有私有动作参数；二是在视觉预测、动作条件预测与世界-动作（WAM）等七种模式上联合训练同一组生成器权重；三是策略化时从生成器中拆出动作专家。

## 方法与系统

模型基于 Cosmos 3 Edge 4B 初始化，沿用其 reasoner+generator 的混合 Transformer 结构、因果视频 VAE 与整流流训练。机器人阶段冻结 reasoner 与 VAE，只训练生成器、共享动作投影和动作模态嵌入。模式由"哪些流是干净条件、哪些是加噪目标"定义：一段带状态的机器人片段可同时回答场景会怎样、给定轨迹会看到什么、观察到视频由哪条轨迹产生以及下一步做什么。关节状态与末端位姿是同一状态的两种视图，默认腿/躯干/头/臂用相对编码、夹爪与手指保持绝对编码，末端位姿在 SE(3) 内复合，投影器不做正逆运动学；有效性掩码把缺失坐标排除在损失外。策略适配时动作 token 移入专属 Transformer、视频 token 留在生成器，两流逐层联合注意力，动作专家通过复制生成器塔初始化（参数量与生成器塔相同、每步训练时间增约 8%）。训练语料以"原子"（一个子任务片段+同步视角+状态+文本+出处）为单位，共准入 144 万原子、1688.5 小时，质量过滤后 143 万，配命令后 119 万，约 74% 为真实数据。

## 实验设置与数据

世界模型评测分两层：六族机器人的留出录像上检验动作跟随（把指令位移缩放 0、0.5、1、1.5 倍看生成运动是否随之变化），以及在公开基准 WorldArena 1.0（15 项指标：视觉质量、运动质量、一致性、物理、3D 精度、可控性）上与排行榜模型对比。策略评测覆盖 RoboTwin 2.0（排行榜协议、50 任务每设定 100 次）、CALVIN（ABC 训练 D 评测、1000 条指令链）、RoboDojo、LIBERO/LIBERO-plus（七轴扰动零样本），语料不含这些基准数据；真机在 Green 人形上对比 π0.5、Cosmos 3 Edge（同一演示划分，70 条指令、14 个场景配置、9 个分布内 5 个分布外），并按 Flash-WAM 式一致性蒸馏得到单步学生策略。控制实验用固定预算配对比较三个设计选择，95% 区间来自任务与片段的分层 bootstrap。

## 结果、限制与结论

作为世界模型，GreenWAM 在 WorldArena 1.0 对比的世界-动作模型与视频生成器中轨迹、深度与 3D 精度最高（56.0、98.2、93.4），JEPA 相似度 98.41 在全部 127 个参赛条目中列第二（仅次于 BLM 的 98.49）；动作跟随实验中零指令下运动量降到不足记录指令的五分之一，1.5 倍指令多出约四分之一，说明视频确实跟随指令。作为策略，RoboTwin 2.0 排行榜协议下 86.98% 干净 / 48.10% 随机化 / 平均 67.54%，居排行榜前列（榜首 ME-Dex-1.0 为 78.8%，其与 X-WAM 的预训练含 2.75 万条随机化 RoboTwin 演示）；LIBERO 接近专用策略且取得对比方法中最高的 LIBERO-plus 零样本成功率，其中光照 97.4、传感器噪声 95.6、语言 94.3 等扰动下领先两个基线，而单臂 Franka 并不在其双臂语料中；真机人形 ID 95.6% / OOD 84.0%，高于 Cosmos 3 Edge 策略（88.9/80.0）与 π0.5（84.4/76.0），蒸馏学生 91.1/80.0。三项控制结论：机器人特化同时改进预测与控制（PSNR +1.26 dB、干净成功率 +7.9）；适配一开始就拆动作专家再增 +2.8，两项合计 +10.8；适配期保留世界模型模式使随机化成功率 +8.0，保住对场景变化的鲁棒性。限制方面，随机化场景成功率仍明显低于干净场景，作者指出排行榜上预训练见过随机化场景的方法占优；论文未报告 CALVIN 完整名次之外的细粒度失败统计与推理延迟（学生策略单步单遍），更大规模的跨本体负迁移分析当前材料未确认。
