## 研究问题与贡献

VLA-MOPD 来自中国科学技术大学、ACE Robotics 与中南大学（Yongxuan Lv、Zhen Fang、Lichen Man 等共 12 位作者，通讯作者 Feng Zhao）。视觉-语言-动作（VLA）策略提供共享接口，但任务特定后训练往往产生彼此独立的专家模型，把它们合并成一个多任务策略很困难：混合任务强化学习只有稀疏的轨迹级回报信号；离线蒸馏会错过学生实际访问的观测；端点蒸馏只监督最终动作、不监督中间动作生成状态。论文提出 VLA 多教师在线蒸馏协议（VLA-MOPD），把技能获取与技能合并解耦：先获得任务或任务组专家，再由一个共享学生收集机器人 rollout，在学生访问的每个观测与中间常微分方程（ODE）流状态上查询按指令路由的冻结教师，用逐流步的分离转移目标经掩码局部匹配损失监督有效动作块，并可选参考策略正则以保持其他任务的能力。从 LIBERO 每任务一条轨迹出发，平均 success-once 从 75.4% 提升到 98.9%；RoboTwin 2.0 三任务从 73.0% 到 89.3%；真实 Piper 单臂机器人两轮合并后从 70.0% 到 90.0%。

## 方法与系统

动机部分先用变差距离给出换测度上界：任何有界逐状态匹配损失在两个"观测-流状态"分布上的期望差受 M 乘以 TV 距离限制，形式化了为什么学生诱导的状态分布才是转移匹配的天然评估分布。框架流程：多任务 SFT 初始化学生；每个任务（组）经 SFT 或 RL 适配得到冻结专家。每次合并迭代中，冻结学生快照用 ODE 求解器从高斯噪声递推生成动作块并执行收集 rollout，保存观测、指令、教师标识与完整流状态链 x0:K；按指令路由的教师在其自身 VLM 前缀下对相同 (xk, c) 计算 ODE 步均值并停止梯度作为目标；只更新学生的 VLM LoRA 模块与完整动作专家（其余 VLM 参数与全部教师参数冻结），然后刷新 rollout。优化目标从随机转移 KL 出发：共享协方差高斯核下 KL 化为速度场差的缩放平方范数；由于实际动作生成器是确定性 Euler 步，直接采用平方转移匹配代理——在学生存储状态上匹配学生与教师的 ODE 步均值（等价于加权速度 MSE），对所有流步与动作元素平均，掩码剔除终止或填充的无效块。梯度只穿过学生，对冻结快照的分布不微分，即把学生速度场向教师局部投影在学生诱导的外部与内部状态分布上；失败的 rollout 也被教师标注。参考策略正则：冻结初始策略为参考，在保留任务观测上按同一规则匹配其步均值，以权重 beta 控制遗忘。

## 实验设置与数据

评测指标为 success-once（执行中任意时刻完成即算成功），多套件取无加权平均。LIBERO：Spatial、Object、Goal、LIBERO-10 四个单臂套件，每套件 500 回合；极端数据稀缺设置下学生仅用每任务 1 条轨迹 SFT（π0.5 SFT 配方，RLinf 框架）；Spatial/Object/Goal 教师为 RLinf 的 PPO 多任务检查点，LIBERO-10 教师为该检查点再 PPO 训练 120 步。对比完整数据（50 轨迹）参考方法（Octo、OpenVLA、NORA、π0+FAST、π0.5）、路由教师本身、端点动作蒸馏与 MixRL（GRPO，同环境数与 rollout 数）。RoboTwin 2.0：选 Place Empty Cup、Pick Dual Bottles、Stack Bowls Two 三个不同时程的双臂任务，学生为每任务 50 条干净轨迹的多任务 SFT，每任务 100 回合官方限制评测。真机：Piper 单臂三任务（Pick Banana、Stack Cup、Sort Number），学生为 π0.5 混合任务 SFT，教师为各任务单任务 SFT 的 π0.5；两轮 rollout 每轮每任务 50 条轨迹，每轮后训练一个 epoch；每任务 30 次评测。

## 结果、限制与结论

LIBERO：学生初始化（1 轨迹 SFT）四套件平均 75.4%，路由 PPO 教师 98.5%，端点动作蒸馏 98.2%，VLA-MOPD 达 98.9%（Spatial 99.4、Object 99.0、Goal 98.0、LIBERO-10 99.0），超过端点蒸馏且用到的数据量仅为参考方法（50 轨迹）的五十分之一。训练效率：前 500 步内 VLA-MOPD 从 75.4% 非单调升至 300 步 98.1%、末检查点 98.85%；同配置 MixRL 在共享第 400 步仅 82.55% 对 97.6%，差距在 Goal 与 LIBERO-10 最大，与逐观测逐动作块的教师转移监督对二值终端奖励的优势一致。中间流状态监督消融：500 步时端点蒸馏 98.15% 对 VLA-MOPD 98.9%，增益集中在组合目标与长时程套件（Goal +1.2、LIBERO-10 +1.4 个百分点），说明局部动作误差会在动作块间累积。遗忘与保持：用 Spatial 专家提升 Spatial 并以冻结初始学生为 Object 参考（beta=1），在相近 Spatial 成绩（差异至多 1.4 个百分点）下 Object 只降 3.0 个百分点，无参考 OPD 降 13.2、SFT 降 12.8，参考项减少遗忘 10.2 个百分点。Rollout 预算敏感性：64/32/16 环境在第 300 步分别 98.1/91.3/87.0%，第 500 步收敛到 98.9/95.2/94.5%。RoboTwin 2.0：学生 73.0%（69/75/75），教师 94.0%，VLA-MOPD 89.3%（87/93/88）。真机：学生 70.0%（86.7/63.3/60.0），教师 93.3%，VLA-MOPD 90.0%（100/93.3/76.7）。限制（论文自述）：合并前需要任务/任务组专家教师，获取与存储这些教师带来前置训练与维护成本，且可合并的能力受教师质量与任务覆盖限制。结论：在线策略蒸馏把专家监督连接到合并策略实际访问的状态，是流匹配 VLA 多任务整合的有效协议。代码与模型已在 GitHub 开源。
