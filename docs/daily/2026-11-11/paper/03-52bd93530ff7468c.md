## 研究问题与贡献

ObjectWorld 来自新加坡国立大学计算学院、RoboScience 与 NUS 广州研究创新研究院（Haonan Chen、Sicheng Isabella Lu 等共 12 位作者，通讯作者 Lin Shao）。论文要解决的问题：生成式世界模型要成为可扩展的机器人操作路径，需要一个既可大规模监督、又对下游控制可执行的中间表示。现有候选各有取舍：像素空间预测（目标图像/视频）控制不直接；稀疏关键点/affordance 点可能丢失完整物体运动；6 自由度位姿依赖刚体假设、无法处理形变；已有物体流方法只覆盖可见或被跟踪表面。论文提出"3D 全物体流"（3D full-object flow）：为目标物体完整表面（含遮挡区域）上的点分配稠密 3D 轨迹，统一适用于刚性与可变形物体，且与机器人本体无关。贡献包括：1210.1 小时全物体流数据集（454.5 小时仿真轨迹加 755.6 小时自动标注真实视频）、可扩展标注流水线与质量度量、以图像与语言为输入预测稠密全物体流的世界模型，以及流条件化的动作优化实现真实机器人执行。

## 方法与系统

标注流水线不要求机器人动作、深度、标定相机或预扫描网格：先用 Gemini 2.5 Pro 识别目标物体、生成任务描述并把原始视频切分为原子操作片段；每段用 Track4World（Depth Anything 3 骨干）估计相机位姿并重建逐帧点云，SeC 传播目标掩码，SAM 3D 重建完整物体网格，Any6D 估计初始位姿、FoundationPose 全程跟踪，把网格均匀采样点随位姿与坐标变换传播得到以首帧相机系表示的全物体流。质量过滤用投影 IoU 一致性：Golden 门槛（0.70）精度 93.3%，Silver 门槛（0.50）召回 96.3%；对 RoboTwin 97 段 3 秒片段的管线验证给出 98.0% 标注率、目标定位 IoU 0.908、掩码传播 IoU 0.873、重建 Chamfer 2.61%D、稠密流 EPE 3.71 厘米（26.11%D）。世界模型输入首帧 RGB-D 加任务语言：SAM2 掩码与 SAM3D 重建构造物体点集，深度反投影得到场景点云；Qwen 2.5-VL 提供逐点视觉-语言特征，Point Transformer V3 联合编码物体与场景几何；采用线性噪声路径上的 x1 预测参数化，物体 token 经自注意力细化后在以场景与语言 token 为键值的交叉注意力解码器中一次性预测全部 T=48 帧、512 个物体点的位移轨迹，损失为 MSE。训练前用 GeoCalib 估计重力并统一坐标系，动作片段统一重采样以表示归一化动作进度。下游执行采用轻量局部 patch 拟合：抓取模块给出初始位姿与接触区域，接触点局部坐标保持固定（仅局部刚性假设），逐步用 IRLS 加权 Kabsch 对齐恢复机械臂位姿序列，从而允许物体其余表面非刚性运动。

## 实验设置与数据

数据集共 1210.1 小时（16 FPS 标准化计量）：仿真部分聚合 ManiSkill 3、MetaFold、Meta-World、MIKASA、RLBench、RoboCasa、RoboTwin 2.0 七个数据集的 198,947 条轨迹、251 类任务（MetaFold 贡献可变形物体）；真实部分来自三个大规模视频源，过滤后保留 288.7 小时 Golden 子集，模型与学习基线在全部仿真数据加 Golden 子集上训练。评测按五个问题组织（标注可靠性、流预测精度、数据规模与设计、下游执行、环境与本体泛化）。流预测基线为 TraceGen、im2Flow2Act 与 ObjectForesight；仿真执行在 ManiSkill 与 LIBERO 上按与真值轨迹的空间一致性判定成功；真机评测用平行夹爪做香蕉与手电筒取放、倒水，用灵巧手把白菜放到盘子上。

## 结果、限制与结论

流预测：本方法全帧 EPE 6.22 厘米、末帧 EPE 11.17 厘米，全面优于部分流与刚体基线；对物体几何噪声在 2 厘米内几乎无退化，5 厘米噪声下末帧 EPE 仍稳定。数据扩展实验显示仿真与真实数据各自扩充都降低误差，两者组合最佳；用任务语言替换占位符描述使总体末帧 EPE 从 13.76 降至 13.01 厘米（AgiBot 与 SthV2 上分别降 1.53 与 2.21 厘米）。组件消融：去掉 VLM 视觉-语言条件使末帧 EPE 恶化 4.21 厘米、Acc@10 下降 20.5 个百分点。执行：仿真中 ManiSkill PushCube 10/10、PlaceSphere 10/10、Insert 9/10，LIBERO Stack-Arrange 10/10（TraceGen 与 ObjectForesight 约 4-7/10）；真机四任务 4/5、4/5、5/5、5/5，均优于 Dream2Flow 基线；五步流生成在单块 A100 上每条约 1.08 秒。全物体流相对 Track4World 可见表征把中位 EPE/D 从 37.22% 降到 30.74%，完整表面 Coverage@5%D 从 28.4% 提升到 45.8%、遮挡表面覆盖从 9.8% 到 26.6%。限制（论文数据可见）：标注管线表面轨迹误差中位 11.50%D、遮挡几何隐藏表面误差 7.28%D、隐藏覆盖 Recall@5%D 仅 0.462；Golden 与 Silver 门槛需在质量与覆盖间取舍（Golden 召回仅 69.1%）；流预测误差仍在厘米量级，长时程末帧精度显著低于全帧均值。结论：稠密全物体 3D 运动预测是可扩展、可跨本体迁移的机器人世界模型的有前景基础。项目页提供更多结果与视频；当前材料未确认代码开源地址。
