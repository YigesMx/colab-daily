## 研究问题与贡献

ASENA（NVIDIA GEAR 团队，作者含 Jan Kautz、Jim Fan、Yuke Zhu）研究自我进化具身导航智能体：导航机器人要完成"去自动售货机看看有没有我桌上的零食、回来用手势回答"这类任务，需要决定查什么、算什么、记什么、怎么沟通——这些程序依赖新观测、常超出预定义技能，且物理部署需要随程序变化仍有效的安全保障与可保留经验的持久工作区。

贡献有三：（1）具身智能体系统——把通用编码智能体（Codex、Claude Code、GPT-6 Astra 等作为后端）接入机器人传感（360° 相机、LiDAR、里程计、IMU、关节状态）、机载计算、受监督执行与 MCAP 执行记录，统一为"写-运行-检查"工作流；（2）ASENA-VLN，4B 单目导航策略，作为系统内可选工具，用共享自回归解码器同时预测长程路线与短时原子导航行为的机体系轨迹，R2R 68.7%/RxR 70.2% 成功率为论文报告的 SOTA；（3）权重冻结下的工作区演化实验：十轮演化把重复任务子集成功率 72%→98%（R2R）、65%→89%（RxR），并在 Unitree G1 上无预建地图完成搜索、视觉检查、空间推理与合成手势的真机演示。

## 方法与系统

系统三层：①持久工作区+反馈——程序、笔记与可执行技能存于工作区 W_k=(N_k,S_k)，独立固定权重 improver 用执行迹与反馈更新 W_{k+1}=I_φ(W_k,T_k,f_k)，所有模型与控制器权重不动；②传感+可调用运动工具——几何导航工具（LiDAR 占用栅格、路径规划、间隙检查）与 ASENA-VLN 学习策略并列为可调用工具，编码智能体自行决定组合；③受监督执行——合成手势先在 MuJoCo 在线验证（姿态连续性、关节/运动限制、自碰撞采样），失败把违反的约束返回智能体修复；验证通过仍需操作员批准才由 SONIC 全身控制器执行；导航另有运动限制、里程计过期/低电量拒绝、心跳停车与急停等独立保障。

ASENA-VLN 扩展 Qwen3-VL-4B-Instruct：输入最多 8 帧前视历史（新近加权）+结构化 JSON 指令（导航命令，可选期望末端位姿、锚物体、运动约束），专用 token 词表解码最多 8 个累计机体系路点 (x,y,θ)（固定 bin 离散化，无需连续动作头）；像素目标 token (u,v,θ,is_last) 作辅助监督，视觉 QA 保留文本词表。数据：新策划 MP3D/HM3D 九类原子导航任务（定距移动、转朝向、指定方向接近物体、对齐、进房间、过门、沿走廊、跨楼层），用测地距离/可见性/场景几何生成验证，混合 ObjectNav 与 R2R/RxR/ScaleVLN/SRDF（GPT-5.5 重写为 JSON 指令格式），共 430 万样本（3:1 轨迹预测:空间 VQA）。评测用像素目标需额外运动规划器或最短路跟随器，故全部评测用轨迹 token。

## 实验设置与数据

标准评测：R2R/RxR val_unseen（0.25m 步长、15° 转角，NE/OSR/SR/SPL/nDTW）；HM3D-v2 与 HM3D-OVON 物体目标导航（配独立 VLM 做全局搜索规划）；R2R/RxR Agentic Splits（各 100 任务、10 场景，比较 Claude Sonnet 5 high effort 与 GPT-6 Astra max effort 两个后端、有无 VLN 工具）；工作区演化（16 个 Claude Sonnet 5 worker 私有工作区执行，improver 汇总更新规范工作区，R2R/RxR 各 4 组 campaign）；EQA（HM-EQA/MT-HM3D，398/1183 题池，每轮抽 50 题；√(3A) 名义步预算）；G1 真机三次受监督任务。

## 结果、限制与结论

论文报告：ASENA-VLN-4B 在 R2R SR 68.7%（NE 3.52、SPL 64.2）、RxR SR 70.2%（nDTW 73.1），超过 Qwen-RobotNav-4B（66.9/71.3）与 DualVLN（64.3/61.4）等；物体目标导航 HM3D-v2 80.8/38.1、OVON 三划分全部领先（60.5–65.8 SR）。Agentic Splits 揭示互补结构：GPT-6 Astra 仅用几何/程序工具即达 R2R 87% SR（接近人类 90%），超过独立策略；Claude Sonnet 5 加 VLN 工具在两基准各 +11pp SR（61→72、50→61），且两后端平均工具调用数下降 46.9%–62.5%——学习策略吸收低层导航、减少重复智能体交互，其价值取决于后端强弱。工作区演化：四组 campaign 成功率持续上升（图 4），R2R 重复 100 任务子集 72%→98%、RxR 65%→89%，含 VLN 的工作区保持更高 SPL，且每轮 logged 成本下降；EQA 上演化 pass 17 达 HM-EQA 81.2%（低努力 74.8%、步数 0.127，优于手设计高效配置 72.2/0.11），MT-HM3D pass 4 达 66.5%，ASENA-VLN 配对消融减少约 19% 中位探索步。G1 真机三次任务分别完成找洗手间返回指路、数咖啡机并等待、比对零食后挥手+手势回答，全程无预建地图、手势经仿真验证与人工批准。

限制：物理任务全程人工监督（操作员批准），不是自主部署；GPT-6 Astra 后端成本高（表 3 显示 R2R 26.4 次调用/回合），论文用 logged 成本度量但未给出绝对 token 成本；演化评测在相同任务/场景/指令/初始位姿的重复呈现设定下进行，新任务泛化未系统量化；EQA 演化各轮指标有波动；未发布代码仓库（项目页无 GitHub 链接）。对组内启示：编码智能体+可调用学习策略+执行记录反馈是比"单一巨型策略"更灵活的导航系统形态；MuJoCo 在线验证+人工门的轻量安全栈可直接借鉴到人形部署实验；原子导航数据（过门/对齐/定距等可直接由几何生成的监督）是低成本扩充 VLN 训练配方的有效途径。
