## 研究问题与贡献

Magic-W0 是 Magic Lab（Magiclab Robotics）提出的世界-动作基础模型。它针对现有 WAM 的一个结构性缺陷：无论预测未来观测（像素重建）还是通用隐变量预测，都缺少与控制紧密耦合的显式世界表征——未来观测中大量纹理、光照、背景变化与控制无关，二维外观变化也无法表达机器人所在的三维物理空间。

贡献有三：其一，提出结构化世界转移（Structured World Transition），把机器人交互的预测过程组织为"当前状态—转移—未来状态"三段：当前状态由 VLM 上下文+当前 3D 几何构成；转移用 3D 运动描述动作诱导的三维状态变化；未来状态用未来语义表示任务相关的场景结局。其二，层对齐双向耦合架构：演化的动作假设持续条件化世界转移预测，预测的世界表征又持续回馈动作生成，使世界预测成为动作生成全过程的内部预测表征，而非独立辅助目标或末段条件。其三，统一 34 维状态-动作接口与跨本体预训练配方，让自我中心人类操作、UMI、真机与仿真四类数据（约 201.4 万有效片段）共享同一模型。

## 方法与系统

模型由四个深度对齐的流组成：Qwen3.5-2B VLM 骨干（多视角视觉 token+语言+本体状态，提供任务上下文，独立走因果路径）、3D 流（联合建模当前 3D 几何与 3D 运动）、语义流（未来语义）、动作专家（flow matching 生成连续动作块）。网络 24 层，每 3 层 Gated DeltaNet 后接一个注意力层，在第 4、8、…、24 层做联合注意力：3D/语义/动作流互相读取中间隐状态（VLM 不读专家流），动作 token 可见 3D 与语义流，语义与 3D token 可见动作流——训练时以小概率随机屏蔽动作专家到某一世界分支的访问，匹配推理期屏蔽条件。

三路潜在监督只在训练期使用：冻结 Track4World 的 DA3 骨干提供当前帧几何特征、其 3D 运动头提供跨时间三维运动特征；冻结 DINOv3 提供未来帧 patch 语义特征。三者均为 16×16×1024 特征，几何/运动用通道归一化 MSE、语义用余弦距离对齐。动作块 H=50，采用块内 delta 表示（相对块初始状态），按数据源的动作采样倍率 ρi 做动作-世界时间对齐（Δi=⌈H/ρi⌉），保证动作块与未来监督覆盖同一段交互。预训练还混入 9:1 的视觉-语言批次（约 261 万样本，EO-Data1.5M、Robo2VLM-1 等）、FAST 离散动作监督与 VQA 目标，并用梯度隔离（知识绝缘）保护 VLM 骨干只被语言/FAST 目标更新。推理期只缓存一次 VLM 键值，10 步 Euler 积分去噪，每一步 3D/语义/动作流联合重算，教师模型完全不加载。

## 实验设置与数据

预训练语料约 2.014M 有效操作片段：自我中心人类约 69 万（2 数据集）、UMI 约 23.1 万、真机约 64.59 万（4 数据集）、仿真约 44.72 万（2 数据集）；统一 34 维接口（左右各 7 关节+1 夹爪+3 位置+6 旋转），缺位零填充并掩码。评测：RoboDojo-Sim 42 任务（泛化/精度/长程/记忆/开放五维，官方协议与完整官方轨迹聚合）；LIBERO 微调对照（基线取已发表数字）；真机五任务（叠衣、瓶子扶正、收纳笔、物品收纳、厨房收纳），与 π0.5 使用完全相同的演示、训练预算、观测、动作空间与初始状态，每任务 100 次独立试验。机制分析用跨样本动作替换与跨流连接掩码（6 批×4 观测时刻，按流时间 τ 分五档统计）。

## 结果、限制与结论

论文报告：RoboDojo-Sim 平均 Score 27.10/SR 20.84%，在对比 WAM 中第一，超过 OpenWAM-α 9.92 分；泛化维 28.20 超过最强开源 VLA Xiaomi-Robotics-1 4.66 分（但仍低于闭源 Simate-beta 的 33.95 与 GPT-6-Astra agent 的 28.97 平均——注：GPT-6-Astra 平均 28.97 略高于 Magic-W0 的 27.10，分类为 Agent 组）。LIBERO 平均 99.1%（Spatial 99.4、Object 99.2、Goal 99.6、Long 98.0），高于 X-VLA 的 98.1 与 Fast-WAM 的 97.6。真机五任务平均 94.6% vs π0.5 的 91.8%，物品收纳 90→95%、厨房收纳 91→95%，瓶子扶正双方均 100%。干预实验：低噪声段仅替换动作条件使未来语义输出位移 D=0.50、3D 运动 0.37、几何 0.26，Lsem 上升 73.5%，且响应随 τ 增大而衰减；掩码 3d→sem 连接使 Lsem +60.8%（约 23 倍于反向连接的 2.6%），移除全部跨流连接 +95.3%，证明层对齐交互参与计算动作条件化的世界转移。

限制：真机评测仅覆盖一种部署配置下的五类任务；RoboDojo 各基线的预训练数据与算力不同，比较不隔离单一因素；结构化世界表征的价值在长程/泛化任务上更明显但开放维（Open 3.00）仍显著弱于 Agent 组；代码与权重发布时标注"coming soon"（仓库当前仅 README 与资源）。对组内启示：3D 几何/3D 运动/未来语义的三段式结构是比"通用隐变量"更可解释的世界监督配方；3d→sem 强非对称依赖提示共享 3D 表征是动作信息流向未来语义的主要通道。
