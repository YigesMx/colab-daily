## 事件概述

OpenAI 于美国时间 2026 年 9 月 29 日在旧金山 Fort Mason 举办 DevDay 2026，CEO Sam Altman 在约一小时的主题演讲中集中发布约 20 项更新，官方主题演讲视频已发布于 OpenAI 官方频道（上传于 2026-09-29）。本次发布的主线是把 ChatGPT 从"问答工具"改造为"替你干活"的系统：常驻智能体 dots、旗舰模型 GPT-6.1 Sol、Ultrafast 推理模式、Pro 500 订阅、ChatGPT Space 协作空间、Agents API 与 Codex 云端版等一并推出。以下分项细节主要为媒体（新智元）对官方发布内容的转述，官方 recap 页面当前对自动化抓取返回 403。

## 已确认事实与证据

- 事件主体、时间、地点已由 OpenAI 官方频道 Keynote 视频页确认（"OpenAI DevDay 2026 Keynote (FULL)"，OpenAI 官方频道，2026-09-29 上传，见证据）。
- dots：OpenAI 首个常驻 Agent 产品，GPT-6 Astra 驱动、自带云端电脑与浏览器、插件生态接入 4000+ 应用、进驻 Slack 与 Teams，关掉窗口后台继续执行；Pro、Business Premium、Enterprise 用户今日起可创建首个 dot，对话不占用 ChatGPT 额度（官方口径，另见本日 Dots 单篇）。
- GPT-6.1 Sol：Astra 级推理与代码能力、约五分之一价格（每百万输入 2 美元/输出 10 美元，缓存读取 0.10 美元），即刻进入 ChatGPT 工作区、Codex 与 API（另见本日 GPT-6.1 Sol 单篇）。
- Ultrafast 推理模式：约每秒 300 Token、约为标准版 8 倍，初期仅支持 Astra，后续开放给 Sol；配套重启 Pro 200 订阅并新增 Pro 500 档位（使用量为 ChatGPT Plus 的 25 倍、可访问 Ultrafast、无 5 小时限制）。
- ChatGPT Space：AI 原生协作空间，人与各自的 dot 在同一页面协作，共享团队知识库；Altman 称"页面和文件在一起，就像一个网盘，但 Space 是活的"。
- 开发者侧：Codex 整体搬上云（环境预配置、可复用、手机遥控）；Codex CLI 支持语音指令与中途改向，新增 /agents 视图；桌面端新增代码审查并可回推 GitHub/GitLab；Codex Security Cloud 按提交扫描整个仓库并准备修复方案；驱动 dots 的底层能力打包为 Agents API（电脑操作、多智能体协作、工具搜索、上下文压缩）；新增 Decisions API（固定选项快速决策，官方演示 78 次选择对 76 次、响应 230 毫秒）；官方称 Responses API 的 Token 流量较一年前增长 100 倍、可用性 99.9%。
- 上述能力数字均为官方发布口径，未经独立复现；Decisions API 对比测试中"准确率与对手打平、速度更慢"为媒体报道的诚实披露。

## 影响与后续观察

- 战略信号：从"先发最强"转向"先发最能干活"，智能体产品线（dots+Space+Agents API+Codex Cloud）与低成本旗舰（GPT-6.1 Sol+Ultrafast）组合拳明确指向企业工作流入口；与 Meta Muse（上线三周下载量超 300 万）、谷歌 Spark、xAI Grok Bot 的个人智能体竞赛全面展开。
- 订阅体系上探：Pro 500（约 500 美元档）针对高吞吐智能体负载，其真实额度与性价比需待实际账单验证（未确认）。
- Agents API 使第三方可自建"dots 类"常驻智能体，安全责任边界（本机授权、只读研究、敏感操作确认）如何随生态外移值得关注；官方安全细节页当前不可抓取（403），其内容以媒体转述为准。
- 后续观察 Ultrafast 对 Sol 的开放时间、Space 从协作到生产的采用率、以及 dots 额度细则（均未知）。
