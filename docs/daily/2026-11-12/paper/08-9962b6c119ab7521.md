## 研究问题与贡献

**Elastic-WAM: Adaptive Spatiotemporal Imagination for Efficient Robot Control**(面向高效机器人控制的自适应时空想象)——一句话结论:用一个统一的"时空精炼需求场"自适应决定世界-动作模型何时停止未来视频精炼、每步去噪推进多远、刷新哪些未来区域,在冻结 WAM 骨干上以三阶段动作接地的监督学出该场,论文报告在 LIBERO/LIBERO-Pro/LIBERO-Plus/RoboCasa-GR1 四个仿真基准上取得无大规模具身预训练方法中的最佳成功率,并在 RoboCasa-GR1 上比 Joint-WAM 降低 32.2% 推理时延,真机长时程泡茶任务全程成功率 50% 对 Joint-WAM 30%。

世界-动作模型(WAM)通过预测未来视觉动态改进机器人控制,但迭代视频去噪带来沉重推理开销;已有加速路线(部分未来去噪、固定精炼预算、甚至推理期完全去掉显式视频生成)都采用固定预算,与经验事实相悖:作者在 LIBERO-Plus 的 10 个任务上实测,取得最高成功率的去噪步数在 1-4 步之间随任务与状态变化;动作对视频的注意力在 future 区域上分布不均,提示只需选择性精炼与动作相关的区域。Elastic-WAM 的贡献:(1)把自适应世界精炼形式化为统一时空需求场——总质量决定"何时停",时间剖面决定"推进多远",空间幅度决定"刷新哪里";(2)冻结预训练 WAM,通过三阶段动作接地监督(时间剖面→相对空间优先级→总需求)学习该场,推理时以循环稀疏精炼执行;(3)仿真四基准+真机长时程双臂任务的系统评估,展示性能与时延同时改善。该工作处于具身智能中世界模型推理效率方向,直接回应 WAM 上机器人的实时控制瓶颈。

## 方法与系统

需求场建模:把 N_F=196 个未来视频 token 按时间与相机视角边界划分成 G=64 个几何感知组(每组 1/2/4 个 token);每组定义局部精炼曲线 q_g(z|s)=a_g(s)·Beta(z;m_g,c_g),z 为归一化去噪进度,a_g 为剩余需求幅值。由于未来 token 共享同一去噪轨迹,参数化为"共享时间基 B_0(z|s)=Beta(z;m_0,c_0)+组间相对幅值":组相对分数 u_rel 经 token 加权中心化得 Δu_g(stop-gradient 隔离),再与共享偏置 b_0 经 sigmoid 融合为 a_g;全局需求 D(s) 是 token 加权幅值之和,b_0 控制总量、Δu_g 控制相对优先级。三问映射:WHEN——把 D(s_k) 视为条件继续概率,构造累积 World Commit 概率 F_k=1-∏C_j,F_k≥0.5 即停止;HOW FAR——把归一化时间剖面的众数 m_0 映射为去噪步长(δ_min=0.05,δ_max≤0.20 并受噪声区间约束);WHERE——在精确 token 预算 K0=96 下按 Δu_g 选组刷新(学习分数定序,预算定量)。三阶段训练(WAM 全程冻结,梯度只过其计算图):(1)时间剖面——从同一循环状态比较"立即提交"与不同推进距离的继续,以终端动作误差(0.6 序列误差+0.4 相邻差误差)转成软目标监督 B_0,并训练一个提供停止监督的 temporal teacher;(2)空间优先级——在同一去噪态比较稠密教师与可微稀疏学生(直通估计保持硬选择),损失为动作 GT+动作蒸馏+0.1 视频 GT+0.01 预算正则,训毕冻结相对空间分支;(3)总需求——用冻结 teacher 的 hazard 预测构造目标继续质量,单调映射回目标 b_0,用完整循环前缀监督条件/累积停止与提交时机,加低权重终端反事实校正。推理:每轮重规划先做一次稠密联合去噪建立循环状态与 KV 缓存;此后选定组的未来视频 query 重算,未选组复用缓存隐态/KV/上次刷新速度,观测与动作 query 保持稠密且保留完整逻辑注意力上下文;World Commit 后直接复用当前视频表征与逐层缓存继续动作去噪,无需额外视频预填。

## 实验设置与数据

仿真:LIBERO(标准操作)、LIBERO-Plus(七类视觉/环境扰动)、LIBERO-Pro(物体/位置/语义/任务变化泛化)、RoboCasa-GR1(复杂操作+推理时延,报告平均成功率与毫秒级时延);LIBERO-Plus/Pro 用 LIBERO 训练的策略直接评估,不再适配。对比方法:π0.5、OpenVLA/OpenVLA-OFT、π0/π0-Fast、UniVLA、WorldVLA、Motus、Fast-WAM、Joint-WAM、LingBot-VA、GR00T-N1.6、StarVLA 等(各表选取相关子集),精炼场学习期间预训练 WAM 保持冻结。消融(RoboCasa-GR1 与 LIBERO-Plus):学习式空间选择 vs 同预算随机选择/更大预算全激活/FirstKV(复用初始视频缓存);仅 WHERE vs +自适应 WHEN vs +自适应 HOW FAR;token 预算 K 取多档。真机:双臂平台(两台 UFACTORY xArm 7)四阶段泡茶任务(放杯、倒茶、归位等),三种条件——名义、强光照变化 OOD(霓虹灯)、物体替换 OOD(白杯换银色异形杯),每方法每条件 20 次试验,报告全程成功率 SR 与平均任务进度 PS。场的关键常量:未来视频共 N_F=196 个 token 划为 G=64 组,稀疏刷新预算默认 K0=96,World Commit 阈值 0.5,单步去噪推进限制在 0.05-0.20 之间,时间剖面的教师监督用 0.6 序列误差加 0.4 相邻差误差的终端动作误差。动机实验在 LIBERO-Plus 10 个任务上统计最优去噪步数分布、状态间差异与动作-视频注意力图。

## 结果、限制与结论

论文报告值:LIBERO 平均 98.8%(Long 98.2)为表中最优,高于 Joint-WAM 98.5% 与 LingBot-VA 98.5%;LIBERO-Pro 平均 54.1%(语义 97.7、任务 24.7 最高),超 Joint-WAM 52.8% 与 π0.5 53.4%;LIBERO-Plus 平均 73.7%,超 OpenVLA-OFT 69.6% 与 LingBot-VA 69.5%,语言(95.5)、光照(95.1)、布局(81.4)单项最高,相机 52.1/机器人 76.3 为次优;RoboCasa-GR1 成功率 57.4% 最高(Joint-WAM 55.0、Fast-WAM 54.9),时延 388.2ms 比 Joint-WAM 572.6ms 低 32.2%(Fast-WAM 331.1ms 但成功率更低;π0.5/GR00T/StarVLA 约 80ms 但成功率 37.0-48.8%)。消融:学习式空间选择优于随机选择、更大预算全激活与 FirstKV;WHERE 之上加 WHEN 再加 HOW FAR 逐步提升;预算 K=96 最优,更大预算反而降低成功率——刷新更多未来 token 并不必然改进控制。真机:名义与光照 OOD 全程成功率 50.0%(Joint-WAM 30.0,Fast-WAM 0),物体 OOD 与 Joint-WAM 持平 30.0% 但任务进度 47.5 对 35.0;PS 全部条件最高。局限与未报告项:真机仅单一泡茶任务、每条件 20 次,样本量有限;物体 OOD 下全程成功率与 Joint-WAM 无差异,优势只在进度分;对比的时延基线中非 WAM 方法(π0.5 等)时延低一个数量级但成功率也低,论文将其定位为不同取舍而非直接等价比较;精炼场学习需要动作接地监督与循环前缀训练,三阶段流程的工程复杂度与训练成本未完整报告(当前材料未确认);无大规模具身预训练方法内部比较的边界(π0.5 等本身有大规模预训练)由作者自行设定。笔者分析:该工作把"计算该花在哪"从固定超参升级为可学习的场,WHEN/HOW FAR/WHERE 三问的分解清晰、消融完整,对 WAM 走向实时机器人控制有直接工程价值;其"稀疏刷新但保留完整注意力上下文"的设计也提示视频世界模型的 KV 缓存复用是效率优化的富矿。
