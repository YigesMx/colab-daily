## 事件概述

2026 年 11 月 10 日，在 KubeCon + CloudNativeCon 期间，NVIDIA 宣布扩大开源承诺：把面向自主智能体安全与治理的开源运行时 NVIDIA OpenShell 捐赠给云原生计算基金会（CNCF）作为 Sandbox 项目；同时为 Google 主导、同样进入 CNCF Sandbox 的智能体负载框架 Agent Substrate 贡献代码；并发布 NVIDIA DSX AI 工厂平台的三个新开源组件：NVIDIA Kubernetes Engine、NVIDIA Kubernetes Recipes 与 NVIDIA Snapshot。官方将这一组动作定位为让 Kubernetes 成为大规模 AI 工厂负载的主导基础。本文证据为 NVIDIA 官方博客全文存档。

## 已确认事实与证据

以下均为官方公告口径（发布方宣布）：

- OpenShell：为自主智能体提供安全运行环境与治理，对智能体活动施加确定性控制，在智能体使用工具、访问推理服务、执行负载时执行策略；可扩展架构允许组织接入自有算力、推理提供商、凭证存储与监控工具，从而跨部署环境统一治理并接入既有企业系统。官方称已有数百家组织使用，上线不到一年收到数万次贡献。Linux 基金会 CEO Jim Zemlin 评价称，云原生社区面临“给智能体提供安全运行环境”的新基础设施挑战，该捐赠为开发者提供了共享基础与塑造智能体安全演进的机会。
- Agent Substrate：Google 发源、已被 CNCF Sandbox 接纳的长时程智能体负载框架；NVIDIA 参与贡献并确保其与 NVIDIA Dynamo（模型推理）及 KAI Scheduler（共享集群资源调度）协同，把智能体执行、推理服务与资源调度汇聚到 Kubernetes 上；框架可在智能体空闲时释放算力、跨共享智能体池挂起与恢复环境。NVIDIA 与 Google 还在合作 OpenShell 与 Agent Substrate 的集成，使企业能跨云与本地环境安全治理智能体。
- NVIDIA Kubernetes Engine（NVKE）与 NVIDIA Kubernetes Recipes（NVKR）：即日起公开预览的开源构建块，用于在 GPU 基础设施上交付托管 Kubernetes 服务，自动完成集群生命周期管理并提供签名、版本固定的镜像；Mirantis、Netris、OpenNebula Systems、Rafay、Spectro Cloud、vCluster 以及 Firmus、SK Telecom 已就集成计划与 NVIDIA 对齐。
- NVIDIA Snapshot：开源模块化组件，解决推理容量快速扩容问题，可在数秒内恢复检查点副本，无需模型重载或预热，加速启动、故障恢复与弹性伸缩。设计伙伴 Crusoe（亦为上游贡献者）在 Crusoe Cloud 上用 NVIDIA HGX B300 系统测试 GLM-5.3，就绪时间由约 8 分钟降至 31 秒；Saturn Cloud 的基准测试中 vLLM 启动时间由 2 至 8.5 分钟降至 6 至 34 秒。

## 影响与后续观察

- OpenShell 进入 CNCF Sandbox 后的治理转移、维护者构成与版本路线由社区决定；Sandbox 为早期成熟度阶段，企业采用需评估风险。
- NVKE 与 NVKR 处于公开预览，正式发布时间、支持边界与版本策略未知。
- Snapshot 的收益数据来自 NVIDIA 设计伙伴，第三方工作负载的收益需独立验证；对非 NVIDIA 加速器的支持未提及。
- OpenShell 与 Agent Substrate 集成的发布节奏，以及与既有智能体框架和安全策略工具的兼容性，待后续观察。
