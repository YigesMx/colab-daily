## 事件概述

2026 年 11 月 11 日，蚂蚁灵波科技（Robbyant）发布并开源通用触觉基座模型 LingBot-Touch，把视触觉、磁触觉、压阻式三类原理不同的触觉传感器信号，统一转换为动作模型可以直接使用的“通用触觉 Token”，使机器人获得可跨硬件迁移的“手感”。官方项目主页、GitHub 仓库（含技术报告目录）、Hugging Face 与魔搭社区集合页同步上线，本文已直接核验项目主页与 GitHub 仓库在线并存档。新智元同期发布长文报道，将此次发布置于“视觉大模型有眼无手、真机精细操作频繁失败”的背景下解读。

## 已确认事实与证据

已直接核验：

- 官方项目主页 technology.robbyant.com/lingbot-touch 与 GitHub 仓库 github.com/Robbyant/lingbot-touch 在线，仓库内含技术报告目录与论文入口；项目主页配图为官方发布的模型示意图（已存档为图片证据）。

以下为新智元报道口径（媒体转述官方数据，未独立核实）：

- 统一表征：视触觉（指尖相机拍软胶形变，细但帧率受限）、磁触觉（软磁材料受力改变磁场，擅长多向力与滑动但怕磁场干扰）、压阻式（受压变电阻，成本低可铺满但分辨率有限）三类信号，被统一映射到“手指碰在哪、用了多大力、力往哪边走、有没有在滑”四个共性问题；触点统一映射到三维指尖球面坐标（5D-RoPE）并随机微调疏密，防止模型死记单一硬件排布。
- 轻量即插即用：Tiny 版仅 532 万参数，接入三大主流动作模型后参数量只增加 0.13% 到 0.16%。
- 真机成绩（两款构型灵巧手、四款主流动作模型，26 项真机任务与 12 项仿真操作）：抓喷雾瓶喷水成功率由 42.50% 升至 87.50%；全程不看牌面的盲摸麻将分拣成功率翻倍至 70%；T-Rex、π0.5、LingBot-VLA 三大动作模型平均成功率分别提升 23.18、21.81、24.81 个百分点；单页翻书 91.25%、按压弹出 SD 卡 92%、搬运软纸杯最高 100%；仿真转盘子、转笔成功率超 97%，纯视觉 0 分的端托盘平衡滚球达 67.7%。
- 数据：近 5000 小时（4983 小时）、13.3 亿帧真实触觉数据，约三分之二来自真人佩戴轻便触觉手套在日常生活中采集，其余来自真机遥操作；预训练磁触觉数据 100% 来自人类手套，把触觉模型参数完全冻结后直接装上从未见过的新款磁触觉灵巧手，π0.5 平均成功率由 48% 升至 74.17%，搬运软纸杯由 58% 升至 90%（零样本跨硬件迁移）。
- 架构：Tactile-JEPA 借鉴 JEPA 思路，遮住高达 90% 的触点区域（抓握时超过 90% 触点读数为零值底噪），让模型推断被遮区域的受力而非还原原始读数，跨模态检索前 5 名召回率由传统方案的四千小时 3.06% 与 8.69% 提升到 49.32%。
- 对比测试：允许开源模型 FTP-1 外挂硬件专用适配器、LingBot-Touch 全程冻结权重的五项物理接触测试中，指尖盲摸定位误差由 2.19 毫米压至 0.12 毫米（新款磁触觉灵巧手上 0.16 毫米）；指尖三维力感知误差降低约 65%；装入同一动作大脑测 5 项真机任务平均成功率 82.2% 对 67.5%。
- Scaling：在近 5000 小时数据量级上观察到触觉 Scaling，三类传感器数据混训全面优于单类；Tiny 版约 4000 小时后趋饱和，容量更大的 Small 版持续上升。
- 落地（厂商称）：已联合多家机器人本体厂商与行业伙伴，把具身大脑能力带进零售药房、仓储物流和工厂产线；今年已先后开源空间感知模型、世界模型与跨本体动作模型，LingBot-Touch 补齐“具身大脑全栈 2.0”中触觉一环。

背景（报道转述第三方测试）：RoboDojo 测试团队把 GPT-6 Astra 接上真机挑战插充电器与插试管，因缺乏触觉在插头卡死后仍继续施力撞坏硬件，33 次真机测试成功率 0%；Fable 5.2 在同一模拟测试中得分 64.9%。该说法未经本文直接核验。

## 影响与后续观察

- 官方技术报告的完整基准表、开源许可证类型与 5000 小时数据是否公开，需从 GitHub 仓库进一步核对。
- 盲摸麻将、插孔对准等任务与产线真实工况之间的差距，以及人类手套数据零样本迁移在更多本体上的稳定性，需要第三方复现。
- 触觉传感器厂商、灵巧手与整机厂的采用情况（报道提到的“指尖视触觉+手掌压阻阵列”混合方案）尚无公开案例。
- 与 GR00T 2 等不接收触觉输入的动作基础模型互补还是融合，是后续值得观察的工程方向。
