## 事件概述

谷歌 DeepMind 正式发布 AlphaGenome Atlas，一个覆盖人类基因组全部潜在单碱基突变的前沿 AI 可搜索预测数据库。据官方博客（2026 年 9 月 8 日发布，本次已直接抓取核验），该平台包含对约 90 亿种单核苷酸变异（即每一个可能的单字母改变）分子效应的预测，体量约 1PB，是 AlphaFold 数据库的 30 倍以上，被官方定位为迄今最全面的基因突变分子影响图谱，并通过免费网页门户、AlphaGenome API 与 Google Antigravity 智能体技能三种方式开放使用。新智元将其称为 AlphaFold 绘制「蛋白质宇宙」之后，AI 对人类生命密码的又一次全局性测绘，DeepMind 首席执行官 Demis Hassabis 亦表示「AlphaFold 绘制了蛋白质宇宙，现在 AlphaGenome Atlas 开始绘制人类基因组」。

## 已确认事实与证据

以下事实已在本次直接抓取的 DeepMind 官方博客页面中核验：

- 平台名称与规模：官方博客标题为「AlphaGenome Atlas: A predictive map of every possible DNA letter change in the human genome」，明确表述「包含对 90 亿种单核苷酸变异——每一个可能的单字母改变——的效应预测」，并称其为「最全面的基因突变如何影响分子生物学的目录」，供学术研究免费使用。
- 数据体量：AlphaGenome Atlas 是一个约 1PB 的数据集，超过 AlphaFold 数据库的 30 倍；提供网页门户、AlphaGenome API 与 Google Antigravity 技能三种访问方式。
- 统一评分：官方发布 AlphaGenome Variant Impact（AVI）评分，融合 AlphaGenome（擅长基因调控）与 AlphaMissense（擅长蛋白编码变异致病性预测）两种模型的能力，将编码区与非编码区变异压缩为单一数值，供研究者快速排序；同时提供 AVI 特征归因，指出每个变异最可能扰动的分子过程（如 RNA 剪接或基因表达）。
- 罕见病实战：Broad 研究所的 Laura Covill 与 Anne O'Donnell-Luria 团队用 AVI 评分对未确诊罕见病候选变异重排序，发现 DNM1 基因变异（与癫痫性脑病强相关）；官方博客确认「AlphaGenome 的预测提示其影响剪接」，与媒体报道的「创造错误剪接位点、蛋白质异常延长、湿实验证实」机制一致。
- 群体遗传学实战：埃克塞特大学 Gareth Hawkes 将 Atlas 应用于超过 5.4 万名英国生物样本库参与者的全基因组数据，按预测分子效应对罕见变异分组，多发现 22% 的非编码遗传关联（官方博客确认数字）。
- 官方博客还确认发布了「超过 2500 种反复出现的 DNA 序列——基因组的『词』——及其位置」的全基因组 de novo 模体（motif）合集。

以下数字出自新智元报道（转述自官方材料，未在博客页面直接核验到）：每个变异约 27000 项预测指标、总计超 240 万亿个预测值、提炼出 2601 个高频 DNA 模式并标注 2530 亿个实例、计算流水线提速 80 倍（DeepMind 基因组负责人 Žiga Avsec 透露）、BMI 分析中识别出 19 个遗传区域、涉及 PLA2G7 与 EGLN1 的循环蛋白调控变异。

## 影响与后续观察

- 对生命科学研究：非编码区（约占基因组 98%）变异解读过去需要 GPU 资源、资深生信工程师与复杂管线，现在通过浏览器检索即可完成，研究者从变异出发可逐层追查其影响的调控元件、核心模体与转录因子，显著降低门槛。
- 对罕见病诊断：先期合作中已出现「AI 预测重排序定位致病变异并经湿实验证实」的完整案例，为未确诊病例提供新路径；此前临床应用范围与准确率仍属早期。
- 待观察：Atlas 在真实临床流程中的验证进度；预测错误率与适用边界；API 与 Antigravity 技能的生态采用情况；相关论文的同行评审结果（官方称详细内容见其论文）。
- 未确认事项：商业使用条款细节、平台长期维护与更新频率、与既有 GWAS/功能基因组数据库的整合深度。
