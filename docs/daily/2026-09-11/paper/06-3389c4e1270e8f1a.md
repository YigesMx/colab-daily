## 研究问题与贡献

大规模人类动作模仿训练出的全身人形跟踪控制器是可扩展的运动先验,但被刻意设计为对环境"失明":遇到台阶、飞来小球或需要调整抓握时,它没有任何观测可供反应,环境修正全部推给上层规划器。现有感知控制器通常从零训练仅几何的编码器(以语义换仿真到现实迁移的便利)并依赖教师–学生蒸馏。ViBe(南加州大学 Quan Nguyen 团队)提出针对运动跟踪器的视觉行为适应后训练框架:利用预训练视觉编码器加一个多查询提取器模块学习任务相关的感知反馈,经低秩适配器嫁接到跟踪器输入端,实现参数高效微调;给定任务奖励与参考数据集,即可直接用策略优化适配,无需蒸馏或辅助表征损失。贡献有二:一是连接冻结视觉编码器与冻结全身跟踪器(SONIC)的任务条件化提取器 + LoRA 适配器、直接强化学习后训练的视觉行为适应框架;二是在四类任务上实现零样本仿真到现实迁移:路缘与跑酷感知行走、Repose Cube 立方体重定向、泛物体移动操作、躲避球,并在户外强光、低光与 RGB 干扰条件下保持视觉鲁棒;另用刻意简单的固定例程规划器完成目标导向的 Repose Cube 任务,验证感知控制器的效力。

## 方法与系统

ViBe 只学习紧凑的"提取器–适配器"通路,两个预训练先验(视觉编码器与全身跟踪器)全部冻结,策略初始与基础跟踪器一致(适配器零初始化),动作标准差固定。系统三模块:默认视觉编码器为 Theia-Tiny ViT,处理自主体 RGB 图像输出 patch token 网格与全局 CLS token;提取器用单头交叉注意力,以 patch token 为 key/value,查询由三个信号经各自归一化投影构成——全局图像 token、机器人本体感知、可选任务命令,每个查询产生一个注意力加权的 patch 网格摘要;三摘要拼接后投影为固定 128 维感知向量并做层归一化(固定尺寸使控制器接口与图像分辨率和编码器隐维解耦,查询信号只引导 patch 选择、不直接进入感知)。该感知量条件化冻结跟踪器解码器中的 rank-16 LoRA 适配器。训练采用非对称 actor–critic 的 PPO,仅更新提取器与适配器;奖励为运动跟踪奖励与任务奖励(如物体朝上面、目标位姿、避球)之和。另提出参考相位退火课程:参考状态初始化的相位上界随迭代线性收缩,从全参考均匀采样逐渐过渡到总是从第零帧开始,迫使策略掌握完整参考。四任务各有定制:Repose Cube 用 78 条自采参考加"上面朝向"奖励与面 one-hot 命令;行走/跑酷分别用 GRAIL(63 条,多地形映射)与 OmniRetarget(9 条,每条配专属地形);泛物体移动操作在同一环境中放多种物体训练共享策略以防单几何记忆;躲避球参考为站立位姿但需动态感知偏离。

## 实验设置与数据

平台为 Unitree G1 人形机器人,仿真基于 mjlab(MuJoCo Warp),借助 GPU 批量渲染器在 112×63 分辨率下训练,单任务两天内可完成,硬件横跨 RTX 3090、RTX 5090 与 L40S;控制与头部 RealSense D435i 相机均运行于 50 Hz。仿真中随机化相机外参、光照、地面外观、机器人参数与外部扰动以保障迁移。评测包括:与特权观测训练对比(验证是否需要蒸馏);与盲跟踪器的受控对比(相同基座与参考,仅视觉通路不同);视觉鲁棒性硬件测试(户外正午强光行走、低光与彩色移动光照下的立方体重定向);带简单规划器的目标色 Repose Cube 硬件演示(重复"右翻、右翻、前翻"固定例程,规划器无动力学模型与前瞻 rollout,只从固定数据集选片段)。消融以 Repose 任务(成功判据:目标面与竖直夹角在 17.2 度内)展开:编码器选择(Theia-Tiny、DINOv3-S+、SigLIP2-B、从零训练 CNN)、查询消融(去 CLS、去本体感知、去任务命令)与相位退火有无。

## 结果、限制与结论

直接视觉学习的 ViBe 在感知行走、跑酷、泛物体移动操作与躲避球上分别达到对应特权策略的 89.6%、95.5%、90.3%、94.7%,无需教师动作目标即逼近特权性能,证明后训练无需师生蒸馏。盲基线在路缘上碰撞失稳、全局漂移,ViBe-SONIC 调整落脚点成功登上台阶;跑酷中更紧密跟踪运动速度、积累起跳所需动量。硬件零样本迁移覆盖非平坦地形、携带大物体重新定位、经反复接触翻转立方体、躲避动态来球;户外强光、低光与移动彩光下仍有效。消融:DINOv3-S+ 最佳,各预训练骨干成功率标准差仅 2.8% 且全部超过从零训练的 CNN;去掉 CLS token 或本体感知查询各降约 15 个百分点(93.1%→约 78%),去任务命令反而略升至 93.4%(作者认为与该任务命令性质有关、待跨任务研究);相位退火把成功率从 88.5% 提到 93.3%,并稳定不同任务的学习动态。局限有二:动态干扰物仍可能触发错误反应(如躲避球中把投掷者头部误认作球而多余闪避),需更多域随机化事件学习必要不变性;规划器与控制器未闭环联合训练,规划器可能选出适配器训练分布外的参考转移,虽冻结跟踪器保住基本跟踪,任务最优性能需闭环参考生成器。总体给出了一条保留预训练模块、只学中间连接的通用人形感知控制配方。
