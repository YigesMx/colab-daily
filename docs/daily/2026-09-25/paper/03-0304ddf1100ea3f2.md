## 研究问题与贡献

BEE（arXiv:2609.27450，华南理工大学与智元机器人 AgiBot 合作，17 位作者，通讯作者 Xiaohan Yan）研究 VLA 模型的真机在线强化学习问题：VLA 能执行长程多阶段任务，但成败往往取决于少数毫米级精度关键阶段（对准、插装），在线 RL 恰好能优化这些动作，但真机上自由探索代价过高，人类干预（correction）不可或缺。既有方法要么无法接入人类纠正（DSRL 只在 VLA 潜空间搜噪声），要么把纠正当作无差别监督（RLT 用人类动作直接替换 VLA 提案）。BEE 的核心洞察是：人类纠正在不同动作维度上可靠性不同——某些维度一致、某些维度多变——因此应建成分维度、不确定性感知的约束，而不是统一模仿。BEE 让策略"BEyond Expert imitation"：在冻结 VLA 之上，三个真机任务与一个 LIBERO-Pro 仿真任务上全部取得最高成功率，且真机任务人类干预率最低。

## 方法与系统

BEE 构建在 RLT 风格的 chunk 级 VLA-RL 接口上：冻结的 π0.5 VLA 输出动作提案 ã_t，其内部特征经 Extractor 映射为潜 token，与本体状态拼接构成 RL 状态；chunk 级 critic 用 K 步 Bellman 目标离线训练。在此之上 BEE 加了四个组件：(1) 轻量确定性 Residual Policy，输出对 VLA 提案的残差，实际执行 a_θ = ã_t + Δ_θ(s_t, ã_t)；(2) proposal 条件化高斯 Correction Model q_φ，输入当前状态与 VLA 提案，预测"人类会怎样纠正该提案"的残差分布（均值 μ_φ 与对角协方差 Σ_φ），只在人类纠正 buffer B_H 上以负对数似然训练，且保留 (ã_t, a^H_t) 配对而非替换提案；(3) 分维度 Mahalanobis 约束 ρ_φ = (1/D)(a_θ − â^H)ᵀ Σ⁻¹ (a_θ − â^H) ≤ ε，预测均值作为可行集中心、各维方差决定几何——纠正一致的维度约束紧、多变维度放松；(4) 状态相关乘子 λ_ω(s_t) 的 primal-dual 优化，actor 目标为 −Q + η‖a_θ − ã‖² + λρ_φ 经 (1+λ) 归一化。Correction Model 采取保守更新节奏（每 M 个新纠正样本才更新 NM 步）防止小样本方差坍缩。训练时加 TD3 式探索噪声；部署时 Residual Policy 直接驱动机器人，推理开销不增。

## 实验设置与数据

三个真机任务（每个 30–60 秒、约 900–1800 控制步、30 Hz）：Phone Charging（双臂，右臂取充电器对准插入，动作 16 维、chunk 长 K=10）、Snack Hanging（抓取可变形零食袋挂上挂钩）、Cloth Aligning（抓布对齐放到框上，用视觉稠密奖励，其余任务稀疏完成奖励）；仿真任务为 LIBERO-Pro 的 Bowl Placing。基线：Base Policy（π0.5 SFT 后）、RLT、DSRL（附加 DAgger/SiLRI/HIL-SERL 在附录）。协议：所有方法同一微调 VLA 起点、匹配在线数据预算（约 20 段预采人类纠正 + 固定在线 episode 数）；成功率按 3 轮 × 20 试验均值±标准差；干预率为训练中人类接管控制步占比。Phone Charging 与 Cloth Aligning 只在精度关键阶段计成功。

## 结果、限制与结论

论文报告总平均成功率 BEE 91.2%，对比 RLT 57.5%、DSRL 42.1%、Base 38.8%；逐任务：Phone Charging 100%（Base 90.0、RLT 58.3、DSRL 93.3）、Snack Hanging 85.0%（Base 0.0）、Cloth Aligning 90.0%（Base 36.7）、Bowl Placing 90.0%（Base 28.3）；真机干预率 BEE 总体 30.5% 为最低（RLT 49.0%）。样本效率上 BEE 在两个任务所有预算点均高于 RLT，且训练全程动作平滑接近人类。校准分析显示人类纠正在 7 个关节维上的经验标准差相差约 3 倍（q2 最一致、q7 最多变），Correction Model 预测的不确定性 σ 与经验分布模式吻合，纠正后动作在所有维度都比 VLA 提案更接近人类纠正。约束分配分析显示 Mahalanobis 形式把约束份额集中到低不确定维度（q2 最大、q7 最小），而 state-wise 等权形式会把最大份额浪费在高不确定的 q5。消融：去掉 Correction Model（直接用原始纠正监督 actor）与去掉 proposal 条件化是最弱变体；去掉 Mahalanobis（退化为 state-wise）次之。

局限：任务规模较小（3 真机 + 1 仿真任务）；人类纠正分布的建模依赖干预数据量；附录另有 DAgger/SiLRI/HIL-SERL 比较但本文未展开失败案例细节。对本组启示：把人类干预建模为"约束证据"而非"模仿目标"，是把 HIL-RL 与 VLA 结合的一条有理论支撑且真机验证过的路线；分维度不确定性加权值得在其它残差 RL 场景复用。
