## 研究问题与贡献

COMPASS（arXiv:2609.28247，宾夕法尼亚大学 GRASP 实验室 Vijay Kumar、Alejandro Ribeiro 团队等 5 人）研究如何用自然语言指挥大规模机器人集群。LLM 给机器人规划带来零样本能力，但团队规模一大就在简单多机器人任务上失败；向语言模型灌输队友状态还会"腐蚀"其对原任务的推理。COMPASS（COmmanding Multi-robot Policies with Attention and Semantic Steering）是一个在"推理空间"运行的分布式反馈控制架构：把空间 transformer（MAST）接入每个机器人本地 LM 的环路，将集群嵌入聚合成反馈 token 注入 LM。三大贡献：(1) 规模——在千级集群上零样本泛化到 16 倍训练团队规模；(2) 结构化多样性——可将同一任务的不同措辞分散到集群，让跑"更易措辞"的少数提升集体准确率；(3) 泛化——仅靠学习的 query-only 接口，把未见过的方向指令接地为可执行意图。

## 方法与系统

每台机器人维护一个持续"程序"PROG_i = [P ∥ T ∥ f ∥ g]：算子提示 P、思维链 T、反馈 token f、学习到的目标 token g，全在 LM 嵌入空间。快物理系统由 MAST（multi-agent spatial transformer）推进，慢推理状态 z_i(t) 在反馈刷新时从程序重导出：z_i(t+1) = φ_{1:ℓ}(P ∥ T ∥ ψ(π_i(t)) ∥ g)，其中 φ_{1:ℓ} 取 LM 前 ℓ 层（LM 权重全程冻结，只学 f、g 与 MAST）。"思考"阶段每台机器人对同一提示独立采样自己的思维链（160 token 长度经验最优，120/320 均有验证），完成后 KV 缓存冻结直到提示变更；因果掩码下终端位置的 f/g 可查询整个程序而语言 token 不注意它们，使环路 token 无需落在语言流形上，简化学习。"潜推理"层 z_i 即目标 token 位置的隐藏状态，提取深度 ℓ 是设计参数（模糊指令需更深但非单调）。MAST 把推理状态与观测状态拼接为输入 token，经 2D RoPE（仅相对位置进入注意力，平移不变且保持置换等变）在通信图上多跳扩散：输入含本机速度、邻居均值距离与对邻均的速度误差；同一 MAST 输出既投影为低层控制动作，也经适配器 ψ 变成反馈 token 回馈 LM 下一轮推理。每台机器人结构相同地部署，虽以中心化空间掩码训练。

## 实验设置与数据

测试床为语言指挥的集群飞行（flocking）：航向误差可直接以质心航向对指令真值的偏差度量，且需兼顾避撞（向专家学习而非脚本）与仅靠邻居交互涌现的全局一致。训练用行为克隆模仿中心化势场专家（对齐+目标跟踪+内聚+排斥四项），加 DAgger 重标注与截断 BPTT；专家 rollout 取 N=[32,64]、10 秒、密度 0.25 台/m²。语言侧 7 类训练提示（Plain/缩写/反义/地图/时钟/数值 720 方位/Hold），Qwen3-1.7B 以 temperature 0.6 生成每提示 64 条思维链；方向映射 8 点罗盘 + STOP，航空约定（北 0° 顺时针）且从不在提示中告知。评测：双积分器机器人、60 秒 rollout、同初始条件同种子对比；对手包括其专家 oracle、Claude Opus 4.8 中心化 LLM 控制器、无通信消融（r_c=0）与语言-only 通信消融（把邻机状态写进提示）。指标：航向误差、碎片数、速度方差、最近邻距离变异系数 CV。MAST 4 层 256 隐维 8 头，通信半径 4 m。

## 结果、限制与结论

论文报告：规模上 COMPASS 训练于 N=32/64，评测至 N=1024，航向误差随规模下降（N=8 时 2.79° → N=1024 时 0.34°）——集体多样推理经 MAST 多跳整合反而更准；"12 点方向"指令下 1024 台分布式集群以 5 m/s 北向迁徙。语言-only 通信在 N=64 分裂成 15 组、均速仅 2.5 m/s（目标一半），诊断显示思维链被邻机状态推理淹没、无暇判断航向——比彻底去掉通信还差；中心化 Claude Opus 4.8 能解码语义方向但随 N 增大输出数量错乱、加速不协调导致集群碎裂。结构化多样性：全员同措辞或全员不同模糊措辞均无收益，但让 1/4 集群跑更易措辞即可在航向误差与速度上恢复意图，且优势跨规模保持。泛化：训练 8 点罗盘，16 点 wrapper 零样本上周向次级方位（NNE 等）平均误差 7.96°±4.41°（24 试验 18 次落扇区内，最差 NNE 13.2°、最好 E 侧 1.7°）；720 数值方位训练使未见数值方位平均误差 2.2°±1.6°，但并不改善语言次级方位——语言接地独立于数值。引擎权衡：Qwen3-0.6B/1.7B/4B 模糊指令相对误差 1.00/0.80/0.65（延迟 3.7–5.0 s、显存 1.2–7.7 GB），默认 1.7B 兼顾边缘部署与泛化。局限：任务限定于语言方向飞行（作者称该环路可推广到可验证、语言可表达目标的任务）；仿真双积分器模型；真实空域通信与时延未验证。对本组启示：小 LM + 学习反馈 token 的"推理空间控制"让集群扩展性反超中心化大模型；"结构化措辞多样性"这一集体推理技巧对多智能体 LLM 系统的指令设计有直接借鉴意义。
