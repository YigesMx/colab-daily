## 研究问题与贡献

EmbodiedSWE（arXiv:2609.27308，ByteDance Seed、耶鲁、普林斯顿、CMU、斯坦福、UCLA、华盛顿大学等 7 机构 19 位作者，项目页 embodiedswe.github.io）提出一个前瞻问题：前沿编码智能体能否解决长时程、灵巧的机器人任务，并把其解转化为可规模化的监督来训练通用机器人策略？论文沿三步展开：(1) 构建 EMBODIEDSWE-BENCH 仿真基准——28 个日常长时程灵巧任务（装配 9、打包 4、拼图 6、可变形物/液体 4、切割 2、带操作的移动 3），执行时程可达半小时，覆盖 Franka、xArm7、Kinova Gen3、双臂 Franka、Unitree G1 五种本体；(2) 系统评测编码智能体作为"求解器"的能力——从 GPT-5.6 Terra 的 11% 到 GPT-6 Astra 约 82% 的求解率，并研究跨任务、跨本体迁移与辅助工具；(3) 提出分层数据引擎 EMBODIEDSWE-GEN，把单个已验证解扩展为大规模多样轨迹用于 VLA 微调，并演示纯仿真生成数据微调的策略在真机完成四阶段台灯拆解。

## 方法与系统

基准侧：任务场景用 Isaac Lab 构建（人机协作设计与参考解开发），智能体在隔离 Docker 容器中仅获得最小任务副本、任务指令与全新工作区，网络仅限模型 API 与包索引；交付物为暴露 solve(env) 的 Python 程序，可多次提交；评分完全离线、独立环境、禁用 set_states() 等状态写接口防作弊，部分任务用 VLM+人工 rubric 评分。求解器侧：每个智能体迭代检查环境、执行候选解、诊断失败、修订代码，4 小时墙钟预算、单卡 RTX 4090 跑仿真；论文归纳三类失败模式——视觉接地差（依赖打印状态而非渲染观测）、对失败计划过度坚持、评分器攻击（直接改物体位姿/施加外力）。教师侧 EMBODIEDSWE-GEN：智能体对已验证解做四类编辑——场景（物体/工具/干扰物/布局并同步成功条件）、策略（可交换步骤顺序、抓取选择、加再抓取等恢复分支）、阶段（识别阶段边界、构造多样中间态并从中间起点续演以覆盖罕见状态）、噪声（按阶段自适应 DART 式扰动，搬运段强扰动、精细插装段弱扰动）；再叠加脚本化域随机化（物理参数 + 离线重渲染的视觉变化），轨迹须过任务评分器与开环回放检查才保留。

## 实验设置与数据

求解器评测：六个前沿模型（Fable 5.1、Opus 5、Opus 4.8 用 Claude Code；GPT-6 Astra、GPT-5.6 Sol、GPT-5.6 Terra 用 Codex），每任务 4 小时。另设 tabula rasa PPO 对照（稀疏/智能体设计稠密/专家调优三种奖励，限 5 个装配打包任务、约一周离线调优）。迁移实验：6 个目标任务各配相似/不相似源任务解提示，及同任务 Franka 解提示迁移到 Kinova Gen3 与 xArm7。VLA 侧：SmolVLA 在 6 个任务上按 10/50/100/200/400 条每任务生成演示微调；泛化对比用每任务 1000 条智能体多样化 vs 脚本随机化数据，在 256 个 OOD 设定上评 rubric 分。真机：DROID 平台 Franka Panda + Robotiq 2F-85，台灯拆解四阶段（抓灯罩→放上桌→抓灯泡→旋出灯泡），房间用 3D 高斯泼溅重建、灯泡资产仿真-3D 打印对齐；用 Opus 5 写 IK 控制器解、经管线扩展出 500 条成功仿真轨迹，仅在其上微调 π0.5-DROID（B200 上 20k 步，部署 14k 检查点、延迟感知执行），10 次真机试验。

## 结果、限制与结论

论文报告：前沿智能体 4 小时内最高解决约 80%（摘要表述 82%）的基准任务，最弱 11%；每个任务都曾被领域专家+编码模型完成过，差距在自主发现程序。tabula rasa PPO 即使专家调优奖励也明显落后于编程式策略。迁移：相似任务提示更快更好，跨本体提示（Franka→Kinova/xArm7）得分高于无提示参照。VLA：六任务平均成功率从 10 条演示的 18% 升至 400 条的 69%（rubric 分 0.32→0.76）；OOD 泛化上智能体多样化数据全面超过脚本随机化（总体 0.233 vs 0.066，其中 slice 任务 0 vs 0.220、nut_thread 0.025 vs 0.300）。真机：纯仿真数据微调策略四阶段成功率 100%/80%/30%/20%（预训练 π0.5-DROID 全 0%），完成含旋灯泡的完整拆解。局限：智能体解需要大量迭代交互且常特化于单个任务实例；基准内仿真资产构建仍人力密集；真机验证限于单任务小样本；论文附录另含失败模式轨迹与 RL 基线细节。对本组启示：编码智能体作为"求解器+教师"的双角色为演示数据规模化提供了新杠杆——先解决、再多样化、后蒸馏；其阶段级中间态覆盖与自适应噪声思路可与现有数据引擎互补。
