# Meta 发布 Muse Spark 1.3 并发起价格战

## 事件概述

新智元报道（9 月 4 日）：在谷歌 Gemini 3.8 Flash 发布次日，Meta 发布 Muse Spark 1.3 并直接发起价格竞争。扎克伯格在 X 上官宣该模型「以前沿性能带来几乎便宜到无需计量的体验，是 Meta 在编程与智能体工作上迄今的最大飞跃」。

## 已确认事实与证据

- 发布主体与渠道：Meta 官方（扎克伯格 X 帖），超级智能实验室负责人 Alexandr Wang 连发三条 X 说明升级要点。
- 官方口径的改进（Wang 帖，媒体转述）：相较 Muse Spark 1.2，无效轮次减少、工具调用次数减少约 20%、Token 消耗减少约 25%，长周期任务中更好保持需求。
- 媒体列出的第三方跑分（新智元转述，未经官方页面逐项核验）：DeepSWE v1.1 75.4（Claude Opus 5 74.0、GPT-5.6 Sol 73.0）；SWEAtlas CodeBase QnA 59.4；Terminal-Bench 2.1 88.8；MRCR 512K-1M 98.1；Artificial Analysis 智力指数（Max 推理）62。
- 五个月内 Meta 已迭代四个 Muse Spark 版本（媒体统计）。

## 影响与后续观察

- 「前沿性能 + 近乎免计费」的组合若属实，将直接冲击 GPT-5.6/Fable 5/Gemini 3.8 Flash 的定价体系，编程与智能体工作负载可能加速向低价模型迁移。
- 待观察：官方定价与限流细则；独立基准对上述分数的复核；与谷歌的公开竞争互动走向。
