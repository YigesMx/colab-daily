## 研究问题与贡献

让机器人完成新任务通常需要采集数据并训练专用策略。本文提出 Agent as Policy（AGP）：让通用大模型 agent 在整个任务执行过程中直接驱动物理机器人，无需任何任务特定或环境特定训练，把基础模型的推理与编程能力直接落到真实操作上，探索“零训练的通用机器人策略”这条最短路径。

## 方法与系统

给定任务与机器人接口后，agent 自主完成感知-编程-指令-修正闭环：解读视觉证据、编写可执行程序、下发运动指令，并根据物理执行结果修正后续动作。一个准备 agent 会先生成可复用的任务定义与技能库；执行时 agent 逐步调用接口并读取反馈。整套流程不经过任何策略网络训练。

## 实验设置与数据

真机评测覆盖五类任务：从人类视频引导的装配、目标图像引导的积木搭建、骰子重定向、定向投掷与双手叠毛巾；报告成功率、完成时间、token 用量与推理成本，并考察经验积累是否提升后续表现。

## 结果、限制与结论

八个任务变体中七个成功率至少 80%，其中积木搭建三种配置分别为 100%、100%、80%；单次任务耗时 20.6–54.3 分钟，每次成功推理成本约 7.46–27.41 美元。限制很直接：执行时间与推理成本是实用化的硬门槛，成功率也受限于模型视觉推理的稳定性。结论：AGP 证明了“通用 agent 直接当策略”在没有任务训练下是可行的，为评估基础模型具身能力提供了新的零训练基线，也量化了这条路线与部署现实之间的距离。
