# 388个PR全部AI操刀，180个已合并！Claude之父：程序员只剩下签字

## 事件概述

Claude Code 负责人 Boris Cherny 公布内部实验：让 Claude 接管 Anthropic 自家 App 的日常维护，几周内生成 388 个 PR，其中 180 个被合并。

## 已确认事实与证据

报道描述例程覆盖 iOS、Android、桌面端、Web、CLI 和 Agent SDK 六类环境，任务包括崩溃巡检、复现、修复、重复抽象合并、死代码清理、抽象泄漏修复、弱测试清理和上线开关移除。疑似不可达代码会先埋日志观察一天再删除；工程师主要负责审查、反馈与决定是否合并。

## 影响与后续观察

原文关键证据摘录：- 写代码变便宜了 审代码就变贵了 一个团队几周内多出388个AI生成的PR，谁来看？
