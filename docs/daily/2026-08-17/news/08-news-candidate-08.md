# OpenAI研究员：100%代码已交给AI！Claude重写Python库

## 事件概述

新智元报道了两条相关表态：OpenAI 研究员 roon 称“我不写代码了，100%都是 GPT 完成”；Rails 之父 DHH 则展示用 Claude Fable 5 将 Python 库 TerminalTextEffects 重写为 Rust。

## 已确认事实与证据

报道转述 DHH 的实验称，重写消耗约 1100 万 token，Rust 主代码约 2.1 万行，全程约 3 小时 11 分；8 个 Agent 分支同时工作，分别读代码、生成实现、编译、测试和处理失败。报道还称新版本可运行 37 种效果、成为约 3MB 可执行文件，并用同一方法让 Codex 复现，成本约 43 美元。上述性能数字来自当事人公开表述，需仓库和独立测试复核。

## 影响与后续观察

原文关键证据摘录：- OpenAI研究员roon说得更绝：「我不写代码了，100%都是GPT完成的」。
- 一天之内，他便可以合并27个PR，全由Claude代劳。
- 它既可以作为命令行程序使用，也可以作为Python库导入其他应用。

该案例与 Anthropic 内部 PR 实验共同指向同一趋势：AI 大幅提高代码产量后，人类价值向任务定义、审查标准、架构取舍和安全问责转移。后续等待公开仓库、完整测试、缺陷率和长期维护数据，不应把单例外推为普适生产力结论。
