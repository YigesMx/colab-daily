# 刚刚，Cursor彻底消失！

## 事件概述

新智元报道，SpaceX 已完成对 Cursor 约 600 亿美元的收购交易，Cursor 品牌不再独立存在，相关能力并入 SpaceXAI。

## 已确认事实与证据

报道称 Cursor 的现金、知识产权、员工、企业客户合同和编程数据流并入 SpaceXAI；原内部智能体能力将以 Grok Bot、Grok Build 等形态继续交付，Grok Bot 被描述为具备云端虚拟机、工具登录、全天候运行和多智能体协作的产品。交易细节主要来自媒体报道，本文未独立查看交易文件。

## 影响与后续观察

原文关键证据摘录：- 马斯克的600亿，果真没白花。
- 再见了，独立的 Cursor。
- 就在前几天，Grok Bot已经发布。
- 而马斯克的SpaceXAI，也赢下了通往ASI决赛的门票。

AI 编程入口与自有算力、模型和分发体系的垂直整合会进一步加深，独立应用公司的品牌、数据和客户合同边界也会被重塑。后续关注监管文件、客户迁移、开发者合同变更、Grok Bot 可用性与原 Cursor 生态承诺。
