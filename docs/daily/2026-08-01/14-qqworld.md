## 核心内容

潜变量世界模型希望在紧凑空间预测动力学并执行规划，但 LeWorldModel 使用的 Epps-Pulley（EP）正态性目标虽然约束整体分布，仍会留下明显重尾。论文把 EP 重新写成采用单位带宽高斯核的 MMD，并分析其梯度：当某个投影潜变量远离样本主体时，样本间作用项和向中心吸引项都会快速衰减，恢复力在超过核作用范围后几乎消失。因此一个统计上能识别分布差异的检验量，并不一定是优化几何良好的训练目标。

QQWorld 改为对随机一维投影后的样本排序，将第 n 个顺序统计量直接匹配标准高斯的第 `(n-0.5)/N` 分位数。其梯度是潜变量与对应分位数之差的两倍，偏差越大，纠正越强；在没有 ties 时可微，而相邻样本发生秩交换的边界在局部是排斥的，不会吸引样本坍缩。作者还证明 QQ 误差趋零可控制 EP 误差，反向则不成立，因为 EP 可能忽略少量任意远的尾部样本。

## 关键技术与数据

方法沿随机单位方向投影 d 维 latent，并在多个方向上平均 QQ 损失。Cross-Batch QQ 将当前 N 个投影特征与过去 K 个 batch 的 detached 特征合并，在 M=(K+1)N 个样本中估计秩，但只保留当前 batch 的计算图。这样以很小的额外显存降低小 batch 的秩估计方差，同时也引入历史表示滞后的偏差；论文明确分析了这个 bias-variance 权衡。

实验沿用 LeWM 的预处理、训练和基于 CEM 的目标条件规划，在 Two-Room、Reacher、PushT、OGBench-Cube 四个离线控制环境中比较。QQWorld 仅替换 EP 正则，四个环境统一使用权重 3.5；规划结果以 6 个随机种子的均值和标准差报告。正态性评估固定抽取 20,000 个 latent，并沿 6,144 个随机方向投影。原文没有报告更大规模真实机器人数据或在线交互实验，因此证据局限于这些离线控制环境。

## 结果与结论

QQWorld 四环境平均规划成功率为 85.08%，LeWM 为 79.75%，提升 5.33 个百分点，并在四个环境逐一超过 LeWM。Two-Room 的投影 QQ RMSE 从 0.157 降至 0.121，192 维 latent 半径超过高斯 90% 分位点的比例从 0.315 降至 0.123。四环境平均的 KS 统计量从 0.038 降至 0.032，EP 统计量从 119.909 降至 82.294，即便 LeWM 本身直接优化 EP。

跨批次实验中，batch 32 只用当前批次时平均成功率 65.42%，加入两个历史 batch、总排名池 96 时达到 83.50%，显存仍约 3,435 MB；相比 batch 128 的 85.08%，显存降低约 73%。但队列增至 4 个 batch 后回落至 81.75%，batch 64 或 128 加历史样本也没有收益，符合滞后偏差判断。结果说明 QQ 是一个简单且在该设置中有效的替换项，但四个环境规模有限，尚不足以证明其对所有世界模型架构和高维复杂控制任务都稳健。
