## 研究问题与贡献

混合 Transformer 式视觉-语言-动作（VLA）模型通常让自回归 VLM 与一个更小的流匹配动作专家配对，专家以 VLM 各层的键值表示为条件预测连续动作。这里有一个关键训练决策：专家的连续动作损失应该只训练专家，还是也让梯度回传更新 VLM（耦合）？主流做法（如 Knowledge Insulation、π0.5 训练配方）阻断专家到 VLM 的梯度（绝缘）以保护预训练能力，同时用视觉-语言共训练与离散动作 token 监督补偿。NVIDIA、普林斯顿与斯坦福团队的这篇论文提出核心疑问：绝缘的好处究竟来自梯度阻断本身，还是依赖于动作 token 监督这一替代信号？论文在自动驾驶与机器人操作中把动作 token 监督（开/关）与专家到 VLM 梯度流（耦合/绝缘）独立交叉，并在三种训练次序（并行、专家先行、VLM 先行）下评测。主要发现：开环驾驶中，有动作 token 监督时绝缘与耦合几乎不可区分，无监督时耦合把轨迹预测误差降低约 25%；并行训练下耦合把闭环驾驶路线进度在有/无 token 监督时分别提升约 17% 与 40%，操作任务同样受益；结论是绝缘不应作为 VLA 的默认训练配方。

## 方法与系统

驾驶模型沿用 Alpamayo VLA 架构与 π0.5、Knowledge Insulation 式混合自回归加流匹配配方：Qwen3-VL-2B-Instruct 骨干配同宽度非因果流匹配动作专家，专家逐层注意对应 VLM 层的键值表示而 VLM 不注意专家的连续动作输入；专家预测未来若干控制对（加速度与曲率），从当前自车状态经离散单轨模型积分得到位置与航点。训练数据混合理性与无推理标注的轨迹样本：VLM 先生成简短、场景相关的驾驶理由，动作 token 监督条件下再预测后续未来轨迹 token；评测时 VLM 总是只生成理由并在起始 token 停止解码，动作 token 永不在推理时解码、仅作为塑造 VLM 表征的辅助训练信号。损失为交叉熵加整流流匹配：耦合时专家损失经层间键值接口回传更新 VLM，绝缘时用停止梯度原样传表示但阻断梯度；关闭动作 token 监督只掩掉未来动作数值 token 的交叉熵（轨迹定界符仍监督、过去轨迹仍在上下文中），并固定归一化基数保持其他监督项权重。四种条件（token 开/关乘路由耦合/绝缘）在每种训练次序下共享相同的预训练起点、专家初始化、优化器与数据配比（轨迹批次约 48.5%，VLM 每步更新、专家仅在轨迹批更新），统一在 30 万优化步、验证性能稳定后比较；专家先行与 VLM 先行均为 10 万步单组件阶段加 20 万步联合训练。

## 实验设置与数据

开环驾驶在公开发布的 Physical AI Autonomous Vehicles 数据集的标称 Public Golden（1,434 场景）与 OOD（273 场景）划分上评测，每例采样六条候选轨迹，主指标为首条候选的平均位移误差（ADE），辅以 minADE；推理质量用冻结 Lingo-Judge 分类器对生成驾驶理由打分（Top-1/Top-k/Avg-k 通过率）。闭环驾驶在 AlpaSim 仿真同一批 827 个场景上做五次随机滚动取均值，报告路线进度并附能力与安全指标。机器人操作把并行训练配方复制到两个模型家族——π0.5 复现实现（主要用 350 小时 DROID 数据，对照 CoVeR 报告的万小时级预训练检查点 40.0% 进度）与 MolmoAct2（四条件交叉 FAST 监督与梯度路由）——在三个 PolaRiS 环境（积木堆叠、餐具收拾、锅具清洁）中从匹配初始状态各跑 50 次滚动，主指标为跨环境平均的归一化任务进度（评分点达成比例，满足即保留）。

## 结果、限制与结论

论文报告：并行训练下，有 token 监督时开环 ADE 绝缘与耦合几乎相同（OOD 2.30 对 2.22 米量级），无监督时耦合显著更好（约降 25%，例如 OOD 从 2.89 降到 2.22 量级、Public Golden 2.21 对 2.36）；该模式在专家先行与 VLM 先行次序下均保持。闭环 AlpaSim 上并行训练耦合把路线进度从 0.600 提到 0.703（有 token）并从 0.425 提到 0.601（无 token，提高 17.6 个百分点、约 41% 相对提升），无 token 耦合约等于有 token 绝缘；全程最高进度 0.703 由并行耦合加 token 取得，VLM 先行名义配方反而不如并行。生成理由质量上绝缘无一致优势（无 token 时 Public Golden 绝缘 56.6% 低于耦合 63.5%），且轨迹精度的提升与理由质量并不同步。操作任务上 π0.5 复现中耦合把进度从 10.3% 提到 32.9%（无 FAST）并从 19.5% 提到 30.7%（有 FAST），无 FAST 耦合为四条件最高、约为有 FAST 绝缘的 1.7 倍；MolmoAct2 同样从 22.0% 到 24.3%（有 FAST）与 14.5% 到 36.5%（无 FAST），无 FAST 耦合最高，而官方 VLM 先行发布检查点经同一适配评测为 32.9%。结论：动作 token 监督与专家梯度是部分可替代的动作学习信号，VLM 只要有其中一种直接动作信号即可；路由选择应与动作监督和训练次序联合决定，并按目标评测场景评估收益。局限（作者自述）：只测了一个驾驶模型家族与两个操作模型家族，架构多样性有限；闭环评测全部在仿真，未在物理机器人上验证操作增益；算力所限每条件只跑一次训练，训练种子方差未测量；研究是经验性的，未建立性能差异背后的机制解释。安全侧有 token 监督下分阶段耦合训练的过错碰撞率更高。代码未随文发布（当前材料未确认仓库）。
