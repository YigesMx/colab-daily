## 事件概述

2026年9月3日，OpenAI 发布新模型 GPT-6 Astra，官方页面将其称为“新一代智能”，并表示 Astra 在计算机操作（computer use）、浏览、软件工程、网络安全、科学与专业工作等方向上达到业界最优。同一阶段，ARC Prize Foundation 发布了由 Greg Kamradt 撰写的评测分析《OpenAI's GPT-6 Astra on ARC-AGI-3》：在 ARC-AGI-3 上，GPT-6 Astra 以 Standard harness 取得 62.7% 得分（约 2.6 万美元成本），以 Provider Adapter harness 取得 99.9% 得分（约 1.9 万美元成本）；更受关注的是“行动效率”（Action Efficiency）指标——在已完成的关卡上，Astra（max）有 96.0% 的关卡使用的动作数少于人类基线，平均每关比人类基线少 51.7%，ARC Prize 称之为“一个重要里程碑（material milestone）”，并表示按 ARC-AGI-3 的行动效率口径，Astra “达到并超越了人类水平”。

9月8日，知乎专栏“具身智能之心”发文《GPT-6的Action Efficiency是底气，OpenAI 的机器人野心已经很明确了。》，把上述两项官方事实与该专栏转述的一段 Sam Altman 采访表态联系起来：在被问及 OpenAI 的机器人项目是做人形机器人还是数据中心专用机器人时，Altman 回答“Both”，并补充“我们一定会做人形机器人（We will definitely do a humanoid）”；专栏据此提出，OpenAI 的具身智能/机器人方向已经明确，而 GPT-6 在“行动”维度的效率提升正是其“底气”。需要说明：这段采访引语目前仅见该专栏转述，原始采访出处未能独立核实。

## 已确认事实与证据

### OpenAI 官方发布内容（2026年9月3日，openai.com）

- OpenAI 在 GPT-6 Astra 发布页面中称其为“世界上最智能且对齐最好的模型”，并称其在计算机操作等方向达到业界最优。
- Computer Use 评测（官方页面表格）：OSWorld 2.0（v2026.08.08 离线集、部分得分口径）上，GPT-6 Astra 得分 72.6%，GPT-5.6 Sol 为 65.7%；ScreenSpot-Pro（不用工具）上，GPT-6 Astra 为 92.7%，GPT-5.6 Sol 为 76.9%。
- 效率表述（官方原文）：在 OSWorld 2.0 的延迟模拟中，Astra 每个任务耗时约 40 分钟、得分 72.6%，而 GPT-5.6 Sol 约需 75 分钟、得分 65.7%，即“每任务时间减少约 47%”。注意这是 OpenAI 自己的延迟模拟，并非实测墙钟时间。
- OpenAI 同页亦称 Astra “以 99.9% 的得分饱和 ARC-AGI-3”，与 ARC Prize 公布的 Provider Adapter harness 结果一致。

### ARC Prize 官方分析（2026年9月3日，arcprize.org/blog/astra）

- 得分：GPT-6 Astra 在 ARC-AGI-3 Semi-Private 上，Standard harness 为 62.7%（成本约 2.6 万美元），Provider Adapter harness 为 99.9%（成本约 1.9 万美元）。Provider Adapter harness 允许模型在多次请求间保留不透明推理状态并进行上下文压缩。
- 人类基线定义：ARC Prize 在发布 ARC-AGI-3 前测试了约 500 名普通公众（未按解谜能力筛选），以每关完成者的动作数中位数作为该关的人类基线。
- 行动效率结论：在 Provider Adapter harness 下，Astra（max）在 96.0% 的已完成关卡上动作数低于人类基线，平均每关少 51.7%；ARC Prize 称其为 material milestone，并表示行动效率上 Astra “达到并超越了人类水平”。
- 行为观察（ARC Prize 的定性描述）：Astra 会把陌生环境压缩为紧凑的符号化世界模型，以逻辑规则表示游戏机制、记录物体坐标与未完成计划，并自创领域专用语言简写、自建工具来规划后续行动。
- 范围限制（官方明确声明）：ARC-AGI-3 是范围和格式受到严格限定的基准，其环境具有确定性、封闭式的机制与目标，“并不代表真实世界的复杂性与开放性”；ARC Prize 同时明确“不声称 Astra 已达到 AGI”，仅认为其代表向泛化方向的实质性进展。

- 专栏援引宇树科技王兴兴在 2026 世界机器人大会上对“具身智能 ChatGPT 时刻”的定义（约 80% 陌生场景中完成约 80% 任务），亦为专栏转述，未另行核实。

## 影响与后续观察

- 评测维度信号：ARC Prize 把“行动效率”与任务完成率明确区分并单独公布，说明评测社区开始关心“用多少次交互达成目标”而不仅是“是否答对”。但需注意三点限定：该测量在 Provider Adapter harness 下取得；人类基线来自约 500 名未经筛选的普通玩家；ARC-AGI-3 仍是抽象、离散、规则确定的环境，官方明确其不代表真实世界的复杂性与开放性。
- Computer Use 的经济含义：同样任务约 47% 的时间缩减若能在真实部署中复现，将直接降低智能体单位任务成本；但该数字来自 OpenAI 的延迟模拟，且 OSWorld 2.0 为部分得分口径，尚待第三方复测。
- 从数字行动到物理行动：即便接受“大模型可以在数字世界里 scale action”的判断，机器人仍需补齐传感器、执行器、实时控制、仿真与现场工程等整栈环节。专栏关于 OpenAI 机器人招聘与人形机器人表态的说法，尚待 OpenAI 官方渠道确认。
- 后续观察点：OpenAI 是否正式公布机器人产品/团队计划及形态选择；ARC Prize 下一代基准如何处理开放性与真实世界复杂性；GPT-6 Astra 的 OSWorld 2.0 与 ScreenSpot-Pro 数字能否被独立复测；Provider Adapter harness 的测量口径是否会成为新的通用评测惯例。
