## 事件概述

小鹏机器人（XPENG Robotics）世界模型团队发布跨本体世界模型框架 AnyWorld，并公开论文《AnyWorld: Factorized Egocentric World Models for Cross-Embodiment Generalization》（arXiv:2608.29242）、项目主页与 GitHub 代码仓库。AnyWorld 的核心思路是把一段人类第一视角交互分解为动作、相机与目标本体三个可控因子，再按目标机器人的身体、视角与场景重新组合（recompose），在不依赖人机成对示范的前提下，把单段人类交互扩展成多样化的"机器人原生"轨迹；进一步地，它支持对场景、物体布局与光照进行定向编辑，构造出原始人类数据与机器人数据中都不存在、但策略恰好缺失的训练状态。论文由南洋理工大学、新加坡科技研究局（A*STAR）、小鹏机器人、浙江大学与香港中文大学的研究者共同完成。

## 已确认事实与证据

以下事实来自官方项目主页、arXiv 论文摘要与全文及官方仓库 README，全部证据已留存：

- 因子化接口：动作控制以像素空间运动结构刻画"怎么动"，从具体机器人关节空间中解耦；相机控制用 Plücker 射线显式表达视角演化，把"我在动"与"我看向别处"分开；目标上下文用首帧锚定目标本体、场景、物体布局与初始交互几何。模型以 WAN Fun-Control 14B 初始化。
- 两阶段训练：第一阶段在 20 万段 EgoDex 人类第一视角交互视频上预训练 3 万步（32 张 NVIDIA H200），学习大规模接触与运动先验；第二阶段用 EgoDex、RoboCasa GR1 与 IRON 的无配对混合数据微调（每个目标机器人域用 5 千段 EgoDex 配比），论文强调"不需要同一任务的人类视频与机器人视频一一对应"。消融实验显示人类与机器人数据约 2:1 的混合比例在跨本体可控性上最好。
- 可控性指标：在 60 个测试视频上，AnyWorld 的 ActionAlign / CameraAlign / EmbodAcc 分别为 0.659 / 0.789 / 0.886，三项平均 0.778；对比 WAN Fun-Control 平均 0.609、Cosmos-Predict2.5 平均 0.417。视频质量上 Subject / Background / Flicker / Smoothness 分别为 0.942 / 0.949 / 0.995 / 0.996，即控制能力提升并未以牺牲视频稳定性为代价。论文明确说明：由于跨本体重组没有逐帧配对的机器人真值，这些指标是控制保真度的代理度量，而非"生成视频与真实未来完全一致"的证明。
- 策略层收益：在 RoboCasa GR1 的 18 个 pick-and-place 任务上，混入 AnyWorld 生成的目标域数据后平均成功率从 49.8% 提升至 54.6%；在真实 IRON 人形机器人上，20 次抓取试验成功率从 20.0% 提升至 55.0%。
- 两个定向干预实验：其一，基线策略学到"盒内已有香蕉即任务完成"的错误捷径，AnyWorld 以人类交互为种子重新落地到 IRON 并编辑出"部分完成"状态生成监督，微调后策略恢复继续放置剩余目标；其二，针对原始数据只有单侧单目标抓取、缺少"左右二选一"分布的问题，AnyWorld 编辑出左右对称双目标场景并构造成对语言-动作监督，策略得以仅凭语言指令切换目标；只加动作标签、不改视觉观察的反事实实验无法学会该能力。

## 影响与后续观察

AnyWorld 代表了世界模型在机器人管线中位置的一种转变：不把世界模型塞进实时控制回路做在线预测，而是放进"训练数据工厂"，用已有交互作种子定向合成策略缺失的经验。这与小鹏机器人此前公开的 UniT（跨本体动作语言）、Fe₀ / Si₀（可迁移能力与机器人自感知）构成连续的技术路线，对具身智能数据闭环的含义是：数据瓶颈的提问方式从"还要再采多少条"变成"策略缺哪个状态、能否从已有交互重组出来"。

需要观察的要点：其一，真实 IRON 上 20.0% 到 55.0% 的提升来自仅 20 次抓取试验，样本规模小，结论稳健性待更大规模评测验证；其二，论文自己承认生成 rollout 不是严格物理真值，视频模型"响应动作控制并在接触结果上体现一致变化"与真正物理仿真仍有距离；其三，第二阶段仍需机器人域数据做 grounding，人类视频不能替代机器人数据，跨本体泛化到全新形态（非 IRON/GR1）的效果未知；其四，官方仓库的代码与权重开放范围、EgoDex 许可下的数据复用合规性，以及该框架对小鹏自家机器人产品线的实际数据管线影响，值得持续跟踪。
