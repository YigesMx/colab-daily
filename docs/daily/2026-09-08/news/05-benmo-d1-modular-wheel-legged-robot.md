# 本末科技模块化机器人 D1：3 秒拆合体，直驱轮足产品已售全球 50 国

## 事件概述

量子位 9 月 7 日报道本末科技：其模块化双轮足机器人 D1 可在 3 秒内拆分或合体——两台双轮足对齐合体后可站立转向，理论上可无限合体变形；合体/分身可按任务切换（扫图类轻量任务分身并行、遇台阶合体保机动）。公司产品已卖到全球 50 国。

## 已确认事实与证据

- D1（报道口径）：全球首款整机模块化具身智能机器人，双轮足、四轮足、电足、扁片足多形态自由切换；3 秒拆合体；双轮足与四轮足形态共用一套算法体系，切换 SDK 即可切换运控，调试时间大幅压缩。
- 产品线：刑天（全球首款商业化直驱双轮足机器人，匍匐高负载/拉力 80kg+，可跳跃、爬坡、半坡驻停，面向库房园区物资运输）；TITA（8 自由度、10kg 动态载荷、-10°C~45°C 连续作业，自带光学传感器/喇叭/相机，可巡检、物流、测绘与点对点配送）。
- 技术路线：2020 年成立即专攻一体化直驱关节、不做减速器；直驱关节寿命 5 万-10 万小时、更安静紧凑。创始人张笛（北理工机械工程本科、港科大机器人系统与控制硕士，师从李泽湘）。
- 行业背景（报道引述）：2026 上半年国内具身智能融资约 440 亿元，过半流向「大脑派」；报道观点认为「身体负责到」是被低估的第三层约束。

## 影响与后续观察

- 「本体+小脑」路线与「大脑派」形成产业分工对照：当 VLA/世界模型竞争白热化，轮足本体与模块化形态的工程成熟度直接决定交付能力；50 国销量的口径若属实，本末是具身「卖硬件盈利」路径的代表样本。
- 待观察：D1 模块化接口是否对外开放生态；合体形态的能耗与稳定性数据；海外收入占比与客户结构原文未详述。
- 风险提示：销量与「首款」表述为报道/公司口径。
