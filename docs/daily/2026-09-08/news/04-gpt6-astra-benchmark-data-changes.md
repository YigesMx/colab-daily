# OpenAI GPT-6 Astra 被指官博上线前后多项评测数据发生变化

## 事件概述

新智元 9 月 7 日报道：外媒爆出 OpenAI 官方博客上线前后，GPT-6 Astra 的多项评测数据发生变化，GPT-6 Astra 的跑分「翻车」被抓包，引发关于厂商「跑分作弊」与评测完整性的讨论。

## 已确认事实与证据

- 新智元报道（feed 摘要口径）：「GPT-6 Astra 的跑分竟翻车——就在今天，外媒爆出 OpenAI 官博上线前后，多项评测数据发生变化」。对象为 OpenAI GPT-6 Astra 模型的公开评测数据。
- 事件性质：评测数据在官方发布前后发生变更且未（或滞后）披露变更说明，属于评测透明度问题；具体哪些基准、变更幅度、OpenAI 是否回应，正文细节受访问限制未核验（feed 仅摘要）。

## 影响与后续观察

- 与本期 ARC-AGI 3 相关新闻（Mostik 声称刷爆）形成对照：当厂商与第三方都高度依赖少数基准时，基准数据治理（版本化、变更披露、第三方复核）成为行业基础设施问题。
- 待观察：外媒原文的具体证据链与 OpenAI 官方回应；受影响基准名单与数值差异；是否形成评测披露规范的行业共识。
- 风险提示：本条基于媒体摘要级证据，正文未核验；「作弊」为报道用语，事实认定以官方回应与原始数据比对为准。
