# 元点机器人 OpenBridge 计划：8888 元人形机器人 Zeroth Bridge 免费 200 台，做「人形机器人的安卓」

## 事件概述

具身智能之心 9 月 7 日报道：元点机器人（乐享科技旗下机器人品牌）推出 OpenBridge「筑桥者计划」，瞄准具身智能开发者的冷启动困境（本体贵、工具割裂、Skill 缺失、数据难积累），提出「人形机器人的安卓时刻」：发布 8888 元首发价人形机器人 Zeroth Bridge（昵称「小桥」），并提供 200 个免费名额。

## 已确认事实与证据

- 硬件（报道口径）：Zeroth Bridge 整机高 88cm、重约 13kg，单人可搬运部署；首发价 8888 元；支持二次开发，硬件接口与 OpenBridge 适配；定位教育、遥操作、动作验证与低台面小物体交互，现阶段不承担通用家庭机器人全部任务。
- 生态（报道口径）：Bridge 提供统一硬件载体；SDK 与 API 开放控制、传感器与视觉接口；Simulation Hub 承担仿真调试验证；Skill Hub 用于发布复用模型、动作链与技能；真机数据与失败记录可回流训练流程。
- 动机分析（专栏口径）：开发者换一台本体就要重做结构理解、接口适配、仿真配置与数据采集；厂商难以覆盖教育/科研/娱乐/家庭的长尾能力，需要「本体之上的开发生态」。

## 影响与后续观察

- 若 200 台开发者生态成型，「便宜标准本体 + 开放工具链 + Skill 分发」将测试安卓式分工在人形机器人上是否成立；8888 元定价进一步压低人形机器人入手门槛。
- 待观察：Zeroth Bridge 的实际性能指标（自由度、续航、运控）原文未详述；免费名额的筛选与交付节奏；Skill Hub 的内容质量与第三方参与度。
- 风险提示：产品与生态为发布初期口径，交付能力待验证。
