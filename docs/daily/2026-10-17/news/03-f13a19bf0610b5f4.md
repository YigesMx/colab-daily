## 事件概述

10 月 16 日，新智元报道并转述 OpenAI 官方博客称，横跨旧金山与纽约的初创公司 Third Moment Research 将上万个 AI Agent 投入真实量化金融环境：约 10000 个 Agent 同时运行，连续工作 36 至 48 小时，每天消耗约 1 万亿 token，展示了超大规模智能体集群的长程连续工作能力。报道文末给出了其转述的 OpenAI 官方博客链接。

## 已确认事实与证据

以下内容均据新智元报道转述（发布方称）：

- 实验环境：Third Moment Research 在 Docker 隔离容器中部署 1TB 历史行情数据、技术文档与整套量化代码库；单轮任务的总工时被折算为相当于人类工程师 41 年的工作量（报道称）。
- 关键案例：Agent 在排查中发现回测瓶颈，自行定位两处底层瓶颈并编写缓存优化与内存紧凑打包方案，跑通测试后推上生产环境，把单次一年期美股逐笔订单回测从约 3 小时压缩到 3 至 5 分钟；另有模型顺着数据追查，发现某交易所非公开展示交易（暗池）占成交比例异常的信号。
- 组织架构：容器内执行任务的 Agent 之外，设置了由更强模型驱动的外层监管模型，在内层停滞时判断其是撞上环境缺陷、钻进死胡同还是遇到需要拍板的难题，并决定打回重试、终止或上报人类；系统通过采集轨迹、聚类诊断、合成沙箱、升级脚手架四步循环持续迭代。
- 安全措施：每次大规模仿真启动前，先用网络安全模型驱动红队 Agent 对自家沙箱做自动化渗透测试，配合其他安全模型排查漏洞，确保 Agent 无法逃出隔离环境。
- 后续计划：OpenAI 在博客中透露，下一步准备把并发规模推向数十万个协同工作的子 Agent 集群（报道称）。

### 边界与不确定信息

报道中提到的各代模型的长程任务表现对比、具体成本数字与安全模型分工细节，均来自单一转述来源；OpenAI 原文中的实验设置、统计口径与数据图表，当前材料未确认。

## 影响与后续观察

若实测细节得到官方原文与第三方确认，意味着智能体系统的工程重点正从单次任务能力转向大规模并发下的可控性与自迭代，而量化金融与网络安全这类对算力不设价格上限的领域会率先为万级 Agent 买单。后续可关注 OpenAI 官方博客的完整披露、第三方对成本与稳定性的独立复算，以及该模式向代码库性能排查、供应链重排、商业文档交叉核对等场景的迁移进展。
