# OpenAI「辣椒芯」干翻英伟达！老黄股价不跌反涨

## 事件概述

2026年8月26日，量子位报道，半导体研究机构 SemiAnalysis 公布了对 OpenAI 自研推理芯片 Jalapeño 的评估，认为这颗第一代定制 ASIC 在多项推理基准上可与英伟达 Blackwell 系统竞争。文章同时强调，该芯片仍处于工程样品阶段，2027年才会逐步量产，英伟达新一代 Vera Rubin 也已开始向客户交付。

## 已确认事实与证据

SemiAnalysis 在公开文章中称，其携带 InferenceX 基准到 OpenAI 实验室观察验证；量子位报道则说明，具体跑分数字由 OpenAI 提供，SemiAnalysis 没有完整运行整套测试，也未测试更接近生产负载的 AgentX。

报道列出的主要结果为：Jalapeño 热设计功耗700W；在 GPT-OSS 120B、DeepSeek R1 670B 和 Kimi K2.5 等开源模型上，每千瓦推理吞吐达到 GB200 NVL72 与 GB300 NVL72 的1.5至1.9倍；端到端推理时延比英伟达记录的最佳成绩低1.7至3.6倍，超低时延场景快2.1至4.1倍。对比口径使用单 token 预测，未启用推测解码，而 Blackwell 对比项启用了多 token 预测。

SemiAnalysis 还表示，与 Blackwell 的对比并不完全公平，因为这颗芯片使用 HBM4，更直接的竞争对手是同样使用 HBM4 的 Vera Rubin；OpenAI 目前只有工程样品，量产预计2027年爬坡。量子位另报道，OpenAI 仍计划继续与英伟达算力伙伴合作，并开发后续芯片。

## 影响与后续观察

若后续独立测试和生产部署延续当前结果，OpenAI 在部分推理负载上的自供算力能力可能改善成本和时延，但现有证据来自受限基准、工程样品和 OpenAI 提供的数据，尚不能推出正式产品性能、供货规模或对英伟达市场份额的影响。

后续需要观察 B0 步进实测、完整 AgentX 或生产负载测试、可靠性数据、2027年量产进度、Vindaloo 系统部署，以及 OpenAI 自研芯片与英伟达平台的实际采购组合。股市波动和组织变动不作为本事件的技术结论。
