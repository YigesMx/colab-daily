# 全球首个！10万小时人类数据全开源，Hugging Face罕见站台

## 事件概述

2026年8月26日，新智元报道，光轮智能在8月20日的2026世界机器人大会上宣布与 Hugging Face 联合发布 EgoSuite-Open100K 数据集。可访问的 Hugging Face 集合页面将其描述为“最大规模的全标注开源第一人称人类数据集”，包含10万小时数据和超过15,000个任务与场景。

## 已确认事实与证据

Hugging Face 集合页面显示，EgoSuite-Open100K 由 LightwheelAI 维护，说明文字为“100,000 hours across 15,000+ tasks and scenes”，并列出 EgoStandard 与 EgoPro 两个数据集条目。新智元报道称，该数据集同时上线 Hugging Face Hub 与 AtomGit，可用于学术研究和商业训练，覆盖家居、餐旅、零售、运动、物流、办公和工业等环境。

报道还称，数据包含头戴视角 EgoStandard 与增加腕部视角的 EgoPro；每段视频带有手部位姿、身体位姿和事件级语义三层标注。报道提及 Hugging Face 官方账号和 LeRobot 项目转发或表态支持。本次核验确认了 Hugging Face 集合存在及其元数据，但未逐项验证全部视频、标注质量和下载许可。

## 影响与后续观察

大规模第一人称人类行为数据可降低具身智能研究的数据门槛，并为跨任务、跨场景和跨本体学习提供更统一的公开基础。EgoStandard 与 EgoPro 的多视角和多层标注若质量稳定，可能有助于手部操作、长程任务理解和具身模型评测。

后续需要观察实际下载入口的许可与访问条件、数据完整性、标注质量抽检、任务和场景分布、隐私合规处理，以及不同机器人任务上的可复现训练结果。集合页面显示访问采用手动审批，使用前应确认具体授权条款。
