# 神经接口进入具身数采：OriginFlow 把肌肉反应炼成 Token

## 事件概述

量子位 8 月 22 日报道，具身智能数据采集出现新路线：用表面肌电（sEMG）神经接口腕带捕捉人类运动输出侧的肌肉反应，并将其转化为 token 供机器人学习。代表团队是清华博士生创立的 OriginFlow（渊澈太初）。

## 已确认事实与证据

报道确认：OriginFlow 推进 sEMG 神经肌电数采路线，采集从一条腕带开始；该路线与真机遥操作、无本体便携采集（UMI/Ego）、仿真合成数据、互联网视频蒸馏四类主流方式并列，把数据采集视线从外部动作延伸到人体运动输出侧。报道为长文访谈，含技术路线对比与产业逻辑。腕带硬件规格、数据规模与已落地的训练结果当前材料未确认。

## 影响与后续观察

数据是具身智能的瓶颈，sEMG 路线若能把人类动作意图（含肌力与时序信息）低成本规模化编码，可为模仿学习提供新的信号源，尤其适合精细操作与手部动作。后续应关注：sEMG 信号到动作/意图 token 的映射精度；与视觉运动轨迹数据融合的训练范式；腕带方案的采集成本与人体适配性。
