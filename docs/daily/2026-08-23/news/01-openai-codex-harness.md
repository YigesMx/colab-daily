# OpenAI 宣布全面开源 Codex Harness

## 事件概述

8 月 22 日，新智元报道 OpenAI 宣布将其智能体产品 Codex 的底层核心框架 Harness 全面开源。OpenAI 总裁 Greg Brockman 在 X 上转发该消息，并称“Codex 能驱动的远不止编程工具”。开发者可以把这套智能体循环嵌入自有产品、工程工具、运营看板等系统，而不必把业务流程塞进通用聊天框。

## 已确认事实与证据

报道确认的事实：OpenAI 宣布开源 Codex Harness；官方高管 Greg Brockman 公开转发推介；Harness 是驱动 Codex 智能体的底层框架。报道称此举对开发者生态的影响可能超过一次普通模型迭代。开源范围的具体组件清单、许可证条款与仓库地址在当前材料中未逐一确认。

## 影响与后续观察

若 Harness 以宽松许可开放，开发者和企业可以把 OpenAI 打磨过的智能体循环（任务编排、工具调用、执行反馈）作为自研智能体产品的底座，缩短构建周期；这也可能推动智能体框架层竞争（与 LangChain、OpenHands、Claude Agent SDK 等同类生态）。后续应关注：官方仓库与许可证细节；社区实际采用与二次开发现象；以及 OpenAI 是否把 Harness 与其模型服务深度绑定。
