## 事件概述

2026 年 11 月 24 日，量子位报道：具身智能公司自变量机器人（X2 Robot）发布新一代具身基础模型 WALL-OSS-1.0，并同步开放其首个具身基础模型 API（WALL-API-1.0，即 Wall X API）。报道称该模型无需任何任务微调，仅凭预训练即可在陌生环境与全新任务上直接操作机器人，被视为具身智能行业期待已久的"预训练通用智能时刻"。自变量官方开发者文档确认了 Wall-OSS 开源视觉-语言-动作（VLA）模型系列与 Wall X API 的存在、接入方式及申请渠道；但 WALL-OSS-1.0 本身的官方技术细节目前主要来自公司发布材料经媒体转述，尚未见到独立的官方技术报告（当前材料未确认）。

## 已确认事实与证据

**官方来源（自变量机器人 x2robot.com 开发者文档，已抓取留档）可确认：**

- 自变量运营"量子一号Pro（Quanta X1 Pro）"机器人产品线，开发者文档体系包含"Wall OSS 模型介绍、快速开始、数据准备、模型训练、模型评估、模型推理与真机运行"以及"Wall X API 与推理教程"完整章节。
- Wall X API 通过 WebSocket 服务端点（maas-api.x2robot.com 域名的 v1/vla/wallx 路径）提供，API Key 需向 wallxapi@x2robot.com 邮件申请；支持 quanta_x1_pro、TeleTwin Desktop、YAM、AgileX（松灵）、Franka 等多种机器人本体与夹爪组合，action_horizon 为 32。这与“具身基础模型 API、开箱即用”的报道口径一致。
- 文档对 Wall-OSS-0.5（上一代）的官方描述：基于 3B 视觉语言模型骨干、整体约 4B 参数的开源 VLA 模型；采用"梯度桥接式联合训练"框架（多模态交叉熵 + 离散动作 token 预测作为梯度桥 + 连续动作 flow matching 作为部署接口）；引入 Vision-Aligned RVQ Action Tokenizer；预训练覆盖超过 20 种机器人形态、每轮处理超过 100 万条机器人轨迹、结合约 9000 万多模态样本；在 17 个真实机器人任务上直接评估预训练 checkpoint，强调"预训练能力可直接验证"而非仅作为微调起点。

**媒体报道（量子位，2026 年 11 月 24 日，源自公司发布材料，当前材料未独立核实）：**

- 评测成绩：WALL-OSS-1.0 在 312 项开放式任务真机评测中实现 55.1% 零样本成功率（任务由基础动作随机组合而成）；在 ManipArena 真机评测中，未经任务微调的 WALL-OSS-1.0 比经过多任务微调的 π0.5 高出 70.8%；语义任务成功率 78%（π0.5 为 44%）；轻量版 WALL-OSS-1.0-Lite 在 RoboDojo 仿真赛道以 42.59 分登顶 Top1。
- 训练方法：两阶段——第一阶段视觉、语言、动作数据共同预训练，第二阶段引入精细控制动作专家；动作经升级版 X-Tokenizer 压缩为 token，与视觉、语言数据共同参与预训练；实时分块推理，单次推理延迟降至 60 毫秒以内。
- 数据侧：以无本体数据为主，融合机器人遥操作数据、开源动作数据与人工接管数据；建有 Agent 驱动的接管数据飞轮（机器人先执行、卡壳出错处由人类接手），已积累数万小时接管模式数据。
- 落地：已在国内头部物流企业产线执行翻包裹、对条码、筛异常件；报道称经通用预训练的 WALL-OSS-1.0 仅需约 10 小时产线数据即可上岗，缺少通用预训练的同架构模型需 1000 小时以上；更换光照与环境不同的新站点后仍保留 90% 以上原有能力（对照模型约 10%）。
- 生态：推出 AR、Gen、Lite、Nano 模型家族，及 XR Harness（负责场景推理与任务规划，已开放预览版与 API）；报道提及搭载 GPT-6 Astra、Opus 5.5 等大模型的 Agent 方案在对比中落后。

## 影响与后续观察

- 若上述零样本成绩与产线数据经第三方评测和更多部署案例复现，"预训练孕育通用操作智能"的路线将获得重要实证。官方对 0.5 代的定位——让机器人基础模型从"更好的初始化"走向"可直接验证的预训练能力"——正是这次 1.0 发布的核心叙事。
- 具身基础模型以 API 形式开放（不再是微调起点），若调用规模扩大，可能复制大模型行业"能力即服务"的分工格局：上层 Agent 负责任务规划，VLA 底座负责执行。
- 后续观察点：WALL-OSS-1.0 官方技术报告、模型权重与评测口径的发布（当前材料未确认）；Wall X API 的实际开放规模、配额与计费；RoboDojo、ManipArena 等榜单成绩的第三方复核；物流产线之外（商业服务、家庭等场景）的跨站点复制情况。
