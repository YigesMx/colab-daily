**NAT: Scaling Causal Neural Action Tokenizers Across Embodiments**

一句话结论：论文在 49k 小时、156 个数据集的动作语料上系统研究动作 token 化的规模化行为，提出因果神经动作 token 化器 NAT——其因果解码器让动作在 token 生成过程中即可流式执行，在四个仿真基准上对未见机器人本体的 token 化优于 FAST 与既有神经 token 化器，在 VLA 预训练中以 token 行动时四基准平均 61.4% 对 FAST+ 的 37.4%，首动作延迟 19.0 ms 比 FAST+ VLA 快 5.1 倍；实验还发现仅用人类手部运动训练的 NAT 接近全数据版本。

## 研究问题与贡献

大语言模型的规模化配方是"把文本转成共享词表的 token，再在token 大语料上训练单个自回归模型"；机器人学习可能受益于同一路线，但机器人数据来自众多本体——动作空间、控制频率、运动范围各异，采集方式横跨真机遥操作、UMI 手持夹爪、仿真与人类手部记录。一个基础机器人策略因此需要"通用 token 化器"：能编码多本体、多来源的动作，最好也能覆盖训练时未见的本体。

现有方案各有局限：逐维均匀分箱简单通用但序列过长（实时推理不现实）；FAST 用频域变换加字节对编码压缩动作块、其 FAST+ 在 1M 真机轨迹上拟合后可零样本处理新动作空间；学习型 token 化器（编码器-量化器-解码器）能用更少 token 表示动作，但多在较小数据集上训练，在基础策略所需的数据规模与多样性上行为未知。本文贡献：组装 49k 小时、156 数据集的动作语料（真机、UMI、仿真、人类），训练并评测动作 token 化器；提出 NAT——用多时间尺度有限标量量化（FSQ）把动作块编码为短 token 序列的因果 token 化器，支持流式执行与实时分块；把 NAT 用于 VLA 预训练，验证结果能迁移到大型预训练策略；并与流匹配动作头在成功率与延迟上系统对比。作者 Ahad Jawaid、Alexander Swerdlow 与 Yu Xiang 来自斯坦福大学与德克萨斯大学达拉斯分校。

## 方法与系统

### 架构

NAT 建立在 NAC（Neural Action Codec，取其无非对抗损失的变体）之上并做三处修改：(1) 把多尺度残差向量量化（RVQ）换成多尺度 FSQ——FSQ 不用学习码本而是把每通道限界取整到固定层级，码索引即 token；多级残差式地每级量化前级未捕获的残差，且每级按自己的时间分辨率（先平均相邻若干潜变量再量化），从粗到细。(2) 把 NAC 的逆短时傅里叶输出头换成线性层（性能相当、更简单）。(3) 把编码器与解码器改为因果——这是流式执行的来源，对策略性能影响很小。编码器为 SEANet 式一维卷积栈加 LSTM（卷积只做左填充、LSTM 前向），把按时间展平的动作信号下采样为 T 个潜向量；解码器为 Vocos 式的卷积、自注意力与 ConvNeXt 块栈（卷积左填充、每个潜向量只注意自身与固定窗口内的前序潜变量、归一化统计逐潜向量计算），线性头把第 t 个潜向量的输出映射为它代表的 k 个动作——重建的第 (t-1)k+1 到 tk 个动作只依赖前 t 个量化潜变量。整个模型以均方重建误差端到端训练。跨维度处理：动作按每臂（有定义时）或连续维度切成至多 7 维的组、零填充后各自 token 化再拼接，填充维度不计损失。

### 流式与实时分块

token 化按时间序交错各级 token：走过 T 个潜变量，在每个潜变量处依次发射它需要的、尚未发射的 token（从最粗级到最细级）。因为恢复第 t 个潜变量需要其全部层级的 token、而解码器因果，所以第 t 组动作在其 token 组发射完毕后即可解码执行——流式按组推进而非逐 token。通用 NAT 每块 14 个 token（4 个潜变量）。实时分块：策略预测下一块期间机器人仍在执行当前块；NAT 把仍在执行的末段动作编码为新块的开头并冻结其 token 前缀，策略只生成剩余 token，因果解码器保证前缀解码出正被执行的动作、后续 token 自然续接——以纯 token 方式获得实时分块（RTC）的连续性收益，不改变训练或采样。策略为交叉注意观测特征的 transformer 解码器，冻结 token 化器、以标准下一 token 损失训练，各 FSQ 级使用互不重叠的词表区间。

## 实验设置与数据

动作语料 49.3k 小时（5.5B 动作帧）：真机 20.8k、UMI 11.8k、人类 11.3k、仿真 5.4k；按表示分：关节位置 20.8k、末端位姿 17.0k、手部关键点 6.0k、腕位姿加指尖 2.4k、全身关节 1.9k 等。零样本语料排除评测机器人（Franka Panda 与 Sawyer），除特别说明外 token 化器固定在 1% 子集上训练。对比 FAST、OAT、ActionCodec、NAC（相同数据、51,200 词表、28 token/块、神经 token 化器 63M 参数），策略预测 32 步块、执行 16 步；另有同骨干扩散策略作非自回归参照。基准为 LIBERO-Long、Meta-World、RoboMimic、RoboCasa，四个种子、95% 置信区间。VLA 实验以 LFM2-VL-450M 为骨干：NAT VLA 与 FAST+ VLA 在 MolmoAct2 七机器人混合数据（1.8k 小时、4.8B tokens，含 DROID、BC-Z、RT-1、BridgeData V2）上做机器人预训练，再在四基准联合微调；通用 NAT 每块 4 潜变量 14 token、每级 6,400 码，全零样本语料一遍训练（910M 窗口）。真机为 Trossen AI Solo 臂，481 条遥操作演示、四个任务各 10 次试验。

## 结果、限制与结论

### token 化器与数据

每 token 化器一个跨本体策略（四基准联合训练）的平均成功率：NAT 47.0% 最高（LIBERO-Long 74.4、RoboCasa 36.8 领先），FAST 43.4%、其余神经 token 化器 29.0%-40.9%、扩散策略 35.9%；FAST 在 Meta-World、OAT 在 RoboMimic 上各自最佳。LIBERO 单独策略下 NAT 77.9% 对 FAST 66.2%。token 预算：LIBERO 20 Hz 下一秒动作用通用 NAT 9 个 token，FAST+ 需 24 个（2.8 倍）、逐维分箱需 140 个（16 倍）。数据消融（LIBERO-Long）：仅人类手部数据训练时 NAT 保持 74.4%（全数据 77.9%），而 FAST 因 BPE 非学习而不变（67.0%）、OAT/ActionCodec/NAC 掉 18-33 个百分点；任何单一来源类型子集与全混合差距在 4.1 个百分点内、都高于 FAST，去掉人类手部数据降幅最大（3.1 个百分点）——机器人数据可能并非训练动作 token 化器的必要条件。数据量扫描：从 0.1% 到 100% 语料（50 到 49k 小时、相同更新数）成功率稳定在 74.3%-76.4%。架构消融：尺度数从 1 级（12.9%）到 4 级（75.8%）提升明显、8 级无增益；FSQ 换回 RVQ 损失 8.8 个百分点（作者归因于 RVQ 码本塌缩与 FSQ 固定格的"混淆代价小"结构）；线性头与 ISTFT 头相当；因果化仅差 1.7 个百分点（95% 区间内）。

### VLA 与真机

四基准联合微调（同预训练同微调、以 token 行动）：NAT VLA 平均 61.4% 对 FAST+ VLA 37.4%，四项全领先——LIBERO 90.8% 对 62.0%；无机器人预训练的 NAT VLA 仍有 54.9%，高于预训练过的 FAST+ VLA；机器人预训练经 NAT token 增加 6.5 个百分点。加流匹配动作专家（知识绝缘式中级训练）：NAT VLA 73.6% 对 FAST+ 71.4%（区间重叠，仅 RoboMimic 显著），专家把 NAT 平均提高 12.2 个百分点——说明 token 与专家间在 Meta-World、RoboCasa 等域仍有差距，但 LIBERO 上两者 95% 区间内持平（90.8% 对 89.2%）。真机四任务：NAT 55% 对 FAST+ 35%，四任务中三任务领先；FAST+ 仅在"放葡萄"上更好（70% 对 20%），NAT 在该任务的重建误差其实更小、失败模式表现为夹爪下压不足在开环执行的 16 步内未被纠正。延迟（RTX 4090、批 1、CUDA graph）：NAT VLA 首 8 个动作 19.0 ms（含去 token 化），比 FAST+ VLA 的 97.5 ms 快 5.1 倍、比自身流专家的 42.0 ms 快 2.2 倍；在 3-5B 模型上（GR00T N1.7、π0.5、MolmoAct2 的延迟分析）生成 NAT 首 4 个 token 需 45-101 ms，与各自动作头相当或更快，完整块 85-226 ms，低于首段动作 267 ms 的执行时间。

### 局限与结论

论文自述：以 NAT token 行动在部分基准上仍落后流匹配头，进一步调优 token 预算、解码与微调配方可能缩小差距；每块 token 数固定，动态 token 预算与变长块值得研究；数据规模实验固定了策略的 LIBERO 数据，token 化器语料与策略训练语料协同扩展未探索。总体看，这项工作为"动作 token 化能否规模化"提供了迄今最大规模的实证：FSQ 多尺度量化、因果解码与时间序 token 的组合在未见本体上稳定优于 FAST 系，"人类手部数据可替代机器人数据训练 token 化器"的发现显著降低了通用动作空间的构建成本；对自回归 VLA 路线，NAT 证明离散 token 在 LIBERO 类域可追平流头且首动作延迟优势明显，为实时控制场景提供了比动作头更快的选项。
