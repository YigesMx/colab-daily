**World Models as Native Latent Action Models**

一句话结论：论文提出 Native LAM，让一个预训练视频扩散世界模型同时充当逆动力学模型（IDM）与正向动力学模型（FDM），仅以可学习的"动力学寄存器"作为两者之间的因果桥梁，把视频中纠缠在外观里的动力学蒸馏成紧凑、可跨本体迁移的原生潜动作，并以此提出 VLA 预训练范式 PAWlicy，在 RoboTwin 2.0 上以 3.8B 参数达到 93.6% 平均成功率。

## 研究问题与贡献

大规模多样化视频（自我中心人手视频、异构机器人记录）蕴含丰富动力学，但要么没有动作标签、要么动作空间互不兼容。潜动作模型（LAM）试图从中恢复动力学：IDM 从观测变化推断潜动作，FDM 由潜动作复现变化。但现有 LAM 从头训练 IDM 与 FDM，目标函数在像素重建与潜变量容量/精度之间权衡，且训练脆弱——瓶颈过松会泄漏未来帧，过紧则无法描述运动，居中时潜变量还会漂向相机运动等与智能体无关的干扰因素。

论文的核心观察是：预训练视频世界模型天然就是一个 FDM（也是世界动作模型 WAM 解码动作的基础），其动力学先验强大、渲染保真，但动力学与外观纠缠在每层稠密隐状态中，没有可读出动作的紧凑表示。Native LAM 的贡献在于以最小改动把这种动力学"原生化"地暴露出来：

1. Native LAM：一个预训练视频扩散 Transformer 同时以 IDM 和 FDM 两种模式运行，可学习动力学寄存器是唯一因果桥梁，无需单独的编码器或解码器；
2. 反事实时间对训练范式与无文本 FDM 模式，强制世界模型依赖潜变量，训练覆盖 46 个机器人、人类与仿真视频源；
3. PAWlicy（Pretraining Actions from World models）：以冻结的 Native LAM 作为动力学教师预训练 VLA，训练与推理全程不生成视频，在仿真与真机上均超过 π0.5 基线。

团队来自 SenseTime Research（新加坡）、南洋理工大学 S-Lab 与 ACE Robotics，两阶段均只使用公开数据与公开发布的世界模型。

## 方法与系统

### 一个骨干、两种模式

Native LAM 没有独立的编码器和解码器——两者都是同一个预训练视频扩散 Transformer（公开发布的 Kairos 3.1 4B 机器人世界模型），在冻结视频 VAE 的潜空间上运行。一段视频被编码为 v = (v0, v1, ..., vN)，v0 编码首帧。一段短的可学习动力学寄存器 r 被附加到 token 序列上：

- IDM 模式：在干净视频 token 后附加寄存器，以只读注意力掩码运行骨干（寄存器可注意所有视频 token，但视频 token 不注意寄存器），因此视频流的计算与预训练模型完全一致，寄存器纯粹作为内部状态的读取器；一个小的输出 MLP 把寄存器末态映射为潜动作，按时间分组形成短而时序有序的连续 token 序列。
- FDM 模式：同一网络从首帧与潜动作出发再生成未来——适配器 MLPin 把潜动作映射到骨干宽度，取代原本的文本或动作条件；FDM 模式看不到文本和干净未来，场景如何展开的全部信息必须由潜动作承载，用骨干自身的流匹配目标训练，梯度流经生成器回传到潜动作、寄存器与共享权重。读取一个潜动作只需对干净片段做一次前向，无需去噪。

整体上，Native LAM 把世界模型处理一段视频所需的数千高维 token（Kairos 3.1 下 3,456 个维度 2,560 的 token）压缩为 32 个维度 128 的潜动作 token。

### 让世界模型依赖潜变量

直接在世界模型自身预训练域的视频上训练会导致后验崩溃：预训练 FDM 只凭首帧就能想象一个合理未来，会忽略新初始化的潜动作通路（寄存器旁路）。论文用反事实时间对消除该捷径：对每个片段 x 画一个时间映射 phi，构造同源视频的重定时副本 x' = x ∘ phi，两者共享首帧但运动不同——静止、中途暂停、中途变速、朝同一终点重定时、或倒放/加速。两个片段在 IDM 模式下独立读取；FDM 模式下共享首帧、上下文、噪声与扩散时间，两个生成问题除潜动作外完全相同，唯一解法是让潜动作携带运动差异。消融显示：不用反事实对时 FDM 在 2k 步即忽略潜动作并对静止潜动作也"伸手拿杯子"；使用反事实对后 13k 步的最终模型两种 rollout 均与源一致。

此外，仅对 AgiBot World 2026 与 DROID 两个带动作标签的数据源使用浅层运动学头做接地：从潜动作预测各组段起后的末端执行器路点（基座系平移、旋转增量的对数映射、夹爪变化），损失权重 0.1、前 2,000 步预热；其余 44 个源纯视频训练。

### PAWlicy：从世界模型预训练动作

PAWlicy 用训练好的 Native LAM 作冻结动力学教师，给每段视频（无论是否有动作记录）分配原生潜动作，VLA 学习预测这些潜变量并以其为条件生成动作。实例化为三个共享注意力的专家：编码观测与指令的 VLM（PaliGemma，从 π0.5 基座初始化）、预测原生潜动作的潜动作 DiT、生成电机指令的动作 DiT（两者均为 π0.5 动作专家架构，18 层、宽度 1024，各 0.43B 参数，总计 3.78B，对比 π0.5 的 3.35B）。为缓解 VLM 表示与潜空间不对齐的问题，目标中加入"过去组"重建（输入额外一帧过去帧，随机丢弃以覆盖回合起始），把预测未来潜动作分解为先对齐再外推。两个 DiT 均以流匹配训练，推理时同步跑 10 步 Euler，潜动作 DiT 在每层向动作 DiT 提供键值。预训练 16 个数据集（12 个 Native LAM 源加 4 个新源，RoboTwin 2.0 与 RoboDojo 评测集被排除），50k 迭代、全局批 512、32 GPU。

## 实验设置与数据

Native LAM 在 46 个视频源上训练：真实机器人数据约 65% 采样率、自我中心人手视频约 30%、仿真约 5%，只用主相机/头相机/外相机；13k 迭代、32 GPU。评测包括：LARY 基准（冻结表示的动作分类与控制回归探测，对比 LAPA、UniVLA、villa-X、DiLA、MVP-LAM、CLAP、DreamDojo、WLA3）；RoboTwin 2.0（50 个双臂任务，干净与域随机化场景，官方每任务 100 个评测回合）；RoboDojo（42 个仿真任务、公开榜单、五个能力维度中的四个——不评需要记忆模块的 Memory）；以及真机 Agilex NERO 双 7 自由度臂机器人上的两个任务（三木块堆叠、鞋子入箱，每任务 100 条演示、30 次评测，头相机加双腕相机 20 Hz）。基线为 π0.5 及加上相同过去帧与图像增广的 π0.5 变体，后训练动作空间、数据与预算完全一致，唯一差异是 PAWlicy 预训练阶段。

## 结果、限制与结论

### 潜动作质量与迁移性

LARY 上 Native LAM 是两个轨道都最强的 LAM：分类平均 71.77%（对比此前最优 WLA3 的 70.75%），控制回归平均误差 0.25（对比 0.37），且在四个回归数据集上逐项领先，其中真实机器人集 RoboCOIN（0.36 对 0.55）与 AgiBot-Beta（0.41 对 0.57）优势最大；四个回归数据集均未参与训练。定性方面，从一个视频读出的潜动作在 FDM 模式下从另一首帧重放，能在新本体、新场景、人手到机器人手、仿真到照片级场景中复现同一运动——训练中并未使用任何迁移目标；两个潜动作按系数插值得到的是走完部分路程的一个连贯中间运动，而非图像叠加。与其他 LAM 的解码对比中，逐帧使用时其他方法的潜动作在大位移处像素模糊或丢失（香蕉与机械臂消失），整段自回归滚动时误差在几步内累积殆尽，而 Native LAM 一次前向生成整段并保持运动完整。

### PAWlicy 的策略性能

RoboTwin 2.0 上，仅用干净演示（每任务 50 条）时 PAWlicy 平均 74.02%，超过同条件 π0.5 变体 4.18（干净场景）/6.78（随机化场景）个百分点，且测试场景与训练差异越大增益越大，与"潜变量编码运动而非外观"一致。加入随机化演示（50+500）后，PAWlicy 干净场景 93.8%、随机化场景 93.4%、平均 93.6%——干净场景仅次于 LD4WAM 的 94.0%，随机化与平均为表中最佳，超过最强 VLA 与世界动作模型，比此前使用潜动作预训练的最佳 VLA RotVLA 高 4.5 个百分点，而 PAWlicy 在训练与推理中都不生成视频。RoboDojo 上（官方设置，3,500 条轨迹微调，50 回合/任务，三种子平均）PAWlicy 在评估的四个维度上全部领先表中方法（泛化 17.3、精度 29.1、长程 27.0、开放 2.7）；榜单头部条目依赖自研或未公开预训练数据，而 PAWlicy 仅用公开数据，其精度与榜首条目相当。真机上三木块堆叠从 π0.5 的 23.3% 升至 76.7%（π0.5 加过去帧与增广为 66.7%），鞋子入箱从 33.3% 升至 90.0%（变体 80.0%），30 次评测中 PAWlicy 失败 3 次。

### 计算成本

PAWlicy 用 0.43B 潜动作 DiT 替代数十亿参数视频专家学习动力学：在 33 帧、384x256 片段上，处理 32 个潜动作 token 而非 864（Wan 2.2）或 3,456（Kairos 3.1）个视频 token，使动力学模块每步训练算力降低约 387 倍与 1,270 倍（0.0605 对约 23.4 与 76.9 TFLOPs，仅计各模块自身）。在 RTX 6000 Ada 上推理每控制步 106 ms，与不做视频生成的 Fast-WAM（103 ms，无 VLM）持平，比 Kairos-WAM 快 1.8 倍，比测试时生成视频的 Motus/Fast-WAM 快 5.1-8.5 倍。

### 局限与结论

论文自述：该范式目前只在 Kairos 3.1 上建立；46 个训练源中仅两个提供运动学接地，其余纯视频，评测集无重叠轨迹，说明学到的动作结构并非直接继承自稠密动作标签，但运动学接地的独立贡献尚未隔离；迁移实验保持初始几何而改变本体、场景或域，是对运动保持的受控定性检验，更广泛的几何变化与更多机器人有待验证；未来将测试其他视频 DiT。对具身智能研究而言，这项工作的启示在于：世界模型的价值可以不经过"生成视频"来兑现——把动力学蒸馏成紧凑潜动作接口，既能作为无动作视频的策略预训练教师，又大幅规避了 WAM 路线的渲染开销与外观主导的脆弱性；其"反事实时间对防后验崩溃"的技巧对类似瓶颈结构（如寄存器/查询式信息抽取）具有普遍借鉴意义。
