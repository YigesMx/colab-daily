**Real2Worlds2Real: Scaling Self-Improving Agentic Real2Sim2Real for Robot Manipulation**

一句话结论：论文提出 Real2Worlds2Real，一个自我改进的智能体 Real2Sim2Real 框架：其工具编排 harness 由 GPT-6 Astra 驱动，从有限视觉观测出发构建忠实的数字孪生并扩展为多样、物理可执行的"数字表亲"，在同一框架内智能体编排数据生成、策略学习与基于仿真 rollout 反馈的迭代精化，并把验证有效的流程蒸馏为可复用技能——实验显示世界保真度优于 Real2Sim 基线、仿真训练的策略成功迁移到真机（多数精度任务达 90%-100%），并给出交互数据量与世界多样性两个互补的扩展规律，技能复用把世界构建 token 消耗减半、长程任务成功率从 52.9% 提到 82.2%。

## 研究问题与贡献

机器人基础模型（VLA 与世界动作模型）依赖大规模多样数据，而真机采集成本高：遥操作、监督与反复场景搭建复位都消耗人力。Real2Sim2Real 以有限真实观测锚定仿真，有望同时扩展训练环境多样性与交互数据量；但扩展该范式不只是"多生成几个场景"：仿真世界必须忠实再现任务相关外观与物理交互，同时支持多样且保持可执行的物理变体；世界之外，有效的机器人学习还需要让数据生成与策略精化适配不同任务、用仿真 rollout 中的失败指导后续改进。近期工作或重建逼真可交互孪生（常需标记物、手工分割装配、默认物理参数），或做数字表亲式扩展（固定管线、几何检查或物理沉降，难以回访上游尺度/支撑几何错误），或做应急式孪生（保留固定阶段图与工具集）。

UC Berkeley、NVIDIA、UIUC 与 CMU 团队的 Real2Worlds2Real 以"自适应、反馈驱动"回应上述挑战，贡献有三：可扩展的 Real2Sim2Real 框架（从有限真实观测构建忠实孪生与多样数字表亲，供智能体编排的策略开发使用）；世界构建与策略开发两端的智能体工具编排工作流（反馈迭代精化 + 跨任务技能复用的自我改进）；真机迁移验证、世界视觉与物理保真度验证，以及世界多样性与交互数据量的扩展趋势。

## 方法与系统

### 技能引导的智能体编排

harness 为通用编码智能体提供共享工作区（维护演化的场景与历史操作结果），把可复用过程知识组织为三级：核心原则（任务需求优先、区分观测与推断属性、用现有证据验证结果）、任务工作流（孪生重建、表亲生成等阶段的高层过程、约束与验收标准）、专项技能（几何重建、铰接建模、物理仿真等具体操作）。任务初始化时智能体收到核心原则与相关任务工作流，按需查阅专项技能——决策自适应推进而非固定工具调用序列。

### 可扩展世界构建

场景重建：智能体编写并迭代精化 Blender 脚本，把可操作物体建模为带任务相关交互结构（铰接部件、关节、可变形表面）的可编辑 3D 资产；有额外几何线索时用物体掩码与深度估计约束可见几何、用标定多视角观测做轮廓拟合、用已知尺寸参照确立公制尺度。周围环境用网格、高斯泼溅或混合重建：高斯保留复杂背景外观，网格为桌面等接触面提供碰撞几何；高斯背景中含可操作物体时移除其原位置周围的泼溅并检查渲染残留。数字表亲：以孪生为参照生成物体级变体（几何、外观、材质，保留关节类型、连通性与控制角色、可变形物体的附着关系；也可从现有资产库检索），再做场景级扩展（布局、背景、光照），布局变体保持稳定支撑、足够操作空间与任务相关的功能关系；每个候选场景经渲染与任务相关仿真交互验证视觉合理性、物理稳定性与可操作性。物理仿真与渲染：刚体与铰接体用 PhysX（碰撞几何加关节约束），可变形物体用粒子布料、杆件绳索与体积网格软体，由 PhysX 或 Newton 求解器仿真，精细视觉表面由仿真形变驱动；Omniverse RTX 渲染器支持网格与"网格 + 高斯背景"的混合渲染。物理推断与标定：物理参数（质量、摩擦、阻尼、刚度）由几何与材质估计初始化（如按体积与假定密度估质量），经任务相关仿真检查合理后，若有真实交互记录则设计仿真试验——指定初始条件、控制与候选参数范围，重置仿真、施加并验证参数、录制轨迹，与真实观测对齐量测运动偏差并迭代精化。

执行接地的精化与验证贯穿始终：渲染视图与真实观测对比找视觉差异，仿真交互暴露物理失败；孪生必须表达必要部件与关节关系，通过关节运动、接触行为、形变完整性等任务特定检查，失败时用诊断信息修订资产或参数并重跑。有效流程被蒸馏为"个人技能"（问题描述、解法、证据、适用条件与适配方式），与内置技能分开维护、可跨任务复用。

### 智能体策略开发

不遵循固定训练管线，智能体按任务要求与已有演示/策略自适应选择工具与学习方法：以 code-as-policy 范式合成可执行控制程序（分割定位物体，BODex 风格抓取优化加 cuRobo 运动规划，或 MPC 在线更新）；训练带任务奖励的状态 RL 策略（奖励由任务目标与仿真状态构造，仿真反馈帮助修订程序逻辑与奖励设计）；控制程序与 RL 策略可直接执行或生成演示。视运动策略（ACT、Diffusion Policy）用已有或仿真生成的演示训练——跨数字表亲采集变初始条件演示拓宽覆盖；仿真评测发现的失败触发 DAgger 式修正（兼容专家在策略访问态给纠正动作）或 RL 装饰器（从任务奖励学残差修正、基策略冻结）。开发流程同样蒸馏为可复用技能。

## 实验设置与数据

真机为 Dexmate 机器人加 Sharpa 灵巧手与 Orbbec RGB-D 相机，每任务 30 次试验。两组对照：(a) 世界构建对比——每任务先在 60 条真机演示上训 ACT 作共享初始化与模仿基线，各方法用等量数据做同样的 RL 装饰器精化，对比真机交互精化、PolaRiS 与 SimFoundry 两个 Real2Sim 基线（控制变量：所有 Real2Sim 方法用相同输入视频、只建孪生）；八个精度任务包括插销、叠杯、齿轮插入、取纸擦拭（开容器、抽纸、擦桌）、瓶盖拧紧、举杯、杯取放、螺母拧紧（转五整圈）。(b) 策略开发对比——统一用本文仿真环境，对比 ASPIRE 与 ENPIRE 两个自动策略开发智能体框架（均可利用 60 条真机演示）。扩展实验以 Diffusion Policy 为固定学习器在 Stack Cups 任务上分别扫演示量（固定世界集）与世界数（10 到 1,000、固定 1,000 条演示）。世界质量在 Fruits、HOPE-Video、ARKitScenes 真实采集上评视觉（PSNR/SSIM/LPIPS）、几何（深度、物体检测完备性、3D 放置、可见表面 F 分数）、物理（PyBullet 重力稳定性、无穿模）与场景级（支撑关系召回、表面占用 IoU）四类保真度，并消融去智能体（固定管线）与去自适应精化。物理标定在 EV-RealPhys、GAUGE、IRIS 的七个参数估计任务（摩擦、恢复系数、摆长）上对比默认参数、手册值、视频系统辨识、解析法与直接 VLM 推断。技能复用实验：柠檬切割世界构建的 token 消耗（四级嵌套技能库）与 LIBERO-Pro Long 上 20 个长程任务的脚本编写。

## 结果、限制与结论

### 真机迁移与扩展规律

世界构建对比（a）：Real2Worlds2Real 在插销与叠杯 100.0%、齿轮 93.3%、擦拭 70.0%、瓶盖 93.3%——全部任务优于 PolaRiS 与 SimFoundry，且与"真机交互精化"（86.7/96.7/86.7/60.0/93.3）相当或更好；PolaRiS 与 SimFoundry 相对 ACT 基线提升有限，论文归因于任务关键几何不准（如 SimFoundry 重建的齿轮没有齿、轴距不准）使仿真学到的修正无法迁移。策略开发对比（b）：举杯 100.0%（ASPIRE 90.0、ENPIRE 76.7）、取放 90.0%（86.7/83.3）、螺母 73.3%（63.3/53.3）、杯 100.0%（80.0/80.0）——螺母任务上 ASPIRE/ENPIRE 依赖对螺母位置变化敏感的脚本化转动，本文以闭环策略调整动作更鲁棒。扩展规律：固定世界集时演示数从 0 到 3,000，已见场景成功率从 3% 升至 87%（中途趋平），DAgger 式失败反馈在平台期后继续带来增益；固定 1,000 条演示时世界数从 10 到 1,000，100 个未见场景的成功率从约 17% 持续升至约 64%——数据量提升性能、世界多样性在固定数据预算下提升泛化，两者互补。

### 世界保真度与物理标定

世界质量：本文方法 PSNR 23.8、SSIM 0.85、LPIPS 0.25 全面最佳（PolaRiS 21.5/0.72/0.34；SimFoundry 10.4/0.60/0.66；ACDC 9.5/0.08/1.12），几何（可见表面 F 分数 0.108 对 0.037/0.006）、物理稳定性（0.63 对 0.28/0.17）与场景级（支撑召回 0.55、占用 IoU 0.16）同样领先；去智能体变体 PSNR 跌至 12.3、去自适应精化跌至 15.7，证明智能体编排与反馈精化都不可少。物理参数估计：七个任务上参数误差 4.2%、运动预测误差 2.6%、边界违反 0%——优于 PhysX 默认（119.4%/83.1%/20.1%）、手册值、视频系统辨识与单次 VLM 推断（Qwen3-VL-8B 48.2%、Claude Opus 5.5 25.4%）。技能复用：柠檬切割的世界构建 token 消耗从 28.1M 降到 13.9M（约减半）而 SSIM 保持 0.925 对 0.929；LIBERO-Pro Long 20 任务上技能库从 0 到 136，总体成功率 52.9% 到 82.2%（位置扰动 46.8% 到 78.8%、任务扰动 59.0% 到 85.6%），且"不选优、取全部候选程序均值"也从 44.1% 升到 69.1%——技能带来的是更好的程序而非更好的挑选；无技能库的已有方法（π0.5、CaP-Agent0）不超过 8%。

### 局限与结论

论文结论重申三方面证据：世界保真度、真机迁移与两条扩展趋势，以及经验复用对流水线两端的改进；未单独成节的系统性局限讨论在正文中（当前材料未报告更完整的失败分析与多本体扩展结果）。对具身基础设施方向，这项工作的定位是把"世界构建"与"策略开发"都智能体化并互相咬合：世界构建的验收标准来自任务执行而非几何指标，策略开发的反馈来自仿真 rollout 而非人工检查，两端经验都以技能形式沉淀——相比固定管线的 Real2Sim 系统，这种"执行验证 + 经验复用"结构更接近可持续扩展的数据引擎；其主要代价是每任务的智能体 token 消耗（即使技能复用后仍为千万级 token 量级）与对中心化基础模型的依赖，大规模铺开时的成本与一致性有待后续工作回答。
