谷歌旗下工业机器人公司 Intrinsic 在 ROSCon 2026 多伦多大会上宣布，将其机器人软件平台的核心部分以 Intrinsic Core 之名开源，采用 Apache-2.0 许可证发布在 GitHub 上。官方页面称，该软件包含真实生产部署中使用的 ROS 兼容能力与服务，目标是让开发者无需从零搭建基础设施，即可完成工业机器人应用从原型到生产的构建与运行。公司同时开源了面向数控机床上下料场景的参考方案。

## 事件概述

Intrinsic 官网将 Intrinsic Core 定位为「开源、即用型机器人能力」的本地运行时与 SDK，GitHub 仓库描述其提供「面向工业机器人的开放本地运行时、SDK 与硬件无关的实时控制框架」。据 AI Insider 报道，该发布在 ROSCon 2026 现场公布，包含实时控制、位姿估计、运动与抓取规划、仿真、相机标定与预配置 ROS 驱动等组件，运行在本地硬件上，可用于研究项目或私有生产环境。官方页面同时确认，基于 Intrinsic Core 构建的应用可与 Intrinsic Flowstate、AI 模型与云服务等产品无缝协同，无需重写应用。

## 已确认事实与证据

官方页面确认的能力清单包括：位姿估计，基于 NVIDIA FoundationPose 实现 3D 零件位姿检测，让机器人在复杂环境中无需定制夹具即可动态抓取；传感器控制，支持力控插装等需要精确力反馈的高精度任务；运动规划，自动生成避碰轨迹，减少人工示教；仿真服务，基于 Gazebo 提供虚拟环境中的测试调试；相机标定，自动化相机对准与工位配置；抓取，利用实时传感器反馈适应零件位置与朝向变化。配套开源的 Open Machine Tending 参考方案面向数控机床上下料场景，官方称其预配置、可端到端运行并支持本地定制，硬件生态合作伙伴包括 NVIDIA、Universal Robots、FANUC、ATI、Schunk、Robotiq 与 Basler；媒体报道称该方案可适配 FANUC 与 Universal Robots 等厂商设备，并同样支持 NVIDIA FoundationPose。交叉印证方面，NVIDIA 同期发布的 Isaac ROS 5.0 官方博客亦将 Intrinsic 的机床上下料方案与 Intrinsic Core 列为其生态案例，并描述其通过 FoundationPose 感知管线动态检测与抓取零件、减少刚性工装依赖。Intrinsic 表示后续将发布更多工业自动化开源参考方案。

## 影响与后续观察

Intrinsic Core 是大型科技公司近年在工业机器人软件栈上罕见的一次成体系开源：实时控制框架、数字孪生与预配置 ROS 驱动的组合，直接瞄准中小企业部署工业机器人时「集成成本高于硬件成本」的痛点。若社区采用形成规模，可能加速工业机器人应用开发的标准化，并与 NVIDIA Isaac ROS 生态形成互补分工。后续值得观察：仓库的社区活跃度与对非合作厂商硬件的实际兼容范围；Open Machine Tending 之后更多参考方案（官方称已在计划中）的落地场景；以及「本地运行时加云服务协同」模式在工厂数据合规上的接受度。Intrinsic 隶属谷歌的表述来自媒体报道，其在 Alphabet 内部的具体定位原文未详述。
