新加坡国立大学、西北大学、华盛顿大学与微软的研究团队提出 Grounded Action Model（GAM），主张以预训练可提示 3D 定位模型作为机器人操作策略的基础骨干：语言、2D 点或 2D 框提示先被解析为对象级视觉与度量几何表征，再与机器人状态历史融合预测动作块。论文报告其在 RoboTwin 2.0、LIBERO-PRO 及两台真机上的成功率与抗扰动能力均超过以语言或视频生成为骨干的主流 VLA 与世界-动作模型。

## 研究问题与贡献

论文提出的核心问题是：预训练骨干到底应该学会什么，才能最好地支撑可泛化的动作学习。现有视觉-语言-动作模型（VLA）依赖语言骨干，世界-动作模型（WAM）依赖视频生成骨干，但语言生成目标只要求识别物体并描述关系，视频生成目标偏重外观与纹理，两者都不强制给出操作所需的显式度量定位。动作学习因此只能靠机器人示教隐式地把这些表征连接到空间精确的电机行为；一旦示教环境覆盖有限，这种连接便依赖易失效的视觉相关性。

GAM 的贡献在于提出并验证了第三条路线：以一个为可提示 3D 检测预训练的定位模型（WildDet3D）为骨干。该骨干把观察与任务提示连接到度量 3D 空间中的物体，直接向动作学习器提供"哪些物体重要、它们在哪里、占据什么几何形状"的显式表征。语言、点、框三种提示模态统一映射到同一对象中心表征，使语言只是指定目标的一种方式，人类或高层规划器可直接用视觉提示控制目标，从而支持长时程与依赖记忆的操作组合。

## 方法与系统

系统由冻结的定位骨干与可训练动作头组成。对语言输入，一个在冻结 Flan-T5 编码器上以合成指令模板训练的短语标注头抽取任务相关物体短语（例如从"把海绵放进碗里"抽出海绵与碗），作为独立查询传入 WildDet3D；点或框输入则直接指定物体。骨干对每个被查询物体输出 2D 检测框与度量 3D 框，并预测稠密度量深度图与视觉特征。

论文由检测构造两类 token。图像 token 把骨干特征平均池化到 16×16 网格，仅保留与检测框或由 URDF 正运动学投影得到的机械臂轮廓重叠的单元，其余置零，从而抑制无关场景变化。检测 token 由物体点云（膨胀 3D 框内采样 512 点，经共享 MLP 与最大/均值/八分位池化得到 512 维形状特征）拼接 2D 框、中心坐标的傅里叶特征、范围与 6D 旋转表示构成，每个物体映射为 8 个 token。图像、检测与机器人状态历史 token 经共享自注意力层融合后，送入 12 层多流 transformer（MM-DiT）：图像、检测、状态与加噪动作块四条流各有独立参数，通过联合注意力交换信息，语言嵌入经自适应层归一化注入。动作头以流匹配目标训练，预测绝对关节位置目标与夹爪指令组成的动作块，推理时以若干欧拉步积分得到动作。部署时 CoTracker3 在初始检测框内跟踪点以保持物体关联；Molmo2 规划器可在子任务切换时用新的点提示重新选择目标，而底层动作策略保持不变。

## 实验设置与数据

仿真评测覆盖两个基准。RoboTwin 2.0 包含 50 个双臂任务，每个任务有干净（Easy）与随机化（Hard）两种设定；GAM 按官方单任务协议，仅用基准提供的 50 段干净场景示教训练每任务一个策略，每任务两种设定各 100 次回放评估，随机化场景在训练中从未出现。由于骨干在真实图像上预训练，作者先用仿真器导出的 2D 框、3D 框与深度（无需人工标注）将其适配到渲染域后冻结。LIBERO-PRO 保留 LIBERO 固定布局训练数据，在测试时沿物体外观尺寸（Obj）、摆放位置（Pos）、指令措辞（Sem）与目标更换（Task）四轴扰动，共 16 个设定；GAM 在四个套件的全部示教上训练单一策略，与 π0.5、OpenVLA、X-VLA、Flex-π 等比较。真机实验包括双臂 YAM 上的同色物体分放任务（四种目标组合各 25 段示教，20 次评估，分布内与视觉偏移两种条件）与 Franka 上的四个两到四步长时程/记忆依赖任务（每任务 50 段示教，由 Molmo2 规划器通过点接口驱动）。

## 结果、限制与结论

RoboTwin 2.0 上 GAM 平均成功率 55.3%，超过 Spatial Forcing 的 52.0%；干净场景 63.0%、随机化场景 47.6%，后者显著高于最强基线 Abot-M0 的 30.4%，并保留约 76% 的干净场景性能，而 Spatial Forcing 与 FastWAM 分别跌至 26.7% 与 1.9%。LIBERO-PRO 上 GAM 以 0.61 的 16 设定平均超过 π0.5 的 0.53；在目标被移动（Spatial-Pos 0.60、Object-Pos 0.47）或指令改指新目标（Spatial-Task 0.88、Object-Task 0.50）时优势最大，但在物体外观尺寸变化（Obj）上落后，作者承认策略可能难以对训练中未见过的物体尺寸调整抓取动作。真机上，YAM 分布内 GAM 与 π0.5 均为 19/20，视觉偏移下 GAM 保持 17/20（保留 89%），π0.5 仅 4/20（保留 21%）；Franka 上 GAM-Molmo2 系统分布内步完成率 64.7%（π0.5 为 42.4%、MolmoAct2 为 35.3%），分布偏移下为 49.8%，保留 77% 的分布内性能。注意力可视化显示基线在扰动下注意力分散于背景与干扰物，GAM 则集中于所选目标。

作者在结论中明确列出限制：GAM 依赖定位质量，定位错误会直接传播到动作且无恢复机制；对象中心过滤可能遗漏未选定障碍物等上下文；所用 3D 框只是定位的一种形式，稠密 3D 实例分割可能提供更细几何监督，未来还需更通用的 3D 定位数据与模型、定位感知的失败恢复和自适应上下文选择。代码与检查点在论文发表时标注为准备发布。
