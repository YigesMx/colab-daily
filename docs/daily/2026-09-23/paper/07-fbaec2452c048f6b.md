腾讯 ARC Lab 与合作团队发布 WorldCrafter，一个带隐式 3D 感知记忆的相机可控视频世界模型：记忆编码器从预训练 3D 表征编码器初始化，把历史潜帧写入紧凑记忆空间，位姿条件的读出模块再按即将生成的视角把它压缩成固定数量的记忆 token，直接经自注意力条件化视频扩散 Transformer，无需显式深度对应或目标视图重建。论文报告其重访一致性相对最强基线提升 47.6%，相机控制三项误差指标全部最低，经少步蒸馏的 WorldCrafter-fast 在 4 卡机器上达到每秒 16 帧的流式生成，可支撑分钟级一致性探索。

## 研究问题与贡献

视频世界模型允许用户移动相机交互式探索动态环境，但一致性需要超出近期上下文的记忆：当用户从不同视角回到先前看过的位置时，已观察内容应保持一致。论文梳理了既有记忆方案的困境：全历史注意力计算开销大；选择性历史检索以视角覆盖换效率；显式空间记忆提供共享 3D 参考但依赖精确几何、难处理动态场景；隐式记忆把历史压成学习表征，但近期几何导向的方法优先保证几何预测而非重现已见场景所需的外观保真。WorldCrafter 的核心思路是让"请求的视角"决定多视角证据如何被压缩进生成器的有限 token 预算：记忆与生成器联合训练、共同适应，读出时用目标相机轨迹查询记忆。

贡献包括：隐式 3D 感知记忆机制（固定 token 预算内高效写入与读出，保留时空上下文）；与相机可控自回归视频生成的整合（重访一致性相对最强基线提升 47.6%、相机控制更准，并有受控消融支撑设计）；通过少步蒸馏实现实时交互系统，在分钟级探索中保持视觉质量。

## 方法与系统

模型基于潜空间视频扩散：视频 VAE 把视频映射为时空潜变量，DiT 去噪器以 3D 自注意力处理视频 token，用条件流匹配训练。长视频按固定长度块自回归生成，每个新块以近期历史潜帧与文本为条件。WorldCrafter 在此基础上为每块额外条件化一个从累计历史导出的记忆 M 与目标相机轨迹 C。去噪时 DiT 处理把记忆、近期历史与噪声块拼接的单一潜序列，为记忆增加专用流同时保持块级因果性；相机条件按 PRoPE 思想把相对相机几何编码为自注意力内的位置变换，用 UCPE 的并行相机注意力分支实现（独立 QKV 投影、零初始化投影相加），且只作用于噪声部分。

记忆编码器从 LagerNVS 编码器初始化（去掉浅层图像处理层、新增潜帧 patch 嵌入），把最多 k 个历史潜帧及其相对位姿写入隐式 3D 感知表征，聚合几何与外观而不物化显式 3D 重建。为限制编码器成本，推理时保留最新潜帧并贪婪选择 k-1 个互补帧，使其联合视场最大覆盖即将到来的相机轨迹目标区域，而非像既有方法那样按与目标位姿的两两相似度排序检索。读出模块比较了位姿无关与位姿引导两种机制：后者用从目标轨迹采样的查询位姿集查询表征，把固定 token 预算更有效地分配给目标相关信息，实验中重访一致性与相机控制均更优，故被采用；其浅层解码器同样从 LagerNVS 初始化。训练数据为 Open-Sora-Plan、DL3DV 与 MIND 合成视频，用 Depth Anything 3 标注度量尺度相机位姿、Qwen2.5-VL 生成描述；视频 DiT 从 Helios-base 初始化，四阶段训练：先适配修改后的推理窗口（76 万视频、32 卡），再冻结骨干训练相机分支，然后用 DL3DV 与筛选 OSP 子集预热记忆编码器，最后联合训练记忆读出、编码器、DiT 与相机分支，并追加 MIND 数据强化动态主体。蒸馏采用三分辨率金字塔去噪加分布匹配蒸馏，且区分低噪模型（合成数据适配前、保自然外观）与高噪模型（适配后、保主体跟随）混合推理。

## 实验设置与数据

自建基准包含 145 张图像（HappyOyster、Project Genie、网络来源与 GPT-Image2 生成），覆盖 83 个动态与 62 个静态场景，每张图配 5 条度量相机轨迹（528 至 1648 帧、含闭环重访），每方法生成 725 段视频并统一缩放到 640×384 评测。对比 8 个近期相机可控世界模型：DreamX-World、Alaya-EVOKE、HY-WorldPlay、Lyra 2.0、Echo-WM、LingBot-World 2、Matrix-Game 3.5 与 SANA-WM，覆盖上下文检索记忆、深度空间记忆与状态空间记忆等不同机制。记忆评测按重访协议比较首次与重访帧的 MEt3R、LPIPS、PSNR、SSIM；相机控制用 VGGT-Ω 恢复轨迹并经 Sim(3) 对齐后报告旋转误差、平移误差与位姿矩阵差异；视觉质量用 VBench 自定义输入模式的八项指标。消融比较隐式记忆对上下文记忆、冻结对联合优化编码器、位姿无关对位姿引导读出、最大覆盖对相似度检索，并测量记忆处理时延。

## 结果、限制与结论

重访一致性上两个版本包揽全部四项指标前二，WorldCrafter-fast 最佳；与 Lyra 2.0 相比 LPIPS 从 0.487 降到 0.255，PSNR 从 14.050 升到 18.016 分贝。相机控制上 WorldCrafter 三项误差全部最低，fast 版本各列第三。视觉质量上两个版本在八项 VBench 指标中五项最佳，WorldCrafter 总分 81.910 最高，fast 版本时序闪烁最佳。消融显示：把隐式记忆换成四帧检索上下文记忆会同时降低重访一致性与相机控制，且重访 LPIPS 随间隔增长上升更快、长间隔下差距扩大；冻结记忆编码器则损失记忆与相机性能，联合优化更早达到更低重访误差并保持优势；位姿引导读出优于位姿无关；最大覆盖检索优于相似度检索。效率上，深度空间记忆方法每块需 0.409 秒深度估计加 0.937 秒批处理变形共 1.346 秒，WorldCrafter 记忆编码 0.049 秒加读出 0.013 秒共 0.062 秒，降低约 21.7 倍且不需显式深度与变形。

作者在讨论中列出限制：在特别复杂或很长的轨迹上一致性仍可能崩坏；每个块都需重新编码历史带来额外时延，未来方向是自回归流式记忆编码器增量吸收新生成块。模型权重（WorldCrafter-Fast）与代码已在 GitHub 与 Hugging Face 开放。
