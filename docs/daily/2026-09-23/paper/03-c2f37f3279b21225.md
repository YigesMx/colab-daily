理想汽车基础模型团队发布技术报告 ME-VLM（MachEmbodied-VLM），一个统一具身认知与多模态智能体能力的视觉-语言模型，提供 4B 与 35B-A3B 两个规格。论文报告其在 26 个具身基准上平均 70.9 分（35B 版本）、在多模态智能体基准上平均 72.5 分，并可迁移到自动驾驶与具身导航；配合视觉 token 压缩、W4A8 量化与软硬件协同优化，4B 版本可在理想 M100 车规芯片上本地推理，预填充时延从 400 毫秒降至 188 毫秒。

## 研究问题与贡献

论文的出发点是：数字世界的智能体已能理解复杂指令、做长时程规划、调用工具并根据反馈调整行为，但物理 AI 要求把高层语义目标转化为与真实环境一致的物理行为，并在执行中感知环境变化、评估动作效果、修正后续决策。作者据此提出具身智能体需要两类协同能力：一是具身认知，包括对物理元素与空间的几何感知、时序动作建模与执行反馈建模；二是智能体能力，即在长时程自主规划、技能与工具调用、失败归因与反思之上驱动物理平台形成感知-规划-执行-反馈-修正闭环。

ME-VLM 的主要贡献包括：以统一建模（而非简单级联规划器与执行器）让具身认知与智能体决策相互约束；构建覆盖物理理解、任务规划、技能调用、执行过程理解与失败修正的训练数据与联合训练流水线；验证能力可跨任务迁移到自动驾驶与具身导航；以及面向边缘芯片的 token 压缩、量化与软硬件协同优化，使模型可在车端侧实时运行。

## 方法与系统

ME-VLM 基于 Qwen3.5 系列原生多模态智能体模型构建。训练分三步。第一步是具身能力注入：先做具身基础监督微调，把多模态观察与空间关系、物体可供性、动作前提与可行性、预期后果等物理状态关联；再做具身推理微调，让模型在给定观察与任务状态下识别相关条件、在物理约束下评估并选择动作、预测状态变化并指定验证方式。第二步是专家强化学习：多模态智能体专家从原始基座初始化以保留通用推理与工具能力，具身认知专家从注入后的检查点初始化以继承物理接地，两者独立训练以避免异构目标互相干扰；其中能力单元强化学习用组相对优势与 GSPO 序列级重要性比率优化可验证的下一步决策，环境闭环强化学习则在可复现快照的沙箱中做多轮交互，保留失败轨迹以学习验证、纠错与恢复。第三步是多教师在线蒸馏，把两个专家互补的能力整合进单一可部署模型。

数据构建上，论文提出能力分类学：多模态感知、长时程任务理解、工具与技能调用、推理归因等通用问题求解结构可从数字智能体迁移，而空间状态估计、可供性推理、物理动作约束建模、动作后果预测与真实世界闭环反馈则需专门建立物理认知。边缘部署方面，在视觉投影器与大语言模型骨干之间插入免训练的贪心最大-最小 token 选择模块（按余弦距离最大化保留集内最小两两距离、保持时空间结构），权重从 FP16 量化为 4 比特、激活 8 比特（W4A8），再针对 M100 NPU 的并行能力把预填充 token 预算从 4096 压到 3328，编译工具链完成算子切分与调度，运行时由 Arm CPU 推理层与 NPU 内 RISC-V 固件协同。

## 实验设置与数据

具身评测覆盖物理理解（CV-Bench、VABench、RefCOCO、SPBench、各类空间基准等）、任务规划（Cosmos、EgoPlan2 等）、动作执行（VSIBench、SITE-Bench 等）与纠错（RoboFail 系列、RoboFAC 等）四类共 26 个基准，与 Hy-Embodied 30B-A3B、RynnBrain 1.1 9B、PhysBrain 1.5 8B、MiMo-Embodied 7B 比较。智能体评测覆盖多模态理解、工具与技能调用、长时程规划、推理与指令遵循。迁移评测包括自动驾驶（MAPLM、CODA-LM、DriveAction、nuScenes-QA、MME-RealWorld）与具身导航（R2R 与 RxR Val-Unseen）。边缘评测在 M100 SoC（自研 NPU、24 核 Arm CPU、LPDDR5X 最高 64GB、273GB/s 带宽）上测量预填充时延，并报告量化与 token 压缩后的任务保持率。量化方案在具身任务上的消融显示性能下降小于 1%。

## 结果、限制与结论

论文报告：具身基准上 35B-A3B 平均 70.9 分，超过最强对比模型 PhysBrain 1.5-8B（62.7）8.2 分，在 14 个基准上取得最高分（如 CV-Bench 91.7、VABench-Point 75.4、MindCube 91.1、SPBench-MV 83.5、RoboFail-Execution 86.3）；4B 版本平均 63.4 分，仍高于全部对比基线。智能体基准上 35B-A3B 总分 72.5，超过 RynnBrain 1.1-9B 9.6 分，在五个多模态理解与五个推理基准上全部领先（MMStar 77.3、GPQA 78.7、AIME25 72.9、MMLU-Pro 82.8）；4B 版本 63.1 分同样超过各基线，但与 35B 的差距集中在工具调用、长时程规划与复杂推理，说明这些能力更依赖容量。自动驾驶上 35B-A3B 在 MAPLM 72.2、nuScenes-QA 61.1；具身导航 R2R Val-Unseen 成功率从各基线的 15% 左右提升到 56.3%，RxR 提升到 42.6%。边缘部署上，4B 模型在 M100 上预填充时延从 400 毫秒降到 188 毫秒（约 2.13 倍加速），token 压缩后 4B 与 35B 分别保留 96.7% 与 98.2% 的未压缩分数。

需要说明的是，本文为工业技术报告：论文未公开训练数据的具体规模与来源细节，对比模型多数在作者自建测试框架下评测（MiMo-Embodied 取自原论文），具身评测以基准答题形式为主，尚未报告在真实机器人硬件上的闭环操作实验；导航成功率基线显著偏低的对比条件也未逐项展开。当前材料未确认模型权重与训练数据是否开放，仓库主要提供框架说明与技术报告。
