## 研究问题与贡献

世界-动作模型（WAM）把未来视觉状态预测与动作生成耦合在一起。当前主流 WAM 通过适配大规模预训练的视频生成模型或图像编辑模型来获得预测知识——这些方法在继承预测知识的同时也继承了庞大的生成式骨干。清华大学联合上海交大、复旦、中科大、圣路易斯华盛顿大学、中国电信 TeleAI 与 γ-Robotics 的研究团队提出一个自然的问题：有效的 WAM 学习是否必须继承完整的预训练视觉生成模型？大规模预测式预训练诱导的"预测性视觉潜空间"能否独自提供足够的基础？

论文给出肯定答案并发布 V-JEPA Policy：在冻结的 V-JEPA 2.1 编码器潜空间上，用单一下游阶段从头联合训练"指令条件的未来潜变量预测器"与"流匹配动作专家"。三项贡献：(a) 提出无需继承视觉生成器的 WAM 构建框架，总参数 0.9B、可训练仅 0.6B；(b) 在统一下游框架与训练预算下的受控视觉基底对比，证明预测性视觉潜变量优于判别式、重建式与视频理解导向的替代品，且分布偏移下优势扩大；(c) 展示同一潜空间支持从 DROID 视频-指令对（无动作标签）预训练预测器并迁移到下游控制，显著提升 OOD 泛化。代码已在 GitHub 开源。

## 方法与系统

视觉基底为冻结的 V-JEPA 2.1 编码器。为匹配其时间 tubelet 大小为 2 的设定，每个相机视角由当前帧与更早一帧组成最小两帧观测上下文；训练时把上下文与未来观测（K 个时间偏移 δ1…δK）拼成完整视频片段，沿用 V-JEPA 的上下文/目标构造：上下文路径在编码器 Transformer 块之前移除未来位置的 token，只编码观测 token；目标路径用同一冻结编码器处理完整未掩码片段，输出按特征维归一化后取未来位置作为预测目标。各视角独立编码后拼接得到上下文表示 Zct 与未来目标 Z+t。

未来预测器 Pϕ 采用 V-JEPA 2 预测器的 ViT 架构并从头训练：把 Zct 投影到预测器隐维后与未来查询 token（在所有未来目标位置重复单一可学习掩码嵌入）拼接，双向自注意力联合更新两组 token；3D RoPE（时间/高/宽）区分位置，查询 token 使用其预测目标的坐标；可学习视角嵌入区分相机。指令与状态条件：冻结 T5 编码器编码任务指令，与本体状态投影出的单个状态 token 拼成条件序列，每个预测器块施加"视觉自注意力→对条件序列的交叉注意力→FFN"（条件布局沿用 Wan），使上下文 token 与未来查询都感知指令与本体状态；最终未来查询状态归一化并投影回编码器特征维，单次前向得到未来潜变量预测。

预测与动作的耦合是设计的关键：不使用预测器的最终未来潜变量输出，而是使用其逐层上下文状态。经与未来查询的双向交互，深层上下文状态已融入演化中的未来信息；第 j 层取上下文位置的键值投影（键保留 3D RoPE、值不旋转）构成层间接口 Cϕ。流匹配动作专家 vψ 为 DiT 结构：带噪动作块嵌入为动作 token，与预测器同层数、注意力头维兼容，组成 Mixture-of-Transformers（参数独立）——动作 token 的查询联合 attend 上下文位置与动作 token 自身（公式 6），而预测器 token 不能 attend 动作 token；两模块均经交叉注意力接收指令与状态条件，输出头预测条件速度，以 at−ϵ 为目标。联合目标 L = Laction + λfuture·Lfuture（λfuture=1），动作损失经 Cϕ 回传进预测器，使上下文状态同时被未来预测与动作生成塑造。推理遵循"先想象后行动"：每个决策步单次预测器前向构造 Cϕ 并缓存，动作专家从高斯噪声用 10 步欧拉积分生成动作块，每步只评估动作专家。默认模型：冻结 V-JEPA 2.1 ViT-L（约 0.3B）+ 冻结 T5-XXL，预测器约 0.5B、动作专家约 0.1B，共 0.9B（0.6B 可训练）。LIBERO 训练 10 个 epoch；RoboCasa-GR1 用 50k 步、批 256。

## 实验设置与数据

仿真与真机四类基准：LIBERO（四套件分布内多任务模仿）；LIBERO-Plus（七个受控偏移轴：相机视角、初始状态、语言、光照、纹理、噪声、布局，评估 OOD 鲁棒性，不做偏移微调）；RoboCasa-GR1（24 项桌面任务的人形操作，扩展到不同本体）；TianJi Marvin 四视角双臂真机平台上的两个多阶段任务（桌面清理 Table Cleanup、碟架摆放 Saucer Racking，每任务 20 次试验）。基线覆盖 VLA（OpenVLA-OFT、π₀、π₀.₅、VLA-JEPA、PRTS 等，多有动作监督的具身预训练）与 WAM（FastWAM、ImageWAM、JEPA-WAM 等）。受控研究包括：固定下游配方下替换冻结视觉编码器（判别式 DINOv2/DINOv3、重建式 WAN2.2 VAE、视频理解导向 InternVideo3、预测式 V-JEPA 2/2.1 的 ViT-L/ViT-G）；未来查询通路与未来监督的消融（去查询、去未来损失）；下游算力扩展（从头延长训练到 60k 步）；以及预测器在 DROID 视频-指令对上的无动作预训练及其跨基准迁移。效率评测在 RTX 4090、批 1、三视角一致设定下测动作预测核心的延迟与显存。

## 结果、限制与结论

主结果（从头训练版，无动作监督预训练）：LIBERO 平均 97.3%（98.0/98.8/97.0/96.8），与更大生成式 WAM 接近、与带具身预训练的 VLA 竞争；LIBERO-Plus 总体 79.3%，大幅超过 FastWAM（51.5%），与动作预训练 VLA 相当（ImageWAM 83.1% 仍更高）；RoboCasa-GR1 24 任务 50.92%，超过 StarVLA-π（43.9%）、带动作预训练的 GR00T N1.6（47.6%）与 π₀.₅（37.0%），仅低于 ABot-M0（58.3%）；真机双任务 55%/35%，与生成式 FastWAM（60%/35%）相当。视觉基底对比中，V-JEPA 2.1 ViT-L 达 LIBERO 97.25% / LIBERO-Plus 79.25%：对最强判别式基线 DINOv2 的领先从分布内 2.35 分扩大到偏移下 12.23 分；重建式 WAN2.2 VAE 在偏移下明显最弱（46.43%），作者推测重建目标偏重外观细节、与鲁棒控制所需的对象中心/时间抽象不对齐。预测基底内部：V-JEPA 2→2.1 升级在 ViT-L 与 ViT-G 上都稳健提升偏移鲁棒性，而 ViT-L→ViT-G 扩容主要提升分布内性能、偏移下收益有限甚至为负——V-JEPA 2.1 ViT-L 以更小骨干取得最强 LIBERO-Plus 表现，说明预测表征质量比单纯扩大视觉容量更可靠。消融显示去掉未来查询或去掉未来监督都降低两基准性能，且保留查询通路但去监督无法恢复完整模型——收益来自显式学习与动作耦合的未来视觉表征。预测器预训练（DROID 视频-指令对、无动作标签、编码器冻结）后：LIBERO 97.3→98.7、LIBERO-Plus 79.25→91.50、RoboCasa-GR1 50.92→55.58、真机 55/35→75/85（平均 45%→80%）；七个偏移轴全面正增益，语言偏移最大（+29.73pp）；把从头训练延长到 60k 步只得 81.64%，无法恢复预训练收益。效率：动作预测核心在 RTX 4090 上延迟 178.17ms（P95 186.81ms）、峰值显存 4.66GiB——比 FastWAM 低 63.4% 显存且更快（202.51ms），也优于 PRTS（115.89ms 但 9.96GiB）与 π₀.₅（159.42ms、12.74GiB）的显存占用。

局限方面（原文未设独立局限章节，据实验归纳）：绝对性能上从头版仍低于 ImageWAM 等最强生成式 WAM 与 ABot-M0；预测器预训练依赖 DROID 的指令标注质量与潜空间一致性，其他视频语料的迁移效果当前材料未确认；真机评估限于两个双臂任务，移动操作与更高自由度平台未覆盖；效率评测排除了传感器 I/O 与电机执行延迟。总体而言，本文证明"冻结预测性潜空间 + 从头联合训练"足以构建有效的 WAM，且该潜空间还可作为可复用基底吸收野外视频中的未来建模知识——以 0.9B 参数、4.66GiB 显存获得与数十亿参数生成式 WAM 竞争的性能与更佳的分布偏移鲁棒性。
