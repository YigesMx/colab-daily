## 研究问题与贡献

预训练视频世界模型能预测场景的多种合理未来，但机器人必须实现"任务条件下的那一个"未来。现有把世界模型转化为可执行策略的方法都要付出昂贵代价：基于规划的方案（MPC）在测试时反复想象 rollout，控制频率受限且目标多为目标图像或手工代价；世界-动作模型（WAM）则直接微调重型骨干，需要大量机器人数据与算力。UC Berkeley 联合南方科技大学、西安交通大学的研究者提出不同观点：昂贵部分已在世界模型预训练中付清——其表征空间已经铺开了多样的潜在未来，剩下的只是"选出完成任务的那个未来并读出实现它的动作"。作者把这一任务形式化为"实际化"（actualization）：在冻结世界模型提供的先验之上，学习任务条件的选择与实现。

RoboActualizer 是其实现：在冻结世界模型编码器之上仅用 6000 万可训练参数（比现有 WAM/VLA 少最多 100 倍），单张 GPU、峰值显存 32GB 即可完成全部训练，无需任何具身预训练；在 LIBERO、LIBERO-Plus、RoboTwin 2.0 及两个真机平台五项任务上取得强劲性能，推理延迟 39 毫秒、超过 25Hz 满足实时控制。

## 方法与系统

形式化上，视频世界模型 gϕ 把以 t 结尾的短窗口 RGB 帧编码为潜在表征 zt（N 个 D 维空间 token），跨帧注意力使其蕴含窗口内运动与"接下来可能发生什么"。但世界模型不决定哪个未来会发生：以指令集合 L 计，未来潜变量服从混合分布，每个任务对应一个集中在"任务完成"区域 Fℓ(zt) 的分量。由贝叶斯分解，联合分布拆为先验（由 gϕ 给出）、选择（按指令重加权先验到对应分量）与实现（把选定未来映射为动作）三因子——actualizer 只需学习后两者，先验几何直接继承自冻结空间，这正是"小模型够用"的原因。

实例化：gϕ 采用冻结的 V-JEPA 2.1（ViT-L/16，300M）。未来目标 z⁺ 在动作块上按若干离散步离散化，用同一编码器同法编码；由于编码器冻结，所有潜变量可离线缓存，训练时完全不需要前向运行视频基础模型。表征论证部分给出小模型可行的依据：实际izer 网络宽度 dmodel=384（DiT-S 宽度）只能表达该秩的几何分量，而 LIBERO 演示潜变量的主成分分析显示前 384 个主成分已保留 93.8% 方差（跨套件稳定，仅损失 6.2%）——V-JEPA 表征空间本质低维，窄模型可近乎无损地选择分量并读出动作。为此采用干净样本参数化（x-prediction）：网络直接预测 z⁺ 本身而非含满秩高斯噪声的 v 目标，与输入同样具备低秩结构。

架构：两个轻量 DiT 专家组成 Mixture-of-Transformers（MoT）。潜变量专家预测任务条件的未来潜变量（选择），动作专家生成实现该未来的动作块（实现）；二者权重独立、通过共享自注意力层交互。观测 token 与带噪未来潜变量 token 走潜变量专家，带噪动作 token 走动作专家；任务指令由冻结 UMT5 文本编码器编码，与本体感知状态 st 一起经交叉注意力条件化两个专家。训练损失在速度空间计算：L = La + λz·Lz，两项分别为动作与潜变量的流匹配损失（带噪 token 由线性插值构造）。部署时编码器每个观测只前向一次，仅小头在去噪中迭代；受 Fast-WAM 启发，推理时丢弃未来潜变量预测、只预测动作并缓存去噪中间特征，单张 RTX A6000 上整体延迟 39.9 毫秒。

## 实验设置与数据

仿真基准三个：LIBERO（四个套件 Spatial/Object/Goal/Long，每套件 10 任务，训练单一模型）；LIBERO-Plus（LIBERO 的扰动变体，含相机、光照、背景、噪声、布局、语言等八类分布偏移，评估 OOD 泛化，训练只用 LIBERO 原始演示、不加任何适配分布的数据增广）；RoboTwin 2.0（大规模双臂基准，因算力限制在 50 个任务上每任务随机采样 50 条演示，同时考验有限数据下的泛化）。真机两个平台：FANUC CRX-10iA 单臂（两个第三人称相机+一个手内相机，100 条演示/任务，20 次 rollout 评估）与 Unitree G1 人形（下身固定、头部 RealSense 相机、Dex3-1 灵巧手双臂，约 170 条演示/任务，30 次 rollout 评估）。基线包括 OpenVLA、π₀、π₀.₅、UniVLA、Motus、WorldVLA、Fast-WAM、DC-WAM 等（参数 1.23B–7B），真机上以 π₀.₅（微调）与 Fast-WAM（从头训练）为对照。消融在 LIBERO-Plus 上考察潜变量预测目标的作用（去掉后 60%→17.9%）、不同潜表征（DINOv3 单帧 39.7%、WAN VAE 25.9%、V-JEPA 2.1 单图 46.4%、V-JEPA 2.1 视频四帧 60%——证明"未来可预测性"比表征能力本身更关键）以及世界模型/实际izer 的算力分配组合（80M/300M 编码器 × DiT-S/DiT-B）。

## 结果、限制与结论

LIBERO 上 RoboActualizer（60M，无具身预训练）取得 98.0% 总体成功率（98.4/100.0/96.6/96.8），超过 π₀（94.1%）、UniVLA（95.2%）、WorldVLA（81.8%）等参数量为其 2–100 倍的基线，仅次于 π₀.₅（96.9%）与 Fast-WAM（97.6%）但延迟最低（39.9ms 对 111.7–2230ms）。LIBERO-Plus 上总体 63.1%，显著高于 Fast-WAM 的 51.5%（6.02B 可训练参数）与 DC-WAM 的 60.9%（6B），且无开源代码可测延迟；作者将鲁棒性归因于利用了预训练世界模型的泛化能力而微调往往会侵蚀它。RoboTwin 2.0（50 demos/任务）上 58.8%，大幅领先 Fast-WAM（41.9%）、π₀.₅（31.4%）与 LingBot-VA（17.2%），小模型避免了过拟合、数据效率更高。真机上：FANUC 两任务 95%/60%（Fast-WAM 仅 10%/15%）；G1 三任务 77%/83%/90%（π₀.₅ 为 57%/50%/30%），全部超越基线。成本方面：LIBERO 上单张 NVIDIA PRO 6000（32GB 峰值显存）15 小时训练完毕，而 6B 的 Fast-WAM 据其报告配置估算需约 112 GPU 小时；延迟分解显示大部分时间在一次性视频编码，去噪开销很小。定性分析用 PCA 把潜变量投影到 RGB，显示潜变量专家能在不同指令条件下忠实地预测出对应的任务条件未来。

局限（原文明确列出）：受资源限制未在完整 RoboTwin 2.0 基准上实验（仅抽样 50 demos/任务的设定）；方法目前只结合了 V-JEPA 2.1 一种视频世界模型，与其他世界模型的组合及更大规模基准的实验留待未来工作。此外代码承诺在论文录用后放出（当前项目页与 GitHub 仓库已建立）。总体而言，本文用"冻结世界模型 + 微小 actualizer"的分工证明了：从预训练世界模型提取机器人策略的成本可以比主流 WAM 路线低两个数量级，同时保持性能、泛化与实时性。
