## 研究问题与贡献

基础模型擅长高层推理但太慢太贵,无法直接做细粒度控制器;VLA、全身控制器等快速策略反应迅速却难以泛化。把"深思的大脑"与"反应的小脑"组合是具身系统的自然选择,但存在两大障碍:两类方法构建在不兼容的技术栈上,难以同场景对比;其异步协调很困难——智能体在代理循环里调用 VLA 会让快速执行停摆(论文测得每个 LIBERO-Pro 回合因此闲置 2.6 秒,约占 20% 控制时间),而 VLA 出错才回调智能体又会反复触发同一错误、漏掉静默失败(590 个回合中 166 个失败却只触发 6 次升级)。新加坡国立大学 HPC-AI Lab、InfRec Cardinal AI Lab、UC Berkeley、东京大学、中科院深圳先进院与港科大团队提出 REA(Routed Embodied Agent),一个统一运行时:System 2(大脑,智能体)、System 1(具身路由器)与 System 0(小脑,快速策略)在一条黄金法则下协作——任何正在运行的策略都不等待大脑。贡献包括三层运行时与统一策略契约、由路线记忆+边界触发裁判门+共享预算升级梯组成的路由器设计,以及在三个仿真器与真机上的 3 万余条对齐测试回合验证。

## 方法与系统

REA 把回合定义为任务指令、初始状态种子、步数上限与墙钟预算。System 0 中"策略"是任何可从当前状态启动并最终返回的控制器(返回增量步数、耗时、异常与截断标志),可以是冻结的 Python 程序(由编码智能体离线生成,内部调用 SAM 3、ContactGraspNet、PyRoki 逆运动学等原语并在沙箱中运行)、VLA 动作块策略或运动程序段,策略以原生频率运行自己的闭环并可在段边界让出。System 2 离线负责 Generate 生成候选策略,在线提供两个服务:Judge(比较回合初始帧与当前帧判断 done/not_done)与 Advise(推荐候选策略)。System 1 路由器拥有全部控制流,由三个模块组成:路线记忆在评测前把每个候选策略在开发回合上测得成功率与平均步数存成路由表,测试时调度只是查表,把大脑彻底移出派发路径;边界触发裁判门只在策略返回时调用一次 Judge——done 则结束并保护已完成的工作,not_done 则升级,从而既捕获静默失败又不会因同一异常反复唤醒大脑;升级梯按 [first, other, first] 的顺序从当前状态派发下一个策略,所有运行与大脑调用共享同一步数/时间预算,保证恢复有界。运行时还提供串行与异步两种模式,并支持观测条件化的学习式策略选择器(把初始指令、图像与机器人状态编码后给七个 VLA 或 Python 策略打分)。

## 实验设置与数据

主实验在 LIBERO-Pro(MuJoCo/robosuite 后端)的 60 个任务、3000 条测试回合上进行,同场次对比使用相同(任务,种子)对、相同初始状态语义、相同步数与时间预算、共享冻结策略代码库与同一 Score 判定;路线记忆与裁判阈值全部在开发回合上事先冻结。基线包括 Agents SDK + GPT-6、阻塞式顾问(blocking advisor)、ASPIRE、zero-shot GPT-6 策略生成、Codex CLI 以及最强单一 VLA 基线 MEDex 等。扩展实验覆盖 BEHAVIOR-1K(OmniGibson/Isaac Sim,50 回合)、RoboTwin 2.0(SAPIEN,50 干净 + 50 随机化回合的 VLA/代码策略研究及 200 场景侧对侧对比)与真机 Unitree G1(行走并推椅子,10 次试验,Score 由操作员判定)。论文报告总测试规模超过 3 万条对齐回合。

## 结果、限制与结论

论文报告:LIBERO-Pro 上 REA 取得 95.9% 成功率,超过其策略池中最强单智能体基线 Agents SDK + GPT-6 的 94.7%(p=0.004),距 hindsight 逐任务 oracle 不到 1%;比阻塞式顾问减少 25% 控制步数、比 Agents SDK 少 17% 控制时间,大脑阻塞时间从每回合 2.62 秒降为 0。路由带来的改进:ASPIRE 与 zero-shot GPT-6 策略分别提升 +8.6% 与 +7.0%;裁判门比异常门多 +3.1 个百分点成功率(p=0.022),代价是每次成功耗时约 2.1 倍。RoboTwin 2.0 上 VLA 池达 84%、VLA+代码混合池 86%,均高于 MEDex 的 80%;BEHAVIOR-1K 上 27/50 对 Agents SDK 的 25/50(作者注明未达统计显著),RoboTwin 场景 97/200 对 Codex CLI 的 75/200,真机 G1 推椅子 8/10,均为对比中最好成绩。讨论部分明确:大脑仍决定上限(不同方法成功率相差 20-47%),路由器决定能兑现多少;裁判门应按策略库在开发回合上选择——策略很少失败时免费的异常门就够,静默失败多时裁判门才划算。论文未报告独立的消融局限章节之外的系统性失败分析;作者希望 REA 成为开发与比较具身大脑和快速策略的共享平台。方法代码是否随论文发布在当前材料中未确认(项目页对应仓库为项目页源码)。
