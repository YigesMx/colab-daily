## 研究问题与贡献

具身模型如何获得广泛的任务泛化?论文在"世界-动作模型"(World Action Models, WAMs)框架下把它分解为两种互补能力:视频泛化(预测新任务的视觉演化)与动作泛化(通过视频到动作的桥接把预测转成可执行行为)。作者(WorldBridge Team, Joy Future Academy)通过在 RoboTwin 2.0 上系统性改变分布外(OOD)任务的监督来源做归因:只用分布内(ID)视频-动作监督时 OOD 成功率仅 25.07%;为 OOD 任务补充无动作标签的视频即提升到 55.90%;再为每个任务加一条动作标注示教进一步提升到 70.70%。这说明更广的视频覆盖能让模型调用既有的逆动力学能力实现任务迁移,而稀疏动作监督能进一步强化该能力。在此认识之上,论文提出 WorldBridge:用混合变压器(Mixture-of-Transformers)架构与联合流匹配把视频专家和动作专家连接起来,并配套统一数据处理管线,在多个操作基准上取得对比方法中的最优结果。

## 方法与系统

WorldBridge 采用 MoT 双专家结构:视频专家与动作专家各自保有模态专属参数、前馈网络与输出解码器,通过联合自注意力交换信息;视频专家额外用交叉注意力注入语言特征(T5 编码),视觉观测经视频 VAE 编码为条件上下文。训练目标是联合流匹配:对干净的未来视频隐变量 z 与动作块 A_t 独立采样视频/动作流时间步 τ_v、τ_a,按线性概率路径加噪,回归速度目标(噪声减数据);推理时从纯噪声出发对视频隐变量与动作块并行去噪。三个关键设计:一是结构化注意力掩码,建立"记忆 token → 当前帧 → 未来帧 → 动作"的方向性信息通路,使预测的视觉动态显式成为控制的条件;二是双时间尺度视觉记忆,短期记忆捕捉局部运动、长期记忆追踪任务进展,二者与当前观测一起空间 token 化后前置到未来视频 token 前;三是动作强制(action forcing),训练时把动作块按组赋予不同噪声水平,迫使每个动作 token 依赖上下文视觉信息,推理时仍用共享时间步联合去噪。数据侧的统一管线把异构机器人轨迹与第一人称人类手部示教标准化到共享的 46 维动作表征,按维度有效掩码保留不同本体的部分监督;机器人轨迹做运动学与时间一致性校验,手部轨迹在统一参考系下经几何与运动约束过滤。

## 实验设置与数据

预训练语料合计 380 万+回合、2.8 万+小时:真实机器人数据包括 ABC-130K、AgiBotWorld-Beta、AgiBotWorld2026、DROID、Galaxea Open-World、RoboMIND、RoboCOIN、RoboMIND 2.0,仿真数据包括 GenieSim 3.0 与 InternData-A1,覆盖单臂、双臂与类人平台(平行夹爪或灵巧手);视频骨干基于 Wan 预训练权重。仿真评测覆盖 RoboTwin 2.0(全量与 clean-to-random 设定)、RoboCasa GR1 TableTop、RMBench 与 DOMINO Level-1。真机在 AgiBot G2 与 ARX AC-1 两个平台上部署:同一联合预训练检查点分别微调,平台专属适配器连接 16 维(G2)与 14 维(AC-1)原生控制接口;任务涵盖长程执行、依赖记忆的任务、空间定位、小件分拣与双手协调,对比 π0.5、LingBot-VA、FastWAM、Motus 等方法。

## 结果、限制与结论

论文报告:RoboTwin 2.0 全量设定 96.23%、clean-to-random 80.9%、RoboCasa GR1 TableTop 82.8%、DOMINO Level-1 57.6%,RMBench 83.0% 追平对比中最好结果。真机六任务平均成功率 72.5%,高于 π0.5 的 57.5%、LingBot-VA 的 39.2%、FastWAM 的 29.2% 与 Motus 的 10.8%;G2 上插花 70%、挂杯 85%,AC-1 上装箱 80%、螺丝分拣 55%。消融显示去掉联合视频-动作预训练会使真机平均成功率从 72.5% 降至 46.7%(下降 25.8 个百分点),其中螺丝分拣从 10% 升至 55%,说明联合预训练对精细小件操作价值最大;依赖记忆的饮料扫描任务要求记住放置目的地、已扫描项与新插入物品,论文专门分析了该任务的记忆需求。明确的剩余挑战:AC-1 上螺丝分拣仍是最弱任务,精细小件分拣被列为该套件内的未解难题;饮料扫描任务与其他任务的差距也被指出待改进。论文未报告在上述基准之外的更广泛真机失败案例统计(当前材料未确认)。
