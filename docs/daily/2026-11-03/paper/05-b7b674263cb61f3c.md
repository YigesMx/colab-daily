## 研究问题与贡献

代码即策略(Code-as-Policy, CaP)让智能体观察相机图像、面向感知与运动 API 写代码来控制机器人,但现有 CaP 系统回避了训练:要么直接提示闭源前沿模型(每回合调用成本高、无法为新手臂微调、不能上机载算力),要么把抓取、放置等操作本身委托给预训练 VLA 或高层技能,使智能体被技能训练数据封顶;而小型开源 VLM 直接控制机器人几乎全失败(Qwen3.5-4B 在其 harness 中 LIBERO 零成功率)。香港中文大学等机构团队(通讯作者 Xiangyu Yue)提出 CaPtain,一个开放的后训练流水线,把语言智能体成熟的"SFT 学接口 + 多轮 RL 学精通"配方完整搬到 CaP 上:从 Qwen3.5-4B 出发,不依赖 VLA、前沿模型或测试期特权状态,得到能独立操控机器人的 CaPtain-4B,并开放全部代码、数据与模型权重。配套贡献包括只暴露低级原语的 CaPtain-Harness 执行环境,以及把仿真器特权物理状态转化为逐请求稠密信用的物理评判器(physical critic)。

## 方法与系统

CaPtain-Harness 以 ReAct 式循环组织任务:策略(一个 VLM)在每次请求中先在思考通道推理,再输出若干 Python 工具调用;沙箱化 Python 会话跨请求持久保存变量(检测、位姿、助手函数),机器人调用不抛异常而是返回带成功标志、失败类别、消息与值的结构化回执(receipt),记录停止原因、执行距离、峰值力、爪开度等物理事实。harness 只暴露 22 项低级能力加 finish():感知(observe 头/腕 RGB-D、SAM 3 文本提示分割、Molmo2 指点、mark_point、track_target)、测量(物体几何、接触与释放检查)、运动(move_to 绝对末端位姿或爪指令、hold、recover 有界回退、release)与只读的可达性/状态查询;没有 grasp/place 技能、没有 VLA,抓取点、接近方向、闭合时机全部由策略以显式 Python 写出。上下文管理显式截断工具输出、只保留最近 12 张图像,并在接近窗口上限时逐轮压缩历史(RL 回放与测试同样处理)。训练两阶段:第一阶段在 harness 内用 GPT-6 Astra 生成的合成轨迹做 SFT 对齐格式;第二阶段多轮 RL 的核心困难是每个回合数十个请求、物理效果延迟显现而只在回合末看到单一结果,论文利用仿真训练的不对称性——评判器(五个 MLP 集成)读取策略看不到的特权物理状态,学习 V(s,t) 预测成功概率,按 δ_t = c_t + V(s_{t+1}) − V(s_t) 给每个请求稠密信用;终端回报区分"带 finish 的成功(1)、不带 finish 的成功(0.25)、失败(0)、预算耗尽(-0.1)、假 finish(-0.3)",代价项惩罚失败/被拒的物理动作与已解场景后的多余动作。策略更新采用 SAO 流式单遍更新与双侧 token 掩码,每 1024 个回合累积梯度才更新一步,每回合最多 8 个请求进入策略梯度而评判器使用全部请求。

## 实验设置与数据

主评测在 LIBERO 家族(LIBERO 240 官方状态、LIBERO-PRO、LIBERO-Plus、LIBERO-PRO 扰动与 LIBERO-MAX 动态/基座套件)上进行,RL 采样 40 个 LIBERO 任务的新起始状态(随机化光照、相机位姿与材质),评测用的 240 个官方状态排除在外;报告 host 成功(环境目标谓词)与 strict 成功(还要求以 finish() 结束)及配对 McNemar 检验。零样本迁移评测 SimplerEnv WidowX(83.3%)、CaP-Bench、RoboTwin 2.0 与 RoboDojo;真机实验在仅用粗糙仿真孪生适配后进行。对比对象包括提示前沿模型的 CaP 系统(GPT-6 Astra 在 RoboDojo 榜单超过所有公开条目、带编码 harness 的系统在 LIBERO-PRO 达 94.0%)与围绕冻结 VLA/技能构建的 PyRUA、AgenticRoboRL、SenseNova-RoboRSI 等。

## 结果、限制与结论

论文报告:Qwen3.5-4B 零样本 0%,经 SFT 后 held-out LIBERO 达 55.4%,RL 后 73.8%;LIBERO-PRO 达 78.5%,超过多个前沿模型智能体;RL 增益在三个扰动套件上保持 +17.6 至 +21.2 个百分点(所有主套件 McNemar p 小于 0.00001);无目标域训练下 SimplerEnv WidowX 83.3%,CaP-Bench 75.0 高于前沿模型与在该基准上 RL 训练的 7B 编码器;真机在仅仿真适配后可完成任务。论文明确列出局限:向 RoboTwin 2.0 与 RoboDojo 的迁移仍然有限(22.6% 与 0.8% 成功),分别需要双臂协调与不熟悉的手臂运动学。分析还显示信用集中在物理操作决策上,且去掉梯度累积时相邻更新几乎正交,说明该估计器的梯度噪声尺度高达数千回合量级。结论:在低级执行 harness 上,机器人操作可以像任何语言智能体一样被后训练;代码、数据与 4B 权重已全部开放。
