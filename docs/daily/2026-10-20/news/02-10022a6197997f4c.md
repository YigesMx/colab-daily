## 事件概述

10 月 18 日至 19 日，开源 AI 编程工具 OpenCode 爆出安全漏洞事件。据发布方新智元报道，全球不少 OpenCode 开发者一夜之间发现账户 Token 被大量消耗、余额清零，甚至触发自动充值；有受害者晒出账单，称其 Anthropic 账户在不知情的情况下被消费约 400 美元，另有用户称损失超过 1700 美元，还有用户的 Google Cloud 账单出现 1000 多美元的异常扣款（上述金额均为受害者自述，经媒体转述）。

报道转述 OpenCode 官方表态称：这是一起与大规模蒸馏攻击相关的安全漏洞，影响约 1.4% 的 OpenCode Console 用户；问题源于一个正准备下线的旧版系统，该系统被攻破后，用户保存在工作区中的第三方服务商 API 密钥（涉及 OpenAI、Anthropic、Google 等）可能已经暴露。OpenCode 称已连夜向开发者发送预警邮件，并与 Anthropic、OpenAI 和谷歌协同处置。报道还转述 Anthropic 负责人 Lydia Hallie 的回应：所有疑似泄露的 Claude API 密钥已被强制注销。OpenCode 联合创始人 Dax Raad 在 X 平台发帖称，自己的个人账号也在遭受攻击。

报道并引述分析称，攻击者疑似将盗得的 API 额度用于生成顶级模型的高质量输出、为其自训模型积累训练数据，即所谓分布式白嫖开发者额度的手法；该动机判断属媒体与第三方分析，尚未获得官方证实。

## 已确认事实与证据

- 事件主体与性质：发布方（新智元）文章确认事件为 OpenCode 安全漏洞，涉及第三方 API 密钥暴露与额度盗刷；文章全文已从评分阶段留存的评级证据提取留存（文章页静态 HTML 为客户端渲染壳，抓取记录见证据目录）。
- 官方口径（经媒体转述，未能直接核实原文）：OpenCode 在 X 平台的声明与用户邮件称，漏洞与大规模蒸馏攻击相关、影响约 1.4% 的 Console 用户、源于一个将下线的旧系统。本运行对 X 平台该帖、opencode.com 官网首页、博客路径与安全页的抓取尝试均已留痕：X 页面为脚本壳无法静态提取正文，官网首页与产品页未见事件声明，博客路径返回 404。
- Anthropic 回应（经媒体转述）：疑似泄露的 Claude API 密钥已全部强制注销。
- 未独立核实项（保守标注）：具体受害金额（400 美元、1700 美元、1000 多美元）、创始人账号被攻击的细节、攻击者训练自有模型的动机与手法，均为报道转述或第三方分析；OpenCode 官方一手声明未能静态获取。

## 影响与后续观察

- 用户自救要点（据发布方整理）：到各模型服务商的官方控制台撤销并更换可能泄露的 API 密钥，仅修改登录密码或删除 OpenCode 内的配置，都不能使已外泄的凭据失效；检查近期用量与账单并保留异常调用记录，向服务商申请调查与费用处理；依赖旧密钥的应用需同步更新。
- 供应链警示：事件暴露了第三方 AI 工具聚合平台集中保管 API 密钥的风险；报道引述 TestingCatalog 的评价称，这为使用中小型第三方服务开创了危险先例（个人观点，供参考）。
- 后续观察：OpenCode 是否发布事后复盘报告、受影响用户的费用处理与补偿安排（目前未确认存在补偿机制）、各模型服务商的密钥异常监测与响应机制，均值得持续跟踪。
