## 研究问题与贡献

RAX(Robot Agent eXploration)由 Harvard、NVIDIA、UC Berkeley、MIT、Stanford 等机构合作提出,是一个围绕"扩展在线探索"(scaling online exploration)构建的开源机器人智能体框架。核心问题是:部署新机器人本体或新任务通常需要专门的遥操作语料,由此训练的策略又被模仿分布束缚,难以泛化与持续自我改进。RAX 让一个通用编码智能体直接生成机器人控制代码,不依赖动作演示数据、手工动作原语或价值函数引导,通过在线探索识别达成任务目标的决策序列,并将其编译为覆盖感知-规划-控制全回路的模块化程序。论文贡献包括:多本体系统性研究探索规模化的规律、真机无演示自主习得记忆/关节/精密/可变形/长程任务、以及随探索规模化涌现的主动感知、错误恢复、安全护栏与人机协作行为。

## 方法与系统

RAX 的认知架构受 Sutton 的 OaK 架构启发:所有任务知识都在运行时从智能体自身经验获得。感知层提供 RGB、深度、相机参数与力信号,3D 感知与物体模型拟合行为完全从探索中涌现;规划层把机器人控制 SDK(含逆运动学求解器与 URDF 模型)作为 MCP 工具暴露给智能体,后者在 3D 世界中直接规划动作、搜索可行轨迹并检查碰撞。以空气炸锅任务为例,智能体把 RGB-D 提升为点云,用鲁棒估计拟合炸锅的轴与把手方向构建铰接模型,自己发现"从上方抓短臂再分 3 厘米步拉动抽屉"和"手倾 60 度放入香蕉"等策略。探索到程序的转化:初期由 LLM 逐动作控制,成功后将决策编译为可独立运行的代码程序,像软件开发一样分阶段测试、调试与版本管理,异常时抛出异常让主智能体接管;持续学习层把已验证技能存入记忆,供后续会话组合复用;还支持多智能体多环境并行探索。前端-后端分离使新本体仅需通过 API 接入。

## 实验设置与数据

仿真覆盖六个基准:RoboDojo(双臂 ARX X5,7 个任务含域随机化、精密、记忆、长程与开放指令)、BEHAVIOR-1K(2025 挑战 6 个长程家务任务,Galaxea R1Pro,128 探索 episode,仅给完成关键帧无动作)、HumanoidArena、DexJoCo、LIBERO 与 LIBERO-Pro。每个会话从空工作区开始,改变的唯一变量是探索预算 N;探索结束提交程序,在 30-50 个未见场景按官方协议自动评测。基线为 RoboDojo-Sim 排行榜前五的示教训练策略(VPP2、Awomo-0.5、Simate-beta、Rex-M1、VPP2-Preview)与 PhysicalRSI 智能体系统。真机在 Franka FR3 上完成五类桌面任务:四杯下找方块(记忆)、空气炸锅放香蕉(铰接)、湿毛巾擦污渍(可变形)、0.1 毫米间隙插销(精密)、Bandu 塔拆建(精密长程);另在 Rainbow RB-Y1 移动平台上完成拉椅子-叠杯-装篮-运柜-收椅-搬箱的长程物流任务,只给自然语言指令、零遥操作演示。

## 结果、限制与结论

论文报告:最大预算下 RAX 在 RoboDojo 七任务全部超过基线,平均 78.3%,最强策略 VPP2 仅 24.9%;域随机化任务差距最大,sweep blocks random 上 RAX 71.7% 对最佳基线 8.0%,所有学习策略均失败的 pour by language 达 100.0%;性能随探索预算单调增长,plug in charger 从 4 个 episode 的 26.0% 升至 8 个的 94.0%,swap blocks 16 个 episode 达 100.0%,make kong 从 16 个的 64.0% 升至 32 个的 96.0%;make toast random 需 64 个 episode 才达 47.2%。跨五个仿真基准平均比最强基线高 37.4 个百分点。真机上 RAX 无演示学会全部任务,并通过组合已验证技能持续改进;涌现能力包括主动感知(遮挡时移动相机)、错误恢复、安全护栏与人类协作。局限性:依赖通用编码智能体的既有能力,推理成本与 token 开销较大(论文附录给出算力与成本分析),域随机化与 hang mugs random 类任务仍需很大预算(33-39% 区间徘徊);代码形态知识的跨机器人共享尚属展望。
