## 研究问题与贡献

论文《ALIVE: Making Streaming Video Models Interactive》（arXiv:2611.21366，v1 2026-11-16）由清华大学、北京大学、字节跳动、北航与威斯康星大学麦迪逊分校合作完成（Jinzhao Li、Yuan Xu 共同一作等 16 位作者，通讯 Miao Liu）。一句话结论：把流式视频 LLM 从"被动观看、孤立应答"改造为交互式助手——ALIVE 支持主动监控、流式任务协调与反馈寻求交互三类能力，通过对比式 SFT 与行为对齐信用分配（BACA）强化学习两阶段后训练，在四个公开流式基准与自建 FSI-Bench 上取得对比模型中最高的综合成绩。

研究问题：流式视频 LLM 能持续处理视频流、描述与监控事件，但基本是被动的——无法随时间维护并修订用户任务，也不会在视频推进中主动 engage 用户。论文的问题是：什么样的数据表示与学习框架能赋予现有视频 LLM 交互能力？两大挑战：流式交互数据要把用户请求、反馈与助手响应和每一时刻可用的视觉证据对齐；模型必须在多轮演进中学会"何时回应、如何回应"，相似观测可能对应不同行为。

贡献：(1) 把交互式流式视频理解形式化为三类核心能力（主动监控：主动时机/主动理解/重复主动；流式任务协调：任务状态更新/并发请求；反馈寻求交互：Ask-for-Monitor/Ask-for-Information/Ask-for-Execution），并构建 ALIVE-SFT-288K（288,436 条）与 ALIVE-RL-3K（3,523 条）两阶段后训练数据，及评测反馈寻求的 FSI-Bench（1,235 个 episode、4 任务）；(2) ALIVE 模型：对比式 SFT + BACA RL；(3) 实验证明离线视频 LLM 可经后训练变为有能力的交互式流式视频 LLM，同时保持流式理解能力。

## 方法与系统

数据构建：以 25 个公开视频/标注源（Ego4D、EPIC-KITCHENS、QVHighlights、VideoRefer-700K、WebVid 等）为基础，先做时间证据定位与细化（离线 MLLM 粗定位候选区间，再用带双向时间上下文的 MLLM 细化到条件首次可验证满足的最早采样时刻），再做对话合成与时间对齐（用户请求-助手响应/沉默-任务更新/反馈交换按任务状态与视觉证据对齐），最后质量验证（交互策略有效性 + 因果可答性：每个回答只能依赖其时间戳之前的视频与交互历史）。

模型与两阶段训练：ALIVE 从 Qwen3-VL-8B-Instruct 初始化，冻结视觉编码器与连接器、只更新语言模型。输出格式为单一自回归模型：控制 token 决定回应（R）或沉默（S），回应文本表达策略（直接回答/提议继续监控/请求澄清/请求用户执行）。Stage 1 对比式 SFT 构造两类受控对照：响应门控对照（固定视觉前缀与比较时刻，改变查询相关性、任务状态、反馈状态——同一目标出现时活跃监控请求应通知、取消或完成后应沉默）与动作策略对照（固定任务、改变证据可用性或指代歧义——证据充分直接回答、指代不明请求澄清、视觉证据缺失请求用户动作或继续观察），配合交互感知训练（围绕标注响应采样实例端点与视觉窗长，只监督窗内最终响应与全部沉默 token，按 nR/nS 加权平衡响应与沉默）。Stage 2 RL with BACA：每 episode 采样 G=4 条轨迹，轨迹奖励 R_i = D_i·C_i·P_i（D 策略正确性、C 任务完成度含响应正确性/时机/任务状态合规、P 冗余惩罚 exp(-λK/N)）；行为单元从标注的用户轮次、响应目标与沉默条件构造，分策略选择/任务响应/关键沉默三类，跨轨迹按标注身份对齐；模型调用级优势 = 轨迹级优势 + α×局部单元优势，逐 token 优化并加对 SFT 模型的 KL 正则。SFT 一 epoch、批 512、lr 1e-5、1FPS 采样；SFT/RL 数据另混入 274K/800 条反应式 QA 以保持直接问答能力。

## 实验设置与数据

公开基准四个：OVO-Bench（实时视觉感知/回溯追踪/前瞻主动响应）、StreamingBench（实时视觉理解/全源理解/上下文理解）、IPIBench（主动监控/主动任务管理/交错反应-主动请求）、ProactiveVideoQA（Web/自我中心/电视剧 QA 与视频异常检测，PAUC ω=0.5），均用官方协议与官方结果（无官方结果则适配官方评测代码并尽量保持原生推理设置）。对比模型：VideoLLM-Online、Flash-VStream、Dispider、VideoChat3、JoyAI-VL-Interaction、AURA、Qwen3-VL-8B。FSI-Bench：AFM 154/AFI 446/AFE 459/DA 176 episodes，两种协议（显式决策 EDP 三选一；自由形式 FDP 由固定 LLM judge 推断），决策 D、时机 T（±1 步容忍窗）、准确率 A=T·a 级联计分；对比闭源（GPT-6 Astra、GPT-5.6 Sol、Gemini 3.5 Flash）、开源离线（Qwen3.5-9B、Qwen3-VL-8B、InternVL3-8B）、开源流式（VideoChat3、JoyAI、AURA）并给出人类水平参考。

## 结果、限制与结论

论文报告：四个公开基准综合分 ALIVE 均为对比模型中最高——OVO-Bench 69.1、StreamingBench 76.0、IPIBench 40.3（超最强基线 AURA 18.7 分）、ProactiveVideoQA 51.6；IPIBench 分项上主动时机 67.6、重复主动 34.0、任务取消 57.9、任务修改 31.5、并发多任务 28.6，均大幅领先（次优多在 20–44 区间）。FSI-Bench：ALIVE EDP 综合准确率 52.8、FDP 54.0，分别超最强模型基线 GPT-6 Astra 10.6 与 23.9 分；闭源模型在直接回答（DA）上好（A≈78–82）但 AFI/AFE 接近 0；除 ALIVE 外的开源流式模型三类反馈寻求任务全面疲软（A≤0.4）；ALIVE EDP 下 AFM A=96.6、AFE A=64.0，FDP 下 AFM A=97.5、AFE A=64.9；但距人类 FDP 88.5 仍有巨大差距。消融：去对比数据的 SFT 在 FSI-FDP 掉 3.0 分（48.1→51.1），对比 SFT 加轨迹级 RL（无 BACA）54.0 前仅 51.7，完整 ALIVE 54.0，六项综合指标单调上升，证明对比 SFT 与 BACA 联合贡献。

限制（论文自述）：ALIVE 仍是视觉-语言模型，语音交互需外接 ASR/TTS，向原生全模态扩展是后续方向；与人类水平的差距表明交互能力仍处早期。评测依赖 LLM judge 与固定判定规则，长时程（小时级）连续交互与真实穿戴设备部署的表现当前材料未确认；训练数据为公开视频合成对话，真实用户交互分布的泛化未报告。
