## 研究问题与贡献

论文《BiCAT: Bimanual Coordination Action Tokenization》（arXiv:2611.23499，v1 2026-11-17，新加坡国立大学 MAGIC Lab：Xuanwei Liu、Guipu Cao、Zhongyi Luo、Jiafei Duan）。一句话结论：在自回归视觉-语言-动作（VLA）模型中，双臂操作的动作 Tokenizer 不应把两条手臂拼接成一个向量统一量化，而应"共享运动表征 + 伙伴条件化离散化"，BiCAT 据此在仿真与三种真实双臂本体上取得对比 Tokenizer 中的最高成功率。

研究问题：自回归 VLA 用骨干网络的 next-token 目标预测离散动作 token，动作 tokenizer 因此定义了策略与机器人之间的接口。双臂场景中两臂共享一套动作库但通过互补角色协调（如递接物体），而现有 tokenizer 大多把两臂动作拼接成单一向量（joint tokenization），共同运动模式无法共享、跨臂依赖纠缠在每个 token 内，只能靠策略隐式学习；而简单按臂拆分（per-arm tokenization，如 M2Tok）又丢失伙伴上下文。论文的核心问题即：一旦两臂被分成独立 token 流，这两条流应当如何交互才能成为更好的双臂策略接口。

贡献：(1) 提出 BiCAT——按臂索引 token、跨臂共享运动表征、在离散瓶颈两侧（编码端交叉注意力 + 联合解码器）注入伙伴条件的 tokenizer，仅用重建损失训练；(2) 在 RoboTwin 2.0 仿真上超过 7 个 tokenizer 家族的 8 个基线，真实三种本体上超过 FAST 与 OAT；(3) 系统消融证明 tokenizer 内跨臂交互与策略端按臂分块预测二者缺一不可。

## 方法与系统

镜像规范化：利用双臂镜像安装的先验，用本体特定的符号向量把右臂关节翻转映射到左臂坐标系（如 RoboTwin/YAM 用 s=(-1,1,1,1,-1,-1,1)），并对两臂共享统一的通道级归一化边界，使镜像运动共享同一规范轨迹。共享编码器：线性投影 + 两级因果卷积（核 5/3、步长 2，把 H=32 步压缩为 M=8 个潜位置）+ 因果自注意力，参数两臂共享。协调建模：对称因果交叉注意力使每臂特征在量化前获得伙伴上下文（C^L=S^L+CA(S^L,S^R)，反之亦然，query i 只看伙伴 j≤i）。量化：共享投影后用有限标量量化 FSQ（dz=4，levels (8,8,6,5)，词表 K=1920），两臂用同一网格，同一符号在两条流中含义一致；序列化为左臂 8 token + 右臂 8 token 两个块。联合解码：把每个时刻两臂码字拼成成对 memory，6 层 Transformer 解码器从 H 个零初始化 query 并行重建完整双臂动作块；仅用重建 MSE 训练，FSQ 无需 codebook/commitment 损失。tokenizer 仅 7.4M 参数，是对比方法中最小的。

策略训练：冻结 tokenizer，用其 token 监督预训练 VLM 骨干（仿真用 PaliGemma 2-3B，真机用 Molmo2-ER）。预测采用半自回归两块调度：p(y|o)=p(y^L|o)·p(y^R|o,y^L)，每臂 8 个 token 块内并行、先左后右，右臂块以完整左臂块为条件；训练时用块因果注意力和 MASK 前缀一次前向完成双块监督，推理时贪心解码仅两步。

## 实验设置与数据

仿真：RoboTwin 2.0 基准 50 个双臂任务、2500 条演示全量训练 tokenizer 与策略；在训练前预先选定 10 个代表性任务评测（2 个单臂、4 个松耦合、4 个紧耦合），每任务 100 次 rollout。基线覆盖 7 个 tokenizer 家族共 8 个：Bin、FAST、QueST、OAT（token 级与五块两种调度）、M2Tok、NAC、ActionCodec；控制变量：学习型 tokenizer 词表 1920/2048、每块 16 token（NAC 24）、参数 7.4M–11.9M，共享相同数据、骨干、观测与优化设置，仅 tokenizer 与预测调度不同。真机：三种本体（Bimanual SO-101、Unitree G1 人形、Bimanual YAM），每任务 100 条遥操作演示（Pen 任务 105 条），每本体训练一个 tokenizer 与一个策略，6 个任务各 25 次试验（每方法共 150 次），初始物体摆放跨方法一致，单卡 RTX 5090 推理。

## 结果、限制与结论

仿真论文报告：BiCAT 十任务平均成功率 69.3%，最强基线 NAC 为 51.7%（+17.6 个百分点），8/10 任务最佳或并列最佳；增益随耦合度增大：单臂任务 +1.5、松耦合 +17.5、紧耦合 +21.3 个百分点。逐任务如 Stack blocks two 0.66（次优 0.49）、Place bread skillet 0.44（次优 0.23）、Put bottles dustbin 0.49（次优 0.37）。分析显示重建误差与 token 准确率均不能预测闭环成功率，而视觉依赖度（ρ=0.72）、重规划一致性（ρ=-0.80）、块边界平滑性（ρ=-0.78）与成功相关（作者声明为描述性而非因果）。消融：去掉镜像规范 58.7%、去共享模块 56.9%、去编码端交叉注意力 51.7%、去联合解码 56.0%、完全独立 50.0%、单块预测 51.1%、右臂先预测 54.2%——均不超 NAC；FSQ 词表从 240 到 1920 单调升至 69.3%，4375 反降至 58.9%。短板：Handover Mic 0.88 低于 OAT(0.94)/QueST(0.90)，Dump Bin Bigbin 0.85 低于 NAC(0.87)。真机：BiCAT 113/150 成功（SO-101 Block 25/25、G1 Bottle 24/25、Bowl 21/25、YAM Pen 8/25、Box 14/25、Bottle 21/25），高于 OAT 74/150 与 FAST 25/150，六任务全部领先；推理延迟 91.7±1.3 ms，比 FAST 低 4.7 倍；仿真中两块预测每块仅 40.5 ms，比逐 token 解码快 5.6–11 倍（ActionCodec 单块 26.8 ms 更快，但 BiCAT 单块化会损 18.2 个百分点）。

限制（论文自述）：目前仅工作在关节空间，固定逐关节符号映射不能直接扩展到末端执行器动作（位置与姿态需不同变换）；每个 tokenizer 针对单一本体训练、两臂 token 预算固定且相等；末端执行器动作、跨本体迁移与自适应 token 分配是未来工作。真实试验仅 25 次/任务且初始摆放固定，统计功效有限；对长程任务与动态干扰场景的表现当前材料未确认。
