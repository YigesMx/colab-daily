## 研究问题与贡献

物理落地的铰接式 3D 资产生成要求不止复现物体"看起来如何"，还要捕捉"如何运动与发挥功能"：部件层级、关节、质量与材料、无碰撞运动以及重力下的稳定性。现有学习方法把外观、形状、铰接与各类物理属性割裂处理；程序化生成器受预设规则限制、难以用于基于图像的重建；单智能体的 agentic 方法（如 Articraft）既存在"自评偏差"，又不直接在物理仿真器中检验结果。论文提出 Artisan：在 Articraft 蓝图上引入多智能体流水线与物理仿真反馈，并构建统一的评估基准。

## 方法与系统

流水线由三个相互独立的智能体组成：Design Agent 产出指定部件、关节与铰接的蓝图；Coding Agent 把蓝图翻译为输出几何、铰接与物理参数（含标准 PBR 材质与质量）的程序；Review Agent 校验构建出的资产并把反馈交回 Coding Agent 修订。智能体之间只交换蓝图、3D 资产与反馈，独立性降低了自评偏差；校验环节进一步接入物理仿真器，在目标仿真环境（如 MuJoCo）中验证碰撞与稳定性等物理属性。物理属性上，直接推理部件质量的估计优于"材料密度×几何体积"的推算方式。

## 实验设置与数据

基准覆盖四个方面：空间保真、物理合理性、下游任务表现与总体质量，包含来自 ArtVIP 与 LightWheel 的 100 个参考资产、50 条稳定性提示，以及带参考质量的 50 个 ABO 物体；作者在此基准上评测了超过 10 个代表性模型。下游实验用 Artisan 与 Articraft 资产采集的机器人演示训练 π0.5 模型，在 RoboTwin 2.0 与 RoboCasa365 上评估（每个测试资产 50 次 rollout）。人类评估采用交互协议：参与者在 MuJoCo 中直接操纵物体、观察其对施力与接触的响应，再结合渲染视图投票。

## 结果、限制与结论

Artisan（GPT-6 Astra 底座）在 11 项空间保真指标中的 8 项领先，同时把碰撞率降到单关节评估 1.7%、多关节评估 13.0%，静止与铰接状态稳定性分别达 98% 与 96%，为所有被评测方法中碰撞最低、稳定性最高。消融验证了设计选择：同底座下多智能体流水线相对 Articraft 平均改善 pCD 5.4%、pIoU 4.9%、碰撞率 11.9%；去掉物理验证会使单/多关节碰撞率从 1.9%/16.4% 飙升至 35.7%/73.2%，开启状态稳定性从 96% 降至 90%。机器人任务中，用 Artisan 资产训练的 π0.5 在两个基准上成功率均高于用 Articraft 资产训练，把 Artisan 资产并入原训练集也能提升未见实例上的成功率，资产资格通过率平均高出 37 个百分点。人类评估中 Artisan 获得 43.3% 的 Top-1 与 85.1% 的 Top-3 票，远超第二名 Codex（21.1% 与 68.7%）。
