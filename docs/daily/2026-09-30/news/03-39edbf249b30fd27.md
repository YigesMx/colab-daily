## 事件概述

Anthropic 在 OpenAI 年度开发者大会开幕前夜发布 Claude Sonnet 5.5。据新智元报道（发布与偷跑实测两篇同对象），相较 Sonnet 5 其运行速度提升 30%、完成相同任务成本最高下降 30%，标价约为 Opus 5.5 的一半；在智能体编程测试 Terminal-Bench 4.0 中得分 70.6%，反超 Opus 5.5 的 66.4%；第三方 Artificial Analysis 智能指数榜前三名全部为 Claude 系列模型，Sonnet 5.5 位列第二。它也是首个仅凭屏幕截图通关《宝可梦 红》的 Sonnet 模型。

## 已确认事实与证据

- 发布事实、定价（每百万 token 输入 4 美元/输出 20 美元，为 Opus 5.5 一半）、100 万 token 上下文与单次最多 12.8 万 token 输出：来自 Anthropic 官方产品页与新智元报道，官方页面已留存核对。
- 速度/成本提升（+30%、-30%）、Terminal-Bench 4.0 70.6% 对 66.4%、Artificial Analysis 排名：来自新智元实测转述与榜单引用，属可归源的第三方评测口径。
- 用户可调节 Effort Level（低/中/高/最大）影响思考深度与 token 消耗：官方产品功能。
- 未知事项：训练数据与规模变化、安全评估红队结果，官方未披露。

## 影响与后续观察

- 中杯模型以一半价格反超大杯，直接改写企业智能体工作负载的性价比计算；与上期 Opus 5.5 的"出片潮"呼应，Claude 系列在智能体编程与长任务自治上的优势正在转化为定价权。
- 发布时点选在 OpenAI 大会前夜，竞争姿态明确；后续观察：OpenAI 开发者大会的应对发布、Terminal-Bench 等智能体基准的第三方复测、以及 Sonnet 5.5 在真实工程任务中的采用率。
