## 研究问题与贡献

离散动作 token 的 VLA 模型在机械臂控制上已被证明有效，但人形的全身动作空间（腿、躯干、手臂、手）维度远更高且高度异构，带来 token 化、训练与实时推理的新挑战。Holo-M 据作者所知是首个面向人形 loco-manipulation 的离散 VLA 模型，通过扩展语言模型词表让动作 token 内在地利用语言模型本体。

## 方法与系统

Holo-M 设计统一动作 tokenizer，把人形动作空间分解为末端、身体、手与运动学四个本体部位专属 tokenizer，使跨越人形遥操作、自我中心人类视频与仿真等截然不同的本体和数据源的训练成为可能；把动作 token 直接并入语言模型词表，避免外接连续动作专家带来的"知识绝缘"问题。为满足实时控制，各部位动作 token 通过分组离散扩散解码生成，而非在动作 token 上自回归。

## 实验设置与数据

训练分阶段进行：先在跨本体混合数据上建立统一表征，再在 SIMPLE 人形 loco-manipulation 基准训练集上做后训练对齐目标机器人；评测覆盖 SIMPLE 基准的 generalist 与 specialist 两种模式，与基线模型对比。

## 结果、限制与结论

论文报告：Holo-M 在 SIMPLE 基准的 generalist 与 specialist 两种评测模式下均取得最高成功率，领先第二名显著；作者承诺开源全部代码与模型权重。局限：评测以 SIMPLE 基准为主，真机部署细节与失败案例论文未充分展开（当前材料未确认）；离散 token 化对极高精度接触任务的适配性有待更多证据。以上结论均为论文报告口径。
