## 事件概述

OpenAI Developers 在 10 月 8 日发布的公告中宣布，GPT-6.1 Sol 的 Ultrafast 模式开始向 API、Codex 和 ChatGPT Work 推出。10 月 10 日中文报道进一步讨论了其价格与使用门槛；这不是当天才首次公布的全新模型，而是同一模型新增或扩展高速服务档位。

官方把它定位于延迟敏感工作，声称相较 Sol Standard，API token 生成速度最高可达八倍。该说法有明确比较基线，但不等于任意端到端任务都能缩短到八分之一，也不是本次独立测得的结果。

## 已确认事实与证据

官方定价表列出，Sol Ultrafast 的短上下文价格为每百万输入 token 12 美元、输出 token 60 美元；长上下文栏为 24 和 90 美元。缓存读取、缓存写入有独立价格，部分区域处理端点另有加价，因此上述数字不能直接当作所有请求的最终账单。标准档短上下文输入、输出分别为 2 和 10 美元，高速档的成本差异是真实的服务分层，而非免费提速。

API 指南说明，Ultrafast 对 API 用户开放，需在请求中选择支持的模型和服务档位，并遵守独立于 Standard、Fast 的速率限制。官方强烈建议频繁调用工具的智能体应用使用持久 WebSocket 连接，以避免反复建连抵消延迟收益；HTTP 仍然受支持。Sol Ultrafast 支持全球处理及美国、欧盟数据驻留，但具体地区仍须符合服务支持范围。

Codex 和 ChatGPT Work 的规则不同。官方公告列出的接入范围是 Pro 500、符合条件的按用量企业套餐和按点数教育套餐；企业管理员还需启用。不能据此声称所有订阅用户都可使用，也不能把 API 的普遍可接入与产品套餐门槛混为一谈。

## 影响与后续观察

事故排查、连续工具交互和实时体验可能更看重响应速度；离线批处理或主要耗时在测试、依赖安装、网页加载的任务，未必值得为生成速度支付溢价。评估时应同时记录首字延迟、完整任务耗时、成功率与总费用，而不只看每秒 token 数。

官方“接近 Astra 的智能水平”和最高速度均是发布方表述，不能推导出所有任务质量等同于旗舰模型。媒体中的少量用户测试可作为线索，不能代表稳定服务表现。后续仍需在自身工作负载、速率上限和预算条件下验证收益。
