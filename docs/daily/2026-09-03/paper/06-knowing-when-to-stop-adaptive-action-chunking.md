# Knowing When to Stop: Adaptive Action Chunking via Internal Cross-Attention Dynamics in VLAs

**一句话结论**：清华大学团队发现 VLA 动作专家内部的"动作→观测交叉注意力熵"随预测步数上升并进入高熵平台，且高熵段与离线动作误差强相关（顶部 MSE 四分位误差高 10.4 倍）；据此提出免训练的自适应动作分块——推理时监测熵平台、动态截断执行视野，在 π0.5 与 X-VLA 的 RoboTwin 2.0/LIBERO 与三个真机任务上平均成功率领先全部固定视野与既有自适应基线，附加延迟 <7 ms。

## 研究问题与贡献

动作分块（action chunking）是现代 VLA 的标准执行策略，但固定执行视野 H_e 强制在精度与效率间二选一：短块推理频繁、易震荡，长块与新观测错位、预测精度塌陷；最优视野还随任务与任务阶段变化（快速接近 vs 精细交互）。人工调参或静态启发式限制了泛化。本文三贡献（原文报告）：(1) 刻画流式 VLA 中动作-VLM 逐视野注意力发散现象，证明持续高熵饱和与离线动作误差升高相关，可作为感知接地减弱、预测风险升高的经验指标；(2) 免训练、零架构改动的动态截断机制；(3) 跨两个 SOTA VLA、仿真+真机的系统评测。

## 方法与系统

**统一交互形式**。π0.5（解耦：VLM token 作静态 K/V）与 X-VLA（耦合：VLM 与动作 token 拼接联合自注意力）都可统一为"动作 query 从感知 key 检索信息"的交叉注意力形式，注意力矩阵 W∈R^{H_p×N} 的行是预测步、列是 VLM token。

**熵动力学**。把每层动作→VLM 注意力系数沿层轴聚合归一成分布 p_{i,j}，计算每个动作 token 的交叉注意力熵 E_j（上限 log N，π0.5 为 ln(968)≈6.87）。规律：熵随动作索引上升进入平台；粗接近阶段熵缓升、平台来得晚，精细预交互阶段熵急升、早平台——阶段依赖意味着固定视野无法适配。定性上早期动作注意力锐利集中在语言 token，后期动作注意力转向视觉 token 且几乎铺满整个视野（Layer 9/14 可视化）。

**熵作为精度代理**。留出演示轨迹上逐帧预测 50 步并与记录未来逐步对比：熵与 MSE 显著正相关（Pearson r=0.187、Spearman ρ=0.432，p<10^-120）；对块内动作索引回归后偏相关仍显著（r=0.214），说明不是"越靠后越难预测"的伪相关。12 等频分箱显示 MSE 在 E≈6.5（约 95% 理论上限）处急剧上升；高熵区间内顶部 MSE 四分位的平均误差高 10.4×、误差标准差高 12.1×。

**自适应截断**。最终去噪步计算熵序列，滑动平均（窗口 k=5）去噪后，检测"持续高熵平台"：熵超过 η=0.95（归一化阈值，按熵-MSE 关系一次性选定，不按任务/架构调参）且持续 τ=0.01 以上增长的最早点之前执行；无平台则执行全视野（X-VLA 上升/波动但无持续平台时执行完整 30 步）。只用策略已计算的注意力权重，近乎零开销。

## 实验设置与数据

RoboTwin 2.0 选 10 个代表任务按平均 episode 长度分短/中/长视野三档：π0.5 逐任务 50 条 Aloha Agilex 演示微调 40K 步（H_p=50，固定视野对照 10/15/20/25）；X-VLA 用 50 任务全训开源模型（H_p=30，对照 15/20/25/30）；三种随机种子×100 rollout。动态基线：多种采样（MS，20 次采样估动作熵）与自注意力法（SA）。LIBERO 四套件（π0.5 H_p=10 时窗口降为 k=3）。真机：ARX 双臂（R5 从臂+X5 主臂）+双腕鱼眼+头戴 RGB，20 Hz 图像/60 Hz 控制环，三任务（单臂遮挡挂杯、单臂转双臂递笔、接触密集双臂三杯堆叠），每任务 50 演示微调、20 次试验。效率在单张 A100 上测单次推理周期延迟。

## 结果、限制与结论

**RoboTwin 2.0（论文报告值）**：π0.5 上本方法平均 62.9%，超全部固定块（最强 chunk=10）与 SA、MS；平均执行视野 18.11 步显著长于 chunk=10——高置信阶段延长执行、降低推理频率的同时精度反升。X-VLA 上同一归一化判据（无架构专属阈值）取得最高平均成功率，固定视野只在个别任务达峰但跨任务波动大（如 Blocks rank rgb 在 15 步只有 33.0 vs 20-30 步 82-86）。

**真机（论文报告值）**：三任务平均成功率比最佳固定块配置（chunk=20/30）高 14.2%，比最强自适应基线 SA 高 6.7%；MS 按原文配置因块过小导致执行碎片化、动作间歇停顿而失分。**效率**：MS 每推理周期多 29.5 ms；本方法与 SA 附加延迟 <7 ms，适配高频闭环。

**限制（论文自述）**：依赖可辨识的交叉注意力通路，高度交错或层次化架构难以聚合统一不确定性信号；尚未在新兴世界动作模型（WAM）这类不同生成动力学范式的模型上评估。track 补充：熵阈值 η=0.95 全局固定虽免调参，但熵上限 N 依赖 VLM token 数（π0.5 968 vs X-VLA 200），跨架构归一化假设"熵分布形状相似"，其稳健性原文未完全论证；真机仅三任务×20 次，统计功效有限。
