## 事件概述

2026年11月5日，Anthropic在官网发布研究报告《AI for Scientific Discovery: How Researchers Use Claude》，基于20万余次真实Claude与Claude Code科研会话，系统刻画科研人员如何使用AI。报告主文共35页（另有附录），这是该公司首次用大规模真实使用数据测度AI对科研的实际渗透。报告推演显示：若现有AI能力被广泛采用，部分学科的研究产出可接近翻倍；在所有非体力科研工作全部自动化的假设情景下，计算机科学、统计学等学科产出最高可提升约15倍。多家中文媒体以"全球科研产出或拉爆16倍"为题进行了报道，"16倍"为媒体转述口径，官方正文表述为最高约15倍（15-fold），差异在情景设定与舍入方式，当前材料无法核实媒体"16倍"的精确出处。

## 已确认事实与证据

以下事实均由Anthropic官方页面与官方PDF原文确认:样本为2026年8月2日至9月30日的207,049次科研会话,其中Claude(Chat/Cowork)128,914次、Claude Code 78,135次,另辅以研究者问卷;采用SciNet科研分类法(34个学科、318个子领域、7,262项任务),以隐私保护管线只保留聚合标签。按学科看,Claude会话占比前三位是计算机(11.9%)、工程(8.4%)、医学(7.7%);Claude Code上计算机科学家仅占全球科研人员4.3%,却贡献了32.7%的科研会话,人工智能与机器学习子领域以1.2%的科研人员占比贡献15.2%的Claude Code会话。按任务看,数据分析约占Claude科研会话的三分之一、Claude Code的近一半,写作与交流占比同样显著偏高,而科学家问卷中排名第一、第二的"提出想法与假设""数据采集"恰是AI参与最少的环节。能力匹配上,AI理论能力最强的前20%任务获得了相当于工时占比2至4倍的调用量。情景推演方面:以当前能力广泛普及计,AI可承担27%-52%的研究工时(中位数38%),统计学产出约2.02倍、计算机科学约1.96倍、化学约1.41倍(报告假设AI每小时成本30美元、研究员95美元);若全部非体力工作100%自动化,计算机科学、统计学等最高约15倍,化学、生物等依赖实验操作的学科约3-4倍。问卷中约40%的活跃AI使用者预计2030年前AI可独立完成整个研究项目。

## 影响与后续观察

报告最具结构性的发现是"加速潜力最大的学科恰包括生产AI本身的学科"，即AI加速AI研究、更强AI再加速整体科研的正反馈闭环。这一判断与同期METR对Anthropic的独立评估（模型能力增速约为此前两倍）相互印证，值得持续跟踪。同时应明确：15倍为条件苛刻的模型推演上限而非预测，依赖全员采用、任务全自动化与成本假设成立；实验学科约四成工时必须人工完成的物理瓶颈短期难以消除。调查样本限于Claude消费级计划用户、分类由模型自动完成，存在度量与代表性局限，官方亦提示AI自主研究带来的伦理与监管风险。后续可关注独立团队对方法学的复现检验，以及各学科真实产出统计是否出现可观察的变化。
