# 阿里千问办公接入企业微信

## 事件概述

2026年8月18日，量子位报道称，阿里巴巴旗下 Agent 产品“千问办公”正式接入企业微信。此前该产品已接入钉钉和飞书；此次更新后，千问办公覆盖了国内三大主流协同办公平台。

## 已确认事实与证据

报道称，用户进入千问办公连接器，按页面提示完成企业微信账号授权和必要配置后，无需单独安装或使用命令行工具，即可通过对话调用企业微信能力，包括读取智能表格、新建和读写文档、发送通知、查询日程、预约会议以及创建待办。该功能当时已在网页端开放，客户端入口“即将上线”。

报道还称，千问办公于8月3日开启公测，定位企业级办公场景，除钉钉、飞书和企业微信外，也已接入 Slack；个人和企业用户可通过官网 qwenwork.cn 体验。文章转述产品规划称，未来将上线独立 App 和国际版，并扩大全球企业协同场景覆盖。上述功能范围、公测时间和平台覆盖来自量子位报道，尚未由阿里巴巴官方公告逐项交叉确认。

## 影响与后续观察

接入企业微信使千问办公能够进入以企业微信为核心协同入口的组织，把表格、文档、消息、日程、会议和待办等常见办公对象连接到 Agent 工作流。对企业用户而言，关键观察点包括授权与数据权限边界、跨平台任务的可靠性、审批与审计能力、客户端入口上线时间，以及国际版的数据合规安排。报道中的示例属于功能说明，不代表所有企业环境中的实际部署效果。
