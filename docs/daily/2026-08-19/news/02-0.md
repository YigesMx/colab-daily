# Current Robotics 发布 CurrentWorld-0 交互式世界仿真器

## 事件概述

2026年8月18日，量子位报道称，Current Robotics 团队发布交互式机器人世界仿真器 CurrentWorld-0。报道将其描述为面向机器人评测与训练的“第二世界”，核心目标是让不同本体、不同观察方式和不同动作接口的机器人，在进入真实环境前能对同一个受动作影响的物理过程进行推演。

## 已确认事实与证据

报道称，CurrentWorld-0 将跨本体动作建模、多视角一致生成和力-触觉预测放在同一系统中。系统保留不同机器人本体的 Action Subspace，不强制所有机器人使用同一种动作格式，而是在接收各自动作后推演物体、场景和接触状态的变化。多视角部分旨在让第三视角、头部相机和腕部相机对同一次事件保持一致记录；力觉与触觉部分则用于补足画面难以判断的接触、受力和抓取稳定性。

报道还称，CurrentWorld-0 支持在策略执行进入潜在失败状态时由操作员遥操作接管，当前状态可保存和回滚，纠错轨迹可继续用于策略后训练。文章将其与 Current Robotics 此前的 Hi-WM 工作关联，并说明创始人祝毅晨曾任美的集团具身智能部部长，团队此前完成过 TinyVLA、DiffusionVLA、DexVLA 和 dWorldEval 等研究。上述系统细节和团队背景均来自量子位获授权刊载的报道，报道未提供可独立复核的量化基准。

## 影响与后续观察

CurrentWorld-0 试图解决机器人世界模型评测中的动作可控性、跨本体动作差异、多相机漂移和接触状态不可见等问题。如果公开技术报告或可复现实验验证这些能力，它可能降低机器人策略在真实部署前的试错成本。后续需要观察官方项目页、模型或代码开放情况，跨本体和多模态预测的定量指标，以及纠错轨迹用于后训练的实际收益。报道中的演示效果不能直接等同于真实任务性能。
