# OpenAI 称 Asana 用 Codex 两周完成测试系统替换

## 事件概述

2026年8月18日，OpenAI 官方新闻摘要宣布，Asana 使用 OpenAI Codex 在两周内替换了一套过时的测试系统。OpenAI 称，这项原本预计需要五年工程时间的工作，实际花费约 1.2 万美元完成。

## 已确认事实与证据

OpenAI 官方 RSS 摘要给出的可确认事实包括：使用方为 Asana；工具为 OpenAI Codex；事件为替换过时测试系统；完成时间为两周；原始工程量预估为五年；成本约为 1.2 万美元。该摘要来自 OpenAI 官方新闻源，能够确认发布主体、发布时间、事件和官方 URL。由于文章页直接访问返回 403，且保存记录仅有官方摘要，当前证据没有说明旧测试系统的技术栈、替换范围、代码规模、质量验收方式、参与工程师角色、成本计算口径，也没有提供 Asana 独立署名的复盘材料。

## 影响与后续观察

OpenAI 将该案例用作 Codex 在大型工程迁移任务中的示例，显示 AI 编码代理可能被用于处理范围明确、可验证的存量系统替换。对工程组织而言，更有参考价值的问题不在“两周”本身，而在测试如何验证替换正确性、人工审查投入多少、迁移范围如何界定，以及 1.2 万美元是否只覆盖模型调用成本。后续应关注 Asana 或 OpenAI 公布的完整案例细节、质量指标和长期维护结果。单一厂商摘要不能证明同类任务普遍能在同等时间和成本内完成。
