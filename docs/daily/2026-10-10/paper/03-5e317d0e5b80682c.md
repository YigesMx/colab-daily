## 研究问题与贡献

VLA 模型的成功依赖大规模多样数据，但真实机器人数据昂贵且本体绑定，长时域移动操作更是部分可观测、动作维度高、导航与操作深度耦合，遥操作采集难以覆盖。论文提出 SimVLA，一个完全用合成仿真数据训练、无需任何遥操作的移动操作框架，并实现零样本迁移到真实环境。核心贡献是把仿真用作三种互补监督来源：动作轨迹、特权视觉语言监督与面向部署的策略回放数据。

## 方法与系统

框架包含三个数据集与两阶段训练。SimAction 在程序化生成的厨房场景中通过组合原子技能 API 生成 35 个移动操作任务的动作轨迹，无需遥操作；SimVQA 利用仿真器的特权状态提供空间、几何与子任务级的视觉语言监督用于共同训练；SimDeploy 从多样仿真环境中的策略回放收集，暴露更广的场景布局。模型先在 SimAction 加 SimVQA 上预训练，再在 SimAction 与 SimDeploy 混合上后训练，架构刻意沿用 π0.5 风格以隔离数据贡献，并用子目标随机化与大量 Objaverse 物体实例保证多样性。

## 实验设置与数据

任务包括补货、倒水、清洁等；真实评测覆盖模拟厨房、食品储藏间与真实家庭三类环境，与用 50 或 200 条域内真实演示微调的 π0.5 对比，并专门考察位置与视觉分布外以及目标初始不可见的设定。

## 结果、限制与结论

SimVLA 平均任务进度 54.4%，超过用 50 条真实演示微调的 π0.5；后者即使用 200 条演示在模拟厨房达到 67.8%，在储藏间与真实家庭却分别跌到 21.3% 与 29%，而 SimVLA 在三种环境中保持一致。目标初始不可见时对比移动操作方法成功率为 0，SimVLA 通过习得的主动视觉行为找到目标。局限在于：未拆分各域随机化因子的贡献；任务限于厨房类刚体操作；仅在部分本体与架构上验证；技能 API 仍依赖人工定义，未来可用 LLM 扩展为代码化技能。
