## 事件概述

10月9日，Anthropic 发布 Claude Haiku 5.5。据新智元报道，其单价降至上一代 Haiku 4.5 的十分之一，与 OpenAI 的 GPT-6 Luna 同价，官方将其定位用于批量大、要求快速且省成本的任务，如摘要、上下文压缩、分类与数据库查询。

## 已确认事实与证据

报道援引的定价为：提示在10万 Token 以内时，每百万 Token 输入0.10美元、输出0.50美元；超过10万 Token 后按输入0.50美元、输出2.50美元计费；缓存读取每百万 Token 0.01美元，批处理再打五折。官方测算同样的工作平均比 Haiku 4.5 节省约75%成本。跑分方面：电脑操作基准 OSWorld 从上一代15.7%升至72.4%，同价位的 Luna 为48.9%；终端编程 Terminal-Bench 4.0 从零分升至39.2%；知识工作 GDPval-AA 拿下1620分；HLE 不带工具从10.2%升至45.9%。模型 ID 为 claude-haiku-5-5，上下文100万 Token，单次最多输出12.8万 Token，是首个支持调节思考档位的 Haiku，档位从 Low 到 Max 共五档，API 默认 Medium，已在 Claude 客户端、Claude Code 及多家云平台上线。内测公司反馈，Asana 的任务完成延迟降低三成以上，Box 测得延迟约为 Haiku 4.5 的一半。上述定价与评测数据均来自新智元报道转述，Anthropic 官方发布页当前材料未直接核验。

## 影响与后续观察

低价高性能小模型正在改变代理任务的成本结构：官方建议让 Opus、Sonnet 拆解任务，由 Haiku 5.5 作为子代理执行，复杂编程仍交给 Sonnet 5.5 与 Opus 5.5。同日 Sonnet 5.5 缓存读取价格减半，Max 与 Team 订阅开始按月附送 API 额度，小模型价格战或将进一步加剧。另需注意，报道提到新分词器会使同样文字的 Token 数增加约三成，迁移成本估算需重新核算。
