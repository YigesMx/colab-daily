## 事件概述

据新智元 10 月 17 日报道，Anthropic 宣布 Claude Opus 5.5 的「极速模式」结束研究预览阶段，取消所有等待名单，向全体开发者开放。官方文档称，极速模式采用与标准版完全相同的模型权重与智力水平，纯粹通过优化底层 API 与推理配置把资源集中在响应速度上，每秒输出 token 速度（OTPS）最高提升 2.5 倍，无需在速度与质量之间二选一。

## 已确认事实与证据

- 使用方式：API 请求中加入 speed: "fast" 参数即可；Claude Code 用户在终端输入 /fast 随时切换，v2.1.280 及以上版本中极速模式默认使用 Opus 5.5。目前仅支持 Opus 5.5、Opus 5 与 Opus 4.8，Sonnet、Haiku 等模型不支持，Opus 4.7 极速版已于 2026 年 6 月弃用。
- 定价（每百万 token）：Opus 5.5 极速版输入 8 美元、输出 40 美元，反而低于 Opus 5 与 Opus 4.8 极速版的输入 10 美元、输出 50 美元。
- 注意事项：极速模式拥有独立限流池，触及上限会自动平滑回落到标准速度，冷却后恢复；极速与标准模式之间不共享提示词缓存，会话中途切换可能重新支付一笔无缓存的输入费用（每个对话只收取一次）；对 Pro/Max/Team/Enterprise 订阅用户，极速模式按额外「使用额度」计费，不包含在常规订阅限额内。
- 平台进度：API 与 Microsoft Azure Foundry 已上线，Google Cloud 即将推出，AWS Bedrock 暂不支持。企业可在配置中设置 fastModePerSessionOptIn，强制每次新会话默认关闭、员工手动开启以防成本失控。
- 同期上线的「空闲压缩」会在约 54 分钟闲置后把 20 万 token 级长会话自动压缩成摘要以节省 token，可通过 idleCompaction 关闭。另有传闻称新模型 Fable 5.5 已进入早期访问，属未经官方确认的消息（未确认）。

## 影响与后续观察

有开发者评论称「对智能体循环来说，p95 延迟比什么都重要」，极速模式对高频迭代的编码、实时调试与限时冲刺场景是直接利好，「提速降价」也可能加剧推理服务的价格竞争。后续可关注实际负载下的稳定性与缓存成本、企业侧用量管控效果，以及传言中后续模型的官方发布节奏。
