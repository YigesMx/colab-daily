## 事件概述

Meta 于 10 月 16 日发布并开源新模型 Muse Spark Open：总参数 816B、上下文窗口 100 万 token，原生支持文本、图像、音频与视频输入，官方将其定位为「美国迄今最强大的开源权重模型」。该模型面向复杂编码、长程任务与智能体工作流设计；最引人注目的是，借助苹果统一内存架构，两台搭载 M5 Ultra 芯片的 Mac Studio（合计 1TB 统一内存）即可在本地运行这一 816B 模型。

## 已确认事实与证据

据 AI Insider 与新智元报道：模型采用 MoE 架构，激活参数 42B；权重已在 Hugging Face 开放，并可通过 AWS SageMaker、Google Cloud 与 Microsoft Foundry 获取，Baseten、Fireworks、Groq、Together AI 等主流 API 平台同步上线。

本地运行门槛不低。AI Insider 转引 Engadget 称至少需要 1TB 内存；新智元报道，四台 Mac Studio 组成的集群每秒可生成超过 36 个 token，四张 NVIDIA Blackwell GPU 以投机解码实现单 GPU 每秒超 5 万 token 的吞吐（均为厂商口径）。

Meta 以自家编码终端 Muse Code 驱动智能体工作流：向开源 Mastodon 客户端 Ice Cubes 交付了缺陷修复、新功能与一次完整构建，并端到端操作视频剪辑软件 DaVinci Resolve，完成素材逐帧审看与竖屏裁剪。

许可证为 Muse Model License：当许可方及其关联方任意连续 12 个月合计营收超过 2000 万美元、并将模型作为服务提供时，须事先通知 Meta 并另行签署书面协议；据此，绝大多数开发者可免费商用（据新智元译稿）。

## 影响与后续观察

这一发布把「桌面级超算」叙事推向主流：开发者无需机房与云端 API 即可运行顶级开源权重模型，数据不出本机，对初创团队、独立开发者与视频工作室具备吸引力。新智元还报道了 Meta 与苹果的罕见联手——扎克伯格发帖感谢苹果新 CEO John Ternus，后者回应祝贺，Axios 亦有跟进；双方具体商业安排未披露。后续可关注第三方对官方评测的独立复现、各 API 平台的放量节奏，以及高营收企业许可条款的实际执行。
