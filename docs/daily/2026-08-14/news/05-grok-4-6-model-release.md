# 马斯克Grok 4.6重回一梯队！更低价格反超Fable 5，这Cursor是真没白收购

## 事件概述

量子位于 2026 年 8 月 13 日报道 Grok 4.6 上线，并将其定位为面向长程 agent 任务的模型升级。SpaceXAI（xAI 官网现用品牌）在 8 月 12 日的官方公告中称，Grok 4.6 在 Grok 4.5 基础上强化多步任务、交互式和视觉工作；量子位补充了价格、接入渠道和基准对比。本文把官方可核验内容与媒体转述分开说明。

## 已确认事实与证据

SpaceXAI 官方公告称，Grok 4.6 可在研究主题、分析信息、跨代码库工作或把想法做成应用等多步任务中持续推进；官方表格列出 AA Intelligence Index 61、GDPVal-AA v2 1753、CursorBench v3.2 69.9%、DeepSWE v1.1 65.9%、FrontierCode v1.1 Extended 61.3%、APEX-Agents 57.5%、Terminal-Bench v3.0 26%、AA-Briefcase 1577 和 Harvey LAB 15.8% 等结果，并注明竞品数据来自各开发者系统卡或公开排行榜。官方同时称该模型已在 Cursor、Grok Build、API 及 OpenRouter、Vercel、Cloudflare 等渠道提供，价格起于每百万输入 token 2 美元、输出 6 美元，另有价格翻倍的 fast variant，Cursor 与 Grok Build 首周提供 2 倍包含用量。

量子位报道还称，Grok 4.6 的长上下文定价、不同入口和 Grok Bot 组合构成了产品策略，并转述多项基准“反超”竞争模型。官方公告支持模型定位、渠道、价格起点和自报评测表，但没有独立第三方测试；量子位文章中的商业交易、未来模型时间表和“重回一梯队”等判断应视为媒体/发布方叙述，不能当作已独立证实的行业结论。

## 影响与后续观察

对需要长时间运行编码、资料研究或应用构建的团队，Grok 4.6 的公开 API、合作平台和较低起始价格可能改变模型路由与 agent 成本试算；但终端操作等基准仍显示不同任务类型存在差异。近期应核验实际可用区域、上下文超过阈值时的计费、速率限制、fast variant 的稳定性，以及官方评测在相同提示、工具和硬件条件下的复现。Grok Bot 与 Cursor 的协同是否转化为可持续的企业工作流，也需要独立使用数据和安全评估。
