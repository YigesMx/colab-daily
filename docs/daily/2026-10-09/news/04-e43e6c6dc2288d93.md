## 事件概述

据新智元报道，法国 AI 公司 Mistral 发布新旗舰模型 Mistral Large 4：总参数达1万亿，采用混合专家（MoE）架构，每生成一个 token 仅激活约490亿参数，官方代号为 le Chonk。Mistral 宣布，该模型的完整权重将于月底开源，预览版 API 已在 Mistral Studio 上线。在第三方评测机构 Artificial Analysis 的智能指数中，它以38分追平 GPT-6 Luna，成为中美之外全球排名最高的模型。

## 已确认事实与证据

据新智元报道，在 Artificial Analysis 的智能指数中，Mistral Large 4 拿下38分追平 GPT-6 Luna，位列欧美开源模型第一名，第二名 Thinking Machines 的 Inkling 为25分。在多项细分测试上，Mistral 称其表现超过 GPT-6 与 Claude：法律 Agent 测试分数约为 GPT-6 Astra 的3倍，金融和视觉定位评测也胜过 GPT-6 Astra；科学编程测试 SciCode-Verified 拿到91.8%，高于 Claude Opus 5 的91.3%；视觉定位测试 Dense 200 拿到42%，高于 GPT-6 Astra 的41.5%。

网络安全能力是此次发布的突出卖点。据新智元报道，在一道复现漏洞的网安考题上，Mistral Large 4 拿下全场最高的82%，而 Claude Opus 5.5 和 GPT-6 Astra 直接拒答；在整个网安指数中它成功50次排进全球前五，GPT-6 Astra 成功33次、另有38次被自家安全机制拦下，Claude Opus 5.5 成功29次、被拦36次。Mistral 在博客中直言，两家闭源厂商一刀切的拒答挡住的恰恰是正当的漏洞研究和应急响应。与此同时，面对越狱攻击和恶意 Agent 任务，它的拒绝率据称高于所有开源模型，在 Lakera 公开的 B3 AI 安全基准里挡住了93.3%的攻击。其他成绩包括：DeepSWE v1.1 拿到61.7%，SWE-Atlas-QnA 拿到59.4%，Terminal-Bench 4 拿到28.3%，综合编程 Agent 指数49.8%；AutomationBench（657个真实业务流程）拿到59.9%；AA-Briefcase 的 Elo 分达到1393；Cybench（40道安全竞赛真题）解出93%。

在训练方面，新智元称 Mistral 在欧洲自家机房用3800块英伟达 Grace Blackwell 从零训练了该模型，后训练依靠大规模强化学习：一套自动扩缩的集群同时跑数万条尝试，按当前规模每天产出330亿 token，过滤后约剩160亿可用于训练。模型将指令、推理和 Agent 能力集成于一体，可说160多种语言，覆盖欧盟所有官方语言。预览版 API 定价为每百万 token 输入1.36美元、输出4.18美元。Mistral 手握30亿欧元 D轮融资，据称这是欧洲科技公司史上最大的一笔股权融资。

## 影响与后续观察

Mistral Large 4 的高分与开源承诺，直接冲击「开源模型显著落后于闭源旗舰」的行业认知，其在网络安全任务上「敢于接活」的定位，也把「谁有权决定模型能做什么」的话语权问题摆上台面：权重开源后，企业可将其部署到私有云或自有机房，避免关键时刻能力被切断。若月底如期放出完整权重，欧洲将首次拥有可与中美头部模型掰手腕的开源选项。

尚未确定的事项包括：完整权重开源的确切日期与许可证条款未知；该模型仍是「没练完」的预览版，Mistral 称未来几周到几个月还会有大幅提升，最终性能与安全策略未知；其宣称的各项评测成绩均为官方或第三方口径，尚待独立复现；开源后的实际部署成本与商用生态也需观察。
