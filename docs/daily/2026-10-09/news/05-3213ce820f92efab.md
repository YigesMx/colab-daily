## 事件概述

据量子位报道，Anthropic 发布小杯旗舰 Claude Haiku 5.5。该模型在多项跑分上超越此前的「斩杀线」模型 DeepSeek V4.1 Flash 与 GLM-5.3-Flash，并在官方基准上逐项对标 GPT-6 Luna；同时其 API 价格大幅下调，提示词在10万 token 以内的请求输入输出价格直降90%。这是 Haiku 系列一年来的首次更新，官方将其定位为跑量与速度的执行层模型。

## 已确认事实与证据

据量子位报道，在测 agent 操作真实电脑完成多步任务的 OSWorld 2.1 基准上，Haiku 5.5 的 Low 档达到42.0%准确率、单次成本0.07美元，Max 档达到72.4%、成本0.61美元；而上一代 Haiku 4.5 只有 Max 档15.7%、成本1.45美元——即新一代的低档比上一代的最高档更准，成本还便宜一半。在测44个职业真实专业工作的 GDPval-AA v2.1 上，Haiku 5.5 从 Low 档 Elo 1125（单次0.01美元）到 Max 档 Elo 1620（0.87美元），而 Haiku 4.5 的 Max 档仅为735。Haiku 5.5 也是第一个支持 effort 五档调节（low 到 max）的 Haiku 模型。

定价方面，量子位称10万 token 以内的请求（占 Haiku 4.5 请求量的90%）输入输出价格直接砍90%，超过10万 token 的部分砍50%；除缓存命中的输入外，Haiku 5.5 的价格比 DeepSeek V4.1 Flash 还便宜，整体对标 GPT-6 Luna。但模型换了与 Sonnet 5.5、Opus 5.5 同款的新 tokenizer，同样任务会消耗更多 token，代码、表格和非英语内容的膨胀可能更高，因此实际节省低于标价折扣。

量子位同时指出，Haiku 5.5 并不能替代 Sonnet 5.5：在 Terminal-Bench 4.0 上 Haiku 5.5 为39.2%，Sonnet 5.5 为70.6%，复杂多步编码、跨文件重构和长周期自主规划差距明显，Anthropic 官方也建议复杂 agent 编码优先使用 Sonnet 5.5 或 Opus 5.5。其价值在执行层：任务已拆好、验收标准明确、可并行跑的场景，例如 Cognition 的 Devin 用 Opus 5.5 做主模型、Haiku 5.5 做子智能体，FrontierCode 组合成绩66.2%，高于两模型各自单跑。

从 Haiku 4.5 迁移需要注意五处接口变动：budget_tokens 手动思考配置会直接报错，须改为自适应思考加 effort 参数；temperature、top_p、top_k 全部锁定默认值；assistant 消息预填充被取消；计算机操作工具从 computer_20250124 更新为 computer_toolset_20260801；自适应思考默认开启，响应首块可能是思考块，解析逻辑需按 type 字段过滤。Anthropic 提供了迁移指南。此外还有两条配套福利：Sonnet 5.5 缓存读取价格从每百万 token 0.20美元降到0.10美元，Anthropic 称大多数 agent 任务成本因此下降约20%；Max 和 Team 订阅用户本周起可领取 API 额度（Max 5x 每月100美元、Max 20x 每月200美元、Team 最多每月500美元团队共享）。

## 影响与后续观察

Haiku 5.5 把「能跑 OSWorld 的 agent 模型」的入门价格拉到数美分级，且提供五档 effort 与成本曲线，会直接压缩中小杯闭源与开源模型在跑量场景的价格空间；其主模型加子智能体的组合范式，也为 agent 应用的成本结构提供了新参考。但新 tokenizer 带来的 token 膨胀意味着实际账单节省存在不确定性，量子位也指出其在 AA 测评中「完成任务的平均成本」并未到达理想区间。

尚未确定的事项包括：Claude 家族剩余的 Fable 版本何时发布、能力定位如何未知；GPT-6 Luna 及 DeepSeek、GLM 等对手的后续回应未知；Haiku 5.5 在长周期自主任务上的真实可靠性、以及大规模生产环境中的迁移成本，均有待观察。
