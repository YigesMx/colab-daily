## 事件概述

据 NVIDIA 官方博客报道，在微软于旧金山 Dogpatch Studios 举办的 Windows AI and Surface 活动上，NVIDIA 创始人兼 CEO 黄仁勋与微软 CEO 纳德拉（Satya Nadella）共同阐述了双方如何为「AI 智能体运行在 Windows PC 上」协同设计硬件与软件。NVIDIA 宣布 RTX Spark 笔记本当日开启预购、10月16日上市，紧凑型台式机11月开售；微软则宣布 Microsoft Execution Containers（MXC）正式可用，作为让智能体在操作系统控制下安全、持久地后台运行的系统级基础设施。

## 已确认事实与证据

据 NVIDIA 官方博客，RTX Spark 将完整的 NVIDIA AI 技术栈带入 Windows 笔记本和紧凑型台式机。其规格为：Blackwell 架构 RTX GPU 最高6144个核心，配合最高20核的 Grace CPU，互连带宽600GB/s；FP4 AI 算力达1 petaflop，统一内存最高128GB。NVIDIA 称其可在本地运行 Qwen 3.8 Flash Next（一个125B 总参数、51B n-gram 的模型），无需计量、也不必把数据发送到云端。微软设备负责人 Pavan Davuluri 介绍了围绕 RTX Spark 打造的 Surface Laptop Ultra，同样提供最高128GB 统一内存与最高1 petaflop AI 算力。来自 Acer、华硕、戴尔、惠普、联想、微软、微星和技嘉的整机设计涵盖轻薄本到面向全天候智能体的紧凑台式机，其中紧凑型台式机采用同一颗 RTX Spark 超级芯片、面向24/7运行设计。

软件层面，RTX Spark 运行完整的 NVIDIA CUDA 平台，开发者可在 RTX Spark 与 DGX Station 之间免改写地迁移模型、工具和工作流；面向创作者提供支持 NVFP4 的第五代 Tensor Core、硬件加速 AV1 与4:2:2编解码、DLSS 和 RTX 光线追踪；面向玩家可在 DLSS 5、Reflex 和 G-SYNC 加持下以1440p分辨率超过100帧运行3A游戏。活动上还预览了 NVIDIA DGX Station for Windows：首台把 GB300 Grace Blackwell Ultra 桌面级超级芯片带入 Windows 生态的桌边 AI 超级计算机，提供748GB 一致性内存与最高20 petaFLOPS 的 FP4 AI 算力，足以在本地运行万亿参数级模型，需要时仍可通过 WSL 访问 Linux AI 工具链。

关于智能体平台，纳德拉表示「我们需要让桌面成为智能体执行的最安全场所」；微软宣布 MXC 正式可用，Davuluri 称「我们正把这些原语直接构建进 Windows，让智能体可被安全保护、观察和治理」，并与 Microsoft Security、Agent 365 一起解锁智能体在 Windows 上的全部潜力。黄仁勋则将 MXC 类比为当年的 Windows 与 DirectX：「MXC 将革命性地改变智能体的构建与部署方式」。他还回顾了 NVIDIA 与 Windows 的渊源：「如果没有 Windows，就不会有 GeForce」。

## 影响与后续观察

RTX Spark 加上系统级的 MXC 智能体基础设施，标志着「本地 AI」从运行单模型走向在个人电脑上常驻运行智能体：128GB 统一内存使原本必须依赖云端的模型可以离线运行，数据不出本机；而 CUDA 全栈兼容降低了开发者从工作站到桌边超算的迁移成本。对 PC 产业而言，八大 OEM 同步推出整机，配合微软把智能体安全原语写入操作系统，可能重塑 Windows PC 的产品定义与换机逻辑。

尚未确定的事项包括：NVIDIA 与微软均未公布 RTX Spark 整机的具体售价与首发区域；DGX Station for Windows 仅开放注册等候通知，上市时间与价格未知；Qwen 3.8 Flash Next 等本地模型的实际性能表现、MXC 与第三方智能体框架的兼容细节，以及企业 IT 对「智能体常驻 PC」的安全与治理策略落地情况，均需后续观察。
