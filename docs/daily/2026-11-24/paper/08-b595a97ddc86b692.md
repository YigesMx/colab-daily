## 研究问题与贡献

视觉-语言-动作（VLA）策略常被认为具备力控能力，但这一判断建立在一个未经验证的假设上：代理损失（proxy loss）的下降意味着物理力被正确接地（grounding）。论文证明该假设在三个部署层面失效：冻结的视觉骨干丢弃接触几何信息；下游损失掩盖 token 级梯度对齐；离散指示器会引发优化崩溃。与此同时，前向-only 学习、零阶优化、参数高效微调等方向的评测都只报告本地损失或成功率等代理指标，触觉 VLA 系统也普遍只用每任务一个标量力读数评价——决定物体是否存活的临界物理量几乎从不被一起测量与报告。

FORTH 的贡献是给出一个统一的前向-only 测量框架与执行框架，强制在每个层级把被优化的算法量与其要控制的物理观测量配对报告，只有两者同步移动时才承认该层级有效。框架包含三大支柱：保持空间接触几何、无需反向传播的层局部前向触觉编码器；实现激活空间更新的 token 并行零阶适配器；在滑移萌发时触发的连续触觉验证门 SlipGuard。在弹塑性结构壳上，SlipGuard 控制器的峰值抓握力比同一壳体的反射斜坡低 29 倍，在基线留下永久形变处避免压溃；在三个 LIBERO 套件上以 97.6% 平均成功率匹配最强执行性能，同时把峰值激活内存相对同骨干的反向传播步骤降低 7.12 倍。

## 方法与系统

FORTH 把触觉 VLA 流水线组织为三层，每层绑定一个代理信号。表示层：层局部 Forward-Forward 触觉干路由两个 FF 块构成。传感器表面张量先被切分为不重叠 patch、线性投影到 128 维；每块用局部"良度"目标更新——对隐藏激活做零中心化后取平方和，训练用局部 logistic 损失对比真实触觉正样本与合成反事实负样本，块间只传递标量良度、无端到端梯度。层特定阈值（协议中固定 2.0）划分有效触觉接触与噪声。该干路与反传网络的功能差距在验证集上极小（接触相位任务 0.0004、时序任务 0.012），并用线性探针直接从良度特征读出接触存在，以此诊断冻结骨干的"力失接地"——未接地视觉特征空间对机械载荷不变，命令变化时注意力状态改变而接触几何不变，测得的界面力不随命令移动而 logit 方差居高。

更新层：token 并行零阶低秩适配。对动作头上的 rank-8 适配器参数做正负对称扰动，用对称差分估计每个 token 的方向导数，再在 T 个 token 的总体上聚合为更新量——16 次前向传播（T=8）即可完成一次更新，且前向传播比反向传播的同步依赖链更容易流水线化。关键验证是对齐度量：零阶估计与真实解析梯度的余弦相似度随 token 数增长、在 T=512 达峰（每翻倍约增 0.033），而共享噪声方案反而下降、权重空间扰动接近零——这首次把"总体论证"（独立逐 token 扰动相互抵消）放到物理信号上对照真梯度检验。

控制层：SlipGuard 单类剪比率门。统计量为切向剪力与法向力之比，决策阈值仅在标称轨迹上校准（均值加三倍标准差），完全不需要故障数据；两步去抖滤除瞬态噪声，触发后有界比例修正提升法向力直至接触恢复，并有不应期限制。时序栈为：设备原生 500 Hz 伺服环、1 Hz 适配器更新、30 Hz 策略运行在 4-bit 量化 VLA 骨干（4.6 GB）上，唯一新增输入是 48×64 触觉帧。配对评测协议按成本升序执行四项检查（floor、readout、validity、mechanism），便宜检查不通过就不进入昂贵仿真或硬件试验。

## 实验设置与数据

物理验证在三类物体上进行：橡胶、塑料、金属三种材料域的物体被推过摩擦极限，记录接触动力学；弹塑性空心结构壳与八缝刚性压溃盒用于物理完整性审计，其中压溃力限 Ncrush 取为跌落后摩擦下的标称需求力 Freq，超过即计不可逆形变。反射基线是开环单调积分斜坡（3 N/s 升至 22 N 封顶、从不下降）。故障注入扫描为 8 臂 × 4 种压溃设置 × 3 种严重度 × 每格 20 种子共 1,920 回合；工作包络用扰动时长（5–150 ms）× 压溃-滑移力裕度（1.1–2.5）的 4×4 网格；跨域审计覆盖 1,200 个分布外回合（五种几何、六种质量最高 1 kg、两次中途摩擦阶跃）；传感器替换实验用实测统计量替换仿真统计量并在纸箱上复测。执行性能在 LIBERO 的 Spatial、Object、Long 三个套件上与已发表方法（Octo、Diffusion Policy、OpenVLA、Dita、SmolVLA、π0、UniVLA、MemoryVLA、OpenVLA-OFT）对比，Goal 套件不计入平均。硬件成本在 7B 模型一次适配传递上测量：前向-only 单次延迟 58.8 ms、能耗 28.9 J、峰值激活内存 334 MB，对照反传的 117.5 ms、57.2 J、2381 MB。

## 结果、限制与结论

物理完整性结果：同一个受压空心壳上，反射斜坡在 2.8 N 处越过首个塑性样本、峰值 22.43 N、留下 10.62 mm 残余形变；SlipGuard 保持壳体弹性、峰值 0.77 N、残余 0.01 mm——峰值力相差 29 倍，斜坡臂的残余形变在 SlipGuard 臂中不出现。刚性八缝压溃中斜坡达 15.64 N 切断全部八条缝、盒体跌至 29.6 mm，SlipGuard 峰值 2.27 N、零缝断、维持 40.4 mm 中心高度。按 Ncrush=Freq 约定，SlipGuard 相对手调反射斜坡把物体损伤降低 1.59 到 3.42 倍。1,920 回合故障注入扫描中故障前零误触发，三种严重度下恢复率 1.00、0.95、0.75。工作包络内 160/160 全恢复，对照恒力策略的 68/160（42.5%）与知道真实质量和摩擦的 oracle 的 145/160（90.6%）；零损伤回合对恒力臂的 22 个与 oracle 的 12 个；逐回合配对分别 92 胜 0 负（p 小于 1e-15）与 15 胜 0 负。同一定律在 500、25、15 Hz 下表现相当，说明收益来自压溃上界而非时钟频率。传感器替换后 12/12 恢复对离散门的 1/12 与被动臂的 0/12；纸箱上保持 0.250 N 对斜坡的 22.00 N（88 倍差距）。参数冻结后跨域 1,200 回合 100% 成功、中位峰值力仅 2.34 倍需求力；滑移起始后 6 ms 即响应；故障定位率 87.3% 对标量统计的 47.6%。执行性能上 FORTH 在 LIBERO 三套件平均 97.6%（Spatial 99.3、Object 98.6、Long 94.8），超过 OpenVLA-OFT 的 96.8 与 MemoryVLA 的 96.7，说明接地约束不牺牲任务成功率。

论文自述的边界：阈值是经验校准而非物理推导，真实传感器上存在每传感器偏移，滑移前误报率 0.024（力级统计）与 0.031（比率统计），失败模式是动作目标仍报告低误差而物体已错过目标容器；部署需要剪切/法向传感器对以控制频率采样、一套无故障标称校准回合和策略无法越过的闭环力上限。触觉硬件仿真与结构壳审计为受控实验，真实杂乱场景的大规模验证当前材料未确认。总体而言，FORTH 的方法论价值在于"配对报告"这一评测公约：让每个层级的算法代理与其物理对照量一起动，把触觉 VLA 从"看起来在控力"推进到"可测量地在控力"，同时以 7.12 倍内存削减证明前向-only 路线在边缘部署硬件上的可行性。
