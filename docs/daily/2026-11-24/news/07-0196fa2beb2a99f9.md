## 事件概述

Grid Robotics 团队发布84页综述《Envisioning Agentic Robotics: A New Era of Robotic Systems》（arXiv:2611.18359，2026年11月13日提交），为快速兴起的 Agentic Robotics 建立定义、系统架构、评测框架与发展路线图。这篇白皮书不发布新模型、不造新基准，而是回答一个基础问题：当通用基础模型可以直接理解任务、编写代码、调用工具并控制机器人时，机器人系统应如何重新分工。知乎专栏「具身智能之心」的解读文章在 Hugging Face 相关讨论中热度居前，其核心判断是：具身智能正从「训练更强的动作策略」进入「组织决策系统」的下半场。

## 已确认事实与证据

以下内容均核验自官方一手材料（arXiv 摘要页与论文 PDF 全文、Grid Robotics 官网，均已留存为官方证据）：

- 论文由 Grid Robotics 团队署名（Qingfeng Lan、Duo Li、Tao Yu 等12人），2026年11月13日提交至 arXiv，全文84页。摘要明确：以 GPT-6 Astra 的发布为标志，配备智能体外壳（agentic harness）的前沿模型在数周内于多个具身基准上追平或超过任务专用策略；论文主张「Embodied System 2」——基础模型与具身外壳共同构成的决策核心——是 Agentic Robotics 的关键，并指出社区尚未就定义、评测框架与研究路线图达成共识。
- 三层功能划分：System 2 负责理解意图、规划决策、调用能力并验证结果；System 1 提供 VLA、世界模型、导航、感知与运动规划等技能；System 0 处理逆运动学、关节控制等实时问题。论文强调这是功能划分而非必须三个模型。VLA 与世界模型并未消失，而是被降格为可调用的技能层。
- Embodied Harness 至少包含五个部分：上下文管理器、工具接口、规划器、记忆系统、验证器，另需实时事件监测器在碰撞、人员进入等情况下中断 System 2；论文提出「执行合同」概念，规定每个技能的输入参数、坐标系、前置条件、超时与取消方式等，一次物理调用经历提议、准入、下发、执行、确认终止、验证效果、提交进度的完整流程。
- 外壳的影响幅度（论文汇总多项研究）：仅修改验证器、记忆、接口与调用后决策流程，成功率变化约9至35个百分点；将智能体限制在技能接口内，影响最高达52个百分点。同一模型在 RoboDojo 上的多组公开结果从22.48%到更高值不等，因任务说明、记忆、工具库、推理预算等配置不同而无法直接比较。论文据此提出每项 System 2 结果应附带一张「Harness Card」，披露模型版本与推理预算、外壳配置、本体接口、可见观测、实验次数与人工干预等。
- 数字智能体快速发展的四个条件（接口适配、可自动验证、数据丰富、环境可低成本重置）在物理世界同时失效；论文提出 Capped Scaling：在固定决策时限内提升模型能力，并引用实验数据说明问题——仿真暂停等待模型推理时困难路线安全成功率为19.8%，环境继续运行时降至0.7%，碰撞次数增加12.3倍。
- 评测框架：围绕 Embodied System 2 归纳知识、理解、推理、工具使用、记忆、跨本体、安全、效率八项核心能力，加上成本构成9个维度、53个子项，其中29项与具身强相关。论文对现有结果的判断克制：通用模型配合外壳已在部分窄域仿真任务上超过专用策略，但跨域任务成绩仍低（论文引用 RobotWorld 约19.0%、RoboQuest 约23.2%、HumanCLAW 约16.8%，后者中最好模型能在64.9%的任务里找到目标但最终完成率仅16.8%）；安全存在「文本—行动鸿沟」，同一批模型对危险文本指令拒绝率72%，切换到真实机器人末端控制后仅18%。
- 四级路线图：L1 Primitive（执行单个局部动作）→ L2 Task（协调多技能完成完整任务）→ L3 Workflow（统筹多个相互依赖的任务）→ L4 Role（长期承担一项职责）；当前机器人正在提升 L1、L2 可靠性，L3 刚出现少量演示，非结构化环境中尚无机器人能无人修复地长期承担 L4。

知乎原文提及的「S2 可跳过 S1 直接控制 S0（含伯克利与英伟达的 ATLAS 工作）」等细节属媒体补充，未在本次核验范围内逐条比对论文。

## 影响与后续观察

- 这篇综述的实际作用是一次行业性的「重新分工」：模型能力不再独自代表机器人智能，外壳的上下文管理、接口抽象、验证器与安全机制成为同等重要的竞争变量。Harness Card 的提议若被采纳，机器人基础模型的排行榜将被迫披露系统配置，成绩可比性会显著提高。
- Capped Scaling 与「文本—行动鸿沟」两组数据指向同一个工程结论：通用模型的慢速推理必须与 System 1/System 0 的快速闭环分工，安全约束不能依赖模型判断正确。这对近期「通用模型替代 VLA」的乐观预期是一个可量化的降温。
- 后续可跟踪：评测社区对九维框架与 Harness Card 的采纳情况、L3 Workflow 级别的真机演示进展、以及论文中「具身数据引擎」「真机校准仿真」等基础设施方向是否催生新的开源项目。
