## 事件概述

OpenAI 于2026年11月18日在其官网研究发布页发表文章《Advancing chip design with OpenAI models》，宣布其前沿模型在芯片设计上取得专家级进展：在与 AMD 的合作中，模型通过重写描述旗舰 GPU 电路的 SystemVerilog RTL 代码，在经过多年高度优化的基线之上，将 PPA（功耗、性能、面积）指标最高再提升约14%，OpenAI 称这相当于把大约一年的优化进度压缩到5个月以内完成。部分由模型改写的电路已经进入 AMD 送交制造的近期设计版本，另有一些被写入生产设计文件供后续版本使用。新智元于11月23日报道了该消息，并指出这是「AI 设计芯片」首次在第三方旗舰硬件上产生送厂流片的实际改动。

## 已确认事实与证据

以下事实均直接来自 OpenAI 官方发布页（本页 HTML 已留存为官方证据）：

- 官方页面发布日期为2026年11月18日，标题为 Advancing chip design with OpenAI models，正文按 Jalapeño 计算模块改进、与 AMD 的合作、RISC-V 内核优化、从规格书设计 RISC-V 内核、下一步五个部分组织。
- 关于自研芯片 Jalapeño：OpenAI 从2025年初开始用 GPT-o3 mini 参与设计。官方列举的量化结果包括：一个乘法器重新设计后综合面积减少约15%，延迟从两个时钟周期降为一个；一个加法器面积减少约15%且保持两周期延迟；整个 Jalapeño 设计中模型提出的改动使向量单元标准单元面积减少约13%、矩阵单元减少约10%，并且这些优化在 Jalapeño 的硅片点亮阶段得到验证（silicon proven）。
- 关于与 AMD 的合作：官方原文确认「在高度优化的旗舰 GPU IP 基线上看到最高14%的提升」，方法是由模型重写描述芯片电路的 SystemVerilog RTL；「这代表了在不到5个月内取得的大约一年的进展」；AMD 已将部分改动纳入一份近期送制造的设计，并将其他改动加入生产设计文件用于未来版本；AMD 还在下一代旗舰 CPU 的若干关键模块上验证了模型所写设计带来的个位数百分比 PPA 提升。OpenAI 评价模型在 RTL 层面的推理达到了「专家级微架构师」水平，并使用 Synopsys 工具验证每次重写的行为等价性与 PPA 权衡。
- 关于 RISC-V 评测：OpenAI 在两个开源32位 RISC-V 内核（PicoRV32 与 Ibex，后者用于 OpenTitan）上评测了多代模型。在每次运行约11.2万 token 的相近预算下，GPT-6.2 Astra 在两个内核上平均得分均为最高；在优化现有 PicoRV32 的任务上，其得分约为 GPT-6 Astra 的两倍。完整评测共包含9,881次计分运行。在从书面规格书从头设计的任务上，五个模型的得分都高于优化现有设计的得分。
- 关于下一步：官方表述为「正在与 Synopsys 合作，将前沿智能与工程师已在使用的 EDA 工具相集成」。媒体报道中将这一合作表述为联合训练名为「GPT-Synopsys」的新模型，该命名未出现在官方页面中，属于媒体报道口径，当前材料未确认。
- 媒体报道补充、官方页面未包含的细节：OpenAI 总裁 Greg 在 DealBook 峰会上提及该成果、AMD CEO 苏姿丰转发表示「为这些了不起的成果骄傲」。此类表态来自媒体转述，原文未逐条复核。

## 影响与后续观察

- 这是公开可查的首批「模型改写的电路进入第三方旗舰芯片流片」案例之一，意味着 AI 辅助芯片设计从自用实验走向影响外部产品路线图。对 EDA 行业而言，OpenAI 与 Synopsys 的合作方向若落地，将把模型推理嵌入现有设计验证工具链，改变微架构师的工作分工。
- 14% 的 PPA 提升来自「高度优化的基线」之上，边际收益显著；但官方也承认评测任务放宽了面积约束（最多为原设计的16倍）并允许模型删减性能计数器等对跑分吞吐无贡献的部件，官方自己指出若要求保留这些特性、收紧面积限制并在物理综合后检查时序，测试将更接近生产芯片设计。这意味着评测分数与真实设计收益之间仍有距离，具体量产收益需以后续产品为准，当前材料未确认。
- 值得跟踪的后续：AMD 下一代旗舰 GPU/CPU 中模型所写模块的实际表现、OpenAI 与 Synopsys 合作的具体产品形态（是否存在名为 GPT-Synopsys 的模型待官方确认）、以及 Jalapeño 推理芯片的后续版本中模型参与比例。
