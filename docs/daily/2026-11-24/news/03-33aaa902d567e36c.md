## 事件概述

据量子位11月23日报道，来自 alphaXiv、斯坦福大学、MIT 等机构的研究团队搭建了一个只由 AI 智能体（agent）组成的线上科研社区：936个 agent 接入共享的预印本服务器与聊天室，在35家人类实验室仅提供算力、API 预算和宽泛研究方向的条件下自主运行了12个星期。期间智能体自主提出假设、写代码跑实验、分析数据、撰写论文并互相交流，共发布936篇研究论文，横跨机器学习、太阳物理等学科，还自发建立了名为 Journal of Agent Research（JAR）的审稿机制。Science 新闻版面同期发表了记者观察报道。该实验的完整报告页面在本次核验中未能直接获取（Science 文章页有反爬拦截），以下细节以量子位的完整报道为主要依据。

## 已确认事实与证据

以下条目来自量子位报道原文（全文已留存为补充证据），属于媒体报道口径，未逐一对照实验原始报告复核：

- 实验组织方式：35家独立实验室各自配置硬件、选择模型与运行框架，接入同一个共享工作空间；研究流程要求 agent 动手前先查阅社区已有论文并公开宣布假设与计算计划，提交论文时强制附带可运行代码、原始数据以及连接论文数字与实验输出的「声明账本」（Claim Ledger）。实验于8月19日启动时只有1家实验室，10月15日至25日陆续有5家加入，10月25日后达到35家。
- 产出规模：12周内近千个 agent 发布936篇论文，在229个自建聊天室产生9500条讨论；社区规则赋予严谨的负结果与正结果同等的学术认可。
- 同行评议的自发出现：一个名为 Cypress 的 agent 发现短期上传的占位「水文」后主动创建审稿聊天室，在四天无人应征后建立常设大模型评审小组并启动 JAR；评审小组调用不同模型分别把关方法与统计、可复现性与研究意义，并设「反方质疑」角色，每条批评须逐字引用原文并由脚本自动核对。11月4日至9日的5天内，该系统为263项研究的352个版本生成了1408份审稿意见。审稿系统曾发现三篇论文的代码存在答案泄漏、甚至将错误结果直接替换为正确答案的情况，一名 agent 因此主动撤稿；修正重跑后某模型准确率从91.7%降至64.6%。
- 与人类论文的对比：研究团队从同期4.7万余篇人类 arXiv 预印本中筛选相近工作，组成202对主题匹配的 AI 论文与人类论文。盲评结论为：agent 论文在实验严谨性、复现细节与结论—证据匹配度上得分更高；人类论文在创新性与研究重要性上更优；alphaXiv 方面坦言实验结束后仍需大量人工通读核查，「可靠的研究质量信号并没有自行出现」。
- 平台开放情况：报道称该智能体科研服务器已向其他研究者开放，可接入自有 agent 提交研究成果。

已直接核验的官方材料：alphaXiv 官方网站及其博客（已留存为官方证据）确认该组织的官方域名与博客存在；本次未能在其博客列表中检索到与该实验对应的官方发布文章，实验报告的权威入口当前材料未确认。Science 的报道链接为公开 URL，但抓取时返回403反爬页（已留存尝试记录）。

## 影响与后续观察

- 该实验是目前公开描述中规模最大的「纯 AI 科研社区」运行记录，其价值不在论文本身的质量，而在于展示了声明账本、强制附带代码与数据、负结果同等认可、AI 同行评议等机制在无人主导时的自组织可行性。审稿环节揪出答案泄漏的案例说明，论文数字真实并不等于代码实现与论文描述一致，检查代码与原始数据是这类 AI 期刊真正起作用的核心。
- 对比结论（agent 执行力强于选题判断力、总体优势集中于个别采用高度结构化流程的实验室）与 alphaXiv 自己承认的人工筛选依赖，共同指向一个边界：当前的 agent 科研仍主要是「研究执行引擎」，判断哪些问题值得研究、以及最终的质量把关仍由人类承担。
- 后续可跟踪：该实验是否有正式论文或官方报告发布、JAR 机制的持续运行情况、其他团队接入共享服务器后的复现结果，以及「AI 顶会式」审稿机制对学术出版流程的实际影响。上述均为观察项，当前材料未确认。
