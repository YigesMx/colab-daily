## 事件概述

在今年的蚂蚁医疗健康生态大会上，蚂蚁集团旗下百灵（Ling）团队集中发布了五个医疗健康 AI 模型：开源的 LingSante-3.1-air-VL 与 LingSante-3.1-flash、已在阿福 APP 落地的实时多模态交互模型 LingSante Live、面向疾病风险预测的 LingSante Pulse，以及为医疗 AI 回答做安全检查的 LingSante MedGuard。两款开源模型已上线 Hugging Face 的 inclusionAI 组织页面（模型卡创建于2026年11月19日，MIT 许可证），官方将这一系列的设计目标概括为「模型要像医生一样思考」：信息不足时先追问、依据可追溯、边界收得住、答完可交给医生复核。

## 已确认事实与证据

以下事实直接核验自 Hugging Face 官方模型卡（两个页面 HTML 均已留存为官方证据）：

- LingSante-3.1-flash：基于 Ling-3.1-flash 构建，总参数560B、每 token 激活25B，支持100万 token 上下文窗口；定位为融合复杂医疗推理、专业医疗沟通、循证深度研究与长程医疗任务的开源 MoE 模型；官方卡片明确声明该模型面向研究与评估用途，「不是医疗器械，不得作为诊断、处方或治疗的独立依据」。
- LingSante-3.1-air-VL：基于 Ling-3.0-flash-VL 构建的轻量原生多模态 MoE 模型，总参数124B、每 token 激活5.5B，支持图文输入与256K token 上下文；官方卡片称其为蚂蚁集团健康团队开源的首个大型多模态医疗模型，四大临床方向为医学影像报告、多模态健康评估（皮肤疾病识别、饮食营养分析、医疗报告解读）、医学检索与证据综合、医疗 GUI 智能体；卡片同样附带非医疗器械声明。
- LingSante-Pulse-1.0 已出现在 Hugging Face inclusionAI 组织下，标签为生理信号（physiological-signals）特征提取模型，与媒体所述「已公开生理信号编码器权重」一致。
- 两个开源模型的许可证均为 MIT。

以下事实来自量子位报道（全文已留存为补充证据），属于媒体报道口径：蚂蚁在生态大会现场宣布五连发；LingSante Live 已在阿福 APP 通过「视频通话」入口实现边听、边看、边说、边做的「望闻问切」式交互；阿福当前拥有1.5亿用户、单日近2000万人次健康咨询、其中四分之一为老年人；LingSante Pulse 可做150余项疾病风险预测；报道列举的评测数字（如 HealthBench Professional 65.72%、综合得分61.21%仅次于 GPT-6 Astra、开源 SOTA，以及 BrowseComp、TerminalBench 等训练细节）均来自报道转述，当前材料未能在官方渠道逐一复核。LingSante MedGuard 是否开源、具体发布形式，当前材料未确认。

## 影响与后续观察

- 五个模型按健康问题的发生过程分工：材料理解（air-VL）、长病历推理（flash）、实时交互补全信息（Live）、前置风险监测（Pulse）、回答安全兜底（MedGuard），配套百灵底座的稀疏 MoE 架构，为医院本地部署（敏感数据不出院）提供了开源选项。这一「全流程拆解+两款直接开源」的组合拳对国内医疗大模型落地的参考意义大于单个跑分。
- 「像医生一样思考」的核心主张是行为对齐而非知识堆砌：证据不足先追问、区分已知事实与待核实推测、危险信号提示就医。媒体报道的实测对比（如在缺失血红蛋白数值时 air-VL 拒绝下结论而通用模型直接给出中度缺铁性贫血）与这一主张一致，但属于单篇媒体实测，代表性有限。
- 需要跟踪的后续：官方技术报告与完整评测基准的发布（AFUMED-Behavior 等自建基准的可复现性）、LingSante Live 在阿福 APP 的实际可用范围、MedGuard 的发布形式、以及医疗机构本地部署的公开案例。上述事项当前材料未确认。
