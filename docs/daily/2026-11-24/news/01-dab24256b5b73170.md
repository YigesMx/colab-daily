## 事件概述

2026年11月20日，数学家 Levent Alpöge 以一个约1700万行代码的 Lean 程序库的形式发布了黎曼猜想的证明。11月21日，Lean FRO（Lean 专注研究组织）与 Mathlib Initiative 发布联合声明，宣布 Lean 与 Mathlib 社区经过约一天的集中核验后，正式认证该证明的陈述与证明本身均正确。新智元于11月23日报道了这一进展，并强调核验链条中的多个环节都有 Anthropic 的 Claude 模型参与：MIT 数学家 Andrew Sutherland 的验证页明确写着整套检查是用 Claude Code 运行的，而用于比对的独立检查器 con-leche 本身也是由 Claude 编写、并由 Lean FRO 的 Joachim Breitner 监督的。这是黎曼猜想这一悬置超过160年的数学难题首次获得机器可验证的完整证明认证。

## 已确认事实与证据

- Lean 官方社区博客于11月21日发布署名为 Lean FRO 与 Mathlib Initiative 的联合声明（本页已留存为官方证据）。声明确认：Alpöge 于11月20日发布了由1700万行 Lean 代码构成的黎曼猜想证明，社区在过去一天内完成了核验，并明确写道「我们在此认证，黎曼猜想的陈述和证明都是正确的」。
- 声明逐条核对并确认了帝国理工数学家 Kevin Buzzard 于11月12日在其博客提出的四项核验标准全部满足：其一，所证陈述即 Mathlib 中经过专家反复审校的黎曼猜想定义（RiemannHypothesis）；其二，代码库可完整编译，已有数十人报告编译成功并导出完全一致的原始证明文件；其三，社区另写了一个只导入 Mathlib 的隔离陈述文件，用 comparator 与 con-leche 两个独立工具比对，确认没有被偷换陈述；其四，导出的原始证明交由多个独立实现的内核检查，包括 Lean 官方内核、con-leche、con-ron 以及第三方用不同编程语言实现的检查器，其中 con-leche 与 con-ron 附带相对于集合论的形式化证明，保证其不会接受错误证明。这些检查运行在与证明源码隔离的惰性导出文件上。
- Andrew Sutherland（MIT）的验证汇总页（已留存为官方证据）确认：全部 175,187 个模块编译通过且零错误；五个核心定理只依赖三条标准公理；nanoda 与 con-leche 两个独立编写的内核接受了完整的导出证明；lean4lean 接受了每一个已编译模块；页面署名行为「Andrew Sutherland (MIT), checks run with Claude Code」，页面最后更新时间为2026年11月23日。报道中引用的具体耗时数字（如 nanoda 用时27分42秒、con-leche 用时3分15秒审完约146.8万条声明）来自媒体报道对官方验证页的转述。
- 媒体报道补充的细节：Alpöge 本人未撰写传统论文，他估计若写成人类可读文稿将超过25万页；Lean 创始人 Leonardo de Moura 此前在博客介绍过 con-leche 是第一个用 Lean 写成并被证明自洽的 Lean 内核，其代码与证明由 Claude 完成；陶哲轩在博客中表示该证明「似乎动用了 Langlands 纲领和算术几何现代发展的全部力量」，并称消化需要时间。上述个人表述均属媒体转述，未逐条复核原文。
- 克雷数学研究所为黎曼猜想设置的100万美元奖金按规则需在证明正式发表并经过两年检验期后才可能颁发，目前尚无法启动。

## 影响与后续观察

- 这次认证使形式化方法在顶级数学难题上完成了一次端到端的「机器判卷」：当证明体量超过人类审读能力时，多个独立内核的一致接受成为新的可信来源。数学界仍需按传统流程消化证明思想、撰写并评审论文，机器认证与人类理解之间的时间差将长期存在。
- 证明链路上「写证明、跑检查、当裁判」都有 Claude 参与这一点引发了对循环验证的讨论；联合声明的回应逻辑是 con-leche 附带形式化自洽证明、且最终由多个独立实现的内核交叉确认，因此结论不依赖单一工具的可信度。该论证是否会被更广泛的数学共同体接受为发表级别的审校标准，仍待观察。
- 千禧年大奖难题的下一个焦点预计转向 P/NP 问题，但这只是舆论预期，当前没有任何新的证明进展可确认。克雷奖的授予前提（正式发表加两年检验期）意味着本次认证本身不直接触发任何奖金流程。
- 后续可跟踪：Alpöge 证明的人类可读阐释工作、Mathlib 与 Lean 社区对超大规模证明库核验流程的规范化、以及是否有期刊愿意基于机器认证接收此类无传统文稿的证明。
