## 研究问题与贡献

视频基础模型已能生成高质量短片段，但长视频的一致性与事件驱动的状态变化刻画仍是难题。现有多智能体工作流的问题在于：持续规划与修复不断累积上下文，参考更新手段有限，局部编辑难以保证后续镜头的状态连续。StateWeaver 提出两个机制解决这一问题：Active States（主动状态）与 Hierarchical Collaboration（层级协作），把评审驱动的视觉参考更新与跨镜头状态继承连接起来，实现持续的长视频生产。

论文的贡献：Active States 把评审中发现的状态差异转化为具体的视觉资产需求，指导参考构建、验证与再生成，在保留实体身份与已正确内容的同时修复目标属性；层级协作按任务、镜头与修复轮次隔离执行上下文，用层级记忆组织跨“布景组”（set）的生产，支持自主迭代与并行生产；在四个基准上的实验显示 StateWeaver 在预定义与自主规划两种分镜设定下都改善长视频一致性。

## 方法与系统

Active States：系统从既定故事事件出发规划资产变化；生成与评审中发现的目标状态与实际画面的差异，被翻译为状态精修与视觉参考补充需求（包括参考扩展 RE 与缺陷条件化参考合成 DCS）。系统据此构建并验证新的视觉条件做定向再生成，只修复目标属性而不破坏资产身份和已经正确的内容。确认后的生成结果与对应资产状态、故事时间、参考版本绑定，写入层级记忆，使后续镜头可以校验并复用修复后的状态，而不是继续使用过时的视觉条件。

层级协作：借鉴真实影视制作，把连续的子故事组织为相互独立的“布景组”，每组有自己的导演与执行上下文；执行上下文按专门任务、镜头规划、修复轮次隔离。层级记忆持久保存生产记录（剧本记忆、资产记忆、每组记忆），智能体切换任务时可检索相关计划、参考与确认观测；布景组之间通过证据依赖协调状态交接（如 Set A 的成品道具状态传给 Set B 继续使用），把局部修复所需信息与全局共享生产信息连接起来。整体角色包括编剧、总导演（Chief Director）、执行导演（Executive Directors）与布景导演（Set Directors）。

## 实验设置与数据

实现上，编剧、总导演、执行导演与布景导演均使用 GPT-6.1-sol（默认高推理强度）；GPT-Image-2.5-Sunburst 生成或编辑视觉参考；MiniMax-H3-Sol 以 Ref2VA 模式从提示与参考图生成视频，部署在 NVIDIA RTX PRO 6000 GPU 上。评测集由 ST-Bench、ViMax-Bench、EntityBench 与 DirectorBench 构建的 75 个文本驱动视频生产任务组成：前三个基准保留原始镜头内容与顺序（预定义分镜），DirectorBench 由各框架自主规划镜头。对比基线为 MovieAgent、ViMax、StoryEngine 与 ATAS，五个框架使用完全相同的文本、图像与视频生成模型，仅工作流不同。评测（无音频视频）覆盖审美质量、场景内与跨场景一致性、实体与动作保真、叙事合理性、需求遵循与生成稳定性。人工评测由 20 名独立评审分四组，对完整故事级输出做盲评（跨镜头连续性、状态转换、视觉质量三维度，每组故事至少三人同选才计入）。

## 结果、限制与结论

论文报告：预定义分镜下，StateWeaver 在 ViMax-Bench 与 EntityBench 总分第一，在 ST-Bench 排名第二且审美质量最佳、跨镜头一致性具竞争力；自主规划分镜的 DirectorBench 上保持明显优势，时间一致性与文本-视频一致性指标显示其在无预定义镜头内容与顺序时仍能维持事件推进与状态连续。消融（DirectorBench）：完整模型总分 0.724，冻结参考降至 0.703（长程一致性从完整配置降至 0.622，而叙事保持 0.779），去掉缺陷条件化合成 DCS 降至 0.699；去掉任务上下文隔离 TCI 降至 0.703，去掉镜头/修复轮次隔离 CCI 降至 0.716，两者都去掉降至 0.683；去掉记忆范围过滤 SF 降至 0.704，去掉观测状态交接核验 OH 降至 0.713，两者都去掉降至 0.696。人工 GSB 评测中，StateWeaver 对 ATAS 总分优势最大（67.6），对 StoryEngine 41.8、对 MovieAgent 37.8、对 ViMax 35.6。

限制：论文正文未设独立局限小节（当前材料未确认系统性局限清单）；评测依赖的指标与人工评审细节在附录给出，视频生成模型固定为 MiniMax-H3-Sol 的 Ref2VA 模式，对其他渲染骨干的泛化未在正文报告；LLM 使用声明指出相关文献整理、语言润色与图表制作用了 ChatGPT 辅助，作者对最终研究决策与结果解释负责。结论认为把确认观测绑定到资产状态、故事区间与来源版本，是实现证据化交接与一致性复用的关键。
