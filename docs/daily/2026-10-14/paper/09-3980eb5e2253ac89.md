## 研究问题与贡献

推理后训练流行"堆更多轨迹"的扩展路线，但训练成本攀升带来的性能增益并不成比例。南京大学团队提出一个直接的问题：推理监督到底能压缩到什么程度而不损失能力？他们的出发点是一个观察：正确且教师高置信的思维链（CoT）仍可能掩盖脆弱的推理——教师置信度前 5% 的 CoT 中有 18.1% 落入全局不确定性前 10% 的尾部，正确 CoT 中这一比例达 30.5%。推理的本质不均匀：一条解法往往取决于少数"推理分叉点"，从这些中间状态出发的不同延续会导向成败各异的结果，其过程级不确定性正是模型能力边界的行为信号。据此论文提出不确定性引导的渐进收缩框架，通过两级收缩把监督与优化集中到最有学习价值的轨迹上，证明"训练得更少也能学得更多"。

## 方法与系统

第一阶段是教师侧不确定性收缩：把每条验证正确的 CoT 当作主干轨迹，在其中间状态处构建蒙特卡洛推理树（MCRT）——从每个前缀状态采样 K 条独立延续，以"最终答案正确的比例"估计该状态的正确可达率 p，再用归一化伯努利方差 U=4p(1−p) 度量分支结果的不稳定度（等价于两条延续答案不一致概率的两倍）。高 U 标记的是"合理延续会分岔到不同结果"的状态，而非单纯难或错的状态。轨迹级得分取各状态不确定性的均值（按长度归一），按保留比例 ρ 筛出紧凑的候选池。整个过程纯行为驱动：只需文本前缀、采样延续与可验证结果，不需要 logits、隐状态、梯度或模型参数，因此同一教师画像可跨学生复用，也适用于 API 黑盒教师。第二阶段是学习者感知路由：对候选池先做一个探测 epoch，用长度归一化的响应损失给每条轨迹打分——损失大说明当前学生还没学好这条轨迹——随后的 SFT 只在损失最大的 M 条上更新，且分数随训练动态刷新。

## 实验设置与数据

默认教师为 Qwen3-8B，学生为 Qwen3.5-4B/9B 与 Qwen3-14B，采用 LoRA SFT；跨家族实验覆盖 Gemma-4-E4B-IT、Llama-3.2-3B-Instruct、Mistral-7B-Instruct；另设弱到强迁移（Qwen3-1.7B 教师）与黑盒蒸馏（DeepSeek-V4-Pro、Kimi-K2.6）两组。训练数据为 DAPO-17K（黑盒实验用 Nemotron-Math 前 1000 条以控制 API 开销）。评测覆盖竞赛数学（AIME24/25/26、AMC、HMMT25/26）、通用数学（MATH-500、GSM8K）与科学推理（GPQA-Diamond），并与 Gemma-4-it 12B、Ministral-3-Reasoning 14B、Phi-4-Reasoning-Plus 14B、Nemotron-3-Nano 30B、GLM-4.5-Air 106B、Qwen3-235B-A22B-Thinking、LongCat-Flash-Thinking 560B、DeepSeek-R1-0528 671B 及 GPT-5 Nano 等更大模型横向对比。

## 结果、限制与结论

主结果显示，渐进收缩把学生侧优化预算压到全量 SFT 的 0.22%–1.91%：训练时间从 8.47/9.23 小时降到 0.01–0.07 小时，ρ=1% 时墙钟加速超过 800 倍、训练暴露减少 450 倍以上，性能仍持平或更优，论文图示其仅需约 150 步即超过全量 SFT 约 1500 步才能达到的最优，优化步数减少约 18.7 倍。同一教师画像在三个异构学生家族上以约 0.45% 预算、逾 200 倍加速保持或提升性能。弱到强迁移中，1.7B 教师让 4B 学生 AIME25 从 65.6 提到 80.0、14B 学生 AIME24 从 76.0 提到 86.7，学生训练开销不超过 0.1 GPU 时；黑盒教师实验用 Nemotron-Math 前 1000 条以控制 API 开销，DeepSeek-V4-Pro 与 Kimi-K2.6 分别配 Qwen3.5-4B/9B 学生，结果相对普通蒸馏在多个基准上稳定占优、最高再提升 13.4%。9B 学生在 AIME24/25 达 93.3、AIME26 达 90.0，与 30B 到 671B 的大型推理模型同台竞争。消融证实机制：严格匹配 1% 预算下比普通蒸馏平均高 3.6/4.0 个百分点；不确定性选择比等规模随机选择高 1.6–4.5 个百分点，说明答案正确性不足以刻画监督价值；教师不确定性与学习者路由沿互补轴起作用，缺一即退。局限：结论基于数学与科学推理语料的 LoRA SFT 蒸馏设置，教师侧画像一次构建即可服务多个异构学生（已在跨家族实验中得到验证），但向 RLHF、多轮对话等非蒸馏场景的推广仍是未验证外推。MCRT 画像需对每个中间状态多次采样，教师侧有额外生成成本（虽可跨学生摊销）；论文未随文发布代码或项目页（当前材料未确认），实验可复现性依赖作者后续公开。总体结论：有效推理监督取决于学习价值如何被识别与分配，而非单纯数据规模——这为算力受限场景下的推理后训练提供了可操作路线。
