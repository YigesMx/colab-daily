## 事件概述

2026年11月23日，Anthropic 在官方文章「Introducing Claude Ship」中宣布 Claude Ship 进入测试版（beta）。它由三部分组成：已正式上线的 Code Review、新进入测试的 PR Steward 与 Claude Approvals，目标是让 Claude 在开发者提交拉取请求（PR）之后接管「审查、修复、按团队规则审批」的整段流程——官方口号是「Open a pull request and get back to building」。此前 Anthropic 在2026年3月推出 Code Review 时曾明确表示它不会批准 PR，「那是人的事」；本次 Claude Approvals 在测试版中获得了按团队策略放行常规改动的能力，被新智元报道称为「写代码的 Claude 第一次能给上线签字」。

## 已确认事实与证据

由 Anthropic 官方文章（claude.com，2026年11月23日）确认的事实：

- 组成与定位：Code Review（general availability）+ PR Steward（beta）+ Claude Approvals（beta）。Code Review 对照整个代码库跨文件审查、对发现先做对抗性验证与分类再贴到 PR，提供 Quick、Standard、Deep 三档审查深度；PR Steward 负责处理失败的 CI 检查、合并冲突与审查反馈，每次推送后都注明改动内容与撤销方式，可用 `@claude` 指令引导、`@claude stop` 叫停，并被明确设计为「不批准、不合并 PR」；Claude Approvals 依据团队写在仓库默认分支上的策略文件决定哪些改动可由 Claude 批准、哪些需要人类签字，官方将其比作「更聪明的 CODEOWNERS」。
- 使用方式：开发者在 Claude Code 中运行新的 `/ship` 命令，由 Claude 推送代码、开 PR、审查改动并处理反馈与失败检查；能否合并仍由开发者权限与分支保护规则决定。`/ship` 当日起在 Claude Code 与桌面端陆续推送。
- 自用数据：在 Claude Code 团队约90%代码由 Claude 编写的仓库中，2026年6月至9月合并的 PR 数量翻了一倍以上，线上撤回（revert）比例下降超过40%；官方将 Claude 的审查定位为「更广泛质量流程中的一层」。
- 治理与边界：官方建议先以「只观察（observe-only）」模式运行审批策略建立信任；策略文件位于默认分支，开发者与 PR Steward 无法在自己的分支里降低标准。Claude Approvals 可参考 Code Review 的发现与团队用自然语言定义的分类器。
- 可用性与计费：面向 Claude Team 与 Enterprise 计划、GitHub 仓库；按 token 计费，管理员可为 Code Review 与 PR Steward 设置支出上限；Claude Approvals 无基础费用但分类器按 token 计费；对 Zero Data Retention、HIPAA 配置或客户自管密钥的组织不可用。符合条件的 Claude Enterprise 组织可在2027年1月15日前申领至少10,000美元的 Claude Ship 抵用额度（30天内使用）。
- 官方风险提示：Claude Ship 使用 AI，可能漏掉 Bug、安全漏洞或其他问题。
- 文中包含 TELUS 与 Carvana 相关负责人的正面使用评价。

以下细节来自新智元报道（媒体口径）：Claude Code 之父 Boris Cherny 称自己「每天从早到晚都在用 Claude Ship」；三个组件被描述为分工明确的三个 Claude；挂起的旧 PR 可用 `/steward` 单独接管，PR 打上 `claude-pr-steward-watching` 标签即自动上岗；Anthropic 内部按风险三档审批（低风险免人审、中风险一人签字、最高风险两人把关，计费/鉴权/CI 相关至少一人签字）；一个 AI 写、AI 审的 PR 曾一夜来回修改50多轮最终由作者叫停；社区对「既当运动员又当裁判」的担忧与 Reddit 讨论均为媒体转述。

## 影响与后续观察

- 流程影响：若「审查-修复-审批」闭环按官方描述稳定运行，AI 编码的吞吐瓶颈将从「写得快」转移到「合并得快」；人类角色进一步集中于策略定义（策略文件内容）与高风险改动的判断。官方自用数据显示撤回率同步下降，但该数据来自 Anthropic 自家仓库，尚无第三方复现。
- 风险边界：模型漏检、策略文件设计不当或分类器误判都可能放行问题代码；官方的「只观察模式先行」与「AI 审查只是质量流程中的一层」是当前的主要缓解手段。新智元提及的「Retry-After 解析漏洞」等具体抓虫示例与审批细节均为媒体转述。
- 商业信号：按 token 计费意味着启用 Claude Ship 会直接增加组织成本，支出上限与审批策略的粒度将影响采纳曲线；10,000美元抵用额度限时申领是明确的获客动作。
- 后续观察点：PR Steward 与 Claude Approvals 从 beta 到正式版的时间表；`/ship` 在桌面端的完整铺开；社区对 AI 审批事故率与「审批权边界」的实际反馈；对企业安全合规配置（ZDR/HIPAA/自管密钥）支持与否的后续变化。
