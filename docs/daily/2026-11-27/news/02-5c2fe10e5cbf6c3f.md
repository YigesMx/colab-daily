## 事件概述

2026年11月25日，Google DeepMind 在官方博客发布「Mass Spec Skills for Google Antigravity」。这是一套面向 Google Antigravity 智能体平台的领域技能（skills）：将 Gemini 的化学推理能力与质谱学界成熟的公开工具和公共化学数据库查询结合，帮助科研人员大规模解读串联质谱（MS/MS）数据——从原始谱图出发，推导分子式、检索候选结构、逐条核对碎片峰证据，最终给出候选分子结构与可审计的报告。

官方博文由 Robert Brunck、Stefan Ganscha、Swaroop Guntupalli、Dariusz Lasecki、Gabriella Marfani、Jack Mason、Hussain Masoom、Rose Mirshafian、Eliseo Papa、Zoi Tsangalidou 联合署名。该技能已在 Google Antigravity 上线，用户可安装 Mass Spec 插件使用。

## 已确认事实与证据

以下事实均由 DeepMind 官方博客确认：

- 背景：现代质谱仪可在单滴样品提取物中检出数万个分子信号，但谱图并不直接给出结构。即便参考谱库经过十年扩充，谱图检索平均只能注释约5%的测量谱图（人体样本约10%），其余被称为质谱的「暗物质」。
- 工作方式：Antigravity 运行这些技能，组合结果并进行化学推理，为化学家列出证据链；对已收录分子可加速鉴定，对未知分子则收窄分子式与结构片段，辅助完整结构解析。研究者可用自然语言描述任务与仪器容差，无需逐个配置底层工具。
- 涉及的社区工具与数据库包括：SIRIUS（分子式与碎裂树评分）、MAGMa、MetFrag（碎片匹配）、matchms（谱图预处理）、GNPS 与 MoNA（实验谱库检索）、PubChem（候选结构检索）、RDKit（结构校验与绘制）。
- 基准评测：在 MoNA 中 Enamine REAL MS/MS 集合抽取的100个化合物上，比较三种配置——无网络无技能、仅联网、联网加 Mass Spec Skills，覆盖轻量级 Gemini 3.8 Flash 与两个前沿模型 Gemini 4 Argon、Gemini 4 Carbon。无网络无技能时三个模型的准确率都低于4%；仅靠联网自写脚本时前沿模型会漏掉四分之一到三分之一的谱图，轻量模型漏掉超过四分之三；加上 Mass Spec Skills 后三个模型均以约97%的准确率完成鉴定与验证，轻量模型达到与前沿模型相同的准确率。
- 生成 token 成本：使用技能后，Flash 每次尝试的生成 token 约降至原来的近四分之一，Argon 约降一半，Carbon 约降近五分之一。
- 可用性：Mass Spec Skills 当日起在 Google Antigravity 上可用；同时面向企业用户开放。DeepMind 还宣布向1万名科研人员免费提供6个月 Antigravity 最高用量档（滚动遴选，受资格、容量与选拔限制），申请已开放。
- 明确的局限：镜像异构体与部分近似异构体无法仅凭 LC-MS/MS 谱图区分，需要色谱保留时间、离子迁移或 NMR 等其他测量；真正的新分子（含许多天然产物）不在任何数据库中，智能体无法自行检索或确认其结构，只能给出分子式、峰归属与标注表等起点。

官方博客同时引用了普林斯顿大学、丹麦技术大学（DTU）与比勒陀利亚大学研究人员的使用评价，称其将过去需要数天或数月的分析压缩到数小时量级。

## 影响与后续观察

- 若「轻量模型+领域技能即可达到约97%鉴定准确率」的结论在更广泛数据上成立，意味着化学领域的智能体应用重点可能从模型规模转向工具编排与证据链设计；token 成本同步下降也降低了实验室常态化使用的门槛。
- 该方向直接服务于天然产物药物发现、环境与健康代谢组学中大量未注释信号的解析；免费用量档的遴选结果与实际科研采用情况值得跟踪。
- 需要注意的是：官方给出的97%是在公共谱库已有参考的化合物集合上测得的「复现型鉴定」，对全新分子只有辅助价值；评测范围（100个化合物、三种模型）有限，社区独立复现尚待出现。
- Antigravity 平台的技能生态（此前已有化学信息学、抗菌肽相关技能）正在扩展，Mass Spec Skills 与既有技能的组合方式、以及是否开源对应工具链，官方尚未说明。
