## 事件概述

2026年11月25日前后，Anthropic 研究员 Luke Sernau 在 GitHub 公开仓库 lsernau/grh-lean：在与 Anthropic 同事及 Claude 的协作下，将此前由数学家 Levent Alpöge 与 Claude 合作发布的约1740万行黎曼猜想（RH）与广义黎曼猜想（GRH，Dirichlet L 函数版本）Lean 4 形式化证明彻底重写并压缩，提供两个版本——可读版 grh/ 约30万行，紧凑版 grh-compact/ 约7.6万行。该仓库以 Apache 2.0 许可开源，版权标注为 Anthropic, PBC。

据量子位2026年11月26日报道，相较原版，代码量削减约99.56%；官方 README 则给出两个版本的行数口径：grh/ 约300,000行（总量47.7万行、801个文件，媒体口径），grh-compact/ 约76,000行（总量11.3万行、792个文件，媒体口径）。

## 已确认事实与证据

以下事实由 lsernau/grh-lean 官方 README 直接确认：

- 仓库内容：基于 Mathlib 的 Lean 4 证明，同时证明黎曼假设与 Dirichlet L 函数的广义黎曼假设；证明基于 Levent Alpöge 的原始证明（其说明文档见 alpo.ge/remark.pdf），本仓库是「与我在 Anthropic 的同事以及 Claude 协作产出的更短版本」。
- 定位为研究工件，不维护、不接受贡献；Apache 2.0 许可，版权 2026 Anthropic, PBC。
- 两个版本：grh/ 为可读版，约30万行，入口为 grh/GUIDE.md；grh-compact/ 为紧凑版，包含同样的五个定理，约76,000行。每个目录是独立的 Lake 项目。
- 构建要求：Lean v4.35.0 与 Mathlib 特定提交；在12核、24GB 内存机器上构建需一到两小时（无 Mathlib 缓存时约多85分钟）。
- 状态声明：证明仅通过机器校验（各项校验列于各目录 README）；没有数学家完整通读，也没有配套数学论文。允许使用的公理仅为 propext、Classical.choice 与 Quot.sound。

以下细节来自量子位报道（媒体口径）：

- 原版证明背景：Alpöge 与 Claude 于数日前发布的 RH/GRH 形式化证明长约1740万行、超过17.5万个文件，规模约为 Mathlib 的7倍，在 AWS 高配机器上编译需约21小时；社区 rh-trim 项目用 Tenet（C#）、nanoda（Rust）、tenet-jvm（Java）等多个独立内核复核通过，并分析出最终论证只占整份证明的约6.6%；自动删除死代码最多只能削减约8%且削减版未能编译成功。
- 方法：Luke Sernau 介绍，通过把定义全部展开（unrolling）得到长而扁平的证明、跨模块边界寻找可简化之处、再重新折叠封装（rolling back up），部分环节（如 Vandiver 猜想相关部分）换用全新论证。
- 交叉验证：团队除用 Lean 内核重放全部模块外，还使用官方校验工具 Comparator（v4.35.0）及 nanoda、con-leche、con-ron 等独立检查器交叉验证，全部通过；整个过程未使用 sorry 占位符。
- 人物背景：Luke Sernau 现为 Anthropic 研究员，此前曾任职 Google 与 Google DeepMind，是2023年谷歌内部备忘录《We Have No Moat, and Neither Does OpenAI》的作者，本科毕业于圣母大学数学系，2025年9月前后加入 Anthropic。

上述行数明细、21小时编译时长、交叉验证工具清单与人物履历均以媒体转述为准，官方 README 仅给出「约30万行/约7.6万行」与「仅通过机器校验」的口径。

## 影响与后续观察

- 可读性门槛大幅下降：若按原版「1470万行对应约25万页」的比例粗略换算（媒体口径），紧凑版约对应1300页以内的人类可读论证，使数学家通读核验第一次成为现实可能。官方明确表示尚无数学家读过，人工核验仍是当前最关键的未完成步骤。
- Apache 2.0 许可（原始版本最初未提供许可证）允许社区自由使用、修改与分发这份形式化文本；GitHub 上已出现围绕缩短该证明的社区竞赛型仓库与独立复核项目，后续值得跟踪。
- 对「AI 生成超长形式化证明如何压缩与维护」而言，本事件提供了一个完整样本：机器验证通过、人类可读性恢复、许可证补齐，但数学内容的人类确认仍未完成。
- 后续观察点：数学家对 grh/ 可读版的通读结论；紧凑版与原版五个定理陈述一致性的人工核对；围绕 Lean 证明长度的社区缩短努力能否在保持定理不变的前提下继续压缩。
