## 事件概述

2026年11月24日，第六届 IDEA 大会在深圳福田举办，由粤港澳大湾区数字经济研究院（IDEA研究院）主办，主题为「GREATER IDEA」，会议口号「在更大的舞台，做更棒的事」，全程以「Rethink Computer Science（重新思考计算机科学）」为线索。IDEA研究院官方大会新闻稿与量子位2026年11月26日的报道均确认：创院理事长、美国国家工程院外籍院士沈向洋在会上系统分享了其对 AI 时代创新机会的判断，研究院发布了 MoonBit 1.0、Agent 安全硬件原型、具身智能数据系统 EgoTwin、低空网络相关进展与 AI 药物研发平台 Mozi 2.0 等多项成果（官方口径为50余项创新产研成果首发）。

## 已确认事实与证据

由 IDEA 大会官方渠道（conference.idea.edu.cn 大会新闻，2026年11月26日发布）确认的事实：

- 大会基本情况：第六届，2026年11月24日09:00-18:00，深圳福田；由沈向洋于2021年发起，官方介绍称其「立足深圳，集中发布 IDEA 创新研发成果」，是粤港澳大湾区最具影响力的科技盛会之一。
- 沈向洋的核心观点：AI 正在改变创新发生的条件；从 PC 图形界面、互联网搜索、移动推荐到 AI 自然交互，交互方式每次变迁都孕育新的技术、产品与商业模式；他将机会概括为「Rethink Infra Opportunities（重新思考基础设施）」，认为大模型催生编程工具与 Agent 产品，编程 API 服务是一条商业路径，未来围绕 Agent API、Harness 可能出现新的商业模式；并提出「懂语言者得图灵」——图灵奖颁发60次，约五分之一与编程语言相关。
- MoonBit 1.0 正式发布：2022年10月立项的面向智能体的通用编程语言，由 IDEA 研究院基础软件中心负责人张宏波介绍；官方新闻稿称其在追求编译速度与运行效率的同时，以轻量沙箱、原生机器证明等机制约束执行、验证代码，对稳定性与兼容性作出长期承诺。
- Agent 安全：多模态智能与可信计算中心负责人王嘉平展示「安全盒子」Secure Harness Portal 原型，将敏感资料处理、账号凭据管理与工具执行放在本地，按需向云端模型提供脱敏信息。
- 具身智能数据：讲席科学家、视启未来创始人兼 CEO 张磊展示纯视觉裸手采集与 EgoTwin 系统，从人的自然操作中提取可供机器人学习的数据；香港科技大学谭平团队结合第一视角眼镜、动作捕捉与触觉手套记录动作及接触信息。
- 产业判断：国际先进技术应用推进中心（深圳）主任姚颂提出具身智能应走进开放、真实、复杂的场景，评估时除任务成功率外还需考察响应速度与运行成本。
- IDEA 2.0：院长兼首席科学家郑立中以「开放」概括新阶段定位，提出「面向产业的基础研究」；官方新闻稿还提及 Mozi 2.0、Monnet 莫奈、Luban、Kairos、SalesPulse、蜂巢互联等成果，以及大鹏常态化飞行并将福田中心区建筑模型叠加到测试环境的低空试验进展。

以下细节来自量子位报道（媒体口径，官方新闻稿未直接确认）：MoonBit 对标 Go/Java，数百包编译耗时约为 Rust 的十分之一，在用 Opus 5.5 对照开发数据库引擎的实验中 token 消耗比 Rust 少约12%，语料规模仅约为 Rust 的1%；近半年包下载量近1000万次、生态库由年初约2500个增至3.6万个；团队已用 MoonBit 编写88万行代码的 Office 文档处理工具。姚颂披露的实验中，底层操作模型不变、引入 GPT-6 Astra 规划监督后复杂任务成功率由11%升至92.63%，但每帧推理约32秒、单次测试成本高达14万美元。沈向洋称具身智能训练数据量尚未达到当年 GPT-2 的水平，「灵巧手是人类最后的尊严」（人手27个自由度）；姚颂预判未来3-6个月（最长一年）具身智能可能迎来自己的「GPT-3.5时刻」。会上还发布了低空经济白皮书6.0（媒体口径：迈向时空经济）与分子动态预测模型 BioKinema（传统分子模拟需22小时的任务不到1分钟完成）。

## 影响与后续观察

- 编程语言与基础软件：若 MoonBit 的生态增速延续（媒体称其预计2027年底至2028年初达到与 Rust 相当的生态规模），智能体时代的语言层将首次出现由中国团队主导的候选底座；其沙箱与形式化验证设计能否被主流 Agent 框架采用值得跟踪。
- 具身智能数据瓶颈：EgoTwin 等无本体数据采集路径若能规模化，将直接缓解行业「数据量未到 GPT-2 水平」的短板；相关精度（媒体称指尖间距测量误差约正负5毫米）与跨本体迁移效果需更多公开评测佐证。
- 组织与科研范式：郑立中提出的「面向产业的基础研究」与 IDEA 2.0 的开放策略，是新型研发机构在 AI 时代定位的一次明确表态；其与产业方（比亚迪、识渊科技等）合作的实际产出值得跟踪。
- 低空方向：大鹏试验场常态化飞行、福田建筑模型叠加验证与第二张试验网络（媒体称年底投运）的推进情况，将检验「时空计算」框架的工程可行性；沈向洋设想的千万级日飞行量属于长期愿景，当前材料未给出落地时间表。
