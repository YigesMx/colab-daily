**RoboEvo²: Recursive Robot Self-Improvement via Harness-Policy Co-Evolution**

**一句话结论：** 香港大学联合浙大、南科大等机构提出的 RoboEvo2 用"策略失败驱动的递归 harness-策略协同进化"弥合 VLA 高效执行与推理智能体高成本之间的鸿沟：八轮进化把 LIBERO-PRO 独立成功率从 11.0% 提到 84.1%、混合模式 90.5%，API 成本反而从 430.63 美元降至 98.92 美元；Unitree G1-D 真机上用 120 条自动采集示教训练的策略达 85%（对比 200 条人类遥操作示教的 π0.5 为 80.0%），混合模式 95.0%。

## 研究问题与贡献

机器人应当既能通过交互适应陌生环境、习得新技能，又能通过练习高效执行。现有两类系统各有短板：VLA/世界-动作模型控制高效但对任务与场景偏移脆弱，模仿学习适配需要追加大量人类示教；基础模型智能体能用广泛先验与机器人控制 API 发现解，但反复推理、工具使用与修复带来延迟和 API 成本，不适合日常行为的常态依赖。人类"先推理解题、再练习固化"的学习方式提示需要一个**双向循环**：harness（可执行技能、记忆与编排）发现的能力要内化进底层策略，而策略的进步又改变智能体可用的运动技能与仍需探索的失败。仅进化 harness（Zetta、EmbodiedRSI 等）无法把新技能传给学习控制器；仅进化策略的方法又不随控制器能力变化调整 harness。同期工作（Co-Harness、HarnessForge 等）也研究耦合，但 RoboEvo2 的独特点是把**匹配的失败-修正对**作为反事实监督。

论文三项贡献：失败条件化、多路线并行的 **P2H 修复引擎**（Code / Code+ICL / Code+Policy 三路线，按最低归一化运动抖动选解）；把已验证修正内化为策略能力的**反事实偏好蒸馏 CPD**（同一初始状态下的失败/修正对，相对冻结参考策略优化损失差，含非对称近邻约束）；跨轮次的 **harness 更新与策略复用机制**（技能库、路由与经验记忆持久累积，更新后的策略参与后续搜索）。作者来自香港大学、浙江大学、南方科技大学、香港中文大学（深圳）与香港城市大学（Chenzhi Liu 与 Jiehong Lin 为共同一作，Jiehong Lin 为项目负责人，Xiaojuan Qi 为通讯作者）。

## 方法与系统

### 递归协同进化循环

每轮 r 包含四阶段：(1) **策略滚动**——当前策略作为主执行器生成任务滚动，任务级验证划分为成功与失败轨迹；(2) **P2H 进化**——VLM 编码智能体（GPT-6 Astra）诊断每个失败并搜索三路线解，验证解中兼容的改进被整合为候选 harness；(3) **H2P 进化**——成功滚动与 harness 生成的修正累积为训练数据，匹配的成功/失败执行提供反事实监督，任务均衡、失败感知的采样与策略优化产生候选策略；(4) **评估与选择**——独立（策略直接执行）与混合（harness 协调策略与代码技能）两种模式在匹配的开发任务、初始状态与执行预算上比较，改进才保留。初始 harness 由 CaP-X 与 RATs 的机器人 API 和参数化代码技能构成；初始策略由预训练 VLA/WAM 在机器人示教 D0 上微调而得。

### P2H：失败引导的并行解搜索

对每个失败滚动，编码智能体用策略观测、动作历史与任务结果诊断，检索技能库与经验记忆，并行探索三条路线：**Code** 先用现有代码技能尝试恢复、不行则按执行反馈精化运动目标/抓取接触策略/阶段切换/恢复逻辑；**Code+ICL** 从 D0 随机采一条示教提取任务结构、操作策略与时间线索指导技能修订；**Code+Policy** 把代码技能与当前策略（作为学习到的运动原语）协同，精化子目标分配、技能组合、策略调用、切换条件与恢复。三路线共享任务目标与执行约束、在隔离执行分支上运行（可行时从失败状态起步，否则匹配任务重置），执行与精化持续到成功或预算耗尽，全程策略参数冻结。每路线至多保留一对已验证程序-轨迹；成功候选在匹配条件下按最低归一化运动抖动 J(τ) 选择。每个被解决的失败天然关联"原始失败执行 + 已验证成功修正"，为 CPD 提供配对监督。跨失败整合把兼容修改合并进统一候选 harness：技能库扩展、路由更新、记忆累积失败上下文/尝试方案/执行结果/已验证修复指导；整合后的 harness 做兼容性检查与评估后才替换。

### H2P：反事实偏好蒸馏与持续优化

两类监督：成功策略滚动与已验证 harness 轨迹（含全任务解与恢复续段）做监督学习；策略失败与成功修正构成配对数据集 P（每个配对 (x, y+, y−)：同一初始状态、匹配执行条件下经结果验证的成功/失败续段）。**CPD** 定义 δ± 为当前策略与轮初冻结参考策略在成功/失败目标上的损失差，Δ = δ+ − δ−；目标 = 监督损失 + 偏好项 λpref(Lgap + λprox Lprox)：Lgap 对 Δ 施加偏好边距（max{Δ, −m} + m 平方），Lprox 非对称近邻（禁止成功目标损失变差、限制失败目标损失过度上升 κ）。任务采样用失败权重 w = (1−ŝ)^γ 聚焦低成功任务；EWC（按平方逐样本梯度估计参数重要性）惩罚对旧任务重要参数的漂移防遗忘；无兼容配对时 λpref=0。离线协同进化后还可用 PPO 在仿真器新滚动上以任务成功奖励进一步精化。

## 实验设置与数据

- **LIBERO-PRO**：把在原始 LIBERO 示教上训练的策略迁移到任务与位置扰动，八个设置；进化在初始训练数据保留的种子上运行（无额外人工标注），泛化在 800 个未见回合上评估，八轮进化；
- **RoboTwin C2R**：在 2,500 条干净示教上训练的策略适配 50 个双臂任务的随机化场景，5,000 个未见回合，五轮进化；
- **MolmoSpaces**：自主能力习得（智能体提出场景锚定目标并通过探索发现可执行解），40 个任务（开/关/抓取/抓放），对比 CaP-Agent0 与 RATs；
- **跨本体 harness 迁移**：RoboTwin 上（ALOHA AgileX）进化的 harness 冻结后直接换双 ARX-X5 或双 Franka-Panda（只适配机器人专属控制接口），同 50 任务、每任务 20 持出布局；
- **Unitree G1-D 真机**：四个双臂任务（叠碗、搬物、插入、取物）各 10 次试验；harness 从 RoboTwin 直接迁移，冻结 Code 路线先收 10 条/任务已验证示教微调 π0.5；失败时操作员只把机器人与场景恢复到失败前状态（不遥操作修正动作），智能体再探索三路线并选最低抖动的已验证修正，共收 120 条自动示教（含 20 条/任务的额外成功轨迹）训练最终策略；
- **对比方法**：ASPIRE、Zetta、DynaHarness、EmbodiedRSI（harness 进化类）等自进化系统。

## 结果、限制与结论

### 多轮进化与数据效率

LIBERO-PRO 八轮：独立成功率 11.0% → 84.1%、混合 30.4% → 90.5%，API 成本 430.63 → 98.92 美元；RoboTwin C2R 五轮：独立 46.0% → 77.5%、混合 48.8% → 87.4%，API 成本 719.05 → 323.84 美元——**能力提升伴随智能体成本下降**，验证了把昂贵推理摊销进策略执行的循环。数据效率：从 2,500 条干净示教出发自主收集 5,000 条已验证轨迹，7.5K 总量达 77.5% 独立成功；同样 7.5K 的干净+随机混合训练只到 67.2%，达到 76.8% 需要 27.5K——**RoboEvo2 只用 27.3% 的数据量匹配常规训练**。与自进化系统对比（LIBERO-PRO 八设置平均）：π0.5 版 84.1% 独立/90.5% 混合，超过 EmbodiedRSI 的 86.8% 混合；加 PPO 精化后 94.8%/96.8%（FastWAM 骨干为 75.5%/82.9%）。

### 消融

联合进化（三轮后 52.3% 独立/68.3% 混合）一致优于仅 P2H（策略固定，46.1%/49.0%）与仅 H2P（harness 固定，33.6%/49.0%），且独立模式优势逐轮扩大——进化中的 harness 提供越来越有效的监督。P2H 路线（第一轮，初始策略 11.0%）：修复后任务成功率 Code 29.4%（+7.8）、Code+ICL 44.9%（+13.4）、Code+Policy 45.6%（+14.8，单路线最大增益）、全路线 49.1%（+13.5）；在收集轨迹上训练后独立成功率达 32.1%。CPD 组件：仅监督损失 20.1%，加偏好差距 29.9%，完整 CPD（加非对称近邻）32.1%。

### 能力习得与迁移

MolmoSpaces 40 任务：RoboEvo2 独立策略 57.0%、混合 65.8%（RATs 38.0%、CaP-Agent0 21.0%）；其中关闭类任务独立 99%/混合 100%。跨本体：冻结 harness 在原 ALOHA AgileX 上 45.8%、换双 ARX-X5 42.5%、换双 Franka-Panda 41.0%——小幅下降说明进化的 harness 能力无需再进化即可跨本体复用。

### Unitree G1-D 真机

迁移的冻结 Code 路线 harness 平均 47.5%（无目标侧技能进化）；120 条自动示教训练的策略 85.0%（超 200 条人类遥操作示教的 π0.5 的 80.0%）；混合模式 95.0%。四任务明细：叠碗 90/100、搬物 90/100、插入 70/80、取物 90/100（π0.5 为 80/90/60/90）。

### 限制与结论

论文未设独立的"局限性"小节，可从实验读取的边界包括：插入类真机任务独立成功率仍为 70%（最难任务）；LIBERO-PRO 上 Spat-S 等单个设置（73.0 混合）仍有提升空间；进化依赖任务级验证器与初始示教 D0（Code+ICL 用）；真机失败恢复需操作员近似恢复到失败前状态（虽不遥操作修正动作）；API 成本下降但仍非零。结论：验证过的智能体修正既成为可复用 harness 技能也成为学到的策略行为；改进的策略提供更强运动原语并重定向后续 harness 探索，闭合互惠学习循环，支撑渐进的策略自主性并为未解挑战保留智能体能力。作者称模型与代码将公开发布（仓库 github.com/kaiknower/RoboEvo2 在成文时可访问；模型权重发布状态以仓库为准，当前材料未确认）。LLM 使用声明：OpenAI Codex 用于语言编辑与文献检查，方法本身使用 GPT-6 Astra 作为编码智能体。
