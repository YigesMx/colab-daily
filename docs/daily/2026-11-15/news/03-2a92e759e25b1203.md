## 事件概述

2026年11月13日（北京时间11月14日凌晨），DeepSeek通过官方API文档变更日志宣布，正式向开发者开放其应用全套API：包括联网搜索、文件输入、链接阅读、语音交互（语音识别ASR与语音合成TTS）以及模型安全等能力，开发者可通过在现有接口中开启相应参数直接调用，工具调用与上下文组装由服务端自动完成。量子位当晚以"突发！DeepSeek开放全家桶API"为题报道，称官方甚至表示开发者可以近乎1:1地复刻出完整的DeepSeek App，并同步开源了一套轻量级聊天前端示例。

## 已确认事实与证据

以下事实来自DeepSeek API文档变更日志页面及量子位报道：

- DeepSeek官方变更日志（日期2026年11月13日）确认：发布全套应用API（Releasing the full suite of application APIs），在DeepSeek App（含网页版）中由联网搜索、文件输入、链接阅读、语音交互与安全能力配合模型推理构成对话体验，现向开发者开放；官方页面顶部提示"The full suite of DeepSeek application APIs is now available: web search, file input, URL reading, model safety, ASR, TTS and more"。
- 官方变更日志确认：开发者在现有接口中开启对应参数即可获得对话扩展功能，何时搜索、读哪些网页、如何根据结果作答等工具调用与上下文组装由服务端处理；其中链接阅读通过开启deepseek_read_url工具实现。
- 官方变更日志确认：deepseek-flash模型（量子位报道中称为V4.1-Flash）在Messages、Responses和Chat Completions三类接口下支持上述对话扩展功能。
- 官方变更日志确认此前进展：2026年10月17日曾开放自研Search API，2026年9月10日发布DeepSeek-V4.1-Flash。
- 据量子位援引官方定价表：语音识别原价0.78元每小时、目前五折为0.39元（约合每分钟0.0065元）；语音合成原价每万字符3元、五折后1.5元；搜索与网页抓取为每1000次成功调用5元；OCR为每1000页1.5元。该定价表细节当前材料未在官方文档页面逐一核对。
- 据量子位报道，DeepSeek表示开发者可以1:1复刻出完整的DeepSeek App，并开源了一套支持导入DeepSeek历史对话的轻量级聊天前端Demo；此说法当前材料未在官方渠道直接核验。
- 据量子位报道，对比口径显示DeepSeek语音识别折后价格约为OpenAI GPT-Transcribe（0.27美元每小时）、GPT-4o mini Transcribe（0.18美元每小时）与Google Cloud标准语音识别（0.96美元每小时）的约1/4.6、1/3.1和1/16.5；该对比为媒体计算，未经独立核验。

## 影响与后续观察

此次开放把DeepSeek应用端积累的搜索、文件解析、语音等基础能力以独立接口形式交给开发者，显著降低了搭建"能听会说、会查资料"的对话产品的工程门槛；独立计费与自由组合的接口设计，也可能推动语音助手、会议记录、文档处理等应用的基础调用成本进一步下降。值得观察的点包括：一是官方完整价格表与配额细则需以DeepSeek平台正式文档为准（当前材料未完全核对）；二是开源前端示例生态会否催生大量第三方"类DeepSeek App"产品，及其对现有C端聊天助手形态的冲击；三是与OpenAI、Google等厂商语音API的长期价格竞争走向；四是DeepSeek在公告末尾"现有对话产品只是较基础的一种形态"的表态，是否预示其应用策略将更多转向平台化。以上未尽事项当前材料未确认，建议持续跟踪官方文档与开发者实践反馈。
