## 研究问题与贡献

**SenseNova-U1.5: Towards Native Unified Visual Intelligence**（SenseNova 团队，项目赞助与指导 Dahua Lin，高级项目负责人 Lei Yang、Lewei Lu、Quan Wang、Ruihao Gong、Wenxiu Sun、Ziwei Liu，项目负责人 Haiwen Diao、Jiahao Wang，arXiv 元数据署名 60 余位作者）发布并系统报告了一个 8B 参数 Mixture-of-Transformers（MoT）原生统一多模态模型：在**无外置视觉编码器、无 VAE** 的单一架构内同时完成视觉理解、推理与生成/编辑。相比前代 SenseNova-U1，U1.5 的目标是在不牺牲理解能力的前提下，把图像保真度、双语文字渲染、复杂构图、多参考编辑与交错生成推到开源模型的领先水平，并验证一个更深的论点：**多模态理解能力可以迁移到视觉规划与创作**（生成数据中结构化格式很少，但模型能泛化到长、复杂、结构化的视觉指令）。

核心贡献（已从全文核验）：(1) 近无损视觉接口的升级（分辨率感知噪声条件扩展到 4K、patch 级 MLP 头换成空间耦合轻量解码器）；(2) 五阶段渐进训练配方（生成预训练→统一中训→统一 SFT→多专家 RL→多专家在策略蒸馏）；(3) 在理解、生成、编辑、交错生成四大类基准上的广泛评测；承诺开源训练代码（SFT/RL/在策略蒸馏）。

## 方法与系统

- **近无损视觉接口**：沿袭 NEO 的原生接口，两卷积投影（×16、×2 下采样）把原始图像或加噪视觉输入直接转成每个 32×32 区域一个 token 的紧凑序列，无外部 encoder/VAE；二维正弦位置嵌入+img 特殊标记定界。生成侧显式注入**分辨率相关噪声尺度嵌入**（参考分辨率从 U1 的 2048² 扩展到 4096²），与扩散时间步表示组合。
- **空间耦合解码器**：原 patch 级 MLP 独立解码 32×32 token 会在高分辨率下产生接缝/网格伪影；U1.5 改为轻量空间解码器——恢复 2D 拓扑后经 Pixel Shuffle（×2、×2、×8）逐级上采样，级间 3×3 卷积实现相邻区域信息交换，让 patch 边界像素联合决定。解码器与主干在流匹配目标下端到端联训。
- **原生 MoT 主干**：理解与生成在单一 Transformer 内交错（干净图文上下文与噪声条件视觉状态共序列），共享自注意力做跨流通信，但保留**分离的注意力投影/归一化/FFN**（按 token 类型动态路由）。文本 token 只做因果注意；干净图像块内双向注意；生成 token 块内双向、且可见全部前文干净上下文；反向路径被显式掩码（防止随机生成态污染理解表示）。
- **统一训练目标**：自回归语言建模 + 像素空间流匹配（x-prediction，分辨率自适应噪声轨迹，外加 0.1 权重 LPIPS 感知损失）。
- **五阶段训练**：S1 生成预训练（随机初始化生成分支、冻结理解分支条件化；256²–1024² 180K 步→512²–4096² 原生 4K 100K 步→编辑+交错 185K 步，混合比 60/30/10）；S2 统一中训（30% 理解+40% 文生图+20% 编辑+10% 交错，80K 步，理解/生成损失权重 0.1/1.0）；S3 统一 SFT（10.5K 步）；S4 **四专家 RL**：美学专家（HPSv3++ 奖励+按数据分区路由的 PaddleOCR 双语 OCR 奖励交替训练）、OCR 专家（识别文本与目标的多重集 IoU 分级奖励，GRPO-Guard 稳定稀疏高奖励）、编辑专家（VLM 五维奖励：指令履行/编辑执行/整体质量/文字编辑/未编辑区域保持，+由语义期向纹理期的渐进滑窗）、信息图专家（文字奖励+DPO+交替路由三阶段细化）；各专家 RL 期间冻结最后生成 Transformer 块、流匹配输出头与输出归一化层以抑制奖励诱导漂移。S5 **多专家在策略蒸馏**：按能力硬路由到冻结专家，学生先自生成轨迹，再在学生状态/时间步/条件下对齐专家与学生速度场，把四专家能力合并为单一统一模型。

## 实验设置与数据

- **理解评测**：多模态基准覆盖 STEM 推理、通用 VQA、OCR、幻觉、视觉推理（MMMU、MathVista、MMBench、MMStar、AI2D、OCRBench、HallusionBench、BabyVision、TiR 等），与 Qwen3-VL、Gemma4-12B（同为 encoder-free）等对比；语言侧 MMLU-Pro、C-Eval、IFEval、IFBench 等。
- **生成评测**：Qwen-Image-Bench（英/中）、GenEval、GenEval2、DPG-Bench、OneIG-Bench，覆盖视觉质量、提示对齐、组合生成、密集指令、文字渲染。
- **编辑评测**：ImgEdit、GEdit-Bench、WeEdit（文字中心编辑）、OmniRef-Bench（多参考）、RISEBench（推理中心编辑，含 CoT 变体）。
- **交错生成**：OpenING、VBVR-Pro-Bench（理解-推理-生成一体的开放式交错生成与生成式视觉推理）。
- 数据构造含结构化提示增强与原生最高 4K 分辨率训练（细节在数据章节）。

## 结果、限制与结论

**论文报告的关键数字**（已从全文核验）：

- **理解**：MMMU、MathVista、MMBench、MMStar、AI2D、OCRBench、HallusionBench 等上保持或超过 SenseNova-U1，多数可与 Qwen3-VL 相当或更好；语言侧 MMLU-Pro 86.67、C-Eval 90.41、IFEval 93.35、IFBench 69.00——生成能力的加入没有稀释语言与理解能力。
- **生成**：Qwen-Image-Bench 英/中子集（带提示增强）60.22/60.13，为评测开源模型中最佳；GenEval 总分 0.92，开源最佳，超过 Qwen-Image 等更大基线（计数、位置、属性绑定提升最明显）；GenEval2 带提示增强大幅领先开源基线；DPG-Bench 88.11；OneIG-Bench 英中双语的文字中心生成优势突出。
- **编辑**：ImgEdit 与 GEdit-Bench 总体领先（GEdit 语义一致性提升最明显）；WeEdit 大幅超过开源、可比头部专有系统（翻译与推理密集编辑仍具挑战）；OmniRef-Bench 开源领先，风格一致性与背景保持提升最大；RISEBench 上无 CoT 已超开源基线，加 CoT 后因果/逻辑/时间类编辑进一步提升。
- **交错生成**：OpenING（CoT）总体领先、超过对比的专有流水线；VBVR-Pro-Bench 上取得新 SOTA，域外任务超过 Nano-Banana-Pro 与 GPT-Image-2 等头部专有模型。

**限制与证据缺口**（track 分析；论文技术报告体裁，自述限制很少）：评测多为模型自报告+基准脚本，缺乏第三方复验；8B/8B MoT（理解/生成分支各 8.2B）的推理成本、4K 生成的延迟与显存未报告；训练数据规模与许可细节未完全公开（数据构造章节为定性描述为主）；"理解迁移到视觉创作"的机制性解释以定性案例为主。代码承诺开源（github.com/OpenSenseNova/SenseNova-U1），当前材料未确认发布完整度。

**结论与启示**：U1.5 是"原生统一多模态"路线目前最完整的公开技术报告之一，其核心论点——统一的价值不在架构简化而在**能力交互**（推理改进创作、生成成为解题内部过程）——对组内方向判断有参考价值：对具身智能而言，"无 encoder/VAE 的紧凑视觉接口+MoT 分流"提供了让感知与生成本身互相反哺的可复用架构；多专家 RL+在策略蒸馏的后训练配方对需要兼顾多种能力又不互相干扰的机器人策略训练同样可迁移。
