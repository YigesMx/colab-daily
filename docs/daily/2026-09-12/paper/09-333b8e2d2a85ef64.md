## 研究问题与贡献

**Rapid Learning of Dexterous In-Hand Pen Writing through Real-Time Jacobian Estimation**（ETH Zurich 软机器人实验室，作者 Kai Stewart、Yasunori Toshimitsu（共同一作）、Robert K. Katzschmann）针对灵巧手在手操作的经典困境：接触丰富、高度动态的手-物交互使 RL 需要大量仿真建模（现代仿真器无法完全复现所需接触复杂性）、IL 需要难以采集的灵巧演示。论文提出一条反潮流路线：**在物理机器人上实时估计"手+笔"联合系统的任务雅可比，用纯手指运动驱动笔尖写字**——无需解析的手-物运动学/接触模型、无需仿真训练、无需预采集演示，笔记本 CPU 上约 18 秒初始化后即可开始书写并持续在线适应。据作者所知，这是首个用类人手、纯粹靠在手运动写出任意单笔轨迹的演示，展示了以计算与数据极简的经典控制替代 RL/IL 重型路线的可能性。

核心贡献（已从全文核验）：(1) 把串联臂视觉伺服中的在线前向雅可比估计迁移到冗余腱驱动在手系统，并加上两项关键改造（主动激励阶段+零空间抓握稳定）；(2) 同一估计器/控制器公式在三个类人手系统（ORCA 实体+Shadow Hand、Wuji Hand 2 仿真）上通用，具身无关；(3) 空中与纸上书写的面内精度达亚毫米级（全程平均 0.6 mm）。

## 方法与系统

- **硬件**：ORCA 手——腱驱动类人手，17 个驱动 DoF；笔以固定 power-precision 握持，腕/无名指/小指（7 关节）固定，拇指+食指+中指共 N=10 个受控关节驱动笔。笔外包定制软 TPU 套（有效直径约为裸笔 4 倍），提供更大更稳的抓握面并在笔-握界面引入机械柔性。
- **感知**：网络摄像头跟踪笔上 ArUco 标记与桌面三标记板定义"纸面坐标系"，用固定标记-笔尖偏移恢复笔尖位置；恒速 Kalman 滤波+基于新息的离群剔除平滑轨迹；保留相机时间戳统一时间轴。控制回路事件驱动（每个笔尖更新一步），受感知限速稳定在约 15 Hz（相机标称 30 Hz）。
- **问题表述**：控制笔尖在纸面的平面位置（m=2），$\dot x = J\dot q$ 中的任务雅可比 $J$ 对在手抓握未知且随构型变化；目标是从指令增量 $\Delta q_{cmd}$ 与观测笔尖运动在线估计 $J$ 并（带轻微阻尼）求逆跟踪期望书写轨迹。z 高度不控制（视为漂移，从面内误差中排除并单独报告；纸上书写时把纸折叠垫高约 1 厘米吸收 2–3 mm z 漂移保持笔纸接触）。
- **递归在线估计**：RLS/Kalman 式更新，协方差取对角近似；仅在至少一个关节实际运动时更新（防止静止时被观测噪声漂移）；回归量用上一步**指令增量**而非实测关节速度（估计吸收未建模的执行器/传动效应，实测速度噪声大且曾使估计不稳定）；遗忘因子 λ=0.999 保持可跟踪慢变动力学，协方差下限防退化。
- **激励阶段**：15 秒沿预记录的抓握内关节路径扫描（覆盖可达任务空间、两个受控面内方向）+3 秒稳定；该一次性手工设置只需几分钟、无系统优化，全部物理 ORCA 实验复用同一组路径点。
- **书写路径与控制**：字母 A–Z 定义为三次贝塞尔字形，另支持圆/花/心/星等参数形状与任意单笔 SVG 路径，恒切向速度遍历。任务空间指令为 PID+前馈（Kp/Ki/Kd=100/2/6，积分带抗饱和钳位）。控制律用阻尼伪逆 $J$ 生成关节指令，零空间投影做**抓握姿态正则**（把关节拉向稳定抓握姿态，增益 0.05）——这是保持抓握不丢笔的关键。

## 实验设置与数据

- **主实验（物理 ORCA）**：每 run 建立抓握→激励→跟踪（空中或纸上：闭合形状、字母、自由 SVG）；指标为激励后面内跟踪误差（均值/95 分位/逐轴标准差）、鲁棒性（是否完成/发散）与 z 漂移。默认参数：激励 18 s、书写速度 8×10⁻⁴ m/s、回路约 15 Hz。
- **消融**：每 run 只改一个组件——冻结估计（激励后即刻/约 12 s/约 30 s 后冻结 RLS）、关闭零空间抓握正则、提高书写速度（2×/3×/4× 与中途渐增）。
- **跨具身仿真**：MuJoCo 中 Shadow Hand 与 Wuji Hand 2 上复用同一估计器/控制器结构。
- **长程**：连续写完全部 26 个拉丁字母；写"hello"时由预编程机械臂动作在字母间移位（手指独立完成每一笔，估计跨移位持续保持）。

## 结果、限制与结论

**论文报告的关键数字**（已从全文核验）：

- **精度**：空中 22 个 run 面内误差平均约 0.62±0.12 mm（范围 0.39–0.86，95 分位约 1.4 mm，最好 0.39 mm）；纸上 16 个 run 平均约 0.67±0.08 mm（95 分位约 1.4 mm）——真实纸面接触不降低面内精度；合并 n=38 个 run 平均约 0.64±0.10 mm。z 漂移空中 0.6–3 mm、纸上 2–3 mm。
- **消融**：激励后即冻结的估计 3 run 中 2 个两分钟内离径（一个 40 秒内）；约 12 s 后冻结仍差（1 个发散、一个 1.1 mm）；约 30 s 跟踪后冻结即可保持基线（0.62±0.06 mm，4/4 完成）且能从圆切换到未见字母不降精度（0.54–0.64 mm）——但只有持续更新能适应冻结图从未见过的扰动（如抓握滑移）。关闭抓握正则的 10 run 中 4 个彻底失败（均值大于 12 mm、p95 至 140 mm）、2 个严重退化（2.1/3.3 mm）、仅 4 个近基线。
- **速度**：故意很慢；2× 速度一次 0.8 mm、复现降到 2.3 mm（p95 6.6 mm）；3× 约 2.1 mm；4× 一次仍 1.1 mm；中途渐增速度全部大幅瞬态或发散（偏移至 57 mm）。
- **对比**：与更简单的三指夹爪自由空间航点误差 0.41–0.45 mm 同量级；与最接近的 RL 在手书写（三指触觉手仿真训练）相比，后者报告 0.074–3.624 mm 与 8.3–23.2 mm——但均只在仿真中报告误差，且复杂形状误差显著变大，而本方法所有轨迹误差量级一致。
- **条件数**：面内稳态估计良态（σ1/σ2 平均约 2，全程低于约 3.5），说明两个方向都被充分激励与学习。

**限制**（论文自述）：只控制 2-D 面内空间，z 不受控——不能在刚性表面书写、不能无臂辅助做多笔画字母（如"i"）；手臂仅执行硬编码移位，完整手-臂协调超出本文范围；不能处理接触不连续任务（如重新抓握、手指步进）；书写速度慢（2× 即不可靠），达到人类书写速度需要能补偿更大摩擦的控制器；精度上限受 ArUco 标记抖动约束；所有误差经由驱动控制的同一视觉管线测量，未用物理真值（如墨迹测量）独立核验，绝对精度继承相机标定与标记跟踪精度。

**结论与启示**：这篇工作最有价值的观点是"缺精确模型或缺数据未必是真实灵巧性的障碍"——一个近似的在线雅可比（在足够宽的估计误差有效区内）加激励与零空间稳定，就能在物理世界达到 RL 只在仿真中展示过的精度区间。对组内启示：(1) 在手操作任务里，在线雅可比估计是极低成本的强基线，做 RL/IL 前值得先跑；(2) 激励阶段+指令空间回归量+零空间抓握正则三个工程细节是迁移成败的关键；(3) 跨三个手的公式通用性支持"具身无关控制器"的可行性。
