## 研究问题与贡献

视觉-语言导航（VLN）要求智能体跟随语言指令穿过三维环境。对基于单目流式视频的 VLM 导航智能体而言，缺乏持久情景记忆是长时程导航的关键约束：早期看到的路口与走过的岔路决定后续决策，而现有方案要么把历史压进固定尺寸的循环隐状态，要么依赖全景观测或拓扑地图这类与观测形式耦合的显式记忆，要么记忆容量受限。北京通用人工智能研究院（BIGAI）与北京大学的 MemVLN 提出流式情景记忆框架：维护一个有界的压缩感知特征库，为每个条目标注时间步与由动作推导的相对位姿，经交叉注意力产出紧凑的记忆 token 注入 VLM 的多模态序列。为学习记忆模块，论文设计了带掩码的轨迹摘要辅助任务与多粒度子轨迹分解。在导航微调严格限定于官方 R2R 与 RxR 训练轨迹的约束下，MemVLN 在标准 VLN-CE 基准的大多数指标上取得最优；长时程分析刻画了记忆何时有用；真机 G1 人形上把基线成功率从 17% 提升到 40%，24 条演示的后训练再提升到 47%。

## 方法与系统

模型以 Qwen3-VL-4B（含原生基于 SigLIP-2 的视觉编码器与 LLM）为主干，另接一个冻结的 StreamVGGT-1B 几何编码器，用轻量可训练适配器把相机 token 几何表征与视觉特征融合为局部混合 token，为短期感知补充空间信息。记忆模块是核心：记忆库随导航逐步存入流式观测的压缩感知特征，附带时间步与动作推导的相对位姿；记忆感知器用可学习查询（以当前时间步与相对位姿接地）经交叉注意力从库中提取固定数量的记忆 token，进入 LLM 序列参与自回归动作预测；当库达到容量上限时，帧合并策略把连续帧整合为有界的情景摘要，从而同时保留近期密集观测与长期可查询的摘要。记忆学习依靠专门设计的辅助监督：轨迹摘要任务把局部视觉 token 掩掉，只留记忆 token 作为描述所经路径的视觉证据；同时把每条完整轨迹按层次分解为多粒度子轨迹（R2R 使用 FGR2R 子指令与路径点标注），在多个时间尺度上提供细粒度监督。LLM 用 LoRA 适配，记忆模块与几何适配器从头训练，合计约 10 亿可训练参数；两个模块都不改动底层 LLM 架构，可直接嵌入现有流式视频 VLM。

## 实验设置与数据

导航微调严格限定在官方 R2R（10,819 条）与 RxR（19,996 条）训练轨迹上，不使用额外导航轨迹或外部多模态微调数据；训练数据由流式回合采样器组织，摘要目标复用路线指令并辅以 FGR2R 子指令与路径点标注。仿真在 Habitat-Sim 的 VLN-CE 协议下滚动并报告 Val-Unseen 结果：R2R 用成功率 SR、Oracle 成功率 OSR、路径长度加权成功率 SPL 与导航误差 NE；RxR 用 SR、SPL、归一化动态时间规整 nDTW 与 NE。值得注意的是，记忆条目中的相对位姿由已执行离散动作历史航位推算得到，策略与记忆模块均不接触真值位姿或外部里程计；记忆库满时合并的是块级余弦相似度最高的两帧。近期观测窗口最多 16 帧；模型训练 1 个 epoch，在 8 张 A100 80G 上约 2 天，AdamW 优化器、基础学习率 2e-5、线性预热加余弦衰减。消融逐一关闭记忆、几何与轨迹摘要监督，并分析记忆容量；长时程分析按指令复杂度分组并单独考察回溯回合；论文附录还给出端到端延迟、固定 token 接口与控制频率等推理成本细节。真机评测在 G1 机器人上进行：在单一真实场景采集 30 条指令条件化回合，其中 24 条用作后训练演示、6 条留出测试，报告成功率与碰撞率及指令级分析。

## 结果、限制与结论

R2R-CE 上 MemVLN 达到 55.0% SR 与 50.5% SPL，分别超过此前方法 JanusVLN 2.2 与 1.3 个百分点，OSR 从 58.0% 升至 61.2%，NE 为 5.19 米；RxR-CE 上 SR 从 51.4% 升至 55.4%、SPL 从 44.3% 升至 48.4%，nDTW 从 59.1 升至 64.6，NE 从 6.46 米降到 5.59 米——更长指令、更复杂轨迹上的增益更大。消融显示：仅加记忆就把 R2R 的 OSR 从 51.1% 提到 56.7%、RxR 的 SR 从 48.8% 提到 53.3%；再加几何特征，R2R 的 SR 从 45.6% 升至 49.7%、RxR 升至 56.1%；完整模型比仅几何版本高 5.8 个百分点 SR 与 5.3 个百分点 SPL，NE 从 6.04 米降至 5.19 米，说明情景表征与空间感知相辅相成。长时程分析中，记忆在极复杂指令组收益最大：SR 从 40.5% 升至 46.5%，完整模型达 49.1%、NE 7.14 米；回溯回合 SR 从 43.2% 升至 50.9%，完整模型 52.8%、NE 降至 5.98 米；停止条件与地标经过类指令也分别获得 5.2 与 4.5 个百分点提升。真机 30 次试验中，基线成功率 16.7%（5/30），完整 MemVLN 达 40.0%（12/30），碰撞率从 56.7% 降至 46.7%；用 24 条演示做后训练把成功率进一步提升到 46.7%（14/30），但碰撞率保持在 46.7% 未变。局限方面作者直言：推理期检索与相似度合并是任务无关的，长回合可能丢弃任务相关观测；除轨迹摘要外更广的记忆训练策略尚待探索；真机研究只有一个场景、6 条留出回合且碰撞率仍高，跨场景泛化未测试，未来将研究任务感知的合并、更广的部署设置与安全感知的后训练。
