## 政策行动

据美国全国公共广播电台（NPR）2026年9月23日的独家报道，参议院侍卫官办公室今年春季向参议院工作人员发出内部通知，授权参议院各办公室免费使用三款人工智能聊天工具：微软 Copilot Chat、Google Workspace Enterprise Plus 套件中的 Gemini Chat，以及 OpenAI 的 ChatGPT Enterprise。参议院侍卫官是该议院的首席执法与礼宾官员，其办公室统一负责参议院全部计算机、软件、设备与技术支持服务以及参议院网络安全，由参议员选举产生，现任侍卫官为 Jennifer A. Hemingway。

同一通知及其后续规则显示，侍卫官办公室目前未批准任何更先进的"智能体"（agentic）工具，即能够自主在计算机上完成任务的工具，包括 OpenAI 的 Codex 以及 Anthropic 的 Claude Code 和 Cowork。侍卫官办公室的规则明确要求："平台不得独立访问参议院内部驱动器、共享文件夹、电子邮件、Teams 聊天或其他参议院资源。"

需要说明的是：上述内容来自 NPR 获得的内部通知及对该政策的报道转述。该通知本身未在参议院官方网站公开，参议院官方渠道亦未发布该授权的完整文本（官方原文未确认）。本条目依据已确认事实保守成稿。

## 适用范围与约束力

该政策的适用对象是参议院系统内的办公室与工作人员，属于议院内部的行政性技术使用授权与网络安全管理措施，不是公开颁布的法律或法规。

其约束力体现为内部管理规则：由侍卫官办公室作为参议院网络安全主管机关执行，获批工具的配置和使用必须遵守上述访问限制。据 NPR 报道，参议院规则与行政委员会（负责监督侍卫官办公室）发言人的书面回应称，相关政策旨在"保护参议院数据，并包含更强的安全与合同要求"，且"参议院办公室应当可以使用人工智能工具，但须受各议员和委员会自身政策的约束"。换言之，具体办公室可在统一授权之上附加自己的使用限制。

该政策不适用于众议院：众议院人工智能使用由首席行政官办公室（CAO）另行管理，据 NPR 援引众议院工作人员的说法，众议院规则列明了允许使用人工智能的具体场景，微软、OpenAI、谷歌和 Anthropic 的工具在若干场景下获得批准。该政策对私营部门没有任何约束力。

## 关键条款

已获授权的三款免费工具：Microsoft Copilot Chat；Gemini Chat for Google Workspace Enterprise Plus；OpenAI ChatGPT Enterprise。三者均为基于网页的聊天界面，供参议院办公室无偿使用。

未获授权的工具类别：能够自主执行任务的智能体工具，报道点名的包括 OpenAI Codex、Anthropic Claude Code 与 Cowork。侍卫官办公室被描述为"在平衡创新与风险"，尚未为这类更强大的工具放行。

核心安全限制：获批平台不得独立访问参议院内部驱动器、共享文件夹、电子邮件、Teams 聊天或其他参议院资源。

程序状态：据 NPR 援引匿名参议院工作人员的说法，更先进的工具正在"按具体用例"接受审查，但没有给出时间表；参议院规则与行政委员会的共和、民主两党首席成员未就政策细节直接回应，仅通过发言人发表上述原则性声明。

## 时间线

2026年春季：侍卫官办公室向参议院工作人员发出内部通知，确立三款聊天工具的免费授权（NPR 获得该通知）。

2026年9月23日：NPR 在《面对AI，参议院议员被排除在最先进工具之外》的独家报道中公开该政策内容；AI Policy Daily 等予以转载。

进行中：更先进的智能体工具按具体用例接受安全审查，无公开时间表（未确认）。

未决定：国会层面的人工智能立法仍在权衡之中，参议院对智能体工具的授权范围何时调整未知。

## 影响与待观察事项

这一政策的现实张力在于：负责制定人工智能规则的立法机构，其工作人员目前只能使用最基础的人工智能工具。科技行业组织 Chamber of Progress 首席执行官 Adam Kovacevich 批评称，"立法者在为许多情况下自己从未用过的技术制定规则，这是一个问题"，并认为安全考量在某种程度上是拖延的借口。美国治理研究所执行主任 Daniel Schuman 则承认数据外泄风险真实存在，但同时指出这不应成为不批准技术的最佳理由，并认为参议院领导层若决意推进完全可以加快进程。

也有办公室在规则允许范围内自行探索：俄亥俄州共和党联邦参议员 Bernie Moreno 上周在科技新闻节目 MTS Live 中介绍其办公室如何使用名为 Albert 的人工智能助理进行研究工作，并抱怨参议院在部署上的限制。

待观察事项包括：智能体工具用例审查的进展与结果（未知）；侍卫官办公室是否会公开该政策的正式文本（未确认）；参议院规则与行政委员会是否启动正式的政策审议程序（未确认）；以及参众两院在人工智能工具授权上的差异是否会推动统一安排（未知）。本条目仅为事实梳理，不构成任何法律意见。
