RoboTwin-Phys：物理条件多样性基准揭示 WAM 与 VLA 的鲁棒性缺口

## 研究问题与贡献

当前机器人操作评测体系在视觉与场景多样性上进步显著，但一个关键维度长期缺位：物理条件多样性。现有大规模仿真基准（如 RoboTwin-2.0）会随机化物体外观、场景布局、光照与相机视角，却通常把底层物理参数固定在标称值。而真实世界中，物体质量随装载变化、摩擦系数取决于材料与磨损、质心因制造公差或内容物偏离标称模型、关节阻尼随机械磨损漂移——这些因素直接决定接触动力学与操作成败，却几乎没有被当作独立的评测维度。

论文指出这一缺口带来三个直接后果：缺少标准化评测协议来度量操作性能随物理条件的变化；缺少刻意覆盖多样物理条件的大规模训练数据；缺少与样本一一对应的物理真值标注，使物理感知与条件感知建模难以开展。

RoboTwin-Phys（北京大学与 MEMO 技术报告，第一作者 Jiaqi Zhang）针对该问题提出三项贡献：一是在 RoboTwin-2.0 的 50 个双臂任务平台上构建以物理条件多样性为显式维度的基准，13 个物理属性在物理合理区间内按回合连续采样；二是发布超过 5000 条专家演示数据集（Training Set v1），每条样本附带 13 维物理参数真值；三是给出针对世界-动作模型（WAM）与视觉-语言-动作模型（VLA）的系统评测协议，并用对比实验刻画了显著的物理鲁棒性缺口。

## 方法与系统

基准设计围绕三条原则：物理有效性（每个采样条件必须对应物理可实现的环境，而非任意扰动仿真器参数）、连续多样性（物理因子在有意义区间内连续变化，而不是少数人为选定的离散情形）、可组合性（物理条件变化作为独立评测维度，可单独研究，也可与既有视觉/布局随机化叠加）。

具体实现上，13 个物理属性在每个回合初始化时独立采样并在整个回合内保持不变，采样由回合种子决定，因此物理条件完全可复现。属性覆盖场景几何（物体质量缩放 0.125 至 4 倍并同步缩放惯量张量、质心偏移各轴至 1.5 厘米、几何缩放 0.85 至 1.05 倍、桌面倾角 0 至 2 度、桌高相对 0.74 米标称值下调 0 至 8 厘米）、感知配置（相机距离与角度的三种扰动模式）、外力（沿固定方向、最大为 0.1 倍物重的持续力）、材料属性（摩擦系数 0.01 至 1.25、恢复系数 0 至 0.5）以及关节特性（关节物体阻尼 0 至 25，机械臂与夹爪阻尼 0.5 至 3 倍缩放）。

系统还包含两个关键机制。其一是任务感知的物理有效性：全局区间并不适用于所有任务，例如敲锤任务中细长锤子若套用完整质心偏移区间，质心可能落到锤体外。论文为 9 个物理敏感任务配置了专属可行域（如 dump_bin_bigbin 质心偏移收窄至正负 1 毫米、open_microwave 关节阻尼收窄至 0.25 以内），保证评测度量的是物理多样性下的鲁棒性而非人为制造的失败。其二是可行性校验：采样条件只有当专家规划器能在该环境中预先成功完成任务时才被保留为基准实例，确保模型失败反映的是其应对物理变化的能力，而不是环境本身无解。

数据集与基准保持一致：专家演示均通过可行性校验，保持官方 RoboTwin 数据格式（HDF5 轨迹加 MP4 视频），并额外提供 phys_meta 目录，以 JSON 记录每条回合实例化的 13 个物理属性真值，使物理条件成为可直接监督的学习目标。

## 实验设置与数据

评测基于 RoboTwin-2.0 双臂平台的 50 个操作任务，采用三种环境协议：Clean（关闭全部随机化的标称环境）、Official Random（启用原基准的视觉与布局随机化，物理参数保持标称值）、Physical Random（保留原随机化并叠加按 RoboTwin-Phys 协议采样的 13 个物理属性）。

被评模型共五个，覆盖两类架构：世界-动作模型 Fast-WAM、Motus、FACT，以及 VLA 模型 π0.5 与 Galaxea-VLA（G0.5）。Clean 与 Official Random 两列数字取自相应公开基准的已报告结果，Physical Random 为本文作者自行评测。附录 D 给出完整逐任务结果，每个任务 100 条评测回合。训练数据方面，发布的数据集包含超过 5000 条专家演示，覆盖物理条件分布并附带物理真值标注。

## 结果、限制与结论

论文报告的核心结果是物理条件随机化带来的大幅性能下降。在 Physical Random 设置下，Fast-WAM 成功率从 Clean 的 91.88% 降至 44.24%，Motus 从 88.66% 降至 39.60%，FACT 从 88.40% 降至 39.14%，π0.5 从 82.74% 降至 31.60%，Galaxea-VLA 从 93.70% 降至 37.82%。作为对照，Clean 到 Official Random 的下降小得多：Fast-WAM 仅 0.10 个百分点，Motus 1.64，FACT 1.80，Galaxea-VLA 0.90，π0.5 为 5.98。这说明在常规视觉与布局随机化下依然有效的模型，面对物理条件变化可能出现断崖式退化，且该现象跨 WAM 与 VLA 两个家族一致存在，并非特定架构的问题。

逐任务分析显示失败具有结构化模式而非随机噪声：beat_block_hammer、pick_diverse_bottles、move_stapler_pad、place_can_basket、put_bottles_dustbin 等任务在多个模型上一致低分，这些任务高度依赖接触动力学、物体稳定性、质量分布或关节运动；而 grab_roller、shake_bottle、shake_bottle_horizontally、place_container_plate 等任务保持相对稳健。

限制方面需要明确指出：论文正文未设置独立的局限章节，也未报告基于物理真值的条件感知训练能否缩小上述缺口（作者仅指出该数据为后续物理属性估计、条件感知建模与物理条件化策略训练提供了基础），这部分属于当前材料未确认的开放问题。此外，Physical Random 结果为作者自行评测，Clean 与 Official Random 为引用既有公开评测数字；真实机器人上的物理条件迁移实验在当前材料中未见报告。基准目前绑定 RoboTwin-2.0 仿真平台与双臂形态，对其他形态和真机场景的适用性有待验证。

结论上，论文论证了物理条件多样性是一个独立且必要的评测维度：对常规随机化的鲁棒性不能外推到物理条件变化。RoboTwin-Phys 提供的基准、带物理真值的数据与评测协议，可作为物理条件感知、条件感知建模与自适应控制后续研究的测试床。对本领域研究者而言，该工作提示在部署评测中应显式加入物理参数扰动维度，并利用其发布的数据开展物理属性估计与条件化策略训练。
