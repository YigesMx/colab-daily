## 研究问题与贡献

Anthropic 在官方研究页面"Yes, Claude can do Nine Loops"（2026-09-25，由物理学家、科学作家 Matt von Hippel 撰写的客座文章）公布：Claude 计算出了平面 N=4 超杨-米尔斯理论中六粒子 MHV 振幅的九圈结果，把该问题的人类最好纪录从八圈推进到九圈，结果由 SLAC/斯坦福教授 Lance Dixon 独立验证。这一事件源于 von Hippel 一个月前公开提出的挑战：让 AI 用学术级算力解决散射振幅领域公认"计算上不可行"的前沿问题。对关注前沿模型自主科研能力的读者，这是一个可核验的标志性数据点：Claude 以一个提示词、约一周的 96 CPU 时间与几千美元量级成本，在无实质科学监督（只有"继续"）的情况下一次性跑完了这一脆弱的长链计算。

## 方法与系统

按官方文章与验证者说明：Claude 直接计算九圈振幅本身（而非 Dixon 团队 2023 年提出的"形状因子+反偶极对偶性"间接路线），完整执行了该领域多年积累的计算配方，并用 Python 从零实现全部代码、组织计算资源；计算在内部出错时由 harness 自行推进到底，无需外部协作者介入。Dixon 主要通过由九圈振幅回推形状因子来验证，并表示 Claude 对其 2019/2023 年论文的理解"仅次于共同作者"。完整九圈结果已按此前圈数的格式以计算机可读形式发布；Song He（何向宏）小组同期用 GPT-6 辅助部分约束计算得到了九圈 symbol 的并行结果。

## 实验设置与数据

问题的可验证性来自三层：官方公布的计算结果工件（沿用 Lance Dixon Cosmic 页面格式）、独立物理学家验证（Dixon 两周复核九圈形状因子）、以及同期独立小组的并行结果（何向宏、Jirong Jing、Xiang Li）。原挑战要求"学术级算力预算"，von Hippel 估算 Claude 实际动用的计算量（一周、96 CPU）与学术资源相当甚至更少。

## 结果、限制与结论

von Hippel 的判断明确：Claude 用的是已知方法加更多计算与更好的软件工程实践，并非超智能式的新算法——"低垂的果实比预想的多"是最大启示；他也强调这类精细计算一次跑通本身就证明了执行可靠性。Dixon 的补充则指出，更深的冲击将来自 LLM 先于人类提出新物理原理。对后续研究的启示包括：前沿科学计算任务中 AI harness 的可靠性已被实证，社区需要建立"如何验证机器给出结果"的标准流程。局限与未知：该结论限于玩具模型理论的小子领域，真实世界振幅计算竞争更激烈，"能否再挤出一圈"尚待检验；本文为官方博客性质，完整技术细节以后续正式论文与计算机可读工件为准（性能与引述均来自官方页面原文）。
