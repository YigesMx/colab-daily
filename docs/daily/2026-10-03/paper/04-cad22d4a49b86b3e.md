## 研究问题与贡献

面向视觉-语言-动作（VLA）系统的世界模型通常先预测未来 RGB 观测、再将其重新编码为策略输入，这种间接接口造成仿真与下游策略执行之间的错位：仿真器把容量花在人类可看的像素上，而策略真正消费的是视觉 token。本文研究世界动力学能否直接建模在与策略对齐的紧凑 VLM 视觉 token 状态中。挑战在于原始 VLM token 维度极高（Qwen3-VL 为 108 个空间 token × 2560 通道），直接做自回归动力学建模既难又贵。Token-World 的做法是先用语义 VAE（S-VAE）把特征维度压缩到每 token 16 通道、保持空间布局不变，在压缩空间学习动作条件动力学，需要时再经冻结解码器映射回策略侧表征。贡献：一是把"VLM token 空间仿真"作为 RGB 世界模型的替代接口系统化研究；二是提出不依赖预训练视频生成模型、用流匹配 DiT（时空 Transformer + GRU 循环记忆）在紧凑 token 状态做自回归 rollout 的完整仿真器；三是通过开环保真、闭环策略评估与表征消融验证设计。作者来自北大、南科大、港科大、中科院自动化所、宾夕法尼亚大学与 MUKA Robotics（论文署名机构），通讯作者为北大张航行（Shanghang Zhang）。

## 方法与系统

系统分三层。表征层：冻结 VLM 编码器输出 z_t∈R^(108×2560)，S-VAE 编码器给出对角高斯后验，压缩只沿特征维度（无空间池化/融合），解码器 G_φ 重建原始策略表征；编解码损失为 MSE+余弦+KL 正则，训练后冻结。动力学层：紧凑世界状态 x_t=(c_t,p_t) 由紧凑视觉 token 与机器人本体状态组成；转移模型是因子化的时空 Transformer（空间注意力建模 token 间交互、因果时间注意力建模演化），并用固定大小 GRU 状态跨注意力窗口传递早先交互上下文；训练用 x₀ 参数化流目标加 shortcut forcing（支持少步生成），权重 w(τ)=0.9τ+0.1。推演层：自回归 rollout 全程留在紧凑状态空间——观测到的紧凑状态初始化上下文，之后逐个去噪生成未来状态并拼回历史，仅当下游策略需要时才解码回 VLM 表征；RGB 重建只用于评估可视化，不参与动力学或策略反馈回路。推理时 Token-World 用 16 步（shortcut forcing），而 RGB 基线用 50 步去噪。

## 实验设置与数据

数据：仿真用 RoboTwin 的 50 个操作任务、每任务 100 条轨迹（50 成功 + 50 失败），共 5000 条；真实世界自采 Franka 数据集（Franka Research 3 机械臂 + Robotiq 自适应夹爪 + 两台 Intel RealSense 435 相机），6 个任务（挂 M、挂杯、叠积木、叠环、积木入抽屉、辣椒入抽屉）各 100 条成功轨迹，共 600 条；均 9:1 划分训练/验证，所有方法共享数据。基线：IRASim（ICCV 2025）、Ctrl-World（ICLR 2026）、WorldGym（ICLR 2026）。开环评测：动作重放下预测未来状态，度量 VLM 特征保真（NMSE、余弦相似度）与策略-动作一致性（预测/真值表征分别喂同一冻结策略后比较动作），按任务内轨迹平均再跨任务宏平均。闭环评测：用共享 Qwen3-VL 主干、不同动作头的三个 StarVLA 变体（OFT/PIv3/GR00T）在学得仿真器中 rollout，与参考环境成功率算 Pearson 相关，成功由解码 RGB 人工判定。效率：PPU-ZW810E 加速器上测 batch-1 每步仿真时延。

## 结果、限制与结论

论文报告：RoboTwin 开环上 Token-World 特征余弦相似度 0.7714 / NMSE 0.4892，优于 IRASim（0.7372/0.5685）与 Ctrl-World（0.7097/0.6437）；经策略推理后动作余弦相似度 0.9439 / NMSE 0.1145，同样领先（IRASim 0.9260/0.1533、Ctrl-World 0.9265/0.1463）。长时程（重放块 0/5/10/15、每块 16 步）下退化更慢，可视化显示其更能保持任务相关物体构型与交互推进。闭环策略评估中，仿真成功率与参考成功率 Pearson 相关从 Ctrl-World 的 0.583 提升到 0.794，且回归更贴近 oracle y=x。效率上每步仿真时间 0.359 秒，相对 IRASim、Ctrl-World、WorldGym 分别加速 2.0、5.3、6.1 倍。表征消融：S-VAE 维度从 8 增到 128，重建保真单调上升（NMSE 0.1026→0.0409）但可扩散性指标反向（SEC 0.3511→0.4740、LDS 0.3100→0.1182）；固定动力学骨干仅变维度时 d=16 最优（特征 NMSE 0.1517、特征余弦 0.8306、动作余弦 0.9641），说明动力学性能对表征容量非单调；同骨干下 S-VAE 全面优于原始 VLM 特征（特征/动作 NMSE 0.4892/0.1145 对 0.7851/0.2180）与 SDXL-VAE 潜码（0.8164/0.2586）。作者自述局限：评测集中在操作任务与共享同一 VLM 主干的策略，尚未系统刻画什么语义表征适合世界建模；跨策略主干、更多交互数据与表征设计的扩展留作未来工作。本文分析：该工作抓住了"仿真器应该预测策略要用的表征而非像素"这一接口问题，d=16 与 2560 维之间约 160 倍的压缩比对算力受限的部署侧世界模型很有吸引力；但闭环相关系数（0.794）距离可完全替代真实评测仍有距离，且真实数据仅 6 任务 600 条，跨本体/跨主干的泛化未验证（原文未报告）。
