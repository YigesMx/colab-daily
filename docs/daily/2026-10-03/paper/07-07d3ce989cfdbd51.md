## 研究问题与贡献

机器人基础模型（RFM）普遍采用流匹配动作策略，多步去噪的推理开销限制了决策频率——以 GR00T-N1.6 为例，动作头时延占端到端推理时间的约 40%（桌面 GPU L40）到 50%（边缘平台 Jetson Orin）。MeanFlow 在图像生成中给出一步生成的简洁方案（学习任意两个时间步之间的平均速度 u_{t,r}），但作者发现它直接用于通用 RFM 会性能崩溃。本文贡献：一是诊断出 RFM 速度场与图像生成的两类特异动态——"局部加速度"（Δu/Δt）在去噪早期（t 小于 0.3，接近干净数据）急剧攀升（终值达初始 76 倍），且其样本间幅度散布随去噪推进不断展宽（散布程度与训练数据任务多样性强相关），二者分别造成时间导数项的估计误差与误差放大，破坏 MeanFlow 的自举反馈环；二是基于运动学恒等式（任意中间点 c 下区间平均速度等于两个子区间平均速度的凸组合）提出 Kinematic MeanFlow（K-MF），把时间导数项 d/dt u_{t,r} 解耦为 d/dt u_{t,c} 与 d/dc u_{c,r} 两个子区间项：前者保障早期去噪的稳健估计，后者专司晚期修正，且在 c 处的第二次估计充当锚点抑制散布导致的误差放大；三是给出确定 c 的三种策略（均匀随机 λ、固定中点 λ=0.5、可学习 λ=G_φ(t,r) 的 3 层 MLP），可学习策略最优。作者来自 Intel（IntelChina-AI 代码组织与作者署名，机构细节以论文原文为准）。

## 方法与系统

MeanFlow 的目标 u_{t,r}=v_t+(t−r)·d/dt u_{t,r} 中，v_t 对给定样本训练期恒定，优化主要由时间导数项驱动，而该导数没有真值、由训练中的策略在线生成自举目标。K-MF 在条件流路径上构造 z_t 与 z_c（v_t=v_c=ε−a），把目标改写为 u_K-MF = v_t − (t−r)·[(1−λ)²·sg(d/dt π_θ(z_t,c,t)) + λ²·sg(d/dc π_θ(z_c,r,c))]，λ=(c−r)/(t−r)，用 MSE 回归该解耦目标。三种 c 策略：随机采样（λ~U(0,1)，检验切分多样性价值）、固定中点（λ=0.5，消除切分方差）、可学习策略（3 层 MLP 生成 λ，其目标 L_gen 在不放大训练损失的前提下平衡两个子区间的在线自举误差；权重 ω=1+γ·exp(−1/(‖Δu‖₂+ε)，γ 从 −0.5 线性增至 0.5，实现"早期使解耦估计区别于整体估计、晚期逐渐趋同以保持自洽"）。总目标为 L_K-MF(+α·L_gen)。推理一步（NFE=1）直接预测平均速度。

## 实验设置与数据

训练数据四档规模：LIBERO（2K 轨迹）、BridgeData V2（53K）、Fractal（87K）、COMPASS 生成的点导航数据（658）。评测含 Sim2Sim（LIBERO 原生仿真器、COMPASS PointNav）与 Real2Sim（Fractal、BridgeData V2 经 SimplerEnv）；按协议 GR00T-N1.6 跑 200 次、SimVLA-S 跑 500 次 rollout。RFM 选两种代表：GR00T-N1.6（微调范式）与 SimVLA-S（从头训练范式）。基线：多步流匹配（NFE=4）、MeanFlow（配精细训练配方：梯度裁剪+渐进时间步采样+约 60K 迭代）、α-Flow（区间切分课程）、MVP（速度约束稳定化）。先导实验在 GR00T-N1.6 + LIBERO-10 上做。效率：L40 与 Jetson Orin 上测 eager 与 torch.compile 两种模式的动作头/端到端时延。

## 结果、限制与结论

论文报告：先导实验中标准配方下 MeanFlow 在 RFM 上失效，需精细配方 + 两步生成才达可用但落后流匹配，且性能对分离时间步敏感；推到一步时 MVP 无法产生可用动作、α-Flow 明显退化，K-MF 一步即可比拟多步流匹配。LIBERO 上两种范式（GR00T-N1.6 微调、SimVLA-S 从头训）K-MF 均持平或超过流匹配（配合精细配方的两步 MeanFlow 也被超过）；消融显示 c 策略排序为：可学习 > 固定中点 > 随机（GR00T-N1.6 平均 97.9/97.6/95.3，SimVLA-S 95.1/94.4/93.8），且固定中点显著优于随机采样，说明锚点位置比切分多样性更关键。跨数据/跨本体：Fractal（GoogleX 本体，Real2Sim）平均 78.4% 对流匹配 73.9%（其中 Open 任务 50.5% 对 35.5%）；BridgeData V2（WidowX）59.9% 对 58.4%；PointNav（Unitree G1 本体）ID 84.5% 持平、OOD 63.5% 对 63.0%。效率：GR00T-N1.6 动作头时延在 L40/Jetson Orin、eager/compile 四组合下降 67.5%–74.4%（如 L40 eager 28.0 ms 对 109.3 ms），端到端降 30.3%–54.9%。训练开销相对 MeanFlow 增加训练时间 7.5%–13.6%、峰值显存至多 2.5%；相对流匹配训练时间多 33%（GR00T-N1.6）/27%（SimVLA）。作者自述局限：训练开销高于流匹配（被认为可接受）；评测未覆盖全身控制与灵巧操作。本文分析：该工作对"RFM 速度场动态与图像生成不同"的诊断扎实（含任务多样性与散布的相关性分析），一步生成对边缘端部署的实时控制有直接价值；但全部评测为仿真/Real2Sim，未做真机闭环验证（原文未报告），且收益最大的任务（如 Open）绝对成功率仍有限。
