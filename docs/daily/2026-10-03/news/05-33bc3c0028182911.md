## 事件概述

2026年10月1日，NVIDIA 官方博客发布文章，宣布 OpenAI 的 GPT-6 Astra Ultrafast 推理模式现已在 OpenAI API 中可用，并向符合条件的 ChatGPT Work 与 Codex 用户开放。该模式运行于 NVIDIA Blackwell GPU，官方称其 token 生成速度最高可达 Astra Standard 模式的8倍。

## 已确认事实与证据

NVIDIA 官方博客（作者 Dion Harris）确认以下内容。GPT-6 Astra Ultrafast 运行在 NVIDIA Blackwell GPU 上，加速来自 OpenAI 模型自身参与的推理优化，对 Blackwell 架构能力加以利用；对开发者而言，更快的生成速度可以缩短编码智能体的编辑-测试-调试循环、减少工具调用之间等待响应的时间，并让交互式应用更跟手，官方强调这类提速在智能体写代码、调用工具、检查结果、决定下一步的循环中最有价值。OpenAI 推理负责人 Philippe Tillet 在文中表示，NVIDIA 在工具与文档上的深度投入使 OpenAI 的模型非常擅长为 Blackwell 与 Rubin GPU 编程，Astra 能把这类知识转化为覆盖延迟、吞吐与成本前沿的高性能内核。OpenAI 计算首席技术官 Uday Ruddarraju 表示，OpenAI 用内部模型优化 NVIDIA GPU 上的推理，NVIDIA 平台的可编程性帮助实现了 Ultrafast 背后的加速。博客还确认一项持续性机制：模型部署后性能仍会继续改进，OpenAI 正在用自家模型迭代运行在 NVIDIA GPU 上的推理软件；可编程平台也允许训练、推理与强化学习复用同一套基础设施，按需求变化重配算力、避免按单一负载超配。官方指引开发者通过 API 使用，并说明访问方式、定价与实现细节见 Ultrafast 指南。具体加速倍数在不同工作负载下的分布、以及该模式的独立基准测试，原文未报告。

## 影响与后续观察

Ultrafast 的定位是智能体工作流专用档位：当响应时间在多步循环中被反复放大时，8倍上限的生成提速对迭代效率的边际价值最大，这进一步强化了低延迟推理作为智能体基础设施的竞争维度。值得注意的技术事实是 OpenAI 用自家模型优化自家推理栈，这一闭环若持续，GPU 厂商工具链的开放程度将成为关键变量。观察点包括：Ultrafast 相对 Standard 的实际价格与限流策略、对 Codex 类编码产品的转化数据、以及 Rubin 架构上市后同一优化路径的延续性。NVIDIA 与 OpenAI 双方均未披露涉及的具体集群规模与能效数据，原文未报告。
