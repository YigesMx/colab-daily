# 全球首台「万元级」高性能人形机器人发布

人形机器人的成本曲线出现新的标志性节点：新智元报道「全球首台万元级高性能人形机器人」诞生。

## 事件概述

报道称全球首台「万元级」高性能人形机器人诞生，并以其「比 Mac 还便宜」作为价格锚点。报道背景提及第二届世界人形机器人运动会（2056 台机器人参加 1301 场比赛）带火的人形机器人热度。

## 已确认事实与证据

- 新智元（AIERA 存档）报道该发布事件与价格定位；
- 报道确认：这是一台人形机器人产品的发布，价格进入万元人民币量级；
- 具体厂商、型号、性能参数、量产时间表：报道摘要未提供，需官方发布材料核验，本文不补造；
- 「高性能」的界定标准（速度、负载、自由度）原文未给出，属待核验宣传语。

## 影响与后续观察

- 若价格定位属实，将把人形机器人从工业/科研设备价位拉入消费电子价位段，影响整机与供应链格局；
- 「首台」「高性能」等表述需要官方规格表与第三方评测验证；
- 未知项：厂商身份、量产规模、销售渠道、安全认证路径。
