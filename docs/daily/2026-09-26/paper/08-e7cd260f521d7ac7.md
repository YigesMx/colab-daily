一句话结论:论文提出一种后训练配方,让 VLA 机器人策略把自身在硬件偏移环境下的失败回合压缩为上下文 token 注入策略,无需现场重新标定即可迭代自我修正;论文报告其在真实双臂与灵手任务上恢复了基线策略八成以上的性能。

## 研究问题与贡献

视觉-语言-动作(VLA)模型在大规模机器人数据上训练后已能完成复杂操作,但它们大多无记忆,仅依赖当前观测决策,面对部署期环境变化时会陷入重复失败,其中硬件磨损或标定偏差造成的执行偏置与关节编码器偏移尤为常见。让机器人在部署中自我适应、而不依赖持续人工现场标定,是规模化真实部署与运维的关键瓶颈。本文贡献包括:提出 Self-Adaptive VLA 后训练配方,使策略以自身 rollout 为上下文迭代适应部署期硬件偏移;设计自动化管线,把训练基线策略的人类专家示教改造成硬件偏移条件化的专家数据,无需额外人工采集;设计可插拔的轻量上下文编码器,配合上下文 token 集成策略高效注入失败上下文;并在四种高精度双臂与灵手任务上验证,展示对未知硬件偏移新工作站的稳健部署能力。

## 方法与系统

论文显式建模两类硬件偏移:执行偏置(动作执行整体偏移,状态传感仍准确)与关节编码器偏移(执行与传感同时偏移,偏移量只能从视觉推断)。方法分三步:先在故意注入随机偏移的条件下 rollout 冻结的基线策略,收集次优轨迹作为上下文数据;再对专家示教动作按已知偏移做预补偿,构造上下文条件化的专家示范,补偿目标始终来自高质量人类数据而非次优 rollout,以保证监督质量;最后训练一个即插即用的上下文编码器,把三路相机视频、本体状态与动作序列经视觉 token 化、类型嵌入、两块带一维 RoPE 的自注意力和可学习查询注意力池化,压缩为单个上下文 token。该 token 与扩散时间步条件相加,经 AdaLN 调制 DiT 动作去噪器;训练时 VLM 主干冻结,编码器用与基线相同的条件流匹配损失优化。由于 token 只在失败回合后计算一次并静态注入,闭环高频控制阶段零额外推理开销。多个回合的 token 可直接向量求和集成,支撑逐步定位与修正偏移的迭代自适应;分析显示该潜空间结构良好,各偏移自由度近似构成正交主轴,这正是简单求和有效的几何解释。

## 实验设置与数据

实验覆盖四个需精确抓取与插入的任务:Transport Corn、Insert Tube 与 Cap Marker 使用 6 自由度 Piper/Piper-X 机械臂加平行夹爪,Assemble Ring 使用两台 7 自由度 Marvin 机械臂与 20 自由度 Wuji 灵巧手,每台机器人配一个自视角与两个腕部相机。基线 VLA 以 Qwen3.5-0.8B 为 VLM 编码器、8 层 DiT(340M 参数)为动作去噪器,由人类遥操作示教训练;所有对比方法均从同一基线后训练以保证公平。评测时每种方法测 20 个回合,每回合从硬件特定分布采样一个未见过的偏移,相当于 20 个互不相同的未标定部署环境,每回合最多 6 次尝试、任一次成功即算成功。对比基线包括无记忆基线策略、在偏移 rollout 数据上微调但无上下文编码器的变体,以及在同一上下文数据上训练的门控记忆策略 GMP。

## 结果、限制与结论

论文报告:硬件标定良好时基线接近满分,两类硬件偏移使其成功率降至接近 0;Self-Adaptive VLA 单次尝试即恢复约 46%-49% 的性能差距,集成至多 6 次尝试后平均恢复 80%-84%,其中 Transport Corn 从退化状态完全恢复到 100%,且推理阶段零额外开销;GMP 在两次尝试后难以继续提升,因其固定注意力窗口会覆盖较早上下文。消融显示本体状态输入对两类偏移都有益、对执行偏置尤为关键,而更稠密的视觉 patch token 并无显著增益,说明紧凑的逐帧 CLS token 足以编码物理失败模式。跨工作站实验中,论文报告基线从训练工作站的 95% 跌至两个未标定新工作站的 70% 与 10%,本方法以最多 2 次尝试分别恢复到 90% 与 50%。作者明确的局限包括:方法主要覆盖可映射到机器人位形空间的偏移,尚未涵盖相机标定误差等更广的环境差异;静态 token 不支持回合内在线适应,且假设环境允许安全收集次优 rollout,不适用于首次失败即造成不可逆损伤的安全关键场景。对组内工作的启示:该"失败即上下文"的数据构造思路与 AdaLN 注入设计对任意 DiT 类 VLA 均可复用,直接服务于我们关注的 VLA 部署稳健性与运维成本问题,值得在自研平台上复现验证。
