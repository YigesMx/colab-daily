# OpenAI 修复 Codex 额度异常消耗问题并重置全部付费用户使用额度

## 事件概述

据机器之心 2026 年 8 月 30 日报道，OpenAI Codex 负责人 Tibo（Thibault Sottiaux）通过其 X 账号宣布，OpenAI 已修复 Codex 中导致 token 额度异常消耗的问题，并为所有 Codex 与 ChatGPT Work 付费用户重置使用额度。报道称，OpenAI 方面集中处理了大量用户反馈，官方预计修复后同等额度可支撑更多的工作量。该消息以官方账号公开发布的形式宣布，报道来源为摘要级内容，公告原文页面在当前材料中未能直接取得。

## 已确认事实与证据

- **主体与发布渠道**：公告发布方为 OpenAI Codex 负责人 Thibault Sottiaux（X 账号 @thsottiaux，其个人资料自述为"Codex & ChatGPT @OpenAI"）。本周期抓取中已成功获取该账号的公开 X 时间线，确认其 Codex 负责人身份；该时间线快照也显示其此前多次以同一渠道发布 Codex 额度重置与用量修复类公告。
- **时间与来源**：机器之心于 2026-08-30 发布报道《刚刚，OpenAI要给Codex、ChatGPT Work付费用户集体回血了》，原始文章 URL 为 https://www.jiqizhixin.com/articles/2026-08-30-2 。该 URL 在本周期抓取中可正常访问（HTTP 200），页面元信息确认其归属机器之心站点。
- **事件要点（按报道与冻结证据转述，归属为"OpenAI 方面宣布/称"）**：
  - OpenAI 称集中处理了数千份用户反馈，修复了 Codex 中 8 个导致 token 异常消耗的问题，报道提及的例子包括 `/goal` 命令在任务完成后仍消耗每周额度（幅度 15%-70%）、Computer History 重复总结等；这些具体比例与漏洞细节当前仅见于报道转述，公告原文未直接核验。
  - OpenAI 宣布为所有 Codex 与 ChatGPT Work 付费用户重置使用额度。
  - OpenAI 方面预计，修复后同等额度可多支撑 10%-50% 的工作量（官方预估口径，非独立验证数据）。
  - 报道还提及 OpenAI 正在进行相关架构调整，并开发使用量明细功能。

## 影响与后续观察

- 对 Codex 与 ChatGPT Work 付费用户而言，额度重置与异常消耗修复意味着实际可用工作量回升；但"多支撑 10%-50%"为官方预估，实际改善幅度有待用户使用数据验证。
- 当前材料未确认的细节包括：8 个漏洞的完整清单与技术原因、额度重置的具体生效时间与覆盖套餐范围（哪些订阅层级属于"付费用户"）、架构调整的具体内容，以及使用量明细功能的上线时间。这些均有待 OpenAI 官方公告原文或后续更新确认。
- 后续值得观察：OpenAI 是否发布正式的事故/修复说明；额度重置后用户侧的反馈；以及官方此前承诺的用量透明度改进是否落地。
