# 参议院审议关闭受限Nvidia芯片远程访问漏洞

## 政策行动

美国国会正在推进针对受限Nvidia芯片远程访问的立法。众议院已于1月12日以369票对22票通过Remote Access Security Act（H.R. 2683）；参议院同案法案S.3519由参议员McCormick和Wyden提出，目前停留在银行委员会。

现行规则主要监管芯片物理转移。报道援引政策研究者称，中国公司通过泰国、马来西亚和日本数据中心远程访问受限算力，形式上符合当前出口管制，因此立法拟关闭该远程访问漏洞。

## 适用范围与约束力

该行动处于联邦立法程序中，尚未成为法律。若通过，将约束美国出口管制下的受限芯片和算力服务，尤其是境外数据中心的远程训练与推理访问。当前对企业的直接约束仍来自既有出口管制规则。

## 关键条款

- 将受限芯片的“远程访问”纳入出口管制考量。
- 防止通过第三国数据中心规避物理转移限制。
- H.R. 2683已获众议院通过。
- S.3519尚在参议院银行委员会，未出现程序进展。

## 时间线

- 2026年1月12日：众议院通过H.R. 2683。
- 2026年7月：白宫OSTP主任公开指控Moonshot AI通过泰国设施使用GB300训练Kimi K3。
- 2026年8月19日前后：CNBC等报道Moonshot、字节、阿里、腾讯通过东南亚和日本数据中心获取受限算力。
- 当前：S.3519等待参议院银行委员会行动。

## 影响与待观察事项

若漏洞被关闭，中国AI公司的海外训练算力租赁、云服务和数据选址将受到更严格审查；美国云厂商、海外数据中心和跨国模型服务也需增加客户与工作负载审查。反对者可能关注管辖权、执法可行性和对合法云服务的影响。

后续应关注S.3519委员会动作、BIS规则修订、云服务商审计要求、受影响公司披露，以及是否引发其他国家配套出口管制。
