## 事件概述

据新智元报道，多名开发者观察到 Anthropic 尚未发布的新一代 Opus（内部代号 Opus-Next）正处于灰度测试中：部分原本调用 Opus 5 的请求被“隐式路由”重定向至该模型，测试通道曾在一夜之间被全部下线，又在一天内恢复，且范围从 Claude Code 扩大到了 Claude Chat、Cowork 与 Code。社区普遍将其解读为 Opus 5.2 发布前的最后测试，但 Anthropic 官方未作任何确认。

## 已确认事实与证据

- 灰度现象：独立游戏开发者 Leo 称其灰度测试账号在无预警的情况下被“拔线”、活跃测试账号瞬间归零，数小时后恢复；恢复后其反馈新模型在 Roblox Studio 等 3D 环境任务中表现显著提升。
- 路由机制（社区抓包分析）：报道称 Anthropic 在 API 路由网关层以极低概率将部分 Opus 5 请求静默重定向到 Opus-Next，前端显示的模型名称不变；此类“盲测”可获取真实开发者提示下的高质量测试数据。该机制描述来自第三方分析，未经官方证实。
- 识别方法：社区流传通过询问“重启哥 Tibo”（Thibault Sottiaux）等训练截止日期之后的事实来判别是否命中灰度，命中者能答出、未命中者则不知情。
- 边界说明：以上全部为社区观察与媒体报道，Anthropic 未官宣 Opus 5.2 的存在、时间或能力。

## 影响与后续观察

如果灰度属实，这显示头部实验室正在用生产流量做发布前的“野生”压力测试，其数据价值与用户知情权之间的平衡值得讨论；对开发者而言，模型能力的“间歇性跃升”也会影响对线上稳定性的预期。后续值得观察：Anthropic 是否以及何时正式发布新一代 Opus、灰度范围是否继续扩大、以及发布时与现有 Opus 5 的定价和能力差异；在官方披露前，所有能力对比均属传闻。
