## 事件概述

据量子位报道（量子位注明本文由 APUS 提供并获授权转载），9 月 19 日 APUS 旗下 AI 实验室公布了全球最早一批针对 Jev 的独立开源复现成果，并将其封装为开箱即用的 Agent Skill “fast-browser-use”，支持纯本地模型离线执行，全部代码以 MIT 协议开源，覆盖 macOS、Linux 与 Windows 三大平台。

## 已确认事实与证据

- 项目定位：Jev 是一种面向智能体高频“快判断”需求（分类、选择、评分、真伪判断）的轻量决策模型路线，直接返回类型化答案与置信概率而非逐字生成文本；其名称取自经济学家杰文斯，暗合“智能成本暴跌带来用量暴涨”的杰文斯悖论。此前 Jev 的性能数据均来自 TypeSafe 官方自测。
- 复现内容：APUS 称其基于 Jev 公开文档分析了“跳过自回归解码、隐状态直接打分”的核心逻辑，在开源项目中复现了单 Token Logits 快速决策、KV-Cache 广播与并发批量评估机制；在浏览器自动化场景中，由本地运行的 Qwen3.5-9B 通过单次前向计算完成“点哪里、选哪个”的决策。
- 自述性能：APUS 公布的实测数据显示，在 Apple M2 Pro 笔记本上全程离线完成真实维基百科检索任务的中位耗时约 18 秒，表单填报、站内导航约 3 秒，单任务模型打分次数仅 4 次，零云端调用、零 API 费用。上述数字为 APUS 单方公布。
- 生态：fast-browser-use 已封装为标准 Agent Skill，可通过一行命令接入 Claude Code、Codex、OpenCode 等编程智能体；APUS 表示后续将围绕桌面 GUI 操作等场景继续开源新 Skill。

## 影响与后续观察

这是国内团队对“大模型慢思考 + 轻量决策模型快判断”这一 Agent 分工范式的首批独立开源验证之一，其意义在于证明开源权重加端侧算力也能支撑该路线，并让数据全程留在本机，契合政企与金融场景的合规需求。后续值得观察：第三方对 fast-browser-use 的独立基准复现、决策模型与主流 Harness 的集成深度，以及 Jev 原厂 TypeSafe 对复现结果的回应；在独立评测出现前，18 秒中位耗时等数据应视为厂商自述。
