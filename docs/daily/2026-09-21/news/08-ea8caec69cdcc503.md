## 事件概述

据新智元报道，网友发现 Anthropic 的 Fable 5.2 已开启灰度测试：部分原本调用 Fable 5.1 的请求在后台被悄悄路由到新版本，社区实测案例迅速增多。报道还汇总称，多家头部实验室本周都在进行未官宣的模型灰测与竞技场测试，形成“没有正式发布、却到处是泄露”的一周。

## 已确认事实与证据

- 实测案例（均为社区自述）：博主 notjazii 在高推理模式下用相同提示词对比后称 Fable 5.2 输出“明显优于 GPT-6 Astra”，但代价是更慢、更贵；Bhavani_00007 的“火箭测试”（涉及复杂物理与工程系统设计）称其表现逼真稳定；chetaslua 将 Fable 5.2、Opus-Next 与 GPT-6 Astra 调至最高设置对比，认为前两者细节更丰富；Mr_Salio 称相比 Fable 5.1 是巨大提升。
- 命名与信号：多位网友称此次更新跨度之大使 Anthropic 跳过了“5.1”命名；TokenGremlin 称开始收到关于 Opus 5.2 的资料，称其为 Opus 的大幅改进版本。官方模型选择器中 Opus 与 Fable 位置的微妙调整也被社区捕捉到。
- 灰度识别：与 Opus 线相同，社区用“重启哥 Tibo”问题判别是否命中新版本。
- 本周灰测汇总（报道引述的社区信息）：Fable 5.1 路由至 Fable 5.2、Opus 5 路由至 Opus 5.2（Next）、GPT-5.6 Sol 被重定向至满血 GPT-6 Sol、Grok 4.7 以马甲现身竞技场、Gemini 4 Pro 家族以别名出现。以上均未经各官方确认。

## 影响与后续观察

Fable 线与 Opus 线同时灰测表明 Anthropic 可能在为一次跨产品线的大版本更新做准备，而多家厂商同期“隐形测试”也让基准评测的时效性面临挑战——竞技场与榜单上的马甲模型让外部对比愈发依赖泄漏信息。后续值得观察：Anthropic 是否如社区预测在近期正式发布、Fable 5.2 与 Opus 5.2 的定价和速度权衡、以及各实验室对灰度测试透明度的态度；所有性能对比在官方发布前均应视为未证实传闻。
