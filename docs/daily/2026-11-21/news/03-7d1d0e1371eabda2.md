## 事件概述

2026 年 11 月 19 日，在微软 Ignite 大会期间，NVIDIA 在官方博客宣布与微软扩展全栈合作：从 Azure 数据中心运行 NVIDIA Vera Rubin NVL72 系统的虚拟机，到通过 Microsoft Foundry 提供开放模型定制与部署能力，再到边缘设备与 Windows PC 上的本地 AI 运行选项。同时，微软自身也在用 NVIDIA 技术加速自家模型与服务，包括以 NVIDIA Dynamo 支撑后训练阶段的推理、以 NVIDIA RTX PRO 6000 Blackwell GPU 支持 Bing 搜索模型。

## 已确认事实与证据

以下内容均出自 NVIDIA 官方博客（2026 年 11 月 19 日，作者 Dave Salvator）：

- 基础设施：NVIDIA Vera Rubin NVL72 系统已在 Azure 数据中心运行，为推理、智能体应用与大规模训练提供算力，本次进一步扩大 Azure 虚拟机的使用范围；双方还将机密计算扩展到裸金属与机架级 AI 基础设施，并通过 NVIDIA MaxLPS 协作优化数据中心能效。
- 性能佐证：MLPerf Training v6.1 中，Azure 以 10,240 块 NVIDIA GPU（GB200 NVL72 系统）训练 DeepSeek-V3，为本轮最大规模；MLPerf Inference v6.1 中，Azure 的 GB300 NVL72 系统在 DeepSeek-R1 交互式吞吐上领先其他云提交 10% 以上（第三方 Signal65 测定）。
- 模型定制：Microsoft Foundry 的无服务器 Programmed Training 与新增自定义权重部署的 Foundry Managed Compute 上线更多 NVIDIA 开放模型；Nemotron 3.5 家族扩展（Super 面向长时智能体、Lightning 面向快速响应，另有 Embed、Rerank、Parse、Content Safety，Bolt 与 Transcribe 即将推出）。
- 客户案例：EY 使用 Programmed Training 基于 NVIDIA Nemotron 开放模型适配企业采购记录分类，在其评估集上准确率提升 55%，成本较专有前沿模型降低 15 倍。
- 边缘与本地：Foundry Local 对 Nemotron 3.5 的扩展支持将推理、编码与工具调用智能体带入 Azure Local；Azure Local 将支持来自硬件伙伴的 RTX PRO 6000 Blackwell GPU，并扩展到 NVIDIA Jetson Thor 与 Jetson Orin 边缘平台；Cosmos 物理 AI 模型引入 Foundry Local；基于 NVIDIA RTX Spark 的 Windows PC 将在 Ignite 现场演示本地大模型体验。
- 云 PC：面向 GPU 加速的 Windows 365 Cloud PC 推出 Direct Stream 能力，支持最高两路 4K 60 帧低延迟串流；限量预览已开放报名，公开预览计划于 2027 年初。
- 科学计算：NVIDIA BioNeMo Agent Toolkit 与 ALCHEMI Toolkit 进入 Microsoft Discovery 目录；初期集成 RFD4-Proteina 模型（与华盛顿大学蛋白质设计研究所合作）用于生成候选蛋白结构与氨基酸序列。
- 微软自用：Microsoft AI 以 NVIDIA Dynamo 支撑强化学习 rollout 推理（后训练中生成经验数据的关键环节），协调大规模 GPU 集群上的推理、请求管理、模型更新与故障恢复。

## 影响与后续观察

- Vera Rubin NVL72 Azure 虚拟机的正式商用时间、区域与定价未在公告中披露，预览范围的扩大节奏待观察。
- Windows 365 Cloud PC Direct Stream 公开预览要到 2027 年初，限量预览的实际体验与可用区域未知。
- Nemotron 3.5 Bolt 与 Transcribe 仅标注"即将推出"，无具体日期。
- EY 案例为单一客户的自报评估结果（准确率提升与成本下降基于其自有评估集），可推广性需更多客户数据验证。
- 对国内读者而言，本条目价值主要在于全球云厂商"下一代机架级系统 + 开放模型定制 + 本地/边缘部署"的全栈路线图：从 Azure 到 Azure Local、Jetson 边缘平台与 RTX Spark Windows PC 的分层落地，反映了 2027 年前后企业 AI 部署形态的演进方向。
