## 研究问题与贡献

论文题目为「TuringPAI: A Foundation for On-Device Physical AI」（小鹏基金会模型团队技术报告）。一句话结论：TuringPAI 以 0.65B 的共享视觉语言底座 TuringPAI-VL（HybridViT-MLQ + Qwen2.5-0.5B）同时支撑自动驾驶 VLA（TuringPAI-Drive，在单颗 NVIDIA Orin-X 上以 12 Hz 生成轨迹、开放环 ADE/FDE 与全 token 基线差距在 1.2% 以内）与机器人操作 VLA（TuringPAI-Embodied，LIBERO 四套件平均 96.8%），展示了车规级算力约束下「一个视觉语言底座服务多个 Physical AI 任务」的工程路线。

问题背景：Physical AI 的视觉输入是多相机、多时刻的高分辨率观测，冗余大但局部几何与小的时间变化又对下游动作关键；把每帧编码成稠密 patch 序列、再逐帧送入语言模型，会在有限车载算力与严格时延下迅速膨胀。TuringPAI 的答案是架构与数据双管齐下：架构上先用卷积前端做局部聚合、再用带多尺度潜查询的视觉 Transformer 组织全局与历史证据，压住进入语言模型的 token 预算；数据上在通用视觉语言语料之外补充几何、跨视角与时序监督，让模型显式学会距离、位置、尺寸、朝向与运动变化。

## 方法与系统

HybridViT 将动态分辨率输入按 128×128 计算区域划分，卷积前端以总步长 32 产出局部凝聚的 patch token（同分辨率下数量约为 patch-16 ViT 的四分之一），再由 TuringViT 式混合注意力 Transformer 建模全局关系。Multi-scale Latent Queries（MLQ）在同一视觉 Transformer 内加入由当前帧特征初始化的粗到细多尺度查询层级：查询与 patch token 共享统一 3D RoPE（时间坐标用真实采集时间戳），非对称注意力掩码保证 patch 间注意力不变、查询可聚合全部 patch 与更粗查询的特征，且只有更新后的约 0.3N 个查询 token 进入语言模型——因此 4 帧观测窗口共享一份查询层级，视觉 token 数不随帧数增长。训练分两阶段：第一阶段冻结语言模型做视觉 token 对齐，第二阶段全参数联合训练并从更大的 TuringViT VLM 做逐 logit 蒸馏；数据池按通用理解（OCR、图表、知识、STEM 等）、空间感知与推理（像素深度问答、相机条件 3D 定位、跨视角像素对应与相机位姿）与多图/时序理解（多视角问答、道路与操作多帧序列）组织。TuringPAI-Drive 在底座上加轨迹规划头，输入 12 Hz 七相机四帧序列、输出 6 s 72 航点轨迹；TuringPAI-Embodied 加 π0 风格 flow matching 动作专家（双 256×256 视角、80 维标准状态、十步去噪出 6 步动作块）。

## 实验设置与数据

底座评测以同量级的 InternVL3-1B Base 与更大的 Qwen2-VL-2B Base 为主参照，覆盖 grounding/计数、文本富感知、多模态推理、通用 VQA、视频理解五大组；空间评测含 NYU Depth V2 深度（AbsRel）、ETH3D 对应点误差、7-Scenes 相对位姿 AUC@30°、Omni3D 协议下的 3D 框定位 mAP@IoU0.15、BLINK/EmbSpatial 等。训练成本为对齐阶段 1,640 H800 GPU 时 + 联合阶段 9,870 H800 GPU 时。驾驶侧：约 29.8 万小时、3,500 万片段的自有数据集，在 43.6 万帧验证集上报告 2 s/6 s 的横向/纵向 ADE/FDE、航向误差与 miss 率，并在内部仿真 CCES 套件（合规/舒适/效率/安全 + 导航）上以全 token HybridViT 为 1.0 基准对比；部署侧用自研 XNRT 运行时（QAT 友好、混合精度、硬感知优化），在单颗 Orin-X 上测 VLM prefill 时延并做余弦相似度数值保真校验。操作侧：约 500 小时多本体操作数据预训练后用 LIBERO 演示微调，每套件 500 次试验共 2,000 次，与 OpenPI π0.5 发表数字及同芯片分阶段时延对比。

## 结果、限制与结论

论文报告的结果：底座上 TuringPAI-VL 在 ChartQA（76.96 对 InternVL3-1B 62.92）、MathVista mini（54.20 对 36.60）、RefCOCO（80.91）等占优，MMMU 等少数项落后；几何感知优势最明显——NYU Depth AbsRel 0.146（对照 0.38/0.70）、7-Scenes AUC@30° 19.99（最强基线 2.03），并能在四个 3D 定位基准直接产出 20.00-39.55 mAP（参照模型在该协议下无有效分）；视频三项基准全面超 InternVL3-1B。驾驶上 HybridViT-MLQ 的全部 ADE/FDE 与全 token 基线差距在 1.2% 内、横向 ADE/FDE 反而更低，五类驾驶质量比值都在 ±0.9% 内（追尾风险成本降 3.8%，加加速度升 6.1%），碰撞失败率 0.258%→0.263%；XNRT BF16+INT8 把 VLM prefill 压到 69.77 ms，较 TensorRT FP32 提速 4.93 倍、较 FP32+INT8 提速 3.69 倍，支撑 12 Hz 车载出轨迹（模型将随 VLA 2.0 上车 Orin-X 车型）。操作上 LIBERO 平均 96.8%（Spatial 98.4/Object 99.6/Goal 96.0/10 93.2），与 OpenPI π0.5 发表的 96.85% 相当，分阶段时延合计 168.3 ms 对 π0.5 的 422.2 ms。局限：论文为产业技术报告，训练数据、评测套件（CCES）与运行时细节未完全公开，学术可比性受限；时序建模仍限于 4 帧短窗，异步执行带来的感知-执行错位、跨本体大规模学习与闭环世界模型是作者自列的未竟方向；真实道路闭环性能当前材料未确认。对组内的启示：MLQ 式「卷积局部聚合 + 潜查询历史压缩」是端侧 VLM 压 token 的可复用设计，驾驶与操作共享一个底座的工程验证对我们做多任务具身底座有直接参考价值。
