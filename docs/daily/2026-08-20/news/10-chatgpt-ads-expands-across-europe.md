# ChatGPT Ads 扩展到 31 个欧洲市场

## 事件概述

OpenAI 官方公告称，ChatGPT Ads 将扩展至 31 个欧洲市场，包括德国、法国、西班牙、意大利、瑞典、挪威、丹麦、荷兰与奥地利。

## 已确认事实与证据

公告说明，广告只展示给 Free 与 Go 用户，Plus、Pro 和 Enterprise 保持无广告；广告带明确标签、与回答分离，不依赖模型回答影响投放。平台支持 CPM、CPC、转化优化、地理定向、自定义受众、OpenAI Pixel、Conversions API 与第三方度量。自助 Ads Manager 将在夏季晚些时候推出。

## 影响与后续观察

广告收入可能继续补贴免费与低价 ChatGPT，但用户对语境广告、隐私和答案商业边界保持关注。后续应观察欧洲监管反馈、广告质量、误点击与自助平台权限控制。
