"When Do Discrete Actions Make Good Continuous Controllers?"（离散动作何时能成为好的连续控制器？）是卡内基梅隆大学与亚马逊前沿 AI 与机器人部门（Amazon FAR）的联合研究。一句话结论：在从单任务模仿学习到多任务 VLA、从仿真到真实 Franka 机械臂的系统对比中，离散化动作头（哪怕是朴素的均匀分桶）在任务成功率上可以追平甚至超过连续动作头；离散策略的真正瓶颈不是精度，而是"因子化误差"，可用离散流迭代计算或分类器无关引导（CFG）化解。

## 研究问题与贡献

LLM 等前沿模型都以离散 token 预测输出，但今天的机器人基础模型（VLA）几乎都预测连续动作向量，默认连续表示"无损、高精度"。本文正面挑战这一共识：机器人动作是否必须在其他 AI 模态中独树一帜地用连续值预测？作者系统比较了四种动作头参数化：连续回归（CR，单次前向平方误差回归）、连续流（CF，流匹配生成）、离散回归（DR，对分桶动作做交叉熵分类）与离散流（DF，多步离散流匹配）。覆盖从零训练的单任务 RoboMimic 策略、PaliGemma 主干的 VLA 规模训练，到真实机器人实验，评价指标包括闭环成功率、留出集动作预测误差与动作块内时序变化。三项核心发现：离散策略精度不输连续策略；迭代计算与引导能缓解因子化误差；显式几何先验与结构化分词收益有限。

## 方法与系统

动作统一表示为末端执行器（EEF）相对动作块：3 维平移、旋转（VLA 用轴角、RoboMimic 用 6D 表示）与二值夹爪。离散化把每个动作坐标归一化后均匀切成 B=512 个桶，整块动作展平成长度 L=H×M 的 token 序列。CR 的总体最小化目标是条件均值，多模态行为下会"平均"出无效动作；CF 用流匹配学条件速度场、经 N 步欧拉积分生成；DR 单次前向输出 L×B 个 logits、逐位置 softmax 后贪心解码，天然把联合分布因子化成各 token 边缘的乘积；DF 在离散流匹配目标下多步迭代生成，逐步自我修正。VLA 实验用 π 系列同款 PaliGemma 主干，训练混合数据为六个 RoboCasa365 源、LIBERO-plus 与 DROID 共八个来源，动作视界 24 步，每组评估五个种子、取后五个 checkpoint 中最好者。

## 实验设置与数据

单任务从零训练覆盖 RoboMimic 的 Can、Square、Tool Hang、Transport 四任务（后两个代表高精度控制需求）。VLA 仿真评测：RoboCasa 厨房场景分 atomic-seen（180 回合）、composite-seen（160）与 composite-unseen（160）三组，每任务 10 次尝试；LIBERO 评 Object 与长时序 LIBERO-10 两个套件；DROID（76k 轨迹、564 场景）无仿真器，只作离线诊断与训练数据。真机实验在 Franka 机械臂上训练并微调三个任务：把瓶子扔进垃圾桶、打开笔帽、把马克杯翻正，结果以图 1(b) 柱状图报告。诊断指标包括动作块"加加速度比"（jerk ratio，衡量时序变化是否被低估）、状态响应度（观测变化时预测块的变化幅度）与扰动稳定性。

## 结果、限制与结论

论文报告：在所有设定下离散流 DF 与连续流 CF 相当或略优，离散回归 DR 稳定超过连续回归 CR——即使从零训练也成立，推翻了"精度是离散策略根本瓶颈"与"离散头只在 VLA 里有 token 兼容优势"两个流行假设。RoboCasa 上 DR 27.1%、CR 38.8%、CF 52.7%、DF 53.9%；CFG 从 0 加到 2 使 DR 从 27.1% 升到 49.2%，逼近 DF。机制解释是因子化误差：各 token 边缘独立解码会把时间步与维度上互斥的合理模式拼成不兼容动作；DF 的迭代计算把每块不一致模式数降低 5.28 倍（NFE≥10 时平均低于 1），对应 RoboCasa 成功率 +4.7 个百分点；时间自回归（24 步逐个预测）无引导时 42.8%，加引导后反而略逊。第三，把动作几何显式编入腐蚀路径或换用 FSQ/FAST/RVQ 等结构化分词器，最好组合（FSQ+DF 52.4%、度量路径 52.8%）都未超过均匀桶 DF 的 53.9%；相邻桶的最后一层嵌入余弦相似度很高，说明离散头能自己学到局部几何。限制：真机三任务的具体成功率数值仅在图 1(b) 柱状图中给出、正文未逐一列表；诊断实验还显示连续回归的加加速度比明显小于 1（把专家时序变化过度平滑）、对观测变化的状态响应度也低于离散头，而离散流在块前段（小幅运动区间 0–5 毫米）的末端误差最低，这些刻画了离散表示“更能保留细微时序变化”的机制；离散化在极端高精度任务（如亚毫米装配）上的表现原文未报告；结论基于特定主干与数据混合，跨更大数据规模的外推当前材料未确认。对社区的启示是：机器人动作预测未必需要与其他 AI 模态不同的特殊设计，离散动作预测本身就是一个有竞争力的路线。
