## 事件概述

OpenAI 发布新基准 LifeVal，用于衡量 AI 模型在「个性化智能体消费任务」上的表现：不是考做题，而是考「办事」——找托儿服务、处理退税、规划搬家、管理志愿者等真实生活任务。官方同时发布 16 页配套论文，说明任务集来自美国劳工统计局时间使用调查、覆盖 25 国的多国时间使用研究以及一次 3995 人的人口代表性付费意愿调查，最终归入 148 个消费任务类别，合计对应美国消费者每年约 1.7 万亿美元的付费意愿。新智元以《今天，OpenAI发布AGI新标准！价值1.7万亿美元，接管全球80亿人类》为题报道，本篇以 OpenAI 官方页面与论文 PDF 为准成稿，并剥离标题中的夸张成分。

## 已确认事实与证据

以下事实由 OpenAI 官方 LifeVal 页面与论文 PDF（cdn.openai.com/pdf/lifeval.pdf，16 页）直接确认：

- 定位：面向日常个人助理任务的评价基准，官方称已用其跟踪并驱动过去一年模型在生活任务上的表现；OpenAI 使命表述为让通用人工智能造福全人类，每周有超过 10 亿人使用 ChatGPT。
- 任务来源：以美国时间使用调查（ATUS）与多国时间使用研究（MTUS，25 国）为底，新增一次人口代表性的付费意愿调查（3995 名受访者），归并出 148 个最具价值的活动类别；美国年度付费意愿合计约 1.7 万亿美元（论文表 1 口径）。
- 任务形态：任务用真实 ChatGPT 对话与记忆、参考文件和个人上下文做个性化构造；每个任务配有强化学习环境（RLE），模型需在其中完成浏览器操作、填写表单、生成文件等智能体动作；任务创建者需通过专业度门槛核验。
- 评分机制：两个自动评分器均基于 GPT-5.6——主评分器依据评分细则与 RLE 前后端状态差判断任务是否真正完成；防作弊评分器（Hack Grader）将模型访问 RLE 内部 API 等环境作弊直接判负。
- 实测范围：论文构建 169 个任务，评测 GPT-5.2、5.4、5.5、5.6 与 GPT-6 Astra 五代模型；GPT-5.2 是唯一因 token 耗尽导致任务失败的模型，GPT-5.4 之后在电脑/浏览器操作上的训练使成功率持续上升，官方称 GPT-6 Astra 为「迄今对齐最好的模型」，在涉及高隐私上下文与复杂跨网页操作的任务上更稳定；结果附自助法 95% 置信区间。官方页面展示了幼儿园择校（93.1%）、洪水前组织志愿者（98.0%）、找房（100%）等当前模型任务样例表现。

以下为媒体报道口径、与官方材料有出入或未经确认的内容：标题中「接管全球 80 亿人类」为修辞性说法，1.7 万亿美元在论文中是「美国消费者年度付费意愿」的估值而非基准本身「价值」；报道称受访者为「3800 多名」，官方口径为 3995 人；「GPT-6.2 Astra 即将发布」属传闻（当前材料未确认）；奥特曼关于「人们应永远掌控未来」的推文内容经 X 页面反爬无法直接核验，按媒体转述处理（原文未报告于官方材料）。

## 影响与后续观察

- 评测重心从「考场」转向「生活」：LifeVal 把基准从考试题搬到带真实个人上下文的智能体任务，若被广泛采纳，模型迭代将更直接地围绕执行可靠性、记忆检索与跨应用操作展开，而非单轮答题能力。
- 个性化与隐私张力：任务依赖真实对话与记忆数据，论文强调数据经同意与去标识化处理；「数字超级助理」掌握用户财务、医疗、家庭信息后的安全与问责边界，是该基准规模化前必须回答的问题。
- 观察点一：LifeVal 是否对外开放（第三方复现、排行榜），当前论文仅报告 OpenAI 自家五代模型（原文未报告外部模型成绩）。
- 观察点二：自动评分器（GPT-5.6）自身的可靠性校准与人工复核比例，将决定该基准成绩的可信度（论文提及自助置信区间，未公开逐题复核数据）。
- 观察点三：媒体传闻中的下一代模型（GPT-6.2 Astra 等）在 LifeVal 上的表现与发布节奏（当前材料未确认）。
