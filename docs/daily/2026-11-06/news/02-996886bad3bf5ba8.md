## 事件概述

Anthropic 于官方研究栏目发布文章《Progress on provable inference for large language models》，公布其在大模型「可证明推理」（provable inference）方向的进展，并开源代号 FlashProve 的密码学验真系统：模型服务商无需交出权重，即可为每条模型回复附上密码学证明，客户端在普通 CPU 上数秒内即可验证回复确实出自事先承诺的那一模型。系统代码、Lean 4 形式化证明与文档以 Apache 2.0 协议在 GitHub 开源。新智元以《Anthropic亲手终结「套壳AI」！17秒扒下假模型头套，验身速度快5000倍》为题报道了这一发布，本篇以 Anthropic 官方文章与开源仓库为准成稿。

## 已确认事实与证据

以下事实由 Anthropic 官方文章及 GitHub 仓库直接确认：

- 发布主体为 Anthropic，文章署名包括 Roy Rinberg、Alex Allain（Anthropic）与 Alessandro Chiesa（EPFL/StarkWare）、Miranda Christ（MIT）等密码学研究者，发布于 2026 年 11 月初；官方明确称之为「中间进展」而非完整研究议程。
- FlashProve 基于 zkSNARK（零知识简洁非交互式知识论证）技术路线：服务商先对模型权重生成承诺（commitment），之后为每次推理生成证明；证明为零知识，不泄露权重。
- 性能数据（官方口径）：在单张 NVIDIA H100 上对 4000 亿参数的 Llama 4 Maverick（MoE，4-bit 量化后约 232GB）生成证明，速度约每秒 110 个 token（24 请求批处理约 223 秒）；每个 1024 token 请求的证明约 19MB（18.78MB）。
- 离线承诺阶段每模型约 39 分钟，承诺文件约 6.5MB，可覆盖约 1600 万次请求；客户端验证在 24 线程 CPU 上约 17 秒（单线程约 21 秒），无需 GPU 与权重。证明生成开销约为普通 vLLM 推理 GPU 时间的 70 至 95 倍。
- 官方发布五项成果：博客文章、技术报告、Claude 参与撰写的协议规范文档、可执行代码（含 C++ 快速验证器与 Lean 可证明正确验证器）、顶层数学命题的 Lean 证明及可视化审计工具；代码与证明以 Apache 2.0 开源（仓库 anthropics/FlashProve，版本 0.16.0，标注为研究工件）。
- 仓库 README 写明系统「专为 Agent 运行而建」，Lean 4 定理给出可靠性界：冒充者通过验证的概率约为 q/2^124 + 2^-101（q 为哈希查询次数）。
- 官方列举的应用场景包括：监管合规审计（如算力协议下的模型核验）、服务端被篡改或被更强模型顶替的检测、API 供应链「套壳掉包」验证等。

以下为媒体报道口径、官方原文未直接确认的内容：新智元标题所称「验身速度快 5000 倍」的具体比较基准（官方仅称显著快于此前开源系统，并给出与 vLLM 推理本身 70-95 倍开销的对比）；「114 页论文、近 400MB Lean 证明几乎全部出自 Claude」的分工细节（官方确认 Claude 产出了 zkSNARK 改进并撰写协议规范，但未逐项给出比例）；每次推理约 2000 个 sumcheck 子协议、仅依赖 BLAKE2 哈希等底层细节出自媒体转述的技术报告（当前材料未在官方博客原文中逐条确认）。

## 影响与后续观察

- 「套壳」检测有了数学工具：若服务商部署此类承诺与证明机制，用户或审计方无需权重即可核验模型身份，转售路由、偷换缩水模型等灰色操作将更难遁形；但该体系要求服务商主动接入，官方也指出其不证明硬件没有同时用于训练等其他用途。
- 工程开销仍然显著：证明生成约为推理本身 70-95 倍的 GPU 时间，短期内更可能先用于审计抽检、合规场景而非每一次消费级请求。
- 观察点一：FlashProve 是否被推理服务商或监管框架实际采纳，官方目前仅将其定位为研究工件（not maintained，不接受贡献），后续生态反应待观察（当前材料未确认）。
- 观察点二：媒体所述与其他开源系统（如 DeepProve、VerInf 等）的横向倍数对比，需要以官方后续基准数据核实（原文未报告统一基准）。
- 观察点三：Lean 形式化验证与「AI 写证明、机器验证明」的工程范式是否会延伸到更多安全关键系统；Anthropic 称希望社区在此基础上继续改进。
