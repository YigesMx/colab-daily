## 事件概述

清华大学与加州大学伯克利分校团队发布并开源了机器人使用智能体（Robot-Use Agent, RUA）统一框架 uni-robot-agent，配套论文《Democratizing Robot-Use Agents: A Unified Harness with Open Models》（arXiv:2611.01560）。该项目为开放权重模型提供一套模块化、跨环境统一的 harness，让 Qwen 等开源模型能够直接操控机器人：在 RoboDojo 仿真基准上，Qwen3.8-Flash-Next 借助该框架取得 31.39 分，超过 GPT-6 Astra 此前公开榜单成绩 28.97 分，而调用成本仅为其约百分之六到七。知乎专栏「具身智能之心」以《Qwen以1/20成本超过Astra！清华 x 伯克利开源具身Agent Harness》为题解读了这项工作，本篇以项目 GitHub 仓库、Hugging Face 论文页与知乎专栏记录为准成稿。

## 已确认事实与证据

以下事实由项目开源仓库与 Hugging Face 论文页直接确认：

- 项目名称 uni-robot-agent，开源仓库为 GitHub 上的 Open-RUA/uni-robot-agent，MIT 协议，已发布 PyPI 包（v0.1.1），支持 Codex 与 Claude Code 运行时；官方 README 自述为「robot-use agents 的开源 harness」。
- 论文《Democratizing Robot-Use Agents: A Unified Harness with Open Models》编号 arXiv:2611.01560，署名作者包括袁家睿（Jiarui Yuan）、Zuo Yuxin、Huang Xiaoyu 等；知乎专栏提及通讯作者包括丁宁、Pieter Abbeel、刘知远、徐梦迪（出自专栏转述，当前材料未在论文页逐项核对）。
- 官方 README 归纳四条设计原则：统一（跨环境共享工具接口与反馈，环境差异交给适配器）、高效（智能体推理与工具执行重叠并行）、真实（对齐真机可获取的信息：RGB 图像、本体感知、相机标定与机器人描述文件，不给仿真器深度与任务分数）、模块化（运行时、模型、工具、环境均可替换）。

以下实验数据为知乎专栏转述论文内容（专栏全文已留存为源记录，数字口径以论文原文为准，当前材料未逐条比对论文 PDF）：

- RoboDojo 仿真评测（3 个 seed、2 个 layout、252 个任务）：Qwen3.8-Flash-Next + uni-robot-agent 取得 31.39 分，高于 GaP 基线 21.01 分与 GPT-6 Astra + roboprobe 的 28.97 分；DeepSeek-V4.1-Flash 为 27.11 分，GPT-6 Astra 在该 harness 下达 51.90 分，说明框架并非专为 Qwen 优化。专栏称 Qwen 以约 6.6% 的成本跑赢 Astra 公开成绩，单局调用成本约 1 美元出头。
- 真机评测（双臂夹爪平台、19 个任务）：Qwen 在未见过该环境真机数据的情况下取得 53.50 分，高于在该环境微调过的 π0.5（47.75）；Astra 为 80.50。框架还接入了 Franka 机械臂与灵巧手完成抓取等操作。
- 消融分析：移除深度信息后 Qwen 得分从 35.89 降至 31.39、Astra 基本不受影响；连相机内外参也移除后 Qwen 降至 9.13；关闭技能库后得分保留 96.6%。

需要指出的口径差异：知乎标题称「Qwen以1/20成本超过Astra」，而专栏正文自述为「约 6.6% 的成本」（约 1/15），且「超过」仅指与 Astra 此前公开榜单成绩 28.97 分的比较——在同一 harness 下 Astra 实测 51.90 分仍显著更高。标题的「1/20 成本」与「全面超过」表述当前材料未确认。

## 影响与后续观察

- 开源模型「用得起机器人」：开放权重模型配合统一 harness，使机器人团队可以用约 1 美元级单局成本开展持续实验，并把交互轨迹用于继续训练，缓解闭源 API「不能微调、费用随规模增长」的两难。
- harness 成为具身智能新的竞争层：框架质量（工具接口、反馈、并行调度）直接决定模型表现，uni-robot-agent 的「跨环境统一」设计若被社区采纳，可能成为具身 Agent 的基础底座之一。
- 观察点一：RoboDojo 榜单与真机评测数字的论文原文核对（当前材料未逐条比对 arXiv:2611.01560 PDF）。
- 观察点二：开源模型在去除相机标定信息后的空间推理短板（9.13 分）如何通过训练补齐——专栏称失败集中在视觉理解、空间定位、几何计算与具身推理四类。
- 观察点三：该 harness 与其他具身框架（roboprobe、GaP 等）的标准化对比，以及是否出现基于该底座的后续训练工作。
